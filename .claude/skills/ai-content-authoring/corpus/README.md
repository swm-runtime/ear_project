# corpus — 실제 한국어 대본 표본

`check.py measure`가 읽어서 [`../reference/style-profile.json`](../reference/style-profile.json)을 만드는 자리다.

## 왜 있는가

[`../reference/writing-rules.md`](../reference/writing-rules.md)에 "자연스럽게 쓰라"고 적어두는 것만으로는 문체가 재현되지 않는다. 실측하면 생성 대본이 어디로 새는지가 숫자로 드러난다.

첫 측정(2026-08-14, 대담록 1편 대 생성 대본 1편):

| | 실제 대담록 | 생성 대본 |
|---|---|---|
| 합니다체 비율 | 4.8% | **30.1%** |
| 완충어(만자당) | 107.7 | **8.1** |
| 턴 중앙값 | 23자 | 42.5자 |
| 짧은 턴 비율 | 38.9% | 12.0% |

생성 대본은 `뭐` · `약간` · `그니까` · `되게` · `막` · `그냥`을 **한 번도 쓰지 않았다.** 사람이 읽으면 바로 어색한데 규칙 문서로는 안 잡히던 지점이다.

## 원본은 커밋하지 않는다

전사본·방송 대본은 **남의 저작물이다.** [`.gitignore`](.gitignore)가 막고 있다. 커밋되는 것은 여기서 뽑은 수치(`style-profile.json`)뿐이며, `check.py`가 실제로 쓰는 것도 그쪽이다.

원본은 각자 로컬에 두고, 새로 받으면 프로파일을 다시 뽑는다.

```bash
python3 scripts/check.py measure corpus/*.md
```

## 무엇을 넣는가

**한국인이 실제로 말한 것의 전사본.** 사람이 쓴 대본이라도 낭독을 전제로 쓰인 원고는 이미 문어체라 목표로 삼을 수 없다.

- ✅ 팟캐스트·라디오·유튜브 대담의 전사본
- ✅ 인터뷰 녹취
- ❌ 뉴스 원고, 다큐 내레이션 — 발표 문체다
- ❌ 번역물 — 번역투를 목표로 삼게 된다
- ❌ AI가 만든 대본 — 자기 참조가 된다

형식은 `이음: 대사` 또는 `**이름**` + 다음 줄, 둘 다 읽는다.

## 몇 편이 필요한가

**3편 미만이면 잠정값이다.** `check.py`가 그렇게 표시한다.

1편으로는 `좀`이 만자당 107.7인 게 **한국어 구어의 성질인지, 그 화자의 말버릇인지, 그 프로그램 편집 방침인지 가릴 수 없다.** 여러 편이 있어야 공통점만 남는다.

되도록 **장르를 맞춘다.** 현재 표본은 책 홍보 인터뷰 대담이고 우리가 만드는 것은 지식 전달 2인 대화다. 완전히 같지는 않다.

## corpus를 목표로 삼지 않는 항목

corpus는 **실제 대화**이고 우리 산출물은 **TTS 낭독 대본**이다. 매체가 달라서 그대로 베끼면 안 되는 것이 있다.

| 항목 | 판정 | 이유 |
|---|---|---|
| 종결어미 · 완충어 | **corpus를 따른다** | 어색함의 주된 원인이다 |
| 문장 길이 · 시점 표현 · 낭독 규격 | **corpus를 따르지 않는다** | 실제 대화는 100자 넘는 문장을 마구 쓴다(측정 34건). 즉흥 발화라 가능한 것이고, 낭독으로 옮기면 청자가 놓친다 |

`check.py`가 이 둘을 **실패(규칙 위반)** 와 **경고(프로파일 이탈)** 로 나눠 찍는 이유다.
