# [문서] `content_stats`의 `all`을 원천 재집계에서 `month` 행 합산으로 — `domain.md` 5.4·12.1

| 항목 | 값 |
|---|---|
| 대상 문서 | `backend/domain.md` 5.4(`content_stats` 산출 방식) · 12.1(`user_signals` 보존 근거) |
| 요청 파트 | 문서(구현은 백엔드 `fix(be)/content-stats-all-from-months`, KAN-57) |
| 발행 날짜 | 2026-09-22 |
| 반영 날짜 | 2026-09-22 |
| 발견 시점 | 백엔드 전체 검증(2026-09-15, KAN-57) — 보존 배치와 `all` 재집계의 결합으로 181일째부터 완청률이 왜곡된다는 판정 |
| 심각도 | 중(잠복형) — 오늘 기준 증상 없음. 가장 오래된 신호가 180일을 넘기는 날부터 매일 조금씩 어긋난다 |

## 바꾸는 규칙

종전 5.4 는 세 구간을 구분하지 않고 **"원천에서 구간을 다시 세어 통째로 덮어쓴다"**(재집계 upsert)로만 서술했다. 그 규칙이 `all`에도 그대로 적용되면서 문제가 생겼다.

원천의 보존 기간이 서로 다르다.

| `all` 행의 컬럼 | 원천 | 보존 |
|---|---|---|
| `play_count` · `total_listen_sec` | `play_records` | 무기한 |
| `complete_count` · `replay_count` · `save_count` | `user_signals` | **180일** |
| `source_link_click_count` | `source_link_clicks` | **180일** |

서비스 181일째부터 `all`은 "전체 기간"이 아니라 **분모는 전 기간, 분자는 최근 180일**인 비율이 된다. 12.1이 180일을 둔 근거("지나간 구간을 다시 셀 때")는 유한 구간(week·month)만 염두에 둔 것이고, **끝나지 않는 `all`에는 성립하지 않는다.**

개정: **`week`·`month`는 종전대로 원천에서, `all`만 `month` 행의 합으로 만든다.**

- `month` 행은 그 달이 끝날 때 `is_final = true`로 잠겨 원천이 지워져도 값이 남는다 — 월별 행이 원천 대신 기억을 맡는다.
- **재생 계열도 함께 합산한다.** 재생만 원천에서 가져오면 분자와 분모의 출처가 갈려, 배치가 한 달 넘게 멈춰 그 달 행이 비었을 때 같은 왜곡이 다시 난다. 둘 다 월별 합이면 그 달이 통째로 빠져 값은 줄지만 비율은 유지된다.
- **호출 순서**는 `month`(진행 중) 재집계 뒤 `all` 합산이다.
- **빠진 달 감지** 경고를 둔다. 배치가 한 달 넘게 멈추면 그 달 행이 영영 생기지 않아 영구 오차가 된다(재집계가 직전·진행 중 두 달만 다룬다). 종전에는 매일 원천에서 다시 세어 저절로 메워지던 것이다.

12.1 의 `user_signals` 행에는 **"`all` 구간은 이 보존과 무관하다"**를 덧붙인다 — 보존 기간을 늘리는 것이 해법이 아님을 다음 사람이 알 수 있게.

## 함께 확인한 것 (2026-09-22 운영 DB)

백필이 필요한지 확인했고 **필요 없었다.**

```
원천 데이터   2026-09-04 ~ 2026-09-21
month 행      2026-09-01 (진행 중) 하나뿐
```

데이터가 9월 4일에 시작해 아직 9월이다. 달이 하나뿐이라 **빠진 과거 달이 존재하지 않는다.** 첫 삭제는 2027년 3월 초이므로 시한도 없다. 티켓이 우려한 "집계 도입 전 달의 `month` 행 없음"은 이 서비스에서는 발생하지 않았다.

## 완료 조건

- Given `domain.md` 5.4 / When `all` 산출 방식을 읽는다 / Then `month` 행 합산이라는 것과 그 이유(보존 기간 불일치)가 적혀 있다
- Given `domain.md` 5.4 / When 읽는다 / Then 재생 계열도 함께 합산하는 이유, 호출 순서, 빠진 달 감지가 적혀 있다
- Given `domain.md` 12.1 의 `user_signals` 행 / When 읽는다 / Then `all` 구간이 이 보존과 무관하다고 적혀 있다
