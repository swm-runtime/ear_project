## 왜 기록하는가

와이어프레임 검토(2026-08-09)에서 3장 사용자 조작 목록의 개정 대상 둘이 확인됐다.

**① 더보기의 "공유" 제거 — 기존 합의와의 정합.** 3장은 더보기를 "공유·원문 보기·라이브러리에서
삭제"로 나열하는데, 공유(FR-27)는 **합의(2026-08-06)로 MVP 제외가 확정**돼 라이브러리(L4)·
탐색(E12) 더보기에 노출하지 않는다(`explore.md` 4.6). 플레이어만 공유를 갖는 것은 이 합의와
어긋나므로 더보기 구성을 세 화면과 통일한다. P1에서 공유가 활성화될 때의 형태는 탐색이 이미
정의해뒀다(`explore.md` 4.6 — OS 공유 시트, 텍스트 = 제목 + 저자·출처 + 스토어 링크) —
플레이어도 같은 정의를 따른다.

**② 아래로 스와이프 축소 추가.** 전체 화면 플레이어를 접는 조작이 셰브론 탭·뒤로가기뿐이었다.
풀스크린 오디오 플레이어의 표준 제스처인 **화면 아래로 스와이프**를 같은 동작(재생 유지 ·
미니플레이어로 접힘)으로 추가한다. 미니플레이어의 "스와이프로 종료"(5장)와는 방향·대상이 다른
별개 조작이다(그쪽의 존치 여부는 별도 검토 — `wireframe/player.html` 검증 V7).

## 기록할 내용 (반영 완료 2026-08-09)

`player.md` 3장 사용자 조작을 다음으로 교체한다.

- 더보기: "더보기(공유·원문 보기·라이브러리에서 삭제)" → **"더보기(원문 보기·라이브러리에서
  삭제 — 공유는 FR-27 P1 활성화 시 `explore.md` 4.6 정의를 따라 추가)"**
- 조작 목록에 **"플레이어 축소(셰브론 탭 · 뒤로가기 · 아래로 스와이프 — 재생 유지, 미니플레이어로
  전환)"** 를 추가한다
