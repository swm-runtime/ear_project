## 수정 내용

라이브러리·탐색 검색 줄 오른쪽의 잔여 재생 표시를 **헤드폰 아이콘 + `N/M` 칩**에서 **링 + 숫자**로 바꿨다.

- 지름 28의 링. **가운데 숫자 = 남은 횟수 `N`**, **둘레의 원호 = `N/M` 비율**(12시에서 시계 방향으로 채움). 채운 원호는 본문 글자색, 빈 트랙은 경계색.
- 소진(`N = 0`)이면 원호가 비고 트랙·숫자가 주의색이다. 탭하면 종전대로 페이월(구독 UI 꺼진 빌드에서는 한도 안내 토스트)을 연다. 히트 영역 44pt 유지.
- 낭독기 라벨은 그대로 `"오늘 재생 M회 중 N회 남음"` / 소진 `"오늘 재생 0회 남음"`.
- 한도 크기와 무관하다 — 점 게이지의 "한도 > 5면 문자열 폴백"은 없앴다.

## 사유

PM 지적(2026-09-18): 검색 줄 옆의 아이콘 + 숫자 칩이 낱개 부품처럼 튀어 보인다. 처음엔 4안(점 게이지 · 링 + 숫자 · 글자만 · 목록 위 한 줄) 중 점 게이지를 골랐으나, **2026-09-22 PM 이 링 + 숫자로 바꿨다**: "점보다 가운데 남은 횟수를 적고 그 옆에 원 둘레로 몇 분의 몇 남았는지 보여주자". 숫자는 정확한 값을, 원호는 "얼마나 남았나"를 한눈에 주고, 점처럼 한도가 커지면 못 세는 문제가 없다.

## 문서에 반영할 것

- paywall.md 5장 "문구는 한 문자열만 쓴다(`오늘 재생 N/M 남음`)" → 시각 표현은 링 + 숫자, 문자열은 낭독기 라벨에만 쓴다. `M` 하드코딩 금지는 그대로.
- library-uiux.md 4.3 · explore-uiux.md 4.2의 잔여 표시 설명·상태(소진 주의색, 탭 → 페이월)를 링 + 숫자 기준으로 갱신.

## 완료 조건

- Given 한도 2 · 남은 1, When 라이브러리·탐색 화면을 열면, Then 검색 줄 오른쪽에 반만 채운 링 가운데 `1`이 보이고 낭독기는 "오늘 재생 2회 중 1회 남음"을 읽는다.
- Given 한도 2 · 남은 0, When 같은 화면을 열면, Then 주의색 빈 링 가운데 주의색 `0`이 보이고 탭하면 페이월(또는 한도 토스트)이 열린다.
- Given 한도 10 · 남은 7, When 같은 화면을 열면, Then 7할 채운 링 가운데 `7`이 보인다(문자열 폴백 없음).
