## 왜 필요한가

탐색은 담김·청취 여부와 무관하게 **모든 콘텐츠를 노출**한다(explore.md 4.1 — 담김 여부는
노출에 영향을 주지 않는다). 그래서 이미 완청한 콘텐츠도 피드·필터 목록에 그대로 나오는데,
현행 문서의 행 구성(썸네일·제목·출처·저자·길이·담김 배지)에는 **완청 단서가 없다.**
라이브러리 카드는 완청을 썸네일 좌상단 체크로 표시하므로(library.md 4.1-1, FE 개편
2026-08-07), 같은 콘텐츠가 화면에 따라 완청 표시가 있다 없다 하면 행 문법이 어긋난다.

## 추가할 규칙 (구현 반영 완료)

- 탐색 행의 썸네일에 **라이브러리 카드와 동일한 완청 체크 마킹**(좌상단 체크)을 적용한다.
  판정 근거는 피드 응답 `library.status == 'completed'`다 — 클라이언트가 별도 조회하지 않는다.
- 접근성: 체크는 색이 아니라 형태 단서이며, 행 낭독에 **"완청한 콘텐츠"**를 포함한다
  (library-uiux.md 7장과 동일 문구).
- 담김 배지와 독립이다 — 완청이면 담김 배지 + 체크가 함께 보인다(완청은 담긴 상태의 부분집합).

## 완료 조건

- Given 이 요청이 통합 과정에서 반영된다 / When `explore.md` 4.1과 `explore-uiux.md` 4.1·7장을
  읽는다 / Then 행 구성에 완청 체크 마킹(판정 근거 `library.status` 포함)과 접근성 문구가
  서술되어 있다
- Given 완청한 콘텐츠가 탐색 피드에 있다 / When 행을 본다 / Then 썸네일 좌상단에 라이브러리
  카드와 같은 체크가 보이고, 스크린리더가 "완청한 콘텐츠"를 읽는다
