# [문서] 출처·저자는 콘텐츠 상세에서만 보인다

| 항목 | 값 |
|---|---|
| 대상 문서 | `spec/uiux/explore-uiux.md` 96행(행 구성) · `library-uiux.md`(아이템 카드) · `onboarding-uiux.md`(담기 카드) · `player-uiux.md`(재생 화면 메타) |
| 요청 파트 | 문서(FE 구현은 `feat(fe)/source-only-on-detail`에서 선반영) |
| 발행 날짜 | 2026-09-15 |
| 발견 시점 | 사용자 요청 — 목록마다 "참고한 자료: A, B, C…"가 길게 붙어 화면이 지저분하다 |
| 심각도 | **중** — 표시 변경이지만 **고지 요건(FR-12 · PRD 228)에 닿는다.** 아래 근거 참조 |

## 현재 규칙

`explore-uiux.md` 96행이 행 구성을 못박는다.

> **행(row)**: 썸네일 · 제목 · **출처·저자** · 길이 · 더보기 버튼 — 라이브러리 아이템 행과 같은 문법이다.

라이브러리 카드·온보딩 담기 카드·플레이어도 같은 문법을 쓰기로 했다(2026-09-02).

## 수정 내용

**출처·저자를 콘텐츠 상세에서만 노출한다.** 목록·카드·시트·플레이어에서 뺀다.

| 화면 | 종전 | 변경 |
|---|---|---|
| 탐색 행·인기 카드·타일·더보기 시트 | 출처 · 저자 | **제거** |
| 라이브러리 카드·더보기 시트 | 출처 · 저자 | **제거** |
| 온보딩 담기 카드 | 출처 · 저자 | **제거** |
| 플레이어·더보기 시트 | 출처 · 저자 | **제거** |
| 콘텐츠 상세 | 출처 영역 | **유지** |

- 길이 줄은 그대로 둔다. 탐색 타일은 `출처 · 길이`였으므로 **길이만** 남는다
- **[원문 보기] 칩은 플레이어에 그대로 둔다** — 고지가 아니라 원문 연결 수단이다(FR-12 후단)
- 접근성 라벨에서도 뺀다 — 화면에 없는 값을 낭독하면 화면과 어긋난다
- 라이브러리 **검색은 출처를 계속 포함한다**(FR-22) — 표시와 검색 대상은 별개다

## 고지 요건 검토 — 이 절을 지우지 말 것

이 변경은 두 규정에 닿는다. **결정 시 검토한 내용을 남긴다.**

- **FR-12**(PRD 177): *"모든 오디오는 **적합한 형태로** 원저자·출처를 고지하고 필요에 따라 원문 연결 정보를 제공한다."*
- **PRD 228**: *"저작권·파트너 계약 준수 — 협의된 범위·기간 내 제공, **출처·저자 고지 필수**…"*

**FR-12는 표시 위치를 특정하지 않는다**("적합한 형태로"). 변경 후에도 고지는 두 곳에 남는다.

1. **오디오 멘트** — 콘텐츠 자체가 출처를 말한다(`content-pipeline.md` 4.3의 AI 생성 고지 멘트)
2. **콘텐츠 상세 화면** — 파트너는 저자·제공·[원문 보기], AI 생성은 참고 소스 전수 나열(`content-detail.md` 4.3)

`source_name`은 파트너 콘텐츠에서 **고지 문구를 겸한다**(`domain.md` 538 — 발행 시점 값을 고정해 파트너명이 바뀌어도 변하지 않는다). 그 값과 표시 규칙은 그대로이며, **노출 지점만 상세로 좁힌 것**이다.

> **파트너 계약에 "모든 노출면에 출처를 표기한다"는 조항이 있으면 이 결정을 되돌려야 한다.**
> 계약서를 확인하지 않고 내린 판단이다(결정 2026-09-15, 사용자). 계약 검토 시 이 절을 함께 본다.

## 함께 반영 — 인기 카드 크기

`ExploreFeaturedCard`의 폭을 화면의 78% → **72%**(상한 340 → 312)로 줄인다. 카드가 화면을
덜 차지하면서, "다음 카드가 옆에 걸쳐 보여야 한다"는 원래 의도는 오히려 강해진다.

## 완료 조건

- Given 탐색·라이브러리·온보딩·플레이어 / When 콘텐츠 카드를 본다 / Then 출처·저자 줄이 없다
- Given 콘텐츠 상세 / When 출처 영역을 본다 / Then 종전과 같이 파트너·AI 생성 구성이 보인다
- Given 플레이어 / When `source_url`이 있는 콘텐츠를 본다 / Then [원문 보기] 칩은 그대로 있다
- Given 낭독기 / When 콘텐츠 카드에 초점을 둔다 / Then 출처를 읽지 않는다
- Given 라이브러리 검색 / When 출처명을 입력한다 / Then 그 콘텐츠가 검색된다

## 처리 기록 (반영 날짜: 2026-09-15)

`explore-uiux.md` 96행 행 구성, `library-uiux.md` 아이템 카드·L4 시트, `player-uiux.md` 구성·상시 노출 규칙·메타·더보기 시트에서 출처·저자를 뺐고, 고지 요건 검토 메모는 이 문서를 가리키게 했다. `onboarding-uiux.md`에는 담기 카드의 출처·저자 언급이 없어 고칠 것이 없었다. 인기 카드 폭(78% → 72%)은 uiux 문서에 수치가 없어 반영 대상이 없다. FE는 PR #345로 dev에 선반영됐다. **파트너 계약의 노출면 조항 확인은 남는다** — 계약 검토 시 위 "고지 요건 검토" 절을 함께 본다.
