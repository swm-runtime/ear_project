# 재생 확인 팝업(L3) — [오늘은 그만 보기]를 제목 줄 오른쪽 위로, [취소]는 테두리 없이

| 대상 문서 | `docs/spec/uiux/library-uiux.md` 4.6(228행 구성 · 238~240행 "[오늘은 그만 보기]" 위치 규칙) |
| 발행자 | FE (PM 결정) |

## 수정 내용

- **[오늘은 그만 보기]** 를 팝업 하단 중앙 밑줄 텍스트에서 **제목 줄 오른쪽 위의 작은 회색 글자(xs, 밑줄 없음)** 로 옮긴다. 히트 영역 44pt 는 hitSlop 으로 채운다.
- **[취소]** 의 테두리를 없애고 연한 면(`theme.color.surface`)으로 그린다. [재생하기]는 검정 그대로.
- 두 버튼과 다른 모달의 버튼 전부에 연속 곡률(`borderCurve: 'continuous'`, iOS).
- 동작·문구·차감 규칙은 그대로다(눌러도 재생·차감, 억제 대상은 이 팝업뿐, 기기 로컬 서비스 날짜 저장).

## 사유

PM(2026-09-22): "오른쪽 상단에 오늘 그만보기 넣고 취소는 border 없애고 모달 버튼들도 애플 곡률로". 종전 규칙("텍스트 버튼이며 [취소]·[재생하기]와 나란히 세우지 않는다 — 하단 중앙에 한 단 낮은 무게")의 **의도(세 번째 버튼으로 읽히지 않게)** 는 유지된다 — 모서리의 작은 글자는 버튼이 아니라 설정으로 읽힌다. 밑줄 텍스트가 버튼 줄 아래 있으면 오히려 셋째 버튼처럼 시선을 끌었다.

## 문서에 반영할 것

- library-uiux.md 228행 구성: "하단 [오늘은 그만 보기] 텍스트 버튼" → "제목 줄 오른쪽 위 [오늘은 그만 보기] 작은 글자".
- 238행: "팝업 하단 중앙에 한 단 낮은 무게로 둔다" → "제목 줄 오른쪽 위에 xs 회색 글자로 둔다(hitSlop 44pt)". 근거 문장은 그대로.
- [취소] 스타일 언급이 있으면 "테두리 없는 연한 면" 으로.

## 완료 조건

- Given 한도 2 · 남은 1 / When 재생을 탭한다 / Then 팝업 제목 "오늘 1회 남았어요" 오른쪽 위에 "오늘은 그만 보기" 작은 글자가 있고, 아래에 [취소](연한 면) · [재생하기](검정) 두 버튼만 있다
- Given 같은 팝업 / When "오늘은 그만 보기" 를 누른다 / Then 팝업이 닫히고 재생되며 차감된다(종전과 같음)
