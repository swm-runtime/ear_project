## 수정 내용

탐색 타일(캐러셀·격자)·인기 대표 카드의 **썸네일 좌상단 완청 체크를 없앤다.** 낭독기 라벨의 "완청" 은 그대로 전한다(`EXPLORE_COPY.row.a11yLabel({ completed })`).

## 사유

PM(2026-09-22): "탐색 타일 완청 체크도 빼자". 같은 날 라이브러리 타일의 체크를 뺐고(`library-completed-full-bar.md` — 사진 위 스티커처럼 떠 보이고 표식이 붐빈다), 탐색도 같은 이유다. 라이브러리는 진행률 바 100% 가 완청을 대신하지만 **탐색에는 진행률 바가 없으므로 시각 표식 없이 둔다** — 탐색은 청취 여부와 무관하게 전부 노출하는 화면이고, "다시 들을 필요가 있는가" 는 라이브러리 탭 필터가 답한다.

## 문서에 반영할 것

- explore.md 68행 규칙 삭제(합의 2026-08-07 → 2026-09-22 폐기), 167행 "완청 체크" 삭제, 217행 상태 표의 완청 행 → "시각 표식 없음(낭독기 라벨만)", 271행 완료 조건 삭제.
- explore-uiux.md 23행 삭제, E3 상태 표에서 "완청 체크" 제거, 96행 행 구성에서 "(완청이면 좌상단 체크)" 제거.

## 완료 조건

- Given 완청한 콘텐츠가 탐색 피드·인기 카드·검색 결과에 있다 / When 타일을 본다 / Then 썸네일에 체크가 없고, 낭독기는 라벨에 "완청" 을 포함해 읽는다.
