## 배경

대분류 [돈, 배움, 일]에서 **배움이 잡동사니 칸**이 됐다 — 데이터·AI(기술)·심리학(마음)·인문·교양(교양)·글쓰기(스킬)가 한 칸에 있고, 서비스 전체가 자기계발이라 모든 콘텐츠가 배움이다. 돈·일은 "무엇에 관한가"(주제 영역) 축이고 배움은 "왜 듣는가"(목적) 축이라 축이 섞여 있었다. 소스 풀 `topic_coverage`에는 이미 체계에 없는 값(역사·자격증·TOPCIT·자격증·부동산·자격증·한국사·자격증·산업안전)이 쓰이고 있었고, FE mock은 또 다른 5 대분류를 쓰고 있었다.

유사 서비스(Blinkist·Headway·네이버 오디오클립·밀리·서점 분류)가 수렴하는 자리를 참고해 **축을 주제 영역 하나로 통일**했다. 자격증은 형식이지만 "시험 합격"이 돈·일과 같은 급의 청취 목적이고 제작 규칙(커리큘럼 우선·시리즈·유효기간)이 달라 별도 대분류로 둔다.

- **중분류는 시험 이름**으로 둔다(과목 이름 아님) — 돈·경제>부동산(시장)과 자격증·시험>공인중개사(시험)처럼 같은 말이 두 곳에 생기지 않게.
- **폐지**: 글쓰기(어디에도 두지 않음), 인문·교양(대분류로 승격 — 중분류 4개로 분해). 파이프라인 `topics`에는 `active=false`로 이력 보존.
- **경계 규칙**: 조직·업무 실행 맥락 = 일, 사상·역사 = 인문·교양, 개인 내면의 원리(인지·감정·행동) = 심리·마음. "집중력의 뇌과학"은 심리·마음, "딥워크 업무 루틴"은 일.
- **제품 주제 = 파이프라인 중분류 1:1** (이름·대분류 동일). 진실 원천은 제품 `topics`(사용자 관심사·content_topics FK가 걸림). 파이프라인 `topics`는 AI 배제·해설 페르소나를 덧붙이는 거울. 대분류 이름·순서는 `apps/web/lib/taxonomy.ts`.
- **노출(`is_visible`)은 사람이 켠다** — 콘텐츠가 있는 중분류만. 체계는 완성형으로 두고 노출은 콘텐츠를 따른다.
- 서비스 관심사 선택은 **중분류 단위 유지**(드립이 주제 단위·상한 3개), 화면은 대분류로 묶어 표시 — 온보딩 O·관심사 관리 IM uiux/wireframe에 그룹 표시 추가(별도 개정, FE 산출물).
- 탐색 필터는 대분류 칩(1층) → 중분류 칩(2층) → 난이도·형식·시리즈·길이 패싯 — PRD "탐색 확장 필터는 중분류 확정 후 구체화" 자리(explore 문서 개정 시).
