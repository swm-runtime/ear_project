## 수정 내용

앱바의 달 아이콘이 "준비 중"으로 비활성이던 것을 **실제 수면 타이머**로 구현했다. 동작은 `player.md` 4.7 · `player-uiux.md` 4.6 PL5 그대로다.

- 시트: 핸들 / "수면 타이머" / **5분 · 10분 · 15분 · 30분 · 이 에피소드 종료 시 · 해제**. 탭 즉시 적용 + 닫힘(배속 시트와 같은 문법). 현재 선택은 굵기 + ✓.
- 분 단위: 1초마다 남은 시간을 갱신하고, 만료되면 **4초 페이드아웃 후 일시정지**한다. 음량은 멈춘 뒤 되돌린다(다음 재생이 작은 소리로 시작하지 않게). 앱은 종료하지 않는다.
- "이 에피소드 종료 시": 셀 시간이 없다. 편이 끝나면 재생은 스스로 멈추므로 타이머만 해제한다 — 연속 재생이 없는 지금은 표시상의 약속이고, 연속 재생이 생기면 "다음 편으로 넘어가지 않는다"가 된다.
- 만료와 완청이 겹치면 완청 우선(7장) — 세션이 끝나면 타이머를 먼저 걷는다. 세션이 사라져도 걷는다.
- 재생을 멈춰 둔 동안에도 시간은 간다(벽시계 기준). 만료 때 이미 멈춰 있으면 아무 일도 하지 않는다.
- 플레이어 화면을 닫아도(미니플레이어) 타이머는 계속 간다 — 상태를 화면이 아니라 서비스·스토어가 가진다.

### 문서와 다른 곳

| 문서 | 구현 | 사유 |
|---|---|---|
| uiux 4.1 "하단 보조 줄의 타이머 칩" | **앱바**의 달 아이콘(더보기 왼쪽) | 2026-09-16 컨트롤 재구성에서 이미 앱바로 옮겼다(`player-controls-redesign.md`) — 재생 조작이 아니라 세션 설정이다 |
| uiux 6장 카피 `"타이머 MM:SS"` | 아이콘 왼쪽에 **`"MM:SS"`** 만(달 아이콘이 "타이머"를 말한다). "이 에피소드 종료 시"는 `"종료 시"` | 앱바 폭 |
| (없음) 켜짐 표시 | 걸려 있으면 **달을 채워 그린다** | 선으로만 그린 달은 켜졌는지 아이콘만으로 알 수 없었다(PM 2026-09-19). 색이 아니라 형태로 구분 |
| uiux 2장·8장 "MVP 빌드에서는 진입 칩을 그리지 않는다" | 노출·동작 | P1 활성화(스크립트와 함께) |

낭독기 라벨은 문서 그대로 `"수면 타이머, 9분 41초 남음"`(7장), 종료 시는 `"수면 타이머, 이 에피소드 종료 시"`.

### 남은 계약 — 마지막 선택 저장(BE)

`user_settings.sleep_timer_last_choice`(`domain.md` 3.5)는 **값 집합이 미정**이고 엔드포인트도 없어(`player-api.md` 2장·9장 "P1 구현 시 추가") 이번에 저장하지 않았다. 시트는 매번 "꺼짐"에서 시작한다.

- 제안 값 집합: `5m` · `10m` · `15m` · `30m` · `end_of_episode` (모두 `varchar(20)` 안). "해제"는 저장하지 않는다(마지막으로 **건** 선택이 의미 있다).
- 쓰임: 시트를 열 때 마지막 선택을 강조하거나, 아이콘 길게 누르기로 "지난번과 같게" 거는 정도. 없어도 기능은 완결이다 — 중요도 Lowest.
- 값 집합을 `player.md` 4.7 에 확정해 적은 뒤 BE 티켓으로 발행한다.

## 문서에 반영할 것

- player.md 4.7: 페이드 시간(4초)·벽시계 기준·"이 에피소드 종료 시"의 현재 의미·세션 종료 시 해제를 적는다. 5장 "타이머 설정됨 — 상단에 남은 시간 표시"는 그대로 맞다.
- player-uiux.md: 4.1 보조 줄 서술에서 타이머 칩을 빼고 앱바로, 6장 카피 `"타이머 MM:SS"` → `"MM:SS"`·`"종료 시"`, 2장·8장의 P1 미노출 문장 개정.

## 완료 조건

- Given 재생 중 / When 달 아이콘 → "10분"을 탭한다 / Then 시트가 닫히고 달이 채워지며 왼쪽에 "09:59"부터 줄어드는 남은 시간이 보인다
- Given 10분 타이머 / When 10분이 지난다 / Then 소리가 서서히 줄어든 뒤 일시정지되고, 달이 비워지며 남은 시간이 사라진다. 앱은 종료되지 않는다. 다시 재생하면 음량은 원래대로다
- Given 타이머가 걸려 있다 / When 시트에서 "해제"를 탭한다 / Then 타이머가 꺼지고 재생은 계속된다
- Given 타이머가 걸려 있다 / When 편이 끝까지 재생된다 / Then 완청 처리가 되고 타이머는 해제된다(페이드·일시정지 없음)
- Given 타이머를 걸고 플레이어를 미니플레이어로 접는다 / When 시간이 지난다 / Then 타이머는 계속 가고 만료 때 멈춘다
- Given 낭독기 / When 달 버튼에 초점이 간다 / Then "수면 타이머, 9분 41초 남음"으로 읽힌다
