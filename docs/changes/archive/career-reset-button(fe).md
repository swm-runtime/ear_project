## 왜 기록하는가

와이어프레임 검토(2026-08-09)에서 **입력값 전체를 한 번에 비우는 [초기화] 버튼**을 추가하기로
결정했다. 세 필드를 각각 비우는 경로(직군 시트의 [선택 안 함], 직무 텍스트 삭제, 연차 재탭)는
있지만 "커리어 정보를 더 제공하지 않겠다"는 의사를 한 조작으로 표현할 수단이 없었다.
빈 값 저장은 4.2가 이미 허용하므로("값을 비워 저장하는 것도 허용한다 — 미입력 상태로
되돌아간다") 새 서버 동작은 없고, 화면 구성만 늘어난다.

## 기록할 내용 (반영 완료 2026-08-09)

1. **4.1 화면 구성**에 [초기화]를 추가한다. 동작 규칙:
   - 탭하면 직군·직무·연차를 전부 비워 미입력 상태로 만든다. **확인 팝업 없이 즉시** —
     저장 전의 로컬 편집 조작이라 재입력으로 복구되고, 저장하지 않고 나가면 서버 값이 그대로다
   - 비운 상태는 **변경 있음으로 취급**한다 → [저장] 활성, 저장하면 4.2의 빈 값 저장 규칙을 따른다
   - **비울 것이 없으면(현재 값·편집 모두 빈 상태) 비활성**
   - 위치는 [저장](하단 dock)과 오탭 거리를 둔 앱바 우측 텍스트 버튼
2. **5장 화면 상태 표**에 행을 추가한다 — "초기화 탭 | 전 필드 비움 + [저장] 활성(변경 있음) /
   미입력 상태에서는 [초기화] 비활성"

## 완료 조건

- Given 이 요청이 통합 과정에서 반영된다 / When `career.md` 4.1·5장을 읽는다 / Then [초기화]의
  구성 위치·동작 규칙(즉시 비움·변경 취급·빈 상태 비활성)이 기재되어 있다
- Given 값이 입력된 사용자 / When [초기화] 후 [저장]한다 / Then 확인 팝업 없이 저장되고
  프로필 커리어 카드가 미입력 변형으로 표시된다(기존 4.2·완료 조건과 정합)
