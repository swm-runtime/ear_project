## 결정 내용

1. **직군 선택지 목록의 원천은 서버 제공으로 확정한다** (V1② — 온보딩·커리어 공용 목록,
   클라이언트 상수 금지). 입력 방식은 온보딩과 동일한 형식·선택지를 유지한다. 직무는
   자유 입력(100자 상한)이라 목록이 없다.
2. **저장 성공 토스트를 확정한다** (V2): **"커리어 정보가 저장되었어요"** — 관심사 관리의
   "관심사가 변경되었어요"와 나란한 형태.

## 완료 조건
