## 배경

알림이 말한 것을 탭한 곳에서 바로 확인하게 맞춘다(박준현 2026-10-27). "상위 N%까지 M분" 순위는 프로필의 이번 주 청취·상위 % 카드에서 보이는데, 지금은 라이브러리로 간다.

| 규칙 | 이동 | 이유 |
|---|---|---|
| `weekly_rank_gap` 주간 순위 근접 | **프로필**(`ear://profile`, 바뀜) | 알림이 말한 순위·남은 분을 그 카드에서 확인 |
| `streak_keep` 연속 기록 | 라이브러리(그대로) | "오늘 한 편이면 이어진다" — 바로 들을 편이 있는 곳 |
| `resume_content` 듣던 콘텐츠 | 그 콘텐츠(그대로) | 탭하면 이어서 재생(4.4) |
| `peers_listening` 지금 듣는 사람 | 라이브러리(그대로) | 바로 들을 수 있는 곳 |

## 고칠 내용

1. 3장 `deep_link` 행: 목적지에 **`ear://profile`**(프로필 탭 — 리텐션 주간 순위 근접 알림, 2026-10-27)을 더하고, "모르는 목적지는 라이브러리로 폴백"을 적는다.
2. 4.6 규칙 표 1행 딥링크 칸: 라이브러리 → **프로필**.
