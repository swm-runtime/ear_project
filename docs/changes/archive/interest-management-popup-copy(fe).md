## 결정 내용

1. **해제 확인 팝업은 유지한다** (V6 — 제거안 기각).
2. **문구는 주제명을 명시하지 않는 단일 문구로 확정한다** (V4):
   **"선택이 해제된 주제의 새 콘텐츠가 더 이상 라이브러리에 도착하지 않아요. 이미 받은
   콘텐츠는 그대로 남아 있어요."** 해제 개수(1개·복수)와 무관하게 같고, 팝업은 저장당 1회다.
   (종전 문구 "'OO' 주제를 해제하면 …"의 주제명 조립 문제가 함께 해소된다)
3. **이탈 확인 팝업 버튼은 [계속 편집]/[나가기] 현행 유지** (V7 — [저장]으로 바꾸는 안 기각).
   "변경 사항 N개" 표기 위치도 현행 유지 (V3).

## 완료 조건

- Given 이 요청이 반영된다 / When `interest-management.md` 4.2를 읽는다 / Then 확정 문구가
  주제명 없는 단일 문구로 서술되어 있고, 저장당 1회 규칙이 함께 있다
- Given 와이어프레임 IM4를 본다 / When 팝업 문구를 확인한다 / Then 확정 문구와 일치한다
