> - **4.6** — 막대 탭 말풍선 규칙(토글 · 주 이동/그래프 밖 빈 영역 탭 시 해제 · 값 표기 형식 · 0인 요일도 "0분")을 하위 불릿으로 추가

> - **9장 미결** — "주간 그래프 막대의 수치 라벨" 항목을 확정으로 닫았다. **상시 표시는 여전히 하지 않는다**는 것도 함께 남겼다

## 왜 기록하는가

현행 4.6은 "막대에 수치 라벨을 상시 표시하지 않는다 — 요일별 값은 스크린리더 라벨로 제공한다"로,
**일반(비보조기기) 사용자가 요일별 청취 시간 값을 확인할 방법이 없다.** 상대 높이만으로는
"화요일에 1시간 들었는지 10분 들었는지"를 알 수 없다.

9장 미결 사항이 이 상황을 예상해두었다 — "주간 그래프 막대의 수치 라벨: 시각 표시 없이
스크린리더 전용으로 정했다(4.6). **사용성 검증에서 값 확인 요구가 나오면 막대 탭 시 툴팁
노출을 재검토한다.**" 개발 중 실사용 확인(2026-08-08)에서 값 확인 요구가 실제로 나와
재검토 조건이 충족됐다.

## 기록할 내용 (통합 시 profile-uiux.md에 반영)

**4.6 "주간 청취 그래프" 항목** — 아래 문장으로 교체:

> **막대 스케일은 표시 중인 주의 최댓값 기준 상대 높이다.** 막대에 수치 라벨을 상시 표시하지
> 않는다 — 좁은 7분할에 숫자를 얹으면 겹친다. 대신 **막대를 탭하면 그 요일의 값을 막대 위
> 말풍선으로 표시한다**(개정 2026-08-08 — 개발 중 사용성 확인으로 9장 재검토 조건 충족).
> 같은 막대를 다시 탭하면 닫히고, 다른 막대를 탭하면 옮겨 가고, **주를 이동하거나 그래프 밖
> 화면(다른 상호작용 요소가 아닌 빈 영역)을 탭하면 해제된다**(추가 2026-08-08 — 말풍선이
> 계속 떠 있다는 사용성 지적).
> 값 표기는 **60분 미만 "N분", 60분 이상 "N시간 N분"(버림)** — 스크린리더 라벨(7장)과 같은
> 형식이다. 0인 요일도 탭하면 "0분"을 표시한다(자리 유지와 같은 태도). 스크린리더 요일별
> 라벨은 그대로 유지한다.

**5장 컴포넌트 표의 막대 그래프 행** — "수치 라벨은 스크린리더 전용" →
"상시 수치 라벨 없음 — 탭 시 해당 요일 값 말풍선(4.6). 스크린리더는 막대 라벨로 값을 읽는다".

**7장 접근성** — 주간 그래프 막대 항목에 덧붙임: 막대는 탭 가능한 요소(버튼)로 노출되지만
라벨이 이미 값을 읽으므로 스크린리더 사용자는 말풍선 없이도 값을 얻는다 — 말풍선 자체는
시각 중복이라 보조기기에 별도 노출하지 않는다.

**9장 미결 사항** — "주간 그래프 막대의 수치 라벨" 항목을 확정으로 닫음:
~~주간 그래프 막대의 수치 라벨~~ → **확정(2026-08-08): 막대 탭 시 말풍선 노출로 개정(4.6).**
상시 표시는 여전히 하지 않는다.

## 구현 관계

- 코드는 이 개정 내용 기준으로 `feat(fe)/profile`의 `WeeklyChart`에 선반영한다(사용자 승인
  2026-08-08). 문서 본문 반영만 통합 시점으로 미룬다.

## 완료 조건

- Given 이 요청이 통합 과정에서 반영된다 / When `profile-uiux.md` 4.6·5장·7장을 읽는다 /
  Then 막대 탭 말풍선 규칙(토글·주 이동 시 해제·값 표기 형식·보조기기 비노출)이 기재되어 있다
- Given 반영 후 / When `profile-uiux.md` 9장을 읽는다 / Then "주간 그래프 막대의 수치 라벨"
  미결 항목이 확정(2026-08-08)으로 닫혀 있다
- Given 프로필 화면의 주간 그래프 / When 막대를 탭한다 / Then 그 요일의 값이 "N분"
  (60분 이상 "N시간 N분", 버림) 말풍선으로 표시되고, 재탭·다른 막대 탭·주 이동에서 각각
  닫힘·이동·해제된다
- Given 말풍선이 떠 있다 / When 그래프 밖 화면의 빈 영역을 탭한다 / Then 말풍선이 사라진다
  (카드·버튼 등 다른 상호작용 요소 탭은 각자의 동작을 그대로 수행한다)
