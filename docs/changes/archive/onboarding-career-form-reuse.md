## 바뀐 것 (코드 반영 완료)

- O4 의 **입력 폼 세 필드가 설정 > 커리어 정보(CR) 화면과 같은 부품**이다(`features/career/components/` `JobCategoryChips` · `JobTitleField` · `YearsSegment`, career 공개 API 로 노출).
  - 직군: 종전 면 알약 칩(선택 primary 채움) → **직군 사진 칩 2열 같은 크기**(높이 56, 고른 칩 검정 막 + 흰 글자, 나머지 흰 막 + 검정 글자). 목록 로딩 스켈레톤도 알약 몇 개 → 같은 크기 상자 네 개.
  - 직무: 종전 `md` 모서리 면 입력칸 → **테두리 없는 면 알약** + 입력 중 면 짙어짐 + 글자가 있으면 오른쪽 지우기(×). 낭독 "직무 지우기".
  - 연차: 종전 면 알약 칩 → **한 줄 세그먼트**(연회색 트랙 위 흰 캡슐이 미끄러짐, 재탭 해제).
  - 필드 라벨은 CR 과 같은 값(sm·600·위 md — 종전 md·위 xl).
- **상단은 그대로** — 가운데 타이틀 툴바(왼쪽 [이전] · 우상단 [건너뛰기]) · `2/2 단계` · 큰 회색 헤드라인 · "나중에 프로필에서 언제든 입력할 수 있어요".
- **하단도 그대로** — 우하단 원형 [>]([다음]은 낭독 라벨).
- 동작·계약은 불변: 전부 선택 입력, [다음] 항상 활성, [건너뛰기]도 저장 요청, 재탭 해제, 100 자 상한, 서버 직군 목록·순서.
- 플레이스홀더("예: 백엔드 엔지니어")·연차 표기는 온보딩 copy 그대로다 — 부품은 모양만 소유하고 문자열은 화면이 넘긴다.
