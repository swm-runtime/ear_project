## 결정 내용

주소 단위 5회 제한 위에 **계정 단위 발송 상한을 얹는다: 최근 1시간 20회 / 최근 24시간 50회**
(주소 무관 합산, 3개 진입 경로 공통). [메일 다시 입력]로 주소를 갈아 끼우는 무제한 발송
악용(제3자 메일 발송기·발신 도메인 평판)을 막는 백스톱이다 — 미결 P0 항목 해소.

- **클라이언트에 노출하지 않는다.** 남은 횟수·전용 잠금 화면·안내 문구 없음 — 정상 사용자는
  주소당 5회·쿨다운 30초에 먼저 걸려 도달할 수 없고, 노출하면 우회 힌트만 준다. 초과 시
  발송 요청은 공통 에러 계약의 일반 오류로 처리된다.
- 판정·집계는 서버 소유(`domain.md` 3.7 발송 이력). **클라이언트 대응 작업 없음** — 화면·
  와이어프레임 변경도 없다.

## 완료 조건

- Given 이 요청이 반영된다 / When `auth.md` 4.5·미결 사항을 읽는다 / Then 계정 단위 상한
  수치와 클라이언트 비노출 원칙이 서술되어 있고 P0 미결이 해소 표시되어 있다
- Given 서버 구현이 반영된다(백엔드) / When 한 계정이 1시간 내 21번째 발송을 요청한다 /
  Then 발송이 거부되고 응답은 일반 오류다(전용 코드·문구 없음)
