## 무엇을 바꾸는가

- 먼저 묻는 시트(L18)를 다시 묻는 간격을 **마지막으로 물은 날 + 5 서비스 날짜 → + 2 서비스 날짜**로 줄인다. 상수 `CONTENT_REVIEW_PROMPT_INTERVAL_DAYS = 2`.
  - 예: 10-28에 물었으면 10-29(다음 날)는 묻지 않고 10-30부터 다시 묻는다. 즉 "어제 물었으면 오늘은 쉬고 내일 라이브러리에 들어올 때 묻는다".
- 나머지 판정(스위치 · 그만 보기 · 최근 14일 완청 · 후기 없는 편 · 추천 별점 우선 · 플레이어 화면이 떠 있으면 대기)은 그대로다.
- `content-review-api.md` 4.3 판정 3의 예시 문장을 "물은 날이 10-28이면 10-30부터 다시 묻는다 — 10-29는 묻지 않는다"로 고친다.
- `features/content-review.md` 결정 표에 "2026-10-30 먼저 묻는 간격 5일 → 2일" 행을 더한다.

## 왜

개발계 실기기 확인(2026-10-30)에서 한 번 묻고 나면 5일간 뜨지 않아 너무 드물다는 판단. 완청률이 약 19%라 물을 편(최근 14일 완청 · 후기 없음) 자체가 적어 간격까지 길면 후기 수집 기회가 거의 없다.

## 완료 조건

- Given 어제(서비스 날짜) 먼저 묻는 시트를 닫았다 / When 오늘 라이브러리에 들어온다 / Then 끝까지 들은 후기 없는 편이 있어도 뜨지 않는다
- Given 그저께 시트를 닫았고 끝까지 들은 후기 없는 편이 있다 / When 오늘 라이브러리에 들어온다 / Then 시트가 뜬다
- Given 위 두 문서 / Then 간격이 2 서비스 날짜로 적혀 있다
