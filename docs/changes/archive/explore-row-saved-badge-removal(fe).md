## 왜 필요한가

라이브러리 카드 개편(2026-08-07)과 같은 방향의 정보량 축소다. 실기기 확인 결과 행의
메타 줄(출처·저자·길이) 옆 "담김" 배지가 시각 소음이 되고, 담김 여부가 행에서 즉시
필요한 정보도 아니다:

- 행 탭은 담김 여부와 무관하게 재생이다(explore.md 4.4) — 배지가 행동을 바꾸지 않는다.
- 담기/제거 판단이 필요한 순간은 더보기 시트를 연 때이고, 시트가 [라이브러리에 담기]/
  [라이브러리에서 제거]로 상태를 이미 말해준다.
- 완청 체크(연관: `explore-row-completed-mark(fe).md`)는 유지한다 — "다시 들을 필요가
  있는가"는 행에서 즉시 필요한 정보다.

## 수정 내용 (구현 반영 완료)

- 행 표시 표(uiux 4.1)에서 `library` 값에 따른 "담김" 배지 행을 제거한다 — 담김 여부는
  행에 표시하지 않고, **더보기 시트의 담기/제거 분기로만 확인**한다.
- 6장 카피의 담김 배지 항목, 7장의 배지 낭독·aria-live 규칙, 8장의 "담김 표시를 색만으로
  구분하는 것" 금지 조항을 함께 정리한다(표시 자체가 없어진다).
- **노출 규칙은 그대로다** — 담긴 콘텐츠를 피드에서 제외·후순위화하지 않는다는 규칙과
  응답의 `library` 필드 계약은 변하지 않는다.

## 완료 조건

- Given 팀이 이 개정을 확인한다 / When `explore.md` 4.1과 `explore-uiux.md` 4.1을 읽는다 /
  Then 행 구성에 담김 배지가 없고, 담김 확인 수단이 더보기 시트임이 서술되어 있다
- Given 라이브러리에 담긴 콘텐츠가 탐색 피드에 있다 / When 행을 본다 / Then 담김 배지 없이
  노출되고, 더보기 시트를 열면 [라이브러리에서 제거]가 보인다
