## 결정 내용

player.md 미결 사항에 "확정 필요"로 남아 있던 값들을 확정한다.

1. **구간 이동 컨트롤은 앞뒤 모두 ±10초로 통일한다** (종전 15초 뒤로 / 30초 앞으로).
   잠금화면 컨트롤도 같다.
2. **배속 옵션은 현행 유지** — 0.8 / 1.0 / 1.2 / 1.5 / 2.0, 기본 1.0.
3. **완청은 `max_reached_sec`이 길이의 90%에 도달하는 순간 즉시 판정한다** — 재생 종료를
   기다리지 않는다. (스킵 신호 제거는 별건 — `player-skip-signal-removal(fe).md`)
