## 배경

2026-09-25 PM "애플이었으면 전체·미청취·완료를 어떻게 해?" — 애플은 **같은 목록을 상태로 거르는 데 세그먼트를 쓰지 않는다**(HIG Segmented controls: 뷰 전환용, 콘텐츠 필터링에는 쓰지 말 것). 팟캐스트·메일·파일은 필터 **메뉴/시트** 하나에 상태를 넣고 버튼 라벨·배지가 현재 값을 보인다. 라이브러리에는 이미 출처·주제 필터 시트(L2)와 필터 원 버튼이 있으므로 상태를 그 시트로 합쳤다. 머리 줄이 검색 캡슐 + 잔여 링 + 필터 원 한 줄로 끝나 떠 있는 유리 문법(design.md 5장)에도 맞는다.

## 바뀐 것 (코드 반영 완료)

1. **세그먼트 컨트롤 줄 폐지.** `LibraryTabs` 삭제. 검색줄 우측 trailing = 잔여 링 + **필터 원 버튼**(`LibraryFilterButton`).
2. **L2 필터 시트 맨 위에 "상태" 섹션** — 전체 · 미청취 · 완료, 단일 선택(라디오), '전체'가 해제 상태. [초기화]는 상태도 전체로. [적용]으로만 반영(종전 규칙 그대로).
3. **검색줄 아래 조건 한 줄**(`LibraryFilterSummary`) — 적용 중인 조건을 "미청취 · 재테크" 처럼 적는다(L7 보조 문구와 같은 배열). 탭하면 시트가 열린다. 조건이 없으면 줄 자체가 없다.
4. **배지 수 = 상태(전체 아니면 1) + 출처(1) + 주제 수.**
5. 온보딩 튜토리얼(O 계열 예시 화면)의 라이브러리 머리 줄도 같은 구성으로.

## 문서에 옮겨 적을 것

- 4.2 제목·본문: "세그먼트 컨트롤(상태) + 필터 아이콘" → "검색줄 우측 잔여 링 + 필터 원 버튼, 그 아래 조건 요약 줄".
- 4.5 L2: 섹션 순서 **상태 → 출처 → 주제**, 상태는 라디오.
- 3장 흐름도: `L1 ─[세그먼트 전환]─>` 분기 삭제, L2 에서 상태도 적용.
- "세그먼트를 전환하면 리스트를 최상단부터" → "필터를 적용하면 리스트를 최상단부터".
- `features/library.md` 4.3 상태 탭 서술을 "상태 필터(시트)"로.

## 완료 조건

- Given `library-uiux.md` / When 4.2·4.5·3장을 읽는다 / Then 세그먼트 컨트롤 언급이 없고 L2 에 상태 라디오가 있다
- Given `features/library.md` 4.3 / When 읽는다 / Then 상태는 시트에서 고른다고 적혀 있다
