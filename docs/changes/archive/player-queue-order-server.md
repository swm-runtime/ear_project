| 요청 파트 | 문서(구현은 백엔드 `feat(be)/queue-order-sync`, 계약은 `spec/api/library-api.md` 4.1·4.8에 선반영) |

| 심각도 | 하 — 계약(`library-api.md`)과 스키마(`domain.md` 6.1)는 반영됐고, 동작 규칙 문장만 빠져 있다 |

## 추가할 규칙

- 재생 목록의 순서는 **계정 단위**로 저장된다. 사용자가 항목을 끌어 옮기면 그 순서가 저장되고, 다른 기기·재설치 후에도 같은 순서다.
- **새로 담긴 항목은 맨 위**(최신순)에 온다. 사용자가 정리해 둔 아래쪽 순서는 새 항목이 들어와도 바뀌지 않는다.
- 삭제·회수된 항목은 순서에서 빠지고, 삭제 실행 취소로 복구하면 원래 자리로 돌아온다.
- 순서 저장이 실패해도 재생·라이브러리에는 영향이 없다(표시 순서일 뿐 판정이 아니다).
- 이 순서는 재생 목록 패널에만 쓴다. 라이브러리 화면의 정렬(최신순)은 그대로다.
- 연속 재생(다음 편 자동 재생)은 여전히 비범위다. 들어오면 "다음 편"은 이 순서로 정한다.

- Given `library.md` 4장 / When 읽는다 / Then 라이브러리 화면 정렬과 재생 목록 순서가 별개라는 문장이 있다
