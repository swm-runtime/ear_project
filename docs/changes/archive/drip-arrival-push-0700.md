## 수정 내용

- **편성은 05:00 그대로, 알림만 07:00 KST**에 보낸다. 05:00 배치는 적립만 하고 알리지 않는다.
- 07:00 에 **그날 배치가 적립한 편(정규 + 탐험)을 DB 에서 다시 읽어** 사용자당 1건으로 보낸다. 범위는 서비스 날짜 시작(05:00)부터 배치 종료까지 — 배치가 재개로 이어졌어도 앞 구간이 빠지지 않는다.
- **07:00 전에 지운 편은 알리지 않는다**(소프트 삭제 제외). 전부 지웠으면 알림이 없다.
- 배치가 07:00 까지 끝나지 않았으면(재시작 뒤 재개 등) 07:00 크론은 건너뛰고, **배치가 끝나는 즉시** 보낸다.
- 하루 1건·토글·권한 판정, 방해금지 없음, `ttl`(다음 05:00 배치까지 — 07:00 발송이면 약 22시간)은 그대로다.
- 첫 드립(온보딩 직후)은 종전처럼 도착 알림을 보내지 않는다. 단 05:00~배치 종료 사이에 온보딩한 사용자의 첫 드립은 07:00 알림에 함께 실린다(드묾).

## 사유

새벽 5시 알림은 잠금화면에 묻혀 출근길 청취로 이어지지 않는다 — 미결 169행("통근 시간대 고정 발송 검토")의 결정이다. 07:00 은 통근 직전이다.

- Given 미결 169행 / When 읽는다 / Then 07:00 으로 확정(2026-10-14)되어 있다
