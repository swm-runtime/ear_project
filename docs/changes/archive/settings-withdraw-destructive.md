## 무엇을 고치는가

현재 문서(4.1):

> **회원 탈퇴는 로그아웃과 나란히 같은 무게로 두지 않는다.** 사용자 메뉴의 최하단에 보조 텍스트 톤으로 둔다 — 파괴적이고 되돌릴 수 없는 조작을 일상 조작과 같은 비중으로 두면 오탭이 사고가 된다. 단 **숨기지는 않는다**(찾을 수 없는 탈퇴는 다크 패턴이다).

이 중 **"보조 텍스트 톤"을 "항목명과 같은 크기의 빨강(`color.danger`)"으로 바꾼다.** 나머지(최하단 배치·숨기지 않음)는 그대로다.

## 사유

- **iOS 문법이 그렇다.** 애플 설정의 "계정 삭제"·"모든 콘텐츠 및 설정 지우기"는 **본문과 같은 크기의 빨강**이다. 작게 회색으로 흐려 두는 것은 애플 어디에도 없다.
- **빨강이 이미 경고다.** 작은 회색은 "덜 중요한 항목"으로 읽혀 오탭을 막지 못하고 오히려 **못 찾게** 만든다. 의미색(빨강)이 "되돌릴 수 없다"를 더 정확히 전한다 — `design.md` §1 은 `color.danger` 를 "실패·파괴"에 쓰라고 한다.
- 오탭 방어는 크기가 아니라 **그 뒤의 확인 절차**가 맡는다 — 탈퇴는 별도 화면 + 확인 체크 + 문구 입력이 걸려 있다(`auth-uiux.md` A 계열).

## 반영 문구(초안)

> **회원 탈퇴는 사용자 메뉴 최하단에 둔다.** 항목명은 다른 항목과 **같은 크기**이고 **색만 `color.danger`** 다(iOS 설정의 "계정 삭제"와 같은 문법) — 파괴적이고 되돌릴 수 없는 조작임을 의미색으로 전한다. 오탭 방어는 탈퇴 화면의 확인 절차가 맡는다. 숨기지 않는다(찾을 수 없는 탈퇴는 다크 패턴이다).

## 완료 조건

- Given `settings-uiux.md` 4.1 / When 읽는다 / Then 탈퇴 항목이 "보조 텍스트 톤"이 아니라 "같은 크기 + `color.danger`"로 적혀 있다
- Given 설정 화면 / When 사용자 메뉴 섹션을 본다 / Then 회원 탈퇴가 로그아웃과 같은 글자 크기이고 빨간색이다
- Given 개발계 진단 행 / When 설정 화면을 본다 / Then 종전 보조 톤(`isSubdued`)이 그대로다 — 이 변경은 탈퇴 항목만이다

## 구현 메모

`SettingsRow` 에 `isDestructive` prop 을 더했다(크기 유지·색만 `danger`). `isSubdued`(작은 회색)는 개발계 진단 행이 계속 쓰므로 남겨 둔다.
