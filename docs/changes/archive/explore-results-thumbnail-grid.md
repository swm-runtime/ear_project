## 수정 내용

탐색의 **세로 행 목록 세 곳을 두 칸 썸네일 격자**로 바꿨다 — 라이브러리 격자(`library-thumbnail-grid.md`)와 같은 모양이다.

- E2 주제 칩 필터 결과, E6 검색 결과, E7 결과 없음의 "인기 콘텐츠".
- 타일은 캐러셀 타일(`ExploreTile`)을 그대로 쓰되 `layout="grid"`로 칸 폭을 채운다: 정사각 아트워크(라운드 lg) + 제목 2줄 + 길이, 완청 체크(좌상단)·더보기 ⋯(우상단)는 아트워크 위.
- 좌우 여백 md(검색 줄과 같은 선), 타일 사이 12, 행 사이 lg. 홀수 마지막 타일은 빈 칸을 채워 전체 폭으로 늘지 않는다.
- 필터 전환 로딩 스켈레톤(E11 변형)도 격자 행으로 바꿨다.
- 행 컴포넌트(`ExploreContentRow`)는 제거했다. 탭 = 곧장 재생 판정, ⋯ = 더보기 시트(담기·제거), 무한 스크롤·당겨서 새로고침·직전 결과 유지 로딩은 그대로.
- E1 섹션형 피드(가로 캐러셀·"지금 인기" 카드)는 바뀌지 않았다.

## 사유

PM 지시(2026-09-18): "검색하거나 필터를 썼을 때도 리스트뷰 말고 썸네일 뷰로". 라이브러리를 격자로 바꾼 뒤 탐색의 결과 목록만 행으로 남아 두 화면의 문법이 갈렸다.

## 완료 조건

- Given 탐색에서 주제 칩을 하나 고른다 / When 결과가 뜬다 / Then 두 칸 격자이고 각 타일은 정사각 아트워크·제목 2줄·길이·⋯를 가진다
- Given 검색어를 제출한다 / When 결과가 뜬다 / Then 같은 격자다. 결과가 없으면 검색어 되비춤·관련 주제 칩 아래 "인기 콘텐츠"가 같은 격자로 뜬다
- Given 결과가 홀수 개 / When 마지막 행을 본다 / Then 타일 하나가 왼쪽 칸에만 있고 전체 폭으로 늘지 않는다
- Given 필터 전환 로딩 0.3초 초과 / When 기다린다 / Then 격자 모양 스켈레톤이 보인다
