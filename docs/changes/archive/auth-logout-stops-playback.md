# [문서] 로그아웃·탈퇴 절차에 "재생 중지"를 명시한다

| 항목 | 값 |
|---|---|
| 대상 문서 | `features/auth.md` 4.2(로그아웃) · 4.3(회원 탈퇴) · `features/player.md`(세션 종료 조건) |
| 요청 파트 | 문서(FE 구현은 `fix(fe)/stop-playback-on-sign-out`에서 선반영) |
| 발행 날짜 | 2026-09-08 |
| 발견 시점 | 회수·재발행 검증 중 사용자가 지적 — 로그아웃해도 오디오가 계속 재생됐다 |
| 심각도 | 중 — 문서에 없어서 구현에도 없었다 |

## 문제

`auth.md` 4.2는 로그아웃 절차를 이렇게 적는다.

> 3. 로컬 토큰·캐시(라이브러리 캐시, **재생 위치**, …) 삭제

"재생 위치 삭제"는 있는데 **"재생 중지"가 없다.** 그래서 구현도 세션만 정리하고
오디오는 그대로 흘렀다 — `SessionService.clearSession()`이 `PlaybackService`를 전혀
건드리지 않는다.

사용자에게는 **로그아웃이 안 된 것으로 읽힌다.** 시작 화면으로 나갔는데 소리는 계속
나고, 잠금화면 컨트롤에도 남는다. 다음 사용자가 로그인하면 앞 사용자의 콘텐츠가
미니플레이어에 남는다.

## 수정 내용

**`auth.md` 4.2** — 3번 항목에 재생 중지를 앞세운다.

> 3. **재생 중이면 즉시 중지하고 세션을 내린다**(미니플레이어·잠금화면 컨트롤 포함)
> 4. 로컬 토큰·캐시(라이브러리 캐시, 재생 위치, (오프라인 저장분 — P1)) 삭제

**`auth.md` 4.3**(탈퇴)과 **세션 만료(401 갱신 실패)** 에도 같은 규칙이 적용됨을 명시한다.
세 경로가 모두 "인증 상태 → 비인증 상태" 전이를 지나므로 규칙은 하나다.

**부수 규칙 두 가지도 함께 적는다.**

- **위치를 저장하지 않고 끊는다.** 이 시점엔 토큰이 이미 지워져 저장이 401을 맞고, 그
  401이 토큰 갱신 실패로 번진다. 위치는 길어야 5초 전(저장 주기)에 서버에 있으므로
  그만큼을 잃는 대신 로그아웃 경로를 조용하게 유지한다.
- **잔여 재생 표시값은 버리고, [오늘은 그만 보기] 억제 날짜는 남긴다.** 전자는 사용자의
  것이고 후자는 기기 단위 값이다(`library.md` 4.3).
- **미니플레이어 스와이프 종료 플래그(PL11)를 푼다.** 앞 사용자가 내린 상태가 다음
  사용자에게 이어지면 재생을 시작해도 미니플레이어가 뜨지 않는다.

## 완료 조건

- Given 재생 중이다 / When 설정에서 로그아웃한다 / Then 오디오가 즉시 멈추고 미니플레이어·잠금화면 컨트롤이 사라진다
- Given 재생 중이다 / When 탈퇴한다 / Then 같다
- Given 재생 중이다 / When 토큰 갱신이 실패해 세션이 끊긴다 / Then 같다
- Given 로그아웃 후 다른 계정으로 로그인한다 / When 라이브러리를 연다 / Then 앞 사용자의 미니플레이어가 남아 있지 않다
- Given `auth.md` 4.2 / When 절차를 읽는다 / Then 재생 중지가 단계로 적혀 있다

## 처리 기록 (반영 날짜: 2026-09-08)

요청 전부 반영. **코드가 문서보다 먼저 있었고**(`fix(fe)/stop-playback-on-sign-out`, PR #226) 이 반영으로 문서가 따라붙었다.

- **`auth.md` 4.2** — 재생 중지를 **3번 단계로** 넣고 기존 3~5번을 4~6번으로 밀었다. 절차 아래에 세 경로(로그아웃·탈퇴·세션 만료)가 **하나의 규칙**임을 적고, 부수 규칙 3가지(위치 미저장 · 잔여 재생 표시값은 버리고 억제 날짜는 유지 · PL11 플래그 해제)를 함께 실었다.
- **`auth.md` 4.3** — 5번 단계에 "재생 중이면 즉시 중지(4.2와 같은 규칙)"를 앞세웠다.
- **`player.md` 7** — 예외 목록에 로그아웃·탈퇴·세션 만료 항을 추가했다. **위치를 저장하지 않는 이유**(토큰이 이미 지워져 401 → 갱신 실패로 번진다)를 여기 적었다. 플레이어 문서를 보는 사람이 "왜 마지막 위치가 안 남지"를 묻게 되는 자리다.

**코드 대조**: `app/bootstrap/index.ts`가 세션 전이(`authenticated` → 그 외)를 구독해 `stopPlaybackForSignOut()`을 부른다. auth가 player를 직접 import하지 않아 의존 표(`architecture.md` 4.4)를 지킨다 — 세 경로가 전부 이 전이를 지나므로 한 곳에서 잡힌다.

완료 조건 1~4는 FE 구현이 이미 충족했고, 5(문서에 단계로 적혀 있다)를 이 반영이 충족한다.
