## 수정 내용

상단 **전체·미청취·완청** 을 밑줄 탭(등폭 3분할 + 하단 구분선)에서 **세그먼트 컨트롤**(흰 캡슐 트랙 + 미끄러지는 선택 알약, 칸 폭 64)로 바꿨다. 오른쪽 주제 필터 아이콘·배지는 그대로. 구분선은 뺐다(캡슐이 스스로 경계). 동작(필터 값·API 파라미터·빈 상태)은 그대로다.

## 사유

PM(2026-09-23): "전체·미청취·완료를 애플에선 어떻게 표현하나" → HIG: 서로 배타적인 2~5개 뷰를 같은 자리에서 바꿀 때는 **세그먼트 컨트롤**(사진 앱 연도·월·전체, 미리알림 오늘·예정·전체). 밑줄 탭은 iOS 문법이 아니다. 탐색의 주간·월간·전체와 **같은 부품**을 써서 앱 안의 문법을 하나로 통일했다(`docs/frontend/design.md` §5).

- library-uiux.md 9·49·87행 "탭 3개/탭 전환" → "세그먼트", 4.2 제목·구성 설명을 세그먼트 기준으로(칸 폭 64, 알약 이동 스프링, 낭독기 radiogroup/radio).
- wireframe/library.html 상단 탭을 캡슐 세그먼트로.

## 완료 조건

- Given 라이브러리 / When 상단을 본다 / Then 흰 캡슐 안에 전체·미청취·완청 세 칸과 선택 알약이 있고 하단 구분선이 없다
- Given 전체 선택 / When 완청을 탭한다 / Then 알약이 미끄러져 완청 칸으로 가고 목록이 완청만 보인다(종전과 같은 필터)
- Given 낭독기 / When 세그먼트에 포커스 / Then "상태 필터, 라디오 그룹" 과 각 칸의 선택 여부를 읽는다
