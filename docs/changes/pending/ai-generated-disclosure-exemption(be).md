## 왜 기록하는가

`docs/ai/pipeline.md`를 쓰면서 **AI 자체 생성 콘텐츠(`origin = ai_generated`)는 출처 고지를 하지 않는다**는 결정이 나왔다(합의 2026-08-10). 오디오 멘트도, 화면 표기도 하지 않고, 근거 소스는 제작 도구가 파일로만 보관해 **내부 확인 용도로만** 쓴다.

현행 문서는 고지를 예외 없는 필수로 규정하고 있어 그대로 두면 구현이 문서와 어긋난다.

| PRD FR-12 | "**모든 오디오는** 적합한 형태로 원저자·출처를 고지하고 필요에 따라 원문 연결 정보를 제공한다" |

### 결정의 근거와 그 한계

근거는 **"사실·데이터만 참고하면 저작권 고지 의무가 발생하지 않는다"** 이고, 이는 아이디어·표현 이분법상 타당하다. 사실 자체는 저작권 보호 대상이 아니다.

다만 두 가지를 기록해 둔다. **반영을 막는 사유가 아니라, 나중에 판단 근거를 다시 볼 때 필요한 정보다.**

1. **"AI 생성물은 우리 저작물"이라는 전제는 별개 문제이며 불확실하다.** 문화체육관광부 「생성형 AI 저작권 안내서」(2023.12)는 인간의 창작적 개입이 없는 AI 산출물은 저작물로 보호받기 어렵고 등록도 불가하다는 입장이다. 다만 이는 **우리가 갖는 권리**의 문제이고, 참고한 자료에 대한 의무와는 다른 축이다.
2. **저작권법 제28조(인용) 항변을 쓰게 되면 제37조가 출처 명시를 요건으로 건다.** 사실만 가져왔다는 전제가 나중에 다투어질 때, 고지하지 않은 상태에서는 인용 항변이 약해진다.

→ **법무 확인 항목으로 `domain.md` 15.1에 등재**한다(기존 #18·#19와 같은 성격).

## 기록할 내용

### 1. PRD — `docs/prd/ear_root_prd.md`

- **4.1 콘텐츠 공급**: "모든 콘텐츠에 출처·저자 고지(시작·종료 멘트) 및 원문 연결 정보" → **파트너 콘텐츠 한정**으로 조건을 붙인다.
- **FR-12**: 다음으로 개정한다.
  > **FR-12** (P0) **파트너 콘텐츠**는 적합한 형태로 원저자·출처를 고지하고 필요에 따라 원문 연결 정보를 제공한다. **AI 자체 생성 콘텐츠(`origin = ai_generated`)는 고지 대상이 아니다** — 사실·데이터만 참고하므로 저작권 고지 의무가 발생하지 않으며, 근거 소스는 제작 단계에서 내부 기록으로만 보관한다(개정 2026-08-10).
- **7장 비기능 요구 · 저작권·파트너 계약 준수**: "출처·저자 고지 필수"에 파트너 한정 표기를 붙인다.

### 2. `docs/features/player.md` 4.5

- 오디오 시작·종료 멘트와 화면 상시 노출을 **`origin = partner`에 한정**한다.
- `ai_generated`는 저자·출처를 표시하지 않고 `[원문 보기]` 버튼도 노출하지 않는다(`source_url`이 항상 `null`이므로 기존 조건 분기로 자연히 처리된다).

### 3. `docs/features/content-pipeline.md` 4.3

- 고지 멘트 강제 삽입 규칙을 **파트너 원문 변환 라인 한정**으로 표기한다.
- "AI 자체 생성 콘텐츠도 동일하다. 다만 고지 멘트는 '참고한 자료' 형태로 소스를 명시한다" 문장을 **삭제**하고, `docs/ai/pipeline.md` 4.4를 가리키는 참조로 교체한다.

### 4. `docs/features/admin.md`

- **3.1 업로드 필드 표**: `source_name`의 `ai_generated` 분기를 **"참고한 자료" 소스 표기 → 제작 주체 표기(`"이어"`)** 로 바꾼다. 출처 고지가 아니라 콘텐츠 행의 "출처·저자" 자리를 채우는 값이다.
- **3.1 아래 분기 설명**: `ai_generated`의 필수 항목에서 "참고한 자료 표기"를 뺀다.
- **4.2-1 검수 체크리스트 3번**: `origin`으로 분기한다 — `partner`는 현행대로 오디오 고지 멘트를 확인하고, `ai_generated`는 이 항목을 건너뛴다. **나머지 3개 항목(사실관계 대조·금칙·오디오 품질)은 그대로 이행한다.**

### 5. `docs/backend/domain.md`

- **5.1 origin 분기 표**: `ai_generated`의 `source_name`을 "**필수** — 참고한 자료 소스 표기"에서 "**필수** — 제작 주체 표기(`"이어"`)"로 바꾼다. 필수 여부는 유지된다(행의 출처 칸을 비워둘 수 없다).
- **5.1 서술**: "복수 소스를 별도 테이블·배열로 정규화하지 않는다" 문단에서 소스 목록 관련 서술을 정리한다.
- **15.1 결정 항목 #8**(근거 소스 목록을 시스템 필드로 남길지) → **해소로 표기한다.** 앱에 노출하지 않기로 했으므로 필드를 만들지 않는다. 소스 기록은 제작 도구가 파일로 보관한다(`docs/ai/pipeline.md` 4.2·6장).
- **15.1 법무 확인 항목 추가**: "AI 생성 콘텐츠 출처 고지 면제의 적법성 — 사실만 참고했다는 전제가 다투어질 경우 저작권법 제28조 인용 항변에 제37조 출처 명시 요건이 걸린다."

### 6. 파급 — uiux 확인 필요

`docs/spec/uiux/explore-uiux.md`의 콘텐츠 행이 **"썸네일 · 제목 · 출처·저자 · 길이 · 더보기"** 구성이다. MVP는 전량 `ai_generated`이므로 이 자리에 **`"이어"`** 가 표시된다(합의 2026-08-10). 라이브러리 행도 같은 문법이므로 함께 확인한다.

- 이 요청은 uiux 문서를 직접 고치지 않는다. `doc-sync` 캐스케이드가 domain·PRD 반영 후 처리하는 것이 순서에 맞다.

## 완료 조건

- Given 이 요청이 반영된다 / When PRD FR-12를 읽는다 / Then 고지 의무가 `origin`으로 분기되어 있고 `ai_generated`가 대상 밖임이 명시되어 있다
- Given 이 요청이 반영된다 / When `player.md` 4.5를 읽는다 / Then 오디오 멘트·화면 노출이 `partner` 한정으로 표기되어 있다
- Given 이 요청이 반영된다 / When `admin.md` 4.2-1을 읽는다 / Then 검수 체크리스트 3번이 `origin`으로 분기되어 있고, 나머지 3개 항목은 `ai_generated`에도 그대로 적용된다
- Given 이 요청이 반영된다 / When `domain.md` 5.1 origin 분기 표를 읽는다 / Then `ai_generated`의 `source_name`이 제작 주체 표기로 정의되어 있다
- Given 이 요청이 반영된다 / When `domain.md` 15.1을 읽는다 / Then 결정 항목 #8이 해소로 표기되고 고지 면제의 법무 확인 항목이 등재되어 있다
- Given `ai_generated` 콘텐츠를 업로드한다 / When 필수값 검증을 수행한다 / Then `author_name`·`source_url`이 비어 있어도 통과하고 `chk_contents_partner_disclosure`에 걸리지 않는다

## 보류 사유 — 반영 전 필요한 것

**PRD 개정이므로 3인 합의가 필요하다.** `features/README.md`가 "개발 착수 전에 팀이 확정해야 한다"고 규정한 층이다. 합의 전에는 이 문서를 `pending/`에 둔다.

합의가 필요한 지점은 하나다 — **AI 생성 콘텐츠에 출처를 밝히지 않는 것이 서비스 신뢰에 미치는 영향.** PRD 1.3은 "라이선스 콘텐츠가 서비스 신뢰의 축"이라 했고 MVP는 그 축이 없는 상태로 출발한다. 자기계발·경제 주제에서 근거를 밝히지 않은 단정은 사실오류가 났을 때 "어디서 온 정보냐"에 답할 수단이 없다.

- 반영을 미룰 경우: `docs/ai/pipeline.md` 4.4·4.5·4.6이 상위 문서와 어긋난 상태로 남는다. 제작을 시작하기 전에 닫아야 한다.
