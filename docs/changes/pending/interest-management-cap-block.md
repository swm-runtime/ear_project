## 바뀐 것 (코드 반영 완료)

- 상한까지 고른 상태에서 **새 주제를 누르면 선택하지 않고** 토스트 **"관심 주제는 3개까지 선택할 수 있어요"**(`INTEREST_COPY.limitNotice` — 온보딩 상한 토스트와 같은 문자열)를 띄운다. 이미 고른 주제의 해제는 언제나 된다. 위치: `useInterestManagementScreen` `toggleTopic`.
- **상한을 이미 넘겨 보유한 사람(IM6)** 은 해제만 할 수 있다 — 저장 게이트(`isOverLimit`, max(상한, 기존 보유))와 하단 상한 문구는 그 경우를 위해 남긴다.
- 서버 검증은 그대로다.

## 확인이 필요한 것

- 개수는 화면의 다른 판정과 같은 `selectedCount`(보이는 주제 중 고른 것 전부)로 센다. `interest-management.md` 4.1·4.3(개정 2026-09-30)은 **자동 추가 주제(`auto_expand`)를 상한에서 빼라**고 하지만 현재 클라이언트는 출처를 구분하지 않는다 — 이 차이는 이번 변경 이전부터 있었다(별도 확인 필요).
