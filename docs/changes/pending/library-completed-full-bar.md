## 수정 내용

`completed` 상태의 표식을 **썸네일 좌상단 체크 마킹**에서 **아트워크 아래 변의 진행률 바를 100% 로 채운 것**으로 바꾼다(유튜브의 "본 영상" 문법).

- 체크(`completedMark`)를 지운다. 사진 위 표식이 체크·더보기·"새로운 주제" 셋이라 붐비고, 체크는 사진 위에서 스티커처럼 떠 보였다(같은 이유로 같은 날 "새로운 주제" 알약도 그라데이션+글자로 바꿨다 — `library-thumbnail-grid.md` 갱신분).
- **완청 바는 실제 위치가 아니라 100% 로 고정한다.** 완청 판정이 "최대 도달 90%"(`library.md` 4.4)라 판정 직후의 `position_sec` 은 9할대이고, 완청 뒤 되감으면 3할이 될 수도 있는데 상태는 `completed` 로 남는다. 위치를 그대로 그리면 완청 타일에 덜 찬 바가 남는다.
- 낭독기 라벨은 그대로 "완청한 콘텐츠"다 — 완청 바에 "100% 들음"을 읽히지 않는다.
- **진행률 바가 있는 타일(듣던 중·완청)에도 아래 변 검정 그라데이션(투명→75%, 56pt)을 깐다** — 흰 바가 밝은 사진에서 안 보인다(PM 2026-09-22). "새로운 주제" 글자와 같은 그라데이션 하나를 공유하고, 아래 변에 아무것도 없는 미청취 타일에는 그리지 않는다.
- **바는 아트워크 아래 변에 붙이지 않고 sm(8pt) 띄워 좌우 sm 여백·둥근 끝으로 그린다.** 변에 붙이면 바로 밑이 흰 화면 배경이라 흰 바가 배경에 녹아 안 보였다(PM 2026-09-22 실기기). "새로운 주제" 글자는 그 바 위 xs 에 놓인다.

## 사유

PM(2026-09-22): "완청한 거에 체크 표시하는 거는 이상하지 않아? 그냥 플레이바를 끝까지 보내는 게 낫지 않을까."

감수하는 것: `in_progress` 는 최대 ~90% 까지만 오므로 이론상 완청과 구분되지만, 타일 폭에서 그 차이(약 10%)는 눈으로 갈리지 않는다. 미청취/완청 구분은 탭 필터가, 낭독기 구분은 라벨이 맡고 있어 실용적으로 문제 없다고 봤다.

## 완료 조건

- Given 완청 1편(되감아서 position 30%) / When 라이브러리 목록을 보면 / Then 그 타일의 아트워크 아래 변에 바가 끝까지 차 있고 좌상단에 체크가 없으며, 낭독기는 "완청한 콘텐츠"를 읽는다
- Given 듣던 중 1편(position 40%) / When 목록을 보면 / Then 바가 4할 차 있고 낭독기는 "40% 들음"을 읽는다
- Given 미청취 1편 / When 목록을 보면 / Then 아트워크에 바가 없다
