## 수정 내용

**전체 플레이어만 어두운 팔레트**를 쓴다 — 바탕 `#17171A`(순검정은 너무 꺼멓다는 PM 지적으로 같은 날 차콜로 띄움), 글자·포인트 `#FFFFFF`, 면 `#26262B`, 보조 글자 `#A0A0A8`, 트랙·비활성 `#45454C`. 앱의 나머지(탭 화면·미니플레이어)는 밝은 `theme.color` 그대로다.

- 범위: 플레이어 화면, 그 안의 재생 목록·대본 패널, 더보기·배속 바텀시트. 키 이름이 `theme.color`와 같은 `playerColor`를 참조만 바꿔 쓴다.
- 재생 버튼은 흰 원 + 검정 아이콘(primary/onPrimary 가 뒤집힘). 시크바 채움·썸은 흰색, 트랙은 회색. 재생 목록이 열려 선이 사진 밑변에 걸칠 때는 트랙만 흰 35% — 사진과 검정 바탕 모두에서 같은 "어두운 위의 옅은 선"으로 읽힌다(밝은 바탕 시절의 불투명 회색 트랙·검정 채움은 폐기).
- 전환(4.8): 시트 색은 밝은 미니플레이어 색에서 출발해 진행도 12%까지 유지(미니 제목·▶ 이 그 위에 있다) → 40%에서 검정에 닿는다. 끝까지 고르게 섞으면 중간이 탁한 회색 판으로 보였다. 모션 레이어의 미니 제목·▶ 는 밝은 테마 색 그대로.
- 상태바: 플레이어가 떠 있는 동안 밝은 글자(`expo-status-bar` style="light"), 걷히면 앱 기본.
- 대본 패널 위·아래 페이드는 검정으로 흐른다(`ScrollFade color`).
- **그대로 둔 것**: 재생 확인 팝업(`PlayConfirmDialog`)은 라이브러리·탐색과 공유하는 컴포넌트라 밝은 채로 둔다 — 플레이어 위에서만 어둡게 할지는 미결.

### 추가(같은 날) — 바탕에 흐린 커버

무채색 단색 바탕은 값을 올려도(`#000` → `#17171A`) "꺼멓다"는 인상이 남았다. 유튜브 뮤직·스포티파이(커버 대표색)·애플 뮤직(흐린 커버)처럼 **곡의 색이 바탕에 배게** 한다.

- 시트 안에 아트워크를 화면 가득 깔고 강하게 흐린 뒤(`blurRadius` 60, 가장자리 투명을 피하려 1.25배) 바탕색 72%의 어두운 막을 얹는다. 곡이 바뀌면 분위기가 같이 바뀐다.
- 전환: 시트 색이 검정으로 넘어가는 구간(진행도 12~40%)에 함께 나타난다.
- 재생 목록 시트는 배경을 칠하지 않는다 — 흐린 바탕이 목록 뒤까지 이어진다. 더보기·배속 바텀시트는 불투명 면 그대로.
- 대본 패널 위·아래 페이드는 완전히 덮으면 띠가 막대처럼 보여 최대 불투명도 0.6의 옅은 그늘로 낮췄다(`ScrollFade maxOpacity`).
- 대표색 추출은 쓰지 않았다 — 네이티브 모듈(새 빌드) 또는 서버의 콘텐츠별 색 필드(BE)가 필요하다. 이미지 흐림은 기본 기능이라 OTA 로 나간다.
- 썸네일이 없는 콘텐츠는 단색 바탕 그대로다.

## 사유

PM 결정(2026-09-18). 밝은 바탕에서는 재생 목록을 올려 사진이 화면을 채울 때 사진에 걸친 시크바 색이 끝내 맞지 않았다(흰색 → 그라데이션 → 검정 → 회색 → 불투명 회색, 다섯 번). 검정 바탕이면 사진 위든 밖이든 같은 흰색으로 읽히고, 아트워크가 가장 도드라진다. 흑백 단색 브랜드라 반전이 이질적이지 않다.

- 재생 목록 열림용 이중 톤 교차(앱바 아이콘·제목의 검정↔흰색)는 두 톤이 같은 흰색이 되어 동작상 무의미해졌다 — 코드 정리는 별도 PR.

## 완료 조건

- Given 미니플레이어 / When 탭하거나 끌어올려 연다 / Then 시트가 밝은 회색에서 출발해 중간 전에 검정이 되고, 도착한 플레이어는 검정 바탕·흰 글자·흰 재생 버튼이다
- Given 플레이어 / When 재생 목록·대본·더보기·배속을 연다 / Then 모두 어두운 면 위 흰 글자이고 밝은 면이 섞여 보이지 않는다
- Given 재생 목록 열림 / When 시크바를 본다 / Then 채운 구간(흰색)과 남은 구간(옅은 선)이 사진 쪽·검정 쪽 모두에서 구분된다
- Given 플레이어가 떠 있다 / When 상태바를 본다 / Then 글자가 밝고, 닫으면 앱 기본으로 돌아온다
- Given 탭 화면·미니플레이어 / When 본다 / Then 종전과 같은 밝은 테마다
