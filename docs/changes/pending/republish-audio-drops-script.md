## 넣을 내용

### admin-api.md 4.10
- `script_file` 행: "**오디오를 바꾸는 재발행에서 `script_file`이 없거나 검증에서 거부되면 기존 대본을 삭제한다**(2026-09-26). 응답의 `has_script`가 `false`로 내려가고 감사 로그 `after.script_dropped = true`가 남는다. 틀린 자막보다 없는 편이 낫다. 오디오를 바꾸지 않는 재발행(메타만·파일만)은 대본을 건드리지 않는다."
- 운영 절차 한 줄: 오디오 재발행 뒤 자막은 **발행 목록 [자막 뽑기](워커가 새 오디오와 대본을 강제 정렬) → [반영](`script_file` 단독 PATCH, 버전 무변경)** 으로 다시 채운다. 재발행 요청에 `script_file`을 함께 실어도 된다.

### domain.md 5.3
"재발행으로 오디오가 바뀌면 통째로 교체" 뒤에 "함께 오지 않으면 삭제(행 없음 = 자막 없음)"를 덧붙인다.

### admin.md 4.2
재발행 절에 같은 규칙 한 줄.

## 완료 조건

- Given 오디오만 재발행 / When 응답 / Then `has_script: false`
