## 무엇을 고치나

1. 2장 "로컬 워커가 꺼져 있으면 AI 작업은 `queued`에 머문다 — 화면에 "대기 중(AI 워커 없음)"으로 표시" 문장을 고친다.
   - 운영 워커는 서버 워커뿐이다(2026-10-16 KAN-222). 콘솔 상단바는 **워커 작업 중 / 워커 동작 중 / 워커 중단** 세 상태만 보인다. 누가(어느 Mac이) 띄웠는지는 보이지 않는다.
   - 판정: 워커가 작업 유무와 무관하게 30초마다 `settings` 의 `worker.alive` 줄을 갱신한다.
     - 작업 중 — 집은 작업(`claimed`·`running`)의 heartbeat 가 3분 안
     - 동작 중 — 작업은 없고 `worker.alive.updated_at` 이 2분 안(켜져 있고 일감 대기)
     - 중단 — 둘 다 아님
   - 대기 중인 AI 작업이 있으면 "대기 N건"을 함께 보인다(종전과 같음).
2. 화면 표 "대시보드" 행의 "워커 상태(heartbeat — 누구의 Mac이 AI 워커를 띄웠는지)"를 "워커 상태 — 작업 중·동작 중·중단(작업 heartbeat · 생존 신호 `settings.worker.alive`)"로 고친다.

## 왜

종전 표시는 진행 중인 작업의 heartbeat 로만 워커를 찾아, 서버 워커가 켜져 있어도 큐가 비면 "AI 워커 없음 — 팀원 Mac에서 npm run worker"로 보였다. 노트북 워커는 운영에서 쓰지 않으므로 안내 문구도 맞지 않다.

## 완료 조건

- Given 서버 워커가 작업을 처리하고 있다 / When 콘솔을 연다 / Then 상단바에 "워커 작업 중"이 보인다
- Given 서버 워커가 켜져 있고 큐가 비어 있다 / When 콘솔을 연다 / Then 상단바에 "워커 동작 중"이 보인다
- Given 서버 워커가 2분 넘게 생존 신호를 찍지 않았고 처리 중인 작업도 없다 / When 콘솔을 연다 / Then 상단바에 빨간 점과 "워커 중단"이 보인다
- Given spec/10 을 연다 / Then 2장과 화면 표에 "누구의 Mac" · "AI 워커 없음" 표현이 없다
