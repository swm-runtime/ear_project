## 현재 규칙

- 4장 6항: "스플래시는 최소 0.8초 노출한다(깜빡임 방지). 판정이 더 빨리 끝나도 유지."
- 5장 "판정 중": "스플래시(로고). 1.5초 이상 지연 시 로딩 인디케이터 추가 노출"
- `architecture.md` 2.1: runtimeVersion 은 고정 문자열, 네이티브가 바뀌면 손으로 올린다. 현재 값 `"1"`.

## 수정 내용

### 스플래시 화면은 로고 모션 영상이다

빈 흰 화면에서 로고의 선이 그려져 완성되는 영상(`frontend/assets/splash-logo.mp4`, 130KB)을 `expo-video`로 화면 가운데 **화면 폭 70% 박스**(9:16, `contain`)에 튼다 — 전체 화면은 로고가 화면 폭의 62%를 차지해 포스터처럼 읽혔다(PM 확정 2026-09-17). 로고 폭은 화면의 약 43%, 정지 로고(160pt)와 같은 무게. 소리 없음·음소거·`mixWithOthers` — 다른 앱의 재생을 끊지 않고 잠금화면 컨트롤도 띄우지 않는다.

- 선은 **2.23초**에 다 그려지고 나머지 1.8초는 완성 로고로 머문다.
- **스피너를 두지 않는다.** 그려지는 선 자체가 진행 중임을 보인다.
- **모션 축소 설정**이면 영상 대신 정지 로고(`splash-icon.png`)를 둔다.
- 벡터 재현안(react-native-svg 로 획을 다시 그리기, OTA 가능)을 먼저 만들었으나 PM 이 영상 원본 그대로를 택했다(2026-09-17). 벡터안 코드는 지우고 추출 절차만 세션 기록에 남겼다.

### 4장 6항 최소 노출 — 0.8초 → **선이 다 그려진 뒤 0.8초**(영상 기준 약 3.0초)

선이 다 그려지기 전에 화면이 바뀌면 그리다 만 로고가 잘린다. 판정이 더 빨리 끝나도 완성 후 0.8초 머문 뒤 전환한다. **모션 축소 설정에서는 종전 0.8초**를 유지한다.

- **시계가 아니라 영상의 재생 위치로 판정한다.** 영상 시작은 기기·망에 따라 0.3~1초 늦어질 수 있어(웹 dev 서버에서 1초 실측) 마운트 시각에서 3.0초를 세면 그리다 만 채로 잘린다. 스플래시가 재생 위치 2.23초를 넘긴 시점을 관문에 올리고, 관문은 그 뒤 0.8초에 넘어간다.
- **안전장치 6초** — 영상이 시작조차 못 하면(디코더 오류·자산 누락) 마운트 6초 뒤 무조건 넘어간다. 스플래시에 갇히는 것이 그리다 만 로고보다 나쁘다.

- 영상 끝(4.03초)까지 다 보이려면 `SplashScreen.tsx` 의 `SPLASH_HOLD_MS` 를 1800 으로. 매 실행마다 보는 화면이라 800 으로 줄였다.
- 콜드 스타트 체감이 종전보다 최대 2.2초 길어진다. 판정이 원래 3초 넘게 걸리는 환경에서는 차이가 없다.

### 5장 "판정 중" 행

"스플래시(로고)" → "스플래시(로고 모션 영상 — 2.2초에 완성, 이후 완성 로고 유지)". "1.5초 이상 지연 시 로딩 인디케이터"는 **완성 후** 1.5초 기준으로 읽는다. 인디케이터 자체는 종전과 같이 미구현이며 이번 범위가 아니다.

### `architecture.md` 2.1 — runtimeVersion `"1"` → `"2"`

`expo-video` 는 네이티브 모듈이다. 2.1 규칙대로 문자열을 올렸고, **production 프로필로 새 빌드를 뽑아 스토어에 올려야** 이 스플래시가 사용자에게 간다. 올린 뒤의 OTA 는 runtime `2` 빌드에만 닿는다 — `1` 빌드(현재 스토어 버전)는 스토어 업데이트 전까지 마지막 `1` 발행분에 머문다. 이력 표에 한 줄 추가:

| runtimeVersion | 시점 | 사유 |
|---|---|---|
| `2` | 2026-09-17 | expo-video 추가(스플래시 로고 영상) |

### 원본 자산

영상 원본과 벡터 원본(`로고.ai`)은 저장소에 없다(바탕화면). 앱에는 `assets/splash-logo.mp4` 사본만 있다.

## 완료 조건

- Given runtime `2` 빌드로 앱을 콜드 스타트한다 / When 스플래시가 뜬다 / Then 흰 화면에서 로고 선이 그려져 2.2초에 완성된다(소리 없음)
- Given 세션 판정이 0.1초 만에 끝났다 / When 스플래시를 본다 / Then 로고 완성 후 0.8초 머문 뒤 다음 화면으로 간다(영상이 바로 시작되면 총 3.0초)
- Given 영상이 재생되지 않는다(자산 누락 시뮬레이션) / When 앱을 켠다 / Then 6초 뒤 다음 화면으로 간다
- Given 다른 앱에서 음악이 재생 중이다 / When 앱을 켠다 / Then 음악이 끊기지 않는다
- Given 기기의 모션 축소가 켜져 있다 / When 스플래시가 뜬다 / Then 정지 로고가 바로 보이고 0.8초 뒤 전환된다
- Given `splash.md` 4장 6항 / When 최소 노출을 읽는다 / Then 3.0초와 모션 축소 예외가 적혀 있다
- Given `architecture.md` 2.1 / When runtimeVersion 이력을 읽는다 / Then `2` 와 사유가 있다
