## 결정 내용

연차 구간 칩의 화면 표기를 **"1년 이하" / "2–3년" / "4–6년" / "7년 이상"** 으로 확정한다
(결정 2026-08-12 — 온보딩 코드가 써 온 표기. 경계 구간을 "0–1년"/"7년+" 대신 "이하/이상"으로
풀어 쓰는 쪽이 낫다는 판단).

- 온보딩 O4와 커리어 정보 화면(CR 계열)은 **같은 값 체계·같은 표기**를 쓴다(career.md 3장).
  이 결정으로 온보딩 코드의 "TODO(카피 미확정): 연차 구간 표시 라벨"이 확정으로 바뀌었다.
- career-uiux.md 6장의 확정 문자열("0–1년"/"7년+")과 두 와이어프레임의 칩 표기는 이
  결정과 어긋나므로 개정 대상이다.
- career-uiux.md 9장 미결 "연차 표기의 하이픈"(enum 값과 화면 표기의 대응, 프로필 카드
  "4-6년" 표기와의 문자 단위 일치 여부)도 이 결정으로 함께 정리한다 — 화면 표기는 위
  확정 표기를 쓰고, 요약을 그리는 프로필 카드의 표기(`profile-uiux.md` 4.5)와의 통일 여부는
  개정 시 확인한다.

## 반영할 내용

1. `career-uiux.md` 6장 — 연차 칩 행을 "1년 이하" / "2–3년" / "4–6년" / "7년 이상"으로 교체
   (근거: 결정 2026-08-12 — 온보딩과 동일 유지).
2. `career-uiux.md` 9장 — "연차 표기의 하이픈" 미결을 해소 처리.
3. `onboarding-uiux.md` 4.3 — 연차 라벨 확정 카피를 기재한다(현재는 "연차(칩)" 구성만 있음).
4. `wireframe/career.html` · `wireframe/onboarding.html` — 칩 표기를 확정 표기로 교체.
