## 바뀐 것 (코드 반영 완료 — iOS 26 시스템 탭 바 갈래에서만)

- L1 상단: 떠 있는 검색창 줄이 없다. **큰 제목 "라이브러리"** 내비게이션 바 + **바 안 시스템 검색창**(받아 둔 목록을 그 자리에서 좁히는 규칙은 그대로, 취소 버튼은 시스템 것 — 검색어만 비운다) + 오른쪽 **잔여 링 + 필터 툴바 캡슐**(바 아이템).
- 조건 요약 줄·배너는 목록의 첫 줄로 **목록과 같이 스크롤**한다(고정 아님).
- L6·L9(전체 빈 상태)는 검색창·툴바를 바에 걸지 않는다 — 종전 "탭 줄·필터 아이콘을 감춘다"와 같은 뜻.
- iOS 26 미만·Android(JS 탭 바)는 종전 그대로.
