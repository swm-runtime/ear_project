## 왜 기록하는가

uiux 6장·4.8이 확정한 빈 상태 카피는 "**아직** 청취 기록이 없어요"인데, 구현 과정에서
FE 담당자가 "청취 기록이 없어요"로 수정해 확정했다(2026-08-08). 프로필의 빈 상태는
신규 사용자의 이번 주(P10 변형 A)뿐 아니라 **과거의 전체 0인 주**(4.6 — 주 이동으로
도달)에도 같은 문구가 쓰이는데, 과거 주에 "아직"이 붙으면 시제가 어긋난다 — 이미 지나간
주는 "아직"이 성립하지 않는다. 두 곳에 문구를 가르지 않고 하나로 통일하는 쪽을 택했다.

## 기록할 내용 (통합 시 profile-uiux.md에 반영)

- ~~4.8 변형 A~~ → **반영 완료(2026-08-08, FE 담당자 직접 수정 — feat(fe)/profile PR에 포함).**
- **6장 카피 원칙의 "아직 청취 기록이 없어요"를 "청취 기록이 없어요"로 교체하는 것이 남았다** —
  4.8과 6장이 현재 서로 다른 문구를 들고 있다.
- 코드는 `feat(fe)/profile`의 `profile.copy.ts`(`stats.emptyState`)에 선반영돼 있다.

## 완료 조건

- Given 이 요청이 통합 과정에서 반영된다 / When `profile-uiux.md` 4.8·6장을 읽는다 /
  Then 통계 빈 상태 카피가 두 곳 모두 "청취 기록이 없어요"로 기재되어 있고 "아직"이 남아 있지 않다
- Given 신규 사용자 또는 전체 0인 과거 주 / When 통계 영역의 빈 상태를 본다 /
  Then "청취 기록이 없어요"가 표시된다
