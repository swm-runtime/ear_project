## 배경

PM 확정(2026-10-19): **"온보딩할 때는 고른 언어로 언어·콘텐츠를 통일한다."** 가입 때(A21) 고른 언어로 화면 언어도 맞춘다 — 그 뒤엔 설정 › 언어로 따로 바꿀 수 있다. 실기기 제보: 영어 기기에서 A21 한국어를 골라도 A4부터 영어였다.

FE는 A21 [다음]으로 A4에 갈 때 표시 언어를 고른 언어로 바꾸고, 설정 › 언어와 같은 자리에 저장한다(다시 불러오지 않는다 — 가입 토큰이 메모리에만 있다). 같은 언어면 아무것도 바꾸지 않는다. **시장 판정·시장 불변은 그대로다.**

global-api.md 는 표시 언어를 "앱 실행 때 기기 `locale`로 1차 판단, 바꾸는 길은 설정뿐"으로 적고 있어, 가입 때 한 번 더 정해지는 경로가 빠져 있다.

## 고칠 내용

1. 4.1 가입 화면 질문 설명(현재 "앱 실행 직후의 **표시 언어**는 서버 호출 전이라 클라이언트가 기기 `locale`로 1차 판단한다 — 시장 판정과 별개다") 뒤에 덧붙인다:
   "가입 때 고른 콘텐츠 언어로 표시 언어도 맞춘다(PM 확정 2026-10-19 — 그 뒤엔 설정 › 언어로 따로 바꿀 수 있다). 시장 판정과는 여전히 별개다 — 표시 언어를 바꿔도 시장은 그대로다."
2. 4.3 "왜"의 "사용자가 표시 언어를 바꿀 길이 설정밖에 없다" → "가입 뒤에 표시 언어를 바꿀 길은 설정뿐이다(가입 때는 A21 선택으로 맞춘다)".
3. 참고(결정 아님): 가입 요청 `locale.language_code`는 계약대로 **기기 로캘**이라, A21에서 다른 언어를 고르면 가입 직후 `users.language_code`(기기 값)와 앱 표시 언어가 다를 수 있다. 이 값은 통계용이고 서버 문구 언어는 `users.market`이 정하므로 동작에는 영향이 없다 — 표에 이 한 줄을 남길지 BE가 정한다.

## 완료 조건

- Given global-api.md 4.1 / When 표시 언어 서술을 읽는다 / Then 가입 때 고른 언어로 표시 언어가 맞춰진다는 것과 시장과 별개라는 것이 함께 적혀 있다
- Given global-api.md 4.3 / Then "바꿀 길이 설정밖에 없다"가 가입 뒤로 한정되어 있다
