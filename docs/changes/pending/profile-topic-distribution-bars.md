## 바뀐 것 (코드 반영 완료)

- 주간 그래프와 같은 회색 카드 안에: **1위 헤드라인**("가장 많이 들은 주제" / 주제명 + %) → **전체 비율 가로 누적 막대**(주제별 색) → **주제별 줄**(색 점 · 이름 · % · 그 비율만큼의 막대).
- 나타날 때 막대가 왼쪽에서 자라난다(scaleX, 네이티브 드라이버).
