# 온보딩 O1(관심 주제) 시각 개편에 따른 문서 반영 요청

| 항목 | 값 |
|---|---|
| 발행 날짜 | 2026-09-03 |
| 발행자 | FE (feat(fe)/onboarding-topic-ui 브랜치) |
| 대상 문서 | `spec/uiux/onboarding-uiux.md` 4.1·4.3 · `spec/uiux/interest-management-uiux.md` 5장 · `wireframe/onboarding.html` |
| 관련 코드 | `frontend/src/features/onboarding/screens/TopicSelectScreen.tsx` · `frontend/src/features/interest/components/TopicChip.tsx` |

## 배경

O1–O3 관심 주제 화면을 레퍼런스(사진 알약 + 큰 헤드라인 + 원형 다음 버튼) 결로 시각 개편했다.
동작 규칙(선택 1~3개·상한 토스트·인플라이트 비활성·스켈레톤·에러 상태)과 확정 카피는 전부
유지했고, **표현만** 다음과 같이 바뀌었다.

## 바뀐 표현

1. **상단 툴바** — 가운데 타이틀 "관심 주제"(신규 카피 — 확정 필요)만 있는 툴바를 추가했다.
   O1 규칙에 따라 뒤로가기·[건너뛰기]는 두지 않는다. 높이는 2·3단계 [이전] 버튼과 동일.
2. **스텝 인디케이터 제거** — O1에서 세그먼트 막대 + `1/3` 라벨을 그리지 않는다. 4.1
   "구성"의 "인디케이터 1/3" 항목과 어긋나므로 문서에서 O1 구성을 갱신해 달라
   (O4·O7의 인디케이터는 그대로 — 이 화면만 제거).
3. **제목** — 큰 회색 헤드라인(`xl`·`textSecondary`)로 확대하고, 개수 안내와 **한 문장으로
   합쳤다**: "궁금한 이야기를 / 최대 3개까지 골라주세요"(2줄). 기존 제목 "어떤 이야기가
   궁금하세요?"와 별도 안내 줄은 사라졌다. 선택이 시작되면 그 아래 "N/3 선택"만 나타난다.
4. **주제 칩** — 테두리+이모지 알약 → **주제 사진 배경 알약**(어두운 오버레이 + 흰 라벨,
   선택 시 오버레이만 짙어짐 — 체크 글리프 없음, 상한 dim은 흰 오버레이). 이모지 아이콘은 제거했다.
   사진은 `frontend/assets/topics/*.jpg` 번들 — 전부 **CC0/퍼블릭 도메인**(Openverse 검색,
   출처 표시 불요, 640×320 crop). 서버 계약에 이미지 필드가 없으므로 topicId 매핑은
   클라이언트 소유이고, 미지의 주제는 기본 사진으로 떨어진다.
   `TopicChip`은 공유 컴포넌트이므로 **관심사 관리(IM) 화면도 같은 시각으로 바뀐다**
   (같은 칩 원칙 유지 — interest-management-uiux.md 5장).
5. **칩 배치** — flexWrap 2열 격자 → **4줄 가로 스와이프**(라운드로빈 분배, 행마다 들여쓰기가
   다른 벽돌 흐름, 화면 가장자리 밑으로 흐름). 세로 스크롤 없음. 온보딩 화면 한정 표현이고
   IM 화면 격자는 그대로다. 순서·선택 동작 불변. 같은 묶음 3벌을 이어 붙여 **무한 루프**로
   돌며(가장자리 근처에서 한 벌 폭 되감기), 낭독기에는 가운데 벌 하나만 들린다.
6. **미충족 안내 제거** — 0개 선택 상태의 "관심 주제를 1개 이상 선택해주세요" 문구를
   그리지 않는다. 개수 안내("최소 1개, 최대 3개…")와 비활성 [다음]이 같은 정보를 이미
   전달한다. 4.1 상태 표의 해당 행 갱신 요청(IM 화면의 같은 문구는 그대로다).
7. **개수 안내 통합** — 별도 안내 줄을 없애고 헤드라인에 합쳤다(3번 항목). 최소 1개
   조건은 비활성 [다음]이 전달한다. 4.1 확정 카피·상태 표 갱신 요청.
8. **[다음] 버튼** — 전폭 텍스트 버튼 → **우하단 원형 화살표 버튼**(64pt). "다음" 라벨은
   accessibilityLabel로만 남는다. 비활성 조건·미충족 안내 문구는 기존 그대로.

### O4(커리어, 2/3)도 같은 컨셉으로 개편 (2026-09-03 추가)

- 가운데 타이틀 툴바("커리어" — 카피 확정 필요, [이전]은 왼쪽 유지) · "2/3 단계" 라벨 ·
  큰 회색 헤드라인. 스텝 인디케이터(세그먼트 막대)는 O1과 같이 제거.
- 칩·입력은 테두리 → **면(surface) 문법**. 선택 = primary 채움(동작·낭독 불변).
- [다음] = 우하단 원형 버튼(라벨은 낭독 전용) · [건너뛰기] = 왼쪽 밑줄 텍스트 버튼 —
  44pt 터치 타깃·본문 크기 유지(4.3 "숨기거나 작게 만들지 않는다" 준수).
- 4.3 "구성"과 상태 표의 버튼 서술 갱신 요청.

### O7(추천 담기, 3/3)도 같은 컨셉으로 개편 (2026-09-04 추가)

- 가운데 타이틀 툴바("콘텐츠 담기" — 카피 확정 필요, [이전] 왼쪽 유지) · "3/3 단계" 라벨 ·
  큰 회색 헤드라인. 스텝 인디케이터 제거(O1·O4와 동일).
- [건너뛰기] = **우상단 텍스트 버튼**(O4와 동일) — 담은 것과 무관하게 담지 않고 진행.
  하단은 **우하단 원형 버튼**(O1·O4와 동일) + 왼쪽에 "N개 담기" 캡션. 0개일 때 원형
  버튼은 건너뛰기 동작(4.4의 전환 규칙 유지, 표현만 아이콘).
- 4.4 "구성"의 인디케이터·버튼 서술 갱신 요청.

### O9(완료 요약) 화면 제거 → 착지 화면(탐색) 코치마크로 대체 (2026-09-04)

- O9는 **자동 통과**한다: 완료 처리·알림 사전 안내 신호·뒤로가기 차단 판정은 전부 기존
  그대로 두고, 화면은 인플라이트 스피너만 잠깐 보인다. 완료 요청 실패 시에만 재시도 UI.
- 안내는 온보딩 직후 착지한 **실제 탐색 화면 위 코치마크 2단계**가 대신한다
  (`ExploreWalkthrough` + `shared/ui/walkthrough.store` — markPrePromptPending과 같은 신호
  패턴): ① 검색줄 가리키며 "검색하고 담기" ② 라이브러리 탭 가리키며 "매일 아침 2편 도착".
  [다음]→[시작하기], [건너뛰기] 상시. 코치마크 카피 확정 필요.
- **미결**: 기존 O9의 티어 안내(FR-14 — "무료·하루 2편 재생")가 사라졌다. 노출 위치 재지정
  필요(코치마크 3단계로 추가 vs 페이월 첫 노출에 위임) — 문서 담당 결정 요청.
- 4.6은 화면 제거·코치마크 신설로 개정 요청(코치마크 소유 문서는 explore-uiux.md가 될 수도).

## 수정 요청

- onboarding-uiux.md 4.1 "구성"에 상단 툴바(타이틀 "관심 주제")를 추가하고 카피를 확정해 달라.
- onboarding-uiux.md 4.1 "구성"의 [다음] 서술에 원형 버튼 표현을 반영하고, "다음" 카피는
  낭독 라벨로 유지됨을 명시해 달라.
- interest-management-uiux.md 5장에 칩 시각(틴트 알약) 변경을 반영해 달라.
- wireframe/onboarding.html O1–O3는 시각 참조 동기화 대상(9장 미결 목록에 추가).

## 완료 조건 (Given/When/Then)

- Given 문서 담당자가 onboarding-uiux.md 4.1을 열었을 때, When 반영이 끝나면,
  Then [다음]이 원형 버튼 + 낭독 라벨 "다음"으로 기술되어 있다.
- Given interest-management-uiux.md 5장을 열었을 때, When 반영이 끝나면,
  Then 주제 칩 시각이 틴트 알약으로 기술되어 있고 "같은 칩" 원칙이 유지된다.
