## 수정 내용

라이브러리·탐색 검색 줄 오른쪽의 잔여 재생 표시를 **헤드폰 아이콘 + `N/M` 칩**에서 **점 게이지**로 바꿨다.

- 한도(`M`)만큼 점을 찍고, 남은 횟수(`N`)만큼 앞에서부터 채운다. 빈 점은 테두리만 남긴다.
- 소진(`N = 0`)이면 빈 점 전부를 주의색으로 그리고, 탭하면 종전대로 페이월(구독 UI 꺼진 빌드에서는 한도 안내 토스트)을 연다. 히트 영역 44pt 유지.
- 낭독기 라벨은 그대로 `"오늘 재생 M회 중 N회 남음"` / 소진 `"오늘 재생 0회 남음"`.
- 한도가 5를 넘으면 점이 줄이 되어 세기 어려우므로 종전 `N/M` 문자열로 돌아간다.

## 사유

PM 지적(2026-09-18): 검색 줄 옆의 아이콘 + 숫자 칩이 낱개 부품처럼 튀어 보인다. 4안(점 게이지 · 링 + 숫자 · 글자만 · 목록 위 한 줄) 중 점 게이지 채택 — 숫자를 읽지 않아도 "몇 개 중 몇 개"가 한눈에 들어오고, 소진이면 빈 점만 남아 그 자체가 상태다.

## 문서에 반영할 것

- paywall.md 5장 "문구는 한 문자열만 쓴다(`오늘 재생 N/M 남음`)" → 시각 표현은 점 게이지(한도 ≤ 5), 문자열은 낭독기 라벨과 한도 > 5 폴백에만 쓴다. `M` 하드코딩 금지는 그대로.
- library-uiux.md 4.3 · explore-uiux.md 4.2의 잔여 표시 설명·상태(소진 주의색, 탭 → 페이월)를 점 게이지 기준으로 갱신.

## 완료 조건

- Given 한도 2 · 남은 1, When 라이브러리·탐색 화면을 열면, Then 검색 줄 오른쪽에 채운 점 1 + 빈 점 1이 보이고 낭독기는 "오늘 재생 2회 중 1회 남음"을 읽는다.
- Given 한도 2 · 남은 0, When 같은 화면을 열면, Then 주의색 빈 점 2개가 보이고 탭하면 페이월(또는 한도 토스트)이 열린다.
- Given 한도 6 이상, When 같은 화면을 열면, Then 점 대신 `N/M` 문자열이 보인다.
