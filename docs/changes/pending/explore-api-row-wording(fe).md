# [FE] explore-api.md — 4.1의 "가로 스크롤 카드" 잔존 문구 정리

| 항목 | 값 |
|---|---|
| 대상 문서 | `docs/spec/api/explore-api.md` 4.1 (마지막 불릿) |
| 요청 파트 | 프론트엔드 |
| 관련 작업 | 탐색 FE 구현 (`feat(fe)/explore`, 2026-08-07) 중 발견 |
| 백엔드 협의 | 불필요 — 계약(응답 모양)은 그대로이고 서술만 고친다 |

## 왜 필요한가

explore-api.md 4.1의 마지막 불릿이 "**가로 스크롤 카드**의 개수는 서버가 정해 내려준다"라고
서술한다. 화면 구성은 2026-08-06 합의로 **세로 행(row) 목록**으로 확정됐고(`explore.md` 4.1 ·
`explore-uiux.md` 1장 확정 사항), 같은 문서 3장 설계 메모("두 모드의 행 레이아웃은 같다")와도
어긋나는 개정 전 표현이 남은 것이다. 계약 내용(섹션당 항목 수는 서버가 정한다, 권장 6~10건)은
유효하므로 서술만 고치면 된다.

## 수정 내용

- 4.1 마지막 불릿의 "가로 스크롤 카드의 개수는" → "**섹션 내 행(row)의 개수는**"으로 교체.

## 완료 조건

- Given 이 요청이 통합 과정에서 반영된다 / When `spec/api/explore-api.md` 4.1을 읽는다 /
  Then "가로 스크롤 카드" 표현이 없고, 섹션 내 행 개수를 서버가 정한다는 서술로 되어 있다
