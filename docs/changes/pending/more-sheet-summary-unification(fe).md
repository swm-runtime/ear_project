# [FE] library-uiux.md — 더보기 시트(L4) 대상 요약 구성을 탐색과 통일

| 항목 | 값 |
|---|---|
| 대상 문서 | `docs/spec/uiux/library-uiux.md` 4.7 (L4 더보기 액션시트) · `docs/wireframe/library.html` |
| 요청 파트 | 프론트엔드 (FE 확정 2026-08-07 — 구현 반영 완료) |
| 백엔드 협의 | 불필요 — 화면 구성 통일이다 |

## 왜 필요한가

라이브러리 L4 시트는 대상 표시가 **제목 한 줄 텍스트**였고, 탐색 E12 시트는
**대상 요약(썸네일·제목·출처·저자)**이다(explore-uiux.md 4.4). 같은 "행의 더보기" 조작인데
화면마다 시트 구성이 다르면 같은 문법이 깨진다. 탐색 쪽 구성으로 통일한다.

## 수정 내용 (구현 반영 완료)

- L4 시트 상단의 대상 표시를 **탐색 E12와 동일한 대상 요약(썸네일·제목 2줄·출처·저자)**으로
  교체한다. "어느 아이템에 대한 조작인지 상단에 다시 보여준다"는 기존 규칙은 그대로다.
- 액션 배치도 동일한 문법(좌측 정렬 행 목록)을 쓴다. 메뉴 항목이 삭제 하나뿐인 것은 변화 없다.
- **라이브러리에서 빼는 조작은 두 화면 모두 위험색이다** — L4의 [라이브러리에서 삭제]와
  E12의 [라이브러리에서 제거]는 결과가 같으므로(소프트 삭제 + 드립 영구 제외) 같은 색을 쓴다.
  담기([라이브러리에 담기])는 추가 조작이라 기본색이다.

## 완료 조건

- Given 이 요청이 통합 과정에서 반영된다 / When `library-uiux.md` 4.7을 읽는다 /
  Then L4 시트 구성이 대상 요약(썸네일·제목·출처·저자) + 액션 행 목록으로,
  탐색 E12와 같은 구성임이 서술되어 있다
- Given 라이브러리 카드와 탐색 행에서 각각 더보기를 연다 / When 두 시트를 비교한다 /
  Then 대상 요약과 액션 배치의 구성이 같다(항목 내용만 다르다)
