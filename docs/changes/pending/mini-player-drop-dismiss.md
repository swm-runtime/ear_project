## 수정 내용

미니플레이어 종료 제스처를 **오른쪽→왼쪽 스와이프**에서 **아래로 끌기**로 바꿨다. 카드가 손가락을 따라 캡슐 탭 바 쪽으로 내려가며 납작해지고(scaleY 1→0.12) 살짝 좁아지며(scaleX 1→0.92) 사라진다(opacity). 이동 거리 65pt(카드 반 + 간격 8 + 캡슐 반)에서 캡슐 세로 중심에 닿는다.

- 놓을 때 진행 40% 초과 또는 아래 속도 800dp/s 초과 → 그 자리에서 마저 흡수(snappy 스프링) 후 종료(재생 중이면 정지·세션 정리, 복원 스냅샷이면 이번 실행에서 숨김). **완전히 사라진 뒤에** 정리해 카드가 툭 꺼지지 않는다.
- 미달 → 스프링 복귀.
- 위로 끌기(플레이어 열기)는 그대로. 가로 스와이프는 이제 아무 기능이 없다.
- 낭독기의 "재생 종료" 커스텀 액션은 그대로.
- 확인 팝업·실행 취소 없음(종전과 같음 — 지워지는 데이터가 없다).

### 2026-09-23 추가 — 미니플레이어가 탭 바 독으로 이사, 캡슐과 물방울 병합

PM: "애플의 컴포넌트가 합쳐지는(물방울) 애니메이션으로". iOS 26 유리는 **같은 `GlassContainer` 안**에 있어야 가까워질 때 모핑 병합된다. 그래서 미니플레이어를 각 화면(라이브러리·탐색)에서 빼고 **탭 바 독(`CapsuleTabBar`) 안에 하나만** 둔다(`MiniPlayer placement="dock"`, `GlassGroup spacing 28`). 결과:

- 아래로 끌면 카드 유리가 캡슐 유리와 한 덩어리로 붙으며 흡수된다(iOS 26). 그 밑 OS 는 종전 납작해짐만.
- **미니플레이어가 프로필 탭에서도 보인다**(종전엔 라이브러리·탐색만). 복원 스냅샷도 세 탭 모두에서 보인다 — 노출·대상 판정은 여전히 라이브러리가 하고(`useMiniPlayerResumeStore` 로 올린다), 라이브러리가 마운트돼 있는 한 유지된다.
- 탭 밖 화면(탐색 검색)은 종전대로 화면 안 절대 배치(`placement="floating"`, 병합 없음).
- 문서: library-uiux.md 87행 구성·player-uiux PL11 "미니플레이어 위치 = 탭 바 독(모든 탭)" 으로.

## 사유

PM(2026-09-23): "왼쪽으로 밀면 사라지는 대신 아래로 밀면 footer 알약에 합쳐지는 애니메이션". 탭 바가 떠 있는 캡슐이 된 뒤(2026-09-23) 미니플레이어 카드가 그 위에 얹힌 구조라, "카드를 캡슐에 넣는다"가 종료의 자연스러운 은유가 됐다. 왼쪽 스와이프는 목록 삭제 제스처와도 겹쳤다.

## 완료 조건

- Given 미니플레이어 / When 아래로 40pt 끌다 놓는다 / Then 카드가 캡슐 쪽으로 내려가며 납작해져 사라지고 재생이 종료된다
- Given 미니플레이어 / When 아래로 15pt 끌다 놓는다 / Then 카드가 제자리로 돌아오고 재생은 그대로다
- Given 미니플레이어 / When 왼쪽으로 민다 / Then 아무 일도 일어나지 않는다
- Given 낭독기 / When "재생 종료" 액션 / Then 종전과 같이 종료된다
