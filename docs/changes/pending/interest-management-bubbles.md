## 바뀐 것 (코드 반영 완료)

- **주제 = 원형 사진 버블, UI 스레드 물리**(runtime 33 — Reanimated·Gesture Handler, PM 2026-10-10 "버블 최대한 좋게"). 애플 뮤직 장르 선택·Magnetic 과 같은 모델(`services/bubble-physics.ts`): 밭 중앙으로 일정한 세기로 끌리는 중력 + 원끼리 빈틈 6pt 충돌(큰 원이 덜 밀림) + 감속. 처음엔 밭 바깥에서 날아들어 와 뭉치고, 고르면 1.2배로 커지며 이웃을 연쇄로 밀어낸다. 밭을 끌면 덩어리가 따라오고 놓으면 관성으로 미끄러지다 다시 모인다. 고요해지면 계산을 쉰다. 동작 줄이기면 끝 상태를 바로 그린다. 지름은 밭 넓이의 50% 를 덮게 주제 수로 정한다(64~116pt, ±5% 무늬). 스크롤하지 않는다. 컴포넌트 `InterestBubble`(얼굴)·`InterestBubbleField`(물리·제스처). (10-09 의 격자 배치 계산 `bubble-layout` 은 이것으로 대체)
- **선택 표시는 형태로**: 1.2배로 커짐(물리) + 그림자가 깊어짐. 색만으로 구분하지 않는다. (처음엔 흰·검정 이중 링 + 체크 배지도 있었으나 PM 이 뺐다 — 2026-10-09 22:55)
