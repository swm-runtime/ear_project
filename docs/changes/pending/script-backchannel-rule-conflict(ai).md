## 왜 기록하는가

생성 대본이 **한국인이 읽으면 어색하다**는 지적이 나와, 실제 한국어 대담 전사본과 생성 대본을 나란히 실측했다(2026-08-14). 문체 지표는 예상대로 벌어졌는데, **그중 하나가 현행 규칙과 정면으로 충돌한다.**

`writing-rules.md` "대사 쓰기"는 이렇게 규정한다.

> 맞장구만 하는 대사("아 그렇구나", "네네")를 넣지 않는다. **분량만 늘고 정보가 없다**

실측 결과는 반대 방향을 가리킨다.

| 지표 | 실제 대담 전사본 | 생성 대본 |
|---|---|---|
| 턴 중앙값 | **23자** | 42.5자 |
| 10자 이하 턴 비율 | **38.9%** | 12.0% |
| 턴 평균 | 47.5자 | 53.9자 |
| 최장 턴 | 562자 | 206자 |

**평균은 비슷한데 분포가 전혀 다르다.** 실제 대화는 아주 짧은 맞장구가 열에 넷이고 가끔 긴 발화가 터진다. 생성 대본은 전부 중간 길이로 고르게 깔린다. 사람이 어색하다고 느끼는 지점 중 하나가 여기일 가능성이 높다.

## 그런데 규칙이 틀렸다고 단정할 수 없다

현행 규칙에는 근거가 있고, 그 근거가 이 실측으로 무효가 되지 않는다.

1. **매체가 다르다.** 측정 대상은 **실제 대화 녹취**이고 우리 산출물은 **TTS 낭독 대본**이다. 사람이 말할 때의 "음", "네네"는 자연스럽지만, TTS가 또박또박 읽으면 오히려 가짜로 들릴 수 있다. **검증되지 않았다.**
2. **분량 규칙과 맞물린다.** 본문 3,500~5,250자 하한이 있는데 맞장구를 허용하면 **내용 없이 하한을 채우는 경로**가 열린다. 현행 규칙의 "분량만 늘고 정보가 없다"는 이 위험을 막고 있다.
3. **표본이 1편이다.** 짧은 턴 38.9%가 한국어 구어의 성질인지, 그 진행자의 습관인지, 그 프로그램 편집 방침인지 **1편으로는 가릴 수 없다.**

## 그래서 무엇을 하는가

**지금 규칙을 바꾸지 않는다.** 대신 미결 사항으로 등재하고 닫는 조건을 정한다.

`check.py`는 짧은 턴 비율을 **실패도 경고도 아닌 `참고`로만 찍는다.** 규칙이 확정되기 전에 기계가 한쪽을 강제하지 않게 하기 위해서다.

### 닫으려면 필요한 것

1. **corpus 3편 이상** — 개인 습관과 장르 특성을 가른다
2. **TTS 실물 비교** — 맞장구를 넣은 대본과 뺀 대본을 같은 목소리로 합성해 듣는다. 이 판단은 글로 안 되고 소리로만 된다
3. 허용한다면 **남용 방지 조건을 함께 정한다** — 예: 맞장구 대사는 본문 글자 수에 넣지 않는다(화자명을 빼는 것과 같은 이유). 그러면 분량 하한을 채우는 경로로 쓰이지 않는다

## 기록할 내용

`docs/ai/pipeline.md` 미결 사항에 아래를 추가한다. 낭독 속도 확정 항목 옆에 둔다.

> - **맞장구 대사 허용 여부** — 실제 한국어 대담 실측에서 10자 이하 턴이 38.9%인데 현행 대본 규칙은 맞장구를 금지한다(`writing-rules.md` "대사 쓰기"). 매체가 달라(실제 대화 vs TTS 낭독) 실측을 그대로 옮길 수 없으므로 **corpus 3편 이상 확보 + TTS 실물 비교**로 판정한다. 허용 시 분량 하한을 채우는 경로가 되지 않도록 **맞장구 대사를 본문 글자 수에서 제외**하는 조건을 함께 정한다.

## 함께 드러난 것 — 이건 충돌이 아니라 결함이다

같은 실측에서 **규칙과 충돌하지 않는** 이탈도 나왔다. 이쪽은 판단이 필요 없고 고치면 되는 것이라 이 문서의 대상이 아니며, `check.py`가 이미 경고로 잡는다.

| 지표 | 실제 대담 | 생성 대본 | 판정 |
|---|---|---|---|
| 합니다체 비율 | 4.8% | **30.1%** | 발표 문체다. 낮춘다 |
| 완충어 빈도(만자당) | 107.7 | **8.1** | `뭐`·`약간`·`그니까`·`되게`·`막`·`그냥`을 **한 번도 안 썼다** |

## 완료 조건

- Given corpus가 3편 이상이고 TTS 비교 청취를 마쳤다 / When 맞장구 허용 여부를 판정한다 / Then `writing-rules.md` "대사 쓰기"의 해당 항목이 판정 결과대로 고쳐져 있다
- Given 맞장구를 허용하기로 정했다 / When `writing-rules.md`를 고친다 / Then 본문 글자 수 산정에서 맞장구 대사를 제외하는 규칙이 함께 적혀 있다
- Given 이 문서를 반영한다 / When `docs/ai/pipeline.md` 미결 사항을 연다 / Then 맞장구 항목이 등재돼 있고 닫는 조건 3가지가 적혀 있다
- Given 판정이 끝나지 않았다 / When `check.py check`를 돌린다 / Then 짧은 턴 비율이 `참고`로만 출력되고 실패·경고를 만들지 않는다
