## 배경

PM 2026-10-11 23:02 "이것도 ㄱㄱ"(요일 리텐션). 종전엔 요일을 고르면 오른쪽 두 줄(주간 한 줄)을 숨겼다 — "하루 값엔 순위가 없다". 이제 그 자리에 서버가 고른 **그날의 나와의 비교**를 그린다.

## 바뀐 것 (FE 코드 반영 완료)

요일을 고른 동안 오른쪽 두 줄(윗줄 16pt 회색 · 아랫줄 아이콘 + 20pt 600)이 `daily_listening_highlight[요일]`대로 바뀐다.

| 서버 `kind` | 윗줄 | 아랫줄 |
|---|---|---|
| `more_than_last_week` | 지난주 수요일보다 (지난 주 화면: 전주 수요일보다) | ⬆ 12분 더 |
| `best_day` | 이번 주 (지난 주 화면: 그 주) | ★ 가장 많이 들은 날 |
| `listened_contents` | 그날 | ✓ 2편 들었어요 |
| `null`(0초인 날 · 반영 전 서버) | 숨김 — 자리는 지킨다(그래프가 움직이지 않는다) | |

- 그날 상위 %는 없다(하루 순위는 출렁이고, 주간이 이미 보여 준다 — PM 23:01).
- 낭독: "수요일, 32분, 지난주 수요일보다 12분 더 들었어요"처럼 요약 줄 낭독에 잇는다.
- 7칸이 아닌 응답은 통째로 무시, 모르는 `kind` 칸은 그날만 비운다.
