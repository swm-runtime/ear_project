## 왜 필요한가

카드에 `제목 / 출처·저자·길이 / 출처 배지·청취 상태`의 3줄이 쌓여 시각적 밀도가 너무 높았다.
FE 구현에서 아래처럼 개편했고(사용자 결정 2026-08-07), 문서가 이전 구성을 기준으로 남아 있어
구현과 어긋난다. **동작 규칙 소유자인 features 문서를 함께 개정해야 한다.**

## 확정된 변경 내용 (구현 반영 완료)

1. **카드 3번째 줄 제거** — 출처 배지(드립/담기)와 상태 텍스트(미청취·완료)를 없앤다.
   - 완청: **썸네일 좌상단 체크 마킹**으로 표시. 회색 제목 처리는 색이 유일한 단서가 되어
     uiux 7장(색만으로 상태 구분 금지)에 걸리므로 채택하지 않았다.
   - 듣다 만 것(in_progress): 진행률 바만 유지(텍스트 없음, a11y 라벨 "N% 들음" 제공).
   - 미청취: 표시 없음 — 기본 상태가 곧 미청취다.
2. **상단 탭을 상태 3개로 축소** — `전체 · 미청취 · 완료`. [이어 PICK] 탭을 제거한다.
3. **필터 바텀시트에 "출처" 섹션 신설** — `이어 PICK / 내가 담은 콘텐츠` 단일 선택(재탭 해제).
   탭(상태)·출처·주제는 AND 조합이므로 "미청취 + 이어 PICK" 같은 보기가 가능해진다.
   필터 아이콘 배지는 출처 + 주제 선택 개수의 합이다.
   - "내가 담은 콘텐츠"는 `source IN (save, onboarding)` — 온보딩 적립분 포함
     (library-api.md 9장의 onboarding 취급 미결도 이 방향으로 닫힌다).

## 문서에서 함께 정리할 것

- `library.md` 4.1-1의 **"담기 전용 탭은 두지 않는다"** 와의 관계 — 이번 변경은 탭이 아니라
  필터 옵션이므로 원 취지(보관함을 둘로 나눠 사용자가 관리하게 만들지 않기)는 유지되지만,
  조항 문구를 필터 구성에 맞게 다시 써야 한다. "[이어 PICK] 탭이 드립 라이브러리 역할" 서술도
  "출처 필터가 맡는다"로 바뀐다.
- `library-uiux.md` 9장 미결 **"출처 배지의 용어(드립 vs 이어 PICK)"** — 배지 자체가 사라지므로
  해소된다. 출처 이름은 필터 라벨(이어 PICK / 내가 담은 콘텐츠)로만 노출된다.
- L8(이어 PICK 빈 상태)의 진입 조건 — "탭 선택"에서 "출처 필터 = 이어 PICK 단독 적용"으로 변경.
- 8장 금지 조항 중 "[이어 PICK] 라벨의 말줄임·축약", "주제 칩을 탭 줄에 늘어놓기" 등
  탭 4개 전제의 항목들을 새 구성 기준으로 손본다.
