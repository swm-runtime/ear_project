## 바뀐 것 (코드 반영 완료)

- 커리어 정보 화면(CR)의 직군 칩: 테두리(1.5pt)를 없애고 **배경 사진**을 깐다. 고른 칩은 사진 위 검정 막 42% + 흰 글자(그림자), 고르지 않은 칩은 흰 막 74% + 검정 글자 — 밝기로 크게 갈려 색만으로 구분하지 않는다.
- 사진은 직군 전용이 아직 없어 관심 주제 사진을 물려 쓴다(`career/career.images.ts`): 개발 → IT·개발, 기획 → 생산성, 디자인 → 디자인, 마케팅·영업 → 마케팅, 운영·CS → 커뮤니케이션, 연구·교육 → 자연과학, 기타 → 커리어. 목록에 없는 직군은 기본 사진. 전용 사진이 생기면 이 파일만 바꾼다.
- **온보딩(O4) 직군 칩은 그대로**다 — 이번 범위가 아니다.
