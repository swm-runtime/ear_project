## 바뀐 것 (코드 반영 완료)

- 커리어 정보 화면(CR)의 직군 칩: 테두리(1.5pt)를 없애고 **배경 사진**을 깐다. 고른 칩은 사진 위 검정 막 42% + 흰 글자(그림자), 고르지 않은 칩은 흰 막 74% + 검정 글자 — 밝기로 크게 갈려 색만으로 구분하지 않는다.
- 사진은 **직군 전용**(PM 18:07 "다른 거 찾아서 넣어") — Openverse 에서 CC0·퍼블릭 도메인만 골라 3:1 로 주인공이 가운데 오게 잘랐다(`frontend/assets/careers/`, 출처 `SOURCES.md`). 개발=코드 띄운 노트북, 기획=흐름도 화이트보드, 디자인=와이어프레임 스케치, 마케팅·영업=악수, 운영·CS=통화, 연구·교육=현미경, 기타=노트와 펜. 목록 밖 직군은 기본 사진.
- **칩은 2열 같은 크기**(높이 56, ≈3:1) — 이름 길이대로 폭이 달라 같은 사진이 칩마다 다르게 잘렸다(18:09 "알약에 들어갈 때 사진이 잘린다").
- **온보딩(O4) 직군 칩은 그대로**다 — 이번 범위가 아니다.
