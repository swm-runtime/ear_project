# [문서] 공유 텍스트에서 '저자 · 출처' 줄을 뺀다 — 제목 / 링크 두 줄로 확정

| 항목 | 값 |
|---|---|
| 대상 문서 | `spec/uiux/share-uiux.md` 6장 · `features/share.md` 4.1·완료 조건 |
| 요청 파트 | 문서(FE 구현은 `chore(fe)/ticket-sweep-0910`에서 선반영) |
| 발행 날짜 | 2026-09-10 |
| 발견 시점 | 티켓 `tickets/frontend/archive/share-message-final-copy.md` 처리 — 2026-09-09 공유 회의 결정을 코드에 반영하며 |
| 심각도 | **중** — 문서가 확정값으로 적어 둔 형식과 코드가 어긋난 채로 남는다 |

## 왜 필요한가

2026-09-04에 공유 텍스트를 **세 줄**(`제목 ␤ 저자 · 출처 ␤ 링크`)로 잠정 확정하고 두 문서에
확정값으로 적었다. 그런데 2026-09-09 공유 회의에서 **참고한 자료(저자·출처)는 공유 메시지에
넣지 않는다**고 결정됐다.

이유는 두 가지다.
- 받는 사람이 링크를 열면 **상세에서 어차피 보인다.** 메시지에 또 실을 값이 아니다.
- **출처 문구가 길면 메시지 앱에서 링크 미리보기보다 텍스트가 먼저 잘린다.** 정작 눌러야 할
  링크가 접힌다.

최종 형식은 **A안(제목 / 링크 두 줄)** 으로 확정됐다(2026-09-10, 팀장 결정). 안내 문구를 앞에
붙이는 B안은 채택하지 않았다 — 6장의 "링크를 설명하는 문구를 덧붙이지 않는다"와 충돌한다.

## 수정 내용

### 1. `spec/uiux/share-uiux.md` 6장 — 확정 문자열 표 두 행

| 행 | 현행 | 개정 |
|---|---|---|
| 공유 텍스트의 값 | "`title` · `author_name` · `source_name` 원값" | **"`title` 원값"** — 저자·출처는 싣지 않는다 |
| 공유 텍스트 형식 | "제목 ␤ 저자 · 출처 ␤ 링크 (세 줄). 확정 2026-09-04(시안 SH3). 저자가 없으면 둘째 줄은 출처만" | **"제목 ␤ 링크 (두 줄). 확정 2026-09-10(A안)."** — 저자 유무로 줄 수가 달라지지 않는다 |

마지막 불릿의 "(제안)" 표시를 걷는다 — B안을 물리치며 **확정**됐다.

> - URL은 링크로만 전달한다 — 텍스트 안에서 링크를 설명하는 문구("아래 링크를 눌러…")를
>   덧붙이지 않는다(확정 2026-09-10 — 안내 문구를 앞에 붙이는 안을 검토했으나 채택하지 않았다).

### 2. `features/share.md` 4.1 — 텍스트 구성

현행 44행:

> - 텍스트: **콘텐츠 제목 + 저자·출처**. 저자가 없는 콘텐츠(`ai_generated`의 `author_name = null`)는 출처(`source_name`)만 싣는다 — "저자 없음"으로 채우지 않는다

개정:

> - 텍스트: **콘텐츠 제목**과 상세 링크뿐이다. 저자·출처는 **싣지 않는다**(확정 2026-09-10) —
>   링크를 열면 상세의 "참고한 자료"에서 보이고, 출처가 길면 메시지 앱에서 링크 미리보기보다
>   텍스트가 먼저 잘린다. 그래서 `author_name`이 있든 없든 **형식이 갈리지 않는다.**

35행도 함께 고친다 — "제목·저자·출처를 진입점 화면이 이미 들고 있는 값으로 쓴다"에서
**저자·출처를 뺀다.** 코드도 `ShareContentInput`에서 두 필드를 제거했다(쓰지 않는 값을 계속
모으면 다음 사람이 왜 필요한지 되짚는다).

### 3. `features/share.md` 완료 조건 두 줄

| 위치 | 현행 | 개정 |
|---|---|---|
| 103행 | "…제목·저자·출처 텍스트와 상세 연결 링크가 전달된다" | "…**제목과 상세 연결 링크**가 전달된다" |
| 105행 | "Given `author_name = null`인 콘텐츠 / … / Then 텍스트에 저자 없이 제목·출처만 실린다" | **"Given `author_name`이 있는 콘텐츠와 없는 콘텐츠 / When 각각 공유한다 / Then 두 메시지의 줄 수와 형식이 같다"** |

## 완료 조건

- Given 개정된 `share-uiux.md` 6장 / When 공유 텍스트 형식 행을 읽는다 / Then 두 줄(제목/링크)이 확정값으로 적혀 있고 `author_name`·`source_name`이 없다
- Given 개정된 `features/share.md` 4.1 / When 텍스트 구성을 읽는다 / Then 저자·출처를 싣지 않는다는 것과 그 사유가 적혀 있다
- Given 개정된 두 문서 / When `frontend/src/features/share/share.service.ts`의 `buildShareMessage`와 대조한다 / Then 줄 구성이 일치한다
- Given `features/share.md` 완료 조건 / When 저자 유무 항목을 읽는다 / Then "저자 없이 출처만"이 아니라 "형식이 같다"로 적혀 있다
