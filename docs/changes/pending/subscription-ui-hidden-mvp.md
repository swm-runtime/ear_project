## 현재 규칙

- `settings-uiux.md` 4.1: 설정에 "구독" 섹션 + 플랜 카드(무료: "무료 이용 중" + [구독 알아보기] 강조) → 구독 관리.
- `profile-uiux.md` 4.1: 헤더 플랜 줄 "무료 이용 중 · 하루 N편" + [구독 알아보기] 칩. 줄·칩 모두 구독 화면 진입. 7장 낭독: "현재 플랜, 무료 이용 중 · 하루 2편, 구독 관리 열기".
- `library-uiux.md` 7장: 잔여 표시 N = 0 은 `role=button` + "오늘 재생 0회 남음, 구독 안내 열기".
- `auth-uiux.md` 4.5 / 서버 enum: 탈퇴 사유 선택지에 `price` "구독 가격이 부담됐어요".

## 수정 내용 — **기능 플래그로 비노출, 삭제 아님**

앱에는 인앱 결제 구현이 없다(결제 라이브러리·상품 ID 없음, 서버 영수증 검증 미구현 KAN-40). Apple 은 구독을 언급하는 바이너리에 구매 가능한 IAP 상품이 같이 제출되기를 요구하므로, **결제가 실제로 붙기 전까지 구독 언급을 화면에서 뺀다.** 코드는 `IS_SUBSCRIPTION_UI_ENABLED`(`shared/lib/feature-flags.ts`, 기본 **꺼짐**, `EXPO_PUBLIC_SUBSCRIPTION_UI=on` 으로 켬) 하나로 갈린다.

각 문서에 "**MVP 바이너리(구독 UI 플래그 꺼짐)에서는 아래를 노출하지 않는다**" 단락을 추가한다. 종전 규칙은 플래그가 켜진 빌드의 규칙으로 그대로 남긴다.

| 문서 | 플래그 꺼짐(MVP) | 플래그 켜짐(종전 규칙) |
|---|---|---|
| `settings-uiux.md` 4.1 | "구독" 섹션 자체를 그리지 않는다. 계정 섹션 → 콘텐츠 섹션으로 바로 이어진다 | 구독 섹션 + 플랜 카드 |
| `profile-uiux.md` 4.1 | 헤더 플랜 줄은 **정보 표시만** — "무료 이용 중 · 하루 N편"(유료 상태 문구도 그대로). 탭 불가, [구독 알아보기] 칩 없음 | 줄·칩 → 구독 화면 |
| `profile-uiux.md` 7장 | 낭독 "현재 플랜, 무료 이용 중 · 하루 N편"(목적지 없음, role 없음) | "…, 구독 관리 열기" |
| `library-uiux.md` 7장 | N = 0: `role=button` + "**오늘 재생 0회 남음**". 탭 → 한도 안내 토스트("오늘 들을 수 있는 콘텐츠를 모두 들었어요") | "…, 구독 안내 열기" |
| `paywall.md` 4.5 | 페이월 시트로 가는 진입점을 노출하지 않는다. 한도 판정·차감·확인 팝업(4.1~4.4)은 그대로다 — 서버 판정은 바뀌지 않는다 | 페이월 노출 → 결제 → 복귀 |
| `auth-uiux.md` 4.5 | 탈퇴 사유 선택지에서 `price` 를 뺀다(7개). 서버 enum 은 그대로 — 클라이언트가 안 보낼 뿐이다 | 8개 |

- **금지** — 숨기면서 "웹에서 구독하세요" 류의 외부 결제 안내를 넣지 않는다(3.1.1 재반려). 문구는 한도 안내로만 둔다.
- 탈퇴 화면의 "구독을 이용 중이에요" 안내(활성 구독자 전용)와 보존 항목 "결제·구독 이력"(결제 이력 있는 사용자 전용)은 결제가 없는 MVP 에서 도달 불가라 손대지 않는다.
- `Subscription` 라우트는 등록만 남고 진입점이 없다(플레이스홀더 화면).

## 되돌리는 조건

KAN-40(영수증 검증) + FE 결제 라이브러리 + 스토어 IAP 상품 등록이 끝난 빌드에서 `EXPO_PUBLIC_SUBSCRIPTION_UI=on`. 그때 이 문서의 "플래그 꺼짐" 단락을 "기본 켜짐"으로 뒤집는다.

## 완료 조건

- Given 각 문서 / When 해당 절을 읽는다 / Then "MVP 바이너리(플래그 꺼짐)" 단락이 있고 종전 규칙이 플래그 켜짐 조건으로 남아 있다
- Given 플래그 꺼진 빌드 / When 설정·프로필·플레이어·라이브러리·탐색·탈퇴 화면을 본다 / Then "구독" 단어와 `Subscription` 화면으로 가는 진입점이 없다
- Given 플래그 켜진 빌드 / When 같은 화면을 본다 / Then 종전 구독 UI 가 그대로 돌아온다
