# 오프라인 저장 기능 명세서

> 연결 PRD: FR-26, FR-33 / 범위 4.2(구현 이연) / 검증계획 9.2

## ⚠️ 범위 상태 — **P1 이연 확정**

~~PRD 내 충돌(FR-26 P0 vs 4.2 이연)~~ → **확정: FR-26은 P1이다.** PRD 4.2와 6.5가 모두 P1로 정리됐다.

**본 명세는 도입 시점을 대비한 설계 문서이며 MVP 구현 대상이 아니다.**

- 서버 테이블(`OfflineDownloadRecord`)과 `plans.offline_download_enabled` 컬럼은 **지금 만들지 않는다**(`domain.md` 14장).
- 설정의 오프라인 저장 메뉴도 노출하지 않는다(`settings.md` 4.1).
- 도입 시 `domain.md`에 테이블·컬럼을 먼저 추가한 뒤 이 명세를 실행 대상으로 승격한다.

## 1. 목적 & 연결

유료 사용자가 통근 중 지하철 음영 구간·데이터 절약 상황에서도 끊김 없이 들을 수 있게 한다. 동시에 파트너 콘텐츠가 기기 밖으로 유출되지 않도록 통제한다.

- PRD FR-26 오프라인 저장(유료 전용), 앱 내 암호화 저장소 한정, 파일 내보내기·외부 접근 불가, 구독 만료 시 저장분 재생 차단
- PRD FR-33 (P0) 무단 재배포·다운로드 방지 접근 통제
- PRD 7 비기능 — 저작권·파트너 계약 준수

## 2. 진입 조건

*(P1 이연 — MVP에서는 아래 메뉴가 노출되지 않는다, `settings.md` 4.1)*

- 유료 티어(`entitlements.offline_download_enabled == true`) 사용자만
- 라이브러리 아이템 더보기 > [오프라인 저장]
- 플레이어 더보기 > [오프라인 저장]
- 설정 > 오프라인 저장 관리 (저장 목록·용량·일괄 삭제)

무료 티어에서는 **메뉴 자체를 노출하지 않는다**(잠금 아이콘으로 노출해 페이월을 띄우는 방식은 선택 — 미결 사항).

## 3. 입력값

| 값 | 설명 | 필수 |
|---|---|---|
| content_id | 저장 대상 | 필수 |
| network_policy | wifi_only / all (설정값) | 선택(기본 wifi_only) |
| 사용자 조작 | 저장 / 저장 취소 / 삭제 / 전체 삭제 | — |

## 4. 처리 로직

### 4.1 저장

1. 권한 판정 — 유료 티어가 아니면 메뉴 미노출(방어적으로 서버에서도 403)
2. 저장 가능 용량 확인 — 기기 여유 공간 부족 시 안내 후 중단
3. 서버에서 **다운로드용 서명 URL**을 발급받는다(재생용과 동일하게 단기 만료)
4. 백그라운드 다운로드 시작
   - `network_policy == wifi_only`이면 셀룰러에서는 대기 상태로 둔다
   - 동시 다운로드는 최대 3건, 나머지는 큐 대기
5. 다운로드 완료 → **앱 전용 암호화 저장소**에 저장
   - iOS: 앱 샌드박스 + Data Protection, `isExcludedFromBackup = true`
   - Android: `getFilesDir()` 내부 저장소 + 파일 암호화. 외부 저장소·공유 폴더 사용 금지
   - 파일명은 난수화하고 확장자로 오디오임을 드러내지 않는다
6. 로컬 메타(`OfflineItem`)에 기록하고 서버에도 저장 사실을 보고한다(회수 시 원격 삭제 대상 파악용 — FR-32)

### 4.2 재생 시 우선순위

- 저장분이 있고 유효하면 **로컬 파일을 우선 재생**한다(네트워크 상태와 무관)
- 재생 전 **라이선스 검증**을 수행한다
  - 온라인: 서버에 구독 유효성·콘텐츠 유효성 확인
  - 오프라인: 로컬에 캐시된 라이선스의 유효 기간으로 판정 (아래 4.3)

### 4.3 오프라인 라이선스 (구독 만료 시 차단 — FR-26)

오프라인 상태에서도 구독 만료를 판정할 수 있어야 한다.

- 저장 시 **오프라인 라이선스**를 함께 내려받는다: `{ content_id, user_id, valid_until, signature }`
- `valid_until = min(구독 만료일, 저장일 + 30일)`
- 재생 시 로컬 라이선스의 `valid_until`이 지났으면 **오프라인에서는 재생을 차단**하고 온라인 갱신을 요구한다
- 온라인 접속 시마다 라이선스를 자동 갱신한다(구독이 유효한 동안)
- 구독 만료·환불 확인 시 **즉시 모든 로컬 라이선스를 무효화**하고 저장 파일을 삭제한다

### 4.4 삭제

- 개별 삭제: 로컬 파일 + 로컬 메타 + 서버 보고 삭제
- 라이브러리에서 아이템을 삭제하면 저장분도 함께 삭제한다
- 로그아웃·탈퇴 시 전량 삭제
- 설정에서 [전체 삭제] 및 사용 용량 표시 제공

### 4.5 파트너 회수 반영 (FR-32)

- 회수 요청 시 **저장분도 노출면에 포함한다.** PRD FR-32의 "전 노출면(라이브러리·탐색·드립)"을 **저장분까지 확장 적용한 이 문서의 규칙**이다 — PRD 원문에 저장분은 없다
- 서버가 회수 목록을 관리하고, 클라이언트는 앱 실행·포그라운드 복귀 시 회수 목록을 동기화해 해당 로컬 파일을 삭제한다
- 오프라인 상태로 오래 머무는 기기는 즉시 반영이 불가능하므로, **라이선스 최대 유효 기간을 30일로 제한**해 상한을 둔다

### 4.6 재배포 방지 (FR-33)

- 파일 내보내기·공유 시트 전달·"파일" 앱 노출 일절 금지
- 기기 백업 제외
- 루팅·탈옥 기기 탐지 시 저장 기능을 비활성화한다(재생은 스트리밍으로 허용)

## 6. 데이터 모델

> **스키마는 [`docs/backend/domain.md`](../backend/domain.md)가 유일한 기준이다.** 이 문서에 테이블·컬럼을 중복 기재하지 않는다 — 두 벌을 유지하면 반드시 어긋나고, 수정 비용이 두 배가 된다.
> 컬럼을 추가·변경해야 하면 `domain.md`를 먼저 고치고 이 문서에는 동작 규칙만 남긴다.

**이 기능은 P1 이연이므로 서버 테이블을 만들지 않는다.** `OfflineDownloadRecord` · `plans.offline_download_enabled`는 domain.md에 존재하지 않으며, 도입 시점에 추가한다(domain.md 14장).

| 사용하는 것 | domain.md |
|---|---|
| `contents` — `content_version`(재발행 판정) · `status` | 5.1 |
| `audio_access_logs` — 다운로드용 서명 URL 발급 이력 | 6.5 |

- `OfflineItem` · `OfflineLicense`는 **클라이언트 로컬 전용**이다(domain.md 13.1). 아래 로컬 구조는 참고용이며 서버 스키마가 아니다.

```
OfflineItem   { content_id(PK), local_path, file_size_bytes, status, progress, downloaded_at, last_verified_at }
OfflineLicense{ content_id, user_id, valid_until, signature }
```

## 7. 예외 상황

- **다운로드 중 앱 종료**: 백그라운드 다운로드 세션으로 이어가고, 불가능하면 다음 실행 시 재개(부분 파일 이어받기).
- **다운로드 중 네트워크 전환(Wi-Fi → 셀룰러)**: `wifi_only` 정책이면 일시정지하고 Wi-Fi 복귀 시 재개.
- **저장 파일 손상**: 재생 실패 시 로컬 파일을 삭제하고 스트리밍으로 폴백한 뒤 재다운로드를 안내한다.
- **구독이 만료됐는데 기기가 계속 오프라인**: 로컬 라이선스 `valid_until`로 차단된다. 최대 노출 기간은 라이선스 유효 기간(30일 상한).
- **환불 처리 후 기기가 오프라인**: 차단 신호를 받을 수 없어, 저장 시점에 발급된 라이선스 `valid_until`까지 재생될 수 있다. **FR-26의 차단은 온라인 복귀·라이선스 갱신 시점에 즉시 적용**되며, 오프라인 잔여 위험은 30일 상한으로 관리한다(4.3).
- **콘텐츠가 재발행되어 오디오가 교체됨**: 로컬 파일의 `content_version`이 다르면 삭제 후 재다운로드를 안내한다.
- **기기 용량이 재생 중에 가득 참**: 신규 저장만 막고 기존 재생은 영향받지 않는다.
- **같은 콘텐츠를 여러 기기에 저장**: 허용한다. 기기별로 `OfflineDownloadRecord`를 남긴다.
- **루팅·탈옥 기기**: 저장 기능 비활성화, 스트리밍만 허용.

## 8. 완료 조건

- Given 유료 사용자 / When 콘텐츠를 오프라인 저장한다 / Then 앱 전용 암호화 저장소에 저장되고 저장 배지가 표시된다
- Given 저장된 콘텐츠가 있다 / When 네트워크를 차단하고 재생한다 / Then 정상적으로 재생된다
- Given 저장된 콘텐츠가 있다 / When 저장을 해제한다 / Then 로컬 파일이 삭제되고 기기 용량이 회수된다
- Given 유료 구독이 만료되었다 / When 저장분을 재생 시도한다 / Then 재생이 차단되고 구독 안내가 노출된다
- Given 파트너가 콘텐츠를 회수했다 / When 앱이 온라인으로 동기화된다 / Then 해당 저장 파일이 기기에서 삭제된다
- Given 저장된 오디오 파일 / When 기기의 파일 앱·공유 시트로 접근을 시도한다 / Then 파일이 노출되지 않는다
- Given 무료 사용자 / When 라이브러리 아이템 더보기를 연다 / Then 오프라인 저장 메뉴가 노출되지 않는다
- Given Wi-Fi 전용 설정 / When 셀룰러 상태에서 저장을 요청한다 / Then 대기 상태가 되고 Wi-Fi 연결 시 자동으로 다운로드된다
- Given 라이브러리에서 저장된 아이템을 삭제한다 / When 삭제가 완료된다 / Then 로컬 저장 파일도 함께 삭제된다
