# 커리어 정보 기능 명세서

> 연결 PRD: FR-04 / 사용자흐름 5.5
> **관심사 관리에서 분리된 별도 화면이다**(합의 2026-08-06). 주제 편집은 `interest-management.md`가 소유한다.

## 1. 목적 & 연결

온보딩에서 선택으로 받은 커리어 정보 — 직군·직무·연차 — 를 사용자가 언제든 입력·수정할 수 있게 한다. 커리어는 **추천 랭킹의 보조 신호**다. 드립 편성 대상을 정하는 관심 주제와 역할이 달라 화면도 분리한다.

- PRD FR-04 (P0) 커리어 정보 이후 수정 가능(최초 입력은 온보딩에서, 건너뛰기 허용)
- 진입 카드·요약 표시는 `profile.md` 4.4 · `settings.md` 4.1이 소유하고, 이 문서는 **편집 화면만** 소유한다

## 2. 진입 조건

- 프로필 > [커리어 정보] 카드 (`profile.md` 4.1·4.4)
- 설정 > 콘텐츠 > 커리어 정보 (`settings.md` 4.1)
- 온보딩을 완료한 로그인 사용자만 접근

## 3. 입력값

| 값 | 설명 | 필수 |
|---|---|---|
| job_category | 직군 | 선택 |
| job_title | 직무 | 선택 |
| years_of_experience | 연차 구간 enum(0-1/2-3/4-6/7+) | 선택 |

- **온보딩 커리어 단계(`onboarding.md` 3장)와 같은 필드·같은 구간 값을 쓴다.** 두 화면의 선택지가 다르면 같은 컬럼에 다른 값 체계가 쌓인다.
- 세 값 모두 선택이다. 커리어 입력을 강제하는 지점은 어디에도 없다(온보딩과 동일).

## 4. 처리 로직

### 4.1 화면 구성

```
[직군]   선택형
[직무]   선택형
[연차]   구간 선택 (0-1 / 2-3 / 4-6 / 7+)
[저장]   변경 사항이 있을 때만 활성
```

### 4.2 저장 규칙

- [저장] 탭 → **확인 팝업 없이 저장한다.** 주제 해제(신규 적립 중단)와 달리 잃는 것이 없어 확인할 내용이 없다.
- 변경은 **추천 랭킹의 보조 신호로 즉시 반영**된다. 드립 편성 대상과 기존 라이브러리에는 영향이 없다.
- 값을 비워 저장하는 것도 허용한다 — 미입력 상태로 되돌아간다.
- 저장 성공 시 토스트 후 이전 화면으로 복귀한다. 프로필·설정의 요약은 복귀 시 재조회된다(`profile.md` 4.4).

## 5. 화면 상태

| 상태 | 화면 |
|---|---|
| 로딩 | 필드 스켈레톤 |
| 정상(입력됨) | 현재 값이 채워진 폼 + [저장] 비활성 |
| 미입력 | 빈 폼 + "입력하면 추천이 정확해져요" |
| 변경 있음 | [저장] 활성 |
| 저장 중 | [저장] 로딩, 조작 차단 |
| 저장 성공 | 토스트 후 이전 화면 복귀 |
| 저장 실패 | 인라인 에러 + [다시 시도]. 편집 상태는 유지 |
| 뒤로가기(변경 있음) | "변경 사항을 저장하지 않고 나갈까요?" 팝업 |

## 6. 데이터 모델

> **스키마는 [`docs/backend/domain.md`](../backend/domain.md)가 유일한 기준이다.** 이 문서에 테이블·컬럼을 중복 기재하지 않는다 — 두 벌을 유지하면 반드시 어긋나고, 수정 비용이 두 배가 된다.
> 컬럼을 추가·변경해야 하면 `domain.md`를 먼저 고치고 이 문서에는 동작 규칙만 남긴다.

| 사용하는 것 | domain.md |
|---|---|
| `users` — 커리어 3필드 (`UserCareer` 별도 테이블 없음) | 3.1 |

- 커리어 전용 테이블·이력 테이블을 만들지 않는다. 변경 이력이 필요해지면 `domain.md`를 먼저 고친다.

## 7. 예외 상황

- **여러 기기에서 동시 편집**: 마지막 저장이 최종(last-write-wins).
- **저장 도중 앱 종료**: 서버 트랜잭션 단위로 전부 반영 또는 전부 미반영.
- **오프라인에서 저장 시도**: 저장 실패 처리와 동일 — 인라인 에러 + [다시 시도], 편집 상태 유지.

## 8. 완료 조건

- Given 프로필의 [커리어 정보] 카드 / When 탭한다 / Then 커리어 정보 화면이 열린다(관심사 관리 화면이 아니다)
- Given 커리어 정보를 수정한다 / When 저장한다 / Then 확인 팝업 없이 저장되고 라이브러리 콘텐츠는 변하지 않는다
- Given 커리어를 저장하고 프로필로 복귀한다 / When 커리어 정보 카드를 본다 / Then 변경된 요약이 표시된다
- Given 커리어 미입력 사용자 / When 화면에 진입한다 / Then 빈 폼과 입력 유도 문구가 노출된다
- Given 값을 모두 비우고 저장한다 / When 프로필로 복귀한다 / Then 커리어 카드가 미입력 상태로 표시된다
- Given 변경 사항이 있는 상태 / When 뒤로가기를 누른다 / Then 저장하지 않고 나갈지 확인하는 팝업이 노출된다
