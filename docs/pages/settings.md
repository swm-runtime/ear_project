# 설정 기능 명세서

> 연결 PRD: FR-02, FR-05, FR-06, FR-19, FR-28, FR-31

## 1. 목적 & 연결

계정·구독·관심사·알림 등 사용자가 서비스 동작을 조정하는 모든 진입점을 한곳에 모은다. 설정 자체는 대부분 하위 기능으로 연결하는 허브이며, 상세 로직은 각 기능 명세를 따른다.

- PRD FR-02 (P0) 로그아웃·회원 탈퇴 → `auth.md`
- PRD FR-05 (P0) 관심 주제·커리어 정보 일괄 편집 → `interest-management.md`
- PRD FR-06 (P1) 주제 자동 확장 토글 → `interest-management.md`
- PRD FR-19 (P1) 알림 수신 설정 → `notification.md`
- PRD FR-28/31 (P0) 구독 상태·요금제 변경·해지 → `subscription.md`

## 2. 진입 조건

- **프로필 화면 우상단의 설정 아이콘** (`profile.md` 4.1) — 유일한 진입점이다
- 온보딩 완료 사용자만 접근 가능

**설정은 하단 탭이 아니다**

- 하단 탭은 라이브러리 / 탐색 / 프로필 3개다(`library.md` 2). 설정은 프로필 안에 있다.
- 진입 방향이 프로필 → 설정이므로 **설정 화면에는 프로필로 되돌아가는 계정 카드를 두지 않는다.** 방금 지나온 화면으로 다시 보내는 항목은 경로만 헷갈리게 한다.

## 3. 입력값

설정 화면 자체는 서버에서 아래를 조회한다.

| 값 | 설명 |
|---|---|
| user.email, user.is_email_verified | 계정 섹션의 이메일 항목 표시 (닉네임·제공자는 프로필이 담당). **두 값을 함께 받아야 "미인증" 상태를 구분할 수 있다** |
| user.tier, subscription.expires_at | 구독 요약 표시 |
| interest_summary | 선택한 주제 개수·대표 주제명 |
| user_settings | 배속·자동 확장·이어 Pick 알림(내부명: 드립 알림) 수신 여부 (한 테이블에서 조회) |
| app_version, min_supported_version | 버전 정보·업데이트 안내. 최소 지원 버전은 **배포 설정**에서 온다 |

사용자 입력은 각 항목 탭(내비게이션) 또는 토글 조작.

## 4. 처리 로직

### 4.1 메뉴 구성

| 섹션 | 항목 | 동작 |
|---|---|---|
| 계정 | 이메일 | 미등록이면 [등록], **미인증이면 "인증되지 않음" 배지 + [인증하기]·[변경]**, 인증됐으면 [변경] → 이메일 코드 인증 (`auth.md` 4.4~4.5). 상태 구분은 `profile.md` 4.3과 동일하다 |
| 구독 | 현재 티어·다음 결제일 | → 구독 관리 (`subscription.md`) |
| 콘텐츠 | 관심 주제 관리 | → 관심사 관리 (`interest-management.md`) |
| 콘텐츠 | 커리어 정보 | → 관심사 관리 내 커리어 섹션 |
| 콘텐츠 | 주제 자동 확장 (P1) | 토글 — 즉시 저장 |
| 재생 | 기본 배속 | 선택 시트 — 즉시 저장 |
| 재생 | 오프라인 저장 관리 **(P1 이연 — 메뉴 미노출)** | → 저장 목록 (`offline-download.md`) |
| 알림 | 이어 Pick 알림 (P1) | 토글 — 즉시 저장. 사용자 노출 명칭은 **"이어 Pick 알림"** 이다(합의 2026-08-06 — "드립"은 내부 용어라 화면에 노출하지 않는다) |
| 정보 | 공지사항 | **인앱 화면**(합의 2026-08-06). 화면 명세는 추후 작성한다 |
| 정보 | 이용약관 / 개인정보처리방침 | 인앱 브라우저 |
| 정보 | 앱 버전 | 최신 아님이면 [업데이트] 노출 |
| 지원 | 문의하기 | **카카오톡 채널**로 연결(합의 2026-08-06) |
| 계정 | 로그아웃 | 확인 팝업 → `auth.md` 4.2 |
| 계정 | 회원 탈퇴 | → 탈퇴 화면 (`auth.md` 4.3) |

### 4.2 토글 저장 규칙

- 토글은 **낙관적 UI**로 즉시 반영하고 서버에 비동기 저장한다
- 저장 실패 시 토글을 원상 복구하고 토스트로 알린다
- 별도 [저장] 버튼을 두지 않는다 (관심사 관리 화면은 예외 — 일괄 편집이므로 저장 버튼 사용)

### 4.3 알림 토글과 OS 권한의 관계

- OS 알림 권한이 거부된 상태에서 앱 내 토글을 켜려 하면, 앱 설정 화면으로 이동을 안내한다("기기 설정에서 알림을 허용해주세요" + [설정 열기])
- OS 권한이 허용되어 있으면 앱 내 토글만으로 제어한다
- **알림 사전 안내 유도 배너** — 온보딩에서 사전 안내를 보지 못해 OS 권한이 미결정인 사용자를 위해, 알림 섹션에 유도 배너를 상시 노출한다(합의 2026-08-06 — `notification.md` 미결의 **(b)안 채택**). 배너 탭 → 사전 안내 → [알림 받기]에서 OS 다이얼로그를 띄운다. 권한이 결정되면(허용·거부) 배너를 숨긴다. 문구·상세 규칙은 `notification.md`가 소유한다
- 상세는 `notification.md`

### 4.4 미로그인·세션 만료

- 설정 화면 조회 중 세션이 만료되면 시작 화면으로 이동한다(다른 화면과 동일한 공통 처리)

## 5. 화면 상태

| 상태 | 화면 |
|---|---|
| 로딩 | 상단 계정·구독 카드 스켈레톤, 나머지 메뉴는 즉시 노출 |
| 정상 | 섹션 구분 리스트 |
| 무료(라이트) 사용자 | 구독 섹션에 "무료 이용 중" + [구독 알아보기] 강조 |
| 유료 사용자 | 구독 섹션에 티어명 + 다음 결제일 |
| 해지 예약 | "N월 N일까지 이용 가능" 표시 |
| 조회 실패 | 계정·구독 카드에 "정보를 불러올 수 없어요" + [다시 시도]. 나머지 메뉴는 정상 동작 |
| 토글 저장 중 | 토글 자체는 이미 전환된 상태(낙관적) |
| 토글 저장 실패 | 토글 원복 + 토스트 |
| 업데이트 있음 | 앱 버전 항목에 배지 + [업데이트] |
| 알림 유도 배너 | OS 권한 미결정 사용자에게 알림 섹션에 사전 안내 유도 배너 노출 |
| 이메일 미등록 | 계정 섹션 이메일 항목에 "등록되지 않음" + [등록] |
| 이메일 미인증 | 주소 + **"인증되지 않음" 배지** + [인증하기]·[변경] |
| 로그아웃 확인 | 팝업 "로그아웃할까요?" [취소]/[로그아웃] |

## 6. 데이터 모델

> **스키마는 [`docs/backend/domain.md`](../backend/domain.md)가 유일한 기준이다.** 이 문서에 테이블·컬럼을 중복 기재하지 않는다 — 두 벌을 유지하면 반드시 어긋나고, 수정 비용이 두 배가 된다.
> 컬럼을 추가·변경해야 하면 `domain.md`를 먼저 고치고 이 문서에는 동작 규칙만 남긴다.

| 사용하는 것 | domain.md |
|---|---|
| `user_settings` — 배속·자동확장·드립 알림을 **한 테이블로 통합** | 3.5 |
| `users` — 계정 요약·커리어 | 3.1 |
| `device_tokens` — OS 권한 상태는 **기기 단위**라 여기에만 있다 | 3.6 |
| `subscriptions` — 구독 요약 | 8.2 |

- `UserPlayerSetting` · `UserInterestSetting` · `NotificationSetting` · `UserOfflineSetting` 4개는 `user_settings` 하나로 통합됐다(domain.md 14장).

## 7. 예외 상황

- **토글 연타**: 마지막 상태를 최종으로 삼고, 요청에 시퀀스를 실어 오래된 응답을 무시한다.
- **오프라인 상태에서 설정 진입**: 캐시된 계정·구독 정보를 노출하고 토글 조작은 큐에 적재해 온라인 복귀 시 동기화한다.
- **다른 기기에서 구독을 해지한 상태**: 설정 진입 시 구독 상태를 재동기화해 최신 상태를 표시한다.
- **OS 설정에서 알림 권한을 끄고 앱으로 복귀**: 포그라운드 복귀 시 권한 상태를 재확인해 토글 표시를 갱신한다.
- **오프라인 저장 기능이 P1 이연 상태**(PRD 4.2 / FR-26): 해당 메뉴를 아예 노출하지 않는다. 도입 시 IA 추가 필요.
- **문의하기에서 카카오톡 채널을 열 수 없는 경우**(미설치·열기 실패): 채널 링크를 복사할 수 있는 다이얼로그로 폴백.

## 8. 완료 조건

- Given 무료(라이트) 사용자 / When 설정에 진입한다 / Then 구독 섹션에 "무료 이용 중"과 구독 안내 진입점이 노출된다
- Given 프로 구독 중인 사용자 / When 설정에 진입한다 / Then 현재 티어와 다음 결제일이 표시된다
- Given 기본 배속을 1.2로 변경한다 / When 콘텐츠를 재생한다 / Then 1.2배속으로 재생된다
- Given OS 알림 권한이 거부된 상태 / When 이어 Pick 알림 토글을 켠다 / Then 기기 설정 이동 안내가 노출되고 토글은 켜지지 않는다
- Given 온보딩에서 알림 사전 안내를 보지 못했고 OS 권한이 미결정인 사용자 / When 설정에 진입한다 / Then 알림 섹션에 사전 안내 유도 배너가 노출된다
- Given 설정 화면 / When [문의하기]를 탭한다 / Then 카카오톡 채널로 연결된다
- Given 설정 화면 / When [공지사항]을 탭한다 / Then 인앱 화면으로 공지 목록이 열린다
- Given 토글을 켰는데 서버 저장이 실패한다 / When 응답을 받는다 / Then 토글이 원래 상태로 되돌아가고 실패 토스트가 노출된다
- Given 설정 화면 / When [로그아웃]을 누르고 확인한다 / Then 로컬 데이터가 삭제되고 시작 화면으로 이동한다
- Given 앱 버전이 최신이 아니다 / When 설정에 진입한다 / Then 앱 버전 항목에 업데이트 배지가 노출된다
