# 탐색 · 검색 기능 명세서

> 연결 PRD: FR-21, FR-22, FR-15, FR-27 / 사용자흐름 5.3

## 1. 목적 & 연결

드립으로 받는 것 외에 사용자가 직접 콘텐츠를 발견하고 담을 수 있는 능동 경로. 무료 사용자의 주 사용 경로이기도 하다(무료는 드립 없음, 담기 무제한 — PRD 4.1).

- PRD FR-21 (P0) 추천 피드·주제 필터로 발견하고 담기. 담기는 무제한
- PRD FR-22 (P1) 키워드 검색
- PRD FR-15 (P0) 소비 신호를 추천에 반영
- PRD FR-27 (P1) OS 공유 시트로 공유
- PRD 사용자흐름 5.3

## 2. 진입 조건

- 하단 탭에서 [탐색] 선택
- 라이브러리 빈 상태에서 [탐색 둘러보기] 탭
- 온보딩 완료 후 안내를 통해 진입

## 3. 입력값

**피드 조회**

| 값 | 설명 | 필수 |
|---|---|---|
| user_id | 토큰에서 도출 | 필수 |
| topic_filter | 주제 id 목록 | 선택 |
| cursor | 페이지네이션 커서 | 선택 |

**검색 (FR-22, P1)**

| 값 | 설명 | 필수 |
|---|---|---|
| query | 키워드 | 필수, 2자 이상 |
| topic_filter | 주제 필터 | 선택 |

**사용자 조작**: 카드 탭(즉시 재생) / [담기] / [더보기] > 공유·상세

## 4. 처리 로직

### 4.1 추천 피드 구성

서버가 섹션 단위로 피드를 구성해 내려준다. 섹션 순서·구성은 서버 제어(클라이언트 하드코딩 금지).

| 섹션 | 규칙 |
|---|---|
| 관심사 기반 추천 | 사용자 `UserInterest` + 소비 신호(FR-15) 기반 랭킹 |
| 새로 나온 콘텐츠 | `published_at` 최신순 |
| 인기 콘텐츠 | 기간 내 재생·완청 수 기준 |
| 주제별 모아보기 | 사용자 관심 주제별 묶음 |

- 소비 신호가 부족한 신규 사용자는 인기·신규 섹션 비중을 높인다(콜드스타트, FR-17)
- **이미 라이브러리에 있는 콘텐츠는 피드에서 제외하지 않는다.** 대신 카드에 "라이브러리에 있음" 표시를 하고 [담기] 버튼을 비활성화한다 — 초기 콘텐츠 풀이 작아(PRD 8.1) 제외하면 피드가 비어버린다
- 파트너 회수 콘텐츠(FR-32)는 서버 단계에서 제외

### 4.2 주제 필터

- 상단 가로 스크롤 칩. 사용자의 관심 주제를 앞쪽에 배치하고 나머지 주제를 뒤에 붙인다
- 필터 선택 시 섹션 구조를 버리고 **단일 그리드 목록**으로 전환한다
- 다중 선택은 OR 조합

### 4.3 담기

- [담기] 탭 → `LibraryItem(source = save)` 생성
- **횟수 제한 없음. 무료 티어에서도 페이월을 노출하지 않는다**(PRD 5.4 명시)
- 담기 성공 시 버튼을 "담김" 상태로 전환 + 토스트 "라이브러리에 담았어요" + [보러가기]
- 이미 담긴 콘텐츠를 다시 탭하면 담기 해제(라이브러리에서 삭제)한다. 이 경우 드립 재적립 제외 규칙은 적용하지 않는다(사용자가 탐색에서 직접 되돌린 것이므로)

### 4.4 카드 탭 → 즉시 재생

- 카드 본문 탭 = 즉시 재생(PRD 5.3). 담기 여부와 무관
- **무료 재생 한도 판정** 수행 → 차단 시 페이월
- 탐색에서 재생한 콘텐츠는 라이브러리에 자동 적립한다(`source = save`) — 재생 이력이 라이브러리에서 이어듣기로 이어져야 하므로

### 4.5 검색 (FR-22, P1)

- 검색창은 상단 고정. 탭하면 검색 화면으로 전환
- 2자 이상 입력 시 300ms 디바운스로 자동 검색
- 제목·설명·저자·주제명을 대상으로 검색
- 최근 검색어 로컬 10건 저장, 개별·전체 삭제 가능
- **빈 결과 UX가 중요하다**(초기 콘텐츠 풀 작음 — PRD 8.1): "‘OO’ 검색 결과가 없어요" + 관련 주제 추천 + 인기 콘텐츠 노출

### 4.6 공유 (FR-27, P1)

- 더보기 > [공유] → OS 공유 시트
- 공유 텍스트: 콘텐츠 제목 + 저자·출처 + 링크
- 링크는 MVP에서 **스토어 링크**로 대체한다(PRD 4.2 — 수신자용 웹 랜딩 비범위)

## 5. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 로딩 | 섹션별 스켈레톤 |
| 정상(필터 없음) | 검색창 + 주제 칩 + 섹션형 피드(가로 스크롤 카드) |
| 정상(필터 있음) | 검색창 + 선택 칩 강조 + 세로 그리드 목록 |
| 피드 비어 있음 | "준비된 콘텐츠가 곧 늘어나요" + [라이브러리로 가기] |
| 필터 결과 없음 | "이 주제의 콘텐츠는 아직 없어요" + [필터 해제] |
| 검색 초기 | 최근 검색어 + 추천 키워드 |
| 검색 중 | 인라인 로딩 |
| 검색 결과 없음 | 안내 + 관련 주제 칩 + 인기 콘텐츠 리스트 |
| 담기 처리 중 | 버튼 로딩(중복 탭 차단) |
| 담기 완료 | "담김" 상태 + 토스트 |
| 재생 차단 | 페이월 바텀시트 |
| 네트워크 오류 | 에러 화면 + [다시 시도]. 캐시된 피드가 있으면 캐시 노출 + 오프라인 배너 |
| 재생 중 | 하단 미니플레이어 유지 |

## 7. 예외 상황

- **담기 요청 중복 탭**: 클라이언트에서 버튼을 즉시 비활성화하고, 서버는 `(user_id, content_id)` 유니크 제약으로 멱등 처리한다.
- **담기 → 즉시 담기 해제 연타**: 마지막 요청 상태를 최종으로 삼되, 서버 응답 순서가 뒤바뀔 수 있으므로 요청에 클라이언트 시퀀스를 실어 오래된 응답은 무시한다.
- **재생 시도했으나 페이월로 차단됨**: 라이브러리 자동 적립(4.4)은 수행하지 않는다. 재생이 실제로 시작된 경우에만 적립한다.
- **검색어에 특수문자·이모지만 입력**: 검색을 실행하지 않고 "검색어를 입력해주세요" 유지.
- **검색 중 네트워크 끊김**: 이전 결과를 유지하고 상단 배너로 알린다.
- **피드 스크롤 도중 콘텐츠가 회수됨**: 재생 시 403 → "제공이 종료된 콘텐츠예요" 후 목록에서 제거.
- **관심 주제가 0개인 사용자**(관심사 관리에서 전부 해제): 관심사 기반 섹션을 숨기고 인기·신규 섹션만 노출한다.
- **공유 시트에서 사용자가 취소**: 아무 동작 없음. 공유 신호도 기록하지 않는다(시트 오픈만으로는 공유가 아님).

## 8. 완료 조건

- Given 관심 주제가 설정된 사용자 / When 탐색 탭에 진입한다 / Then 관심사 기반 섹션이 상단에 포함된 피드가 노출된다
- Given 무료 사용자가 오늘 이미 2편을 재생했다 / When 탐색에서 콘텐츠를 담는다 / Then 페이월 없이 정상적으로 담긴다
- Given 무료 사용자가 오늘 이미 2편을 재생했다 / When 탐색에서 카드를 탭해 재생을 시도한다 / Then 페이월이 노출되고 라이브러리에도 적립되지 않는다
- Given 탐색에서 콘텐츠를 탭해 재생했다 / When 라이브러리로 이동한다 / Then 해당 콘텐츠가 라이브러리에 담겨 있고 재생 위치가 유지된다
- Given 이미 라이브러리에 있는 콘텐츠 / When 탐색 피드에서 본다 / Then "라이브러리에 있음"으로 표시되고 담기 버튼이 비활성이다
- Given 주제 필터를 2개 선택한다 / When 목록을 본다 / Then 두 주제 중 하나라도 해당하는 콘텐츠가 노출된다
- Given 결과가 없는 키워드로 검색한다 / When 결과 화면을 본다 / Then 빈 결과 안내와 함께 관련 주제·인기 콘텐츠가 대체 노출된다
- Given 콘텐츠 상세에서 [공유]를 누른다 / When OS 공유 시트가 열린다 / Then 제목·저자·스토어 링크가 포함된 텍스트가 전달된다

## 미결 사항

- 탐색 확장 필터(시리즈 여부·출처별)는 중분류 확정 후 구체화 — PRD 4.2에서 MVP 제외
- 검색(FR-22)은 P1 — MVP 일정에서 제외 시 검색창 자체를 숨길지, 비활성으로 둘지 결정 필요
- 피드 섹션 구성·순서의 운영 변경 수단(어드민 or 코드 배포) 미정
