# 주간 회고

매주 팀 회고와 다음 주 계획을 기록한다. **원본은 여기이고**, 구글 문서는 회의 중 같이 쓰는 작업대다.

## 규칙

- 파일명은 `YYYY-Wn.md` — `2026-W2.md`는 2026년 9월 2주차다. 월이 바뀌면 주차가 겹치므로 **월을 파일 안 제목에 적는다**
- 회의에서 나온 말을 **다듬지 않고 옮긴다.** 읽기 좋게 고치면 그때의 판단 근거가 사라진다. 오탈자 정도만 바로잡는다
- 담당자별 계획은 **누가 무엇을**이 드러나게 유지한다. "우리가 한다"로 뭉치면 다음 주에 아무도 안 한 일이 된다
- 결정이 난 항목은 그 주 문서에 **결정으로 표시**하고, 후속 작업이 생기면 `tickets/`로 발행해 연결한다 — 회고에만 적어두면 목록에서 사라진다
