# references/ — 롤모델 전사본 (내부 분석용)

> 용도: 스타일 분석의 입력. 분석 결과(구조 수치·디렉션)만 `skills/draft/`로 넘어가고,
> **전사본 자체는 프롬프트 자산(examples/)에 절대 넣지 않는다** — 타인 표현의 전이 차단 (spec/09 논의, 2026-08-27 합의).

## 넣는 방법

- 파일명: `{쇼이름}-{회차나 날짜}.txt` (예: `어쩌다어른-ep12.txt`)
- 파일 맨 위에 한 줄 태그: `배우고 싶은 것: (예: 티키타카 리듬 / 도입 훅 / 비유 전개)`
- 화자 분리가 있는 전사본(클로바노트 등) 권장. 타임스탬프 있으면 더 좋음
- 쇼당 1~3편, 전체 2~4개 쇼 이내 (요소별 분담 원칙 — 스타일 평균화 방지)

## 규칙

1. 내부 분석 1회 용도 — 분석 완료 후 보관 최소화, 재배포·외부 공유 금지
2. 소스 확보는 합법 경로로 — 오디오 팟캐스트 공식 RSS 배포본 또는 유튜브 자막 패널 (영상·음원 직접 다운로드 금지)
3. 분석 산출물(디렉션·구조 수치)에는 전사본의 문장을 직접 인용하지 않는다 — 짧은 설명용 인용(한두 문장, 출처 명시)만 예외
