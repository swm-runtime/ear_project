# 썸네일 생성 프롬프트 (프롬프트 자산)

> 버전: **thumb-v3** (2026-09-10) · 원본: 박수헌이 ChatGPT 웹에서 쓰던 프롬프트를 그대로 옮김 · 실행: 워커 `thumbnail` 단계(OpenAI 이미지 API)
>
> **v3 변경**: **모서리를 둥글게 그리지 말 것**을 명시했다. v2까지의 "모서리가 둥글게 잘립니다"는
> *앱이 표시할 때 깎는다*는 설명이었는데 모델이 **"둥근 모서리를 그려라"로 읽어**, PNG 안에 둥근 사각형을
> 그려 넣고 앱이 그것을 다시 깎았다. 편마다 둥근 정도가 달라 한 장만 유독 둥글게 보이는 문제
> (확정 2026-09-10 박수헌). 원본은 **가장자리까지 꽉 찬 정사각형(full-bleed)** 이어야 한다.
>
> **v2 변경**: 오른쪽 위 구분 표시를 **"사선 띠" → "꽉 채운 직각삼각형(코너 웨지)"** 으로 확정했다.
> v1의 "사선 띠"는 해석이 갈려 어떤 편은 가는 리본으로, 어떤 편은 꽉 채운 삼각형으로 나왔다.
> **꽉 채운 쪽이 작은 크기에서 훨씬 잘 보인다**(확정 2026-09-10 박수헌 — gpt-image-2 실측 비교).
> 슬롯 4개를 워커가 채운다 — `{제목}` = 에피소드 제목 · `{주제 분류}` = 중분류 · `{핵심 개념}` = 한 줄 요약(`episodes.one_liner`) · `{띠 색}` = 대분류 색(아래 표, settings `thumbnail.colors`)

당신은 오디오 콘텐츠 앱의 썸네일 일러스트를 만듭니다.

[규격]
- 정사각형 1:1, 1024×1024px
- 한 장이 여러 크기로 쓰입니다:
  · 플레이어 전체 아트워크 — 화면 폭 전체 (약 340pt)
  · 탐색 추천 카드 — 화면 폭 전체
  · 탐색 타일 — 156pt
  · 목록·상세 썸네일 — 72pt
  · 미니 플레이어 — 44pt (가장 작음)
- **정사각형 캔버스를 가장자리까지 꽉 채웁니다(full-bleed).**
  · **모서리를 둥글게 깎지 마세요.** 네 꼭짓점은 직각이어야 합니다.
  · 이미지 안에 둥근 사각형 카드·액자·여백·바깥 테두리를 그리지 마세요.
  · 둥근 모서리는 **앱이 표시할 때 잘라냅니다**(12~16pt). 원본에 미리 그리면
    이중으로 깎여 편마다 모양이 달라집니다.
- 표시 시 모서리가 잘리므로, 가장자리 10% 안쪽에 중요한 요소를 두지 마세요.

[디자인 테마]
- 미니멀, 절제된 톤. 배경은 단색 또는 아주 완만한 그라데이션.
- 앱 배경이 순백(#FFFFFF)입니다. 썸네일 배경을 흰색으로 두지 마세요 —
  경계가 사라집니다.
- 앱 팔레트는 무채색 중심입니다(#1A1A1E / #6E6E76 / #F5F5F7).
  썸네일은 주제색 하나를 골라 그 위에 얹되, 형광·네온은 쓰지 마세요.
- 한 이미지에 색은 2~3개까지. 그 이상은 작게 줄이면 진흙이 됩니다.
- 오른쪽 위 모서리를 **꽉 채운 직각삼각형**으로 잘라 색을 칠해 콘텐츠를 구분합니다.
  · 위쪽 가장자리의 한 점과 오른쪽 가장자리의 한 점을 잇는 **직선 하나로 모서리를 자르고,
    잘려 나온 삼각형 내부를 단색으로 빈틈없이 칠합니다.**
  · **가늘고 긴 띠(리본·스트라이프)가 아닙니다.** 삼각형 안에 배경이 비치는 부분이 없어야 합니다.
  · 삼각형의 두 직각변은 이미지 위쪽·오른쪽 가장자리에 **딱 붙습니다.** 안쪽으로 띄우지 않습니다.
  · 넓이는 전체 이미지의 8~12%.
  · 경계는 선명한 직선 한 개. 테두리·그림자·그라데이션·질감 없음.
  이 삼각형의 색: {띠 색}

[시인성 — 가장 중요]
- 44pt로 줄여도 무엇인지 알아볼 수 있어야 합니다.
  주제를 나타내는 요소는 딱 하나, 화면 중앙에 크게.
- 동시에 340pt로 키웠을 때 허전하지 않아야 합니다.
  질감·그라데이션·명암으로 깊이를 주되, 형태를 늘리지는 마세요.
  → 작게 보면 하나의 실루엣, 크게 보면 결이 보이는 구성.
- 가는 선, 작은 디테일, 촘촘한 패턴, 여러 개의 작은 사물 금지.
  44pt에서 전부 뭉갭니다.
- 배경과 대비를 강하게.

[금지]
- 글자·숫자·로고·워터마크 일절 없음 (작아서 안 읽히고 앱이 제목을 따로 표시합니다)
- 사진 실사, 스톡 이미지풍
- 사람 얼굴, 특정 인물, 실존 브랜드·제품
- 액자, 테두리, 그림자 박스
- **둥근 모서리, 둥근 사각형 카드, 캔버스 바깥 여백** (원본은 가장자리까지 꽉 찬 정사각형)

[주제]
제목: {제목}
주제 분류: {주제 분류}
핵심 개념: {핵심 개념}

핵심 개념을 은유하는 단순한 도형·오브제 하나로 표현하세요.
제목을 글자로 쓰지 말고, 개념을 형태로 바꾸세요.

[출력]
정사각형 이미지 1장.

## 대분류별 띠 색 (thumb-v1 기본값 — settings `thumbnail.colors`, 콘솔 설정 화면에서 바꾼다)

앱 팔레트(무채색)에 얹었을 때 서로 구분되고 형광이 아닌 8색. 44pt에서 띠는 작은 점 크기라 명도·색상이 모두 달라야 한다.

| 대분류 | 색 이름 | HEX |
|---|---|---|
| 돈·경제 | 딥 그린 | #2F6B4F |
| 비즈니스 | 네이비 | #2B4C7E |
| 과학·기술 | 틸 | #2A7F9E |
| 심리·마음 | 더스티 로즈 | #B4656F |
| 인문·교양 | 앰버 | #C2783A |
| 일 | 올리브 | #6B7F3A |
| 배움 | 바이올렛 | #6A4C93 |
| 자격증·시험 | 버건디 | #8C2F39 |

프롬프트의 `{띠 색}`에는 "딥 그린 (#2F6B4F)"처럼 이름과 HEX를 함께 넣는다.
