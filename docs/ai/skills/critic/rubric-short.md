> 버전: **shortcritic-v1.5** (2026-10-30 — 3.5 약속형: 주요 내용을 개념 이름으로 부르지 않으면 5 이하) · 이전 shortcritic-v1.4 (2026-10-30 — 3.5 약속형: 한 문장에 이번 편 주요 내용 + 상황 속 결정·능력) · shortcritic-v1.3 (2026-10-30 — 3.5 훅이 장치 안의 동작이면 5 이하) · shortcritic-v1.2 (2026-10-30 — 3.5 시리즈 회상 · 의외이거나 중요한 결과 · 판단 변화 예고) · shortcritic-v1.1 (2026-10-30 — 3.5 훅의 직설) · shortcritic-v1 (2026-10-30) · 짧은 판(`backlog.length_profile = short`, KAN-296)의 채점에만 쓴다. 앵커 없음 — 사람 판정 3편으로 보정한다. 근거는 `docs/ai/skills/draft/CHANGELOG.md` short-v1.

## 공통

- 이 대본은 짧은 판이다. 비평 루브릭 v2 의 3장(점수) 대신 이 루브릭으로 채점한다. 2장 플래그와 4장 리포트 규격은 v2 그대로 쓴다.
- 짧은 판의 규격: 5~12분, 본문 구간 2~3개, 축 소스 중심, 반론은 착지 구간 안 한두 턴, 도입은 훅 두 턴. 규격 자체로 감점하지 않는다.
- 골드 예시는 15분 편이다. 말투와 주고받기를 비교할 때만 쓴다. 길이·구간 수·도입 형태·관점 수를 골드와 비교하지 않는다.
- 리포트 점수표의 항목 이름은 아래 이름을 그대로 쓴다. 합계는 100점이다.
- 출력 스키마 칸은 v2 와 같다: content.value = 3.1 · content.argument = 3.2 · content.perspective = 3.3 · content.resonance = 3.4 · structure.opening = 3.5 · structure.flow = 3.6 · structure.ending = 3.7 · naturalness.spoken = 3.8 · naturalness.exchange = 3.9 · immersion = 3.10 · persona.voice = 3.11 · persona.listener = 3.12.

## 3.1 핵심의 납득 (12)

핵심 하나를 기제까지 납득시키는가. 다 들은 청취자가 그 기제를 한 문장으로 말할 수 있는가.

| 구간 | 정의 |
|---|---|
| 10–12 | 의외의 결과와 그 기제가 한 줄로 이어진다. 청취자가 처음 품은 생각을 고치게 된다 |
| 7–9 | 기제를 설명하지만 의외성이 약하거나 기제 한 고리가 비어 있다 |
| 4–6 | 구분·정의를 선언하는 데서 멈춘다. 왜 그런지가 없다 |
| 0–3 | 핵심이 무엇인지 남지 않는다 |

## 3.2 근거의 신뢰도 (7)

주장에 사례·수치·연구의 근거가 붙는가. 결과를 과장하지 않는가.

| 구간 | 정의 |
|---|---|
| 6–7 | 핵심 주장마다 근거가 붙고 범위를 넘지 않는다 |
| 4–5 | 근거는 있으나 한 군데가 근거 없이 단정한다 |
| 2–3 | 근거보다 주장이 앞선다 |
| 0–1 | 근거가 없다 |

## 3.3 초점 (5)

한 가지에 집중하는가. 곁가지·조건 안내·반복이 시간을 먹지 않는가. 관점의 수로 채점하지 않는다. 착지 구간 안 반론 한두 턴은 초점을 해치지 않는다.

| 구간 | 정의 |
|---|---|
| 5 | 모든 구간이 핵심 하나에 붙는다 |
| 3–4 | 곁가지가 한 군데 있다(한두 턴) |
| 1–2 | 구간 하나가 축 밖의 안내나 다른 주제로 간다 |
| 0 | 초점이 없다 |

## 3.4 정서적 공명 (6)

청취자 자신의 상황이 떠오르는가. 사례가 사람·행동·결과의 장면으로 나오는가.

| 구간 | 정의 |
|---|---|
| 5–6 | 사례가 장면으로 나오고 청취자의 상황과 겹친다 |
| 3–4 | 사례는 있으나 소개에서 멈춘다 |
| 1–2 | 추상 설명만 있다 |
| 0 | 청취자와 닿는 자리가 없다 |

## 3.5 첫 30초 (10)

인트로 뒤 도입 두 턴이 들을 이유를 세우는가. 훅 문장이 직설인가 — 무엇이 일어나는지, 청취자에게 무엇이 달라지는지가 그 문장 안에서 바로 들리는가. 훅이 던진 질문을 본문 첫 해설 턴이 바로 받는가. 결과·약속을 비유·함축이나 실험 장치·기제의 세부로 말해 청취자가 뜻을 해석해야 하면 5 이하다.

훅 문장이 장치·프로그램·프로토콜 안의 동작 설명이면 5 이하다.

약속형은 약속 문장 한 문장에 이번 편의 주요 내용과, 청취자가 실제 상황 하나에서 내릴 수 있게 되는 결정이나 할 수 있게 되는 일이 함께 있으면 6 이상이다. 그 상황이 구체적이고 들은 뒤 생기는 것이 분명하면 9–10 이다. 상황 없이 배움·이해만 약속하면 5 이하다. 약속 문장에 이번 편의 주요 내용이 개념 이름으로 없으면("오늘 이야기"처럼 뭉뚱그림 포함) 5 이하다. 약속 문장이 이번 편을 가리키는 말 대신 "여러분"·"청취자 여러분"으로 시작하면 1점 깎는다.

시리즈 2화부터는 첫 해설 턴의 첫 문장이 앞 편 회상이다. 회상 한 문장은 감점하지 않고, 그다음 문장을 훅으로 채점한다. 회상이 두 문장 이상이거나 훅으로 이어지지 않으면 1~2점 깎는다.

| 구간 | 정의 |
|---|---|
| 9–10 | 첫 해설 턴이 의외이거나 중요한 결과를 청취자가 보거나 겪는 일로 단언하고, 진행의 질문이 그 긴장을 받고, 본문 첫 해설 턴이 바로 답하기 시작한다 |
| 6–8 | 훅은 서지만 결과·약속이 일반적이거나, 본문 첫 해설 턴이 다른 이야기로 시작한다 |
| 3–5 | 결과 없는 예고, 상황 없는 배움·이해 약속, 답의 구분 예고로 연다. 청취자가 이미 아는 사실이나 개수·횟수 같은 구성 정보로 연다 |
| 0–2 | 도입이 들을 이유를 주지 않는다 |

## 3.6 전개의 속도 (7)

구간이 축으로 곧장 가는가. 이미 한 말이나 조건 설명으로 늘어지는 곳이 없는가.

| 구간 | 정의 |
|---|---|
| 6–7 | 모든 턴이 다음 고리로 간다 |
| 4–5 | 한 군데가 재확인이나 안내로 늘어진다 |
| 2–3 | 두 군데 이상 늘어진다 |
| 0–1 | 전개가 없다 |

## 3.7 들고 갈 한 문장 (8)

마지막 문장이 청취자가 들고 갈 한 문장인가. 구간을 나란히 되짚는 열거가 아닌가. 약속형 훅이면 약속을 회수했는가.

| 구간 | 정의 |
|---|---|
| 7–8 | 마지막 문장이 축을 일상의 말로 남긴다. 약속형이면 약속을 회수한다 |
| 4–6 | 축으로 맺지만 이미 한 구분을 다시 선언한다 |
| 2–3 | 구간을 나란히 되짚는 열거로 맺는다 |
| 0–1 | 맺음이 없다 |

## 3.10 끝까지 (15)

| 구간 | 정의 |
|---|---|
| 13–15 | 매 구간이 다음을 기다리게 한다 |
| 9–12 | 끝까지 따라가지만 한두 군데 늘어진다 |
| 5–8 | 중간에 재확인이나 안내로 주의가 풀린다 |
| 0–4 | 앞부분 뒤로 듣지 않게 된다 |
