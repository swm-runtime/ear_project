## 비평가 실행 규칙 (spec/09 7장 요약)

- **새 컨텍스트에서 실행** — 생성 맥락·소스 원문·피드백 이력·전판 대본 반입 금지.
- 입력 4종만: 검사 대상 대본 · 이 루브릭 · guidelines.md · 골드 예시(examples/).
- 사실 검증은 하지 않는다 — 그것은 QA(spec/05)의 일. 여기서는 **스타일·품질**만 본다.
- 판정은 보수적으로: 확신 없는 지적은 플래그 강도를 `의심`으로 낮춘다. 플래그 남발은
  사람의 판정 비용을 되레 올린다 — 확실한 것 위주로, 에피소드당 플래그 15건 이내 권장.
- **잘된 턴도 찾는다** (⭐ 3~7건) — 예시 승격의 원료. 문제만 찾는 비평가는 반쪽이다.

## 검사 항목

각 항목: 해당 턴을 특정해 플래그. `강도: 위반(명백) / 의심(그럴 소지)`.

### A. 대화 자연화

| # | 항목 | 무엇을 보나 |
|---|---|---|
| A1 | 유도 질문 | 진행자 질문이 다음 해설을 미리 아는 듯한 셋업인가. 기원 서사(왜 궁금한지 한 조각) 없이 정답 방향을 찍는 질문 |
| A2 | 관찰자 시점 이탈 | 진행자가 내용의 당사자처럼 감정·판단을 단정하는가 (추측형 "~것 같은데요?"가 아닌) |
| A3 | 복창 맞장구 | 해설을 같은 말로 반복만 하는 리액션. 번역(비유 전환·관점 이동·일반화)이 없는 "~라는 거네요" 류 |
| A4 | 아는 척 통과 | 청취자가 못 따라갈 개념·용어가 나왔는데 진행자가 되묻지 않고 넘어가는 지점 |
| A5 | 역질문 부재/과다 | 에피소드당 역질문 0회 또는 3회 이상. 역질문 답변에 사실 주장(수치·인용·단정)이 섞였는지도 |
| A6 | 호명 어색 | 호명이 전무하거나 과다·기계적 |
| A7 | 뜸·호흡 부재 | 말줄임표(...) 뜸이 거의 없어 낭독체처럼 읽히는 구간 |
| A8 | 전언체 누락 | 소스 유래 사실이 귀속 없이 단정형으로 서술되는 턴 ("~라고 합니다"류 부재) |

### B. 리듬·구성

| # | 항목 | 무엇을 보나 |
|---|---|---|
| B1 | 리듬 단조 | 처음부터 끝까지 턴 길이가 균질한가. 티키타카 구간(짧은 턴 빠른 교환)과 호흡 구간(긴 해설)의 교차가 있는가 |
| B2 | 해설 공식 이탈 | 긴 해설 턴이 개념→구체 사례→(유머)→일반화 왕복 없이 추상 설명만 이어지는가 |
| B3 | 긴 독백 | 한 턴이 과도하게 길어 대화가 끊기는 지점 (평균 규격: 해설 2~5문장, 진행 1~2문장 — 구간별 변주는 허용) |
| B4 | 정리 습관 고정 반복 | "그러니까 요점은…" 등 동일 정리구가 변주 없이 반복 |

### C. 구조

| # | 항목 | 무엇을 보나 |
|---|---|---|
| C1 | 콜드 오픈 규격 | 존재하는가 / 본편 턴의 발췌인가(새 문장이 섞이면 위반) / 20~30초 분량인가 / 궁금증을 남기는 대목인가 |
| C2 | 도입 구간 부재 (v1.3) | 인트로의 주제 선언 직후, 청취자가 "대화에 앉는" 짧은 구간(질문 + 두세 턴) 없이 첫 해설로 직행 (규칙 13 v5.1). 주제를 감추고 에두르는 옛 방식은 이제 위반이 아니라 규칙 13 위반의 반대 방향 — 주제 선언이 없으면 그것을 플래그 |
| C3 | 말미 출처 나열 | 대본 끝에 출처 낭독·나열이 있는가 (직접 인용 직전 귀속만 허용) |
| C4 | 마무리 규격 (v1.3 tpl-v1) | 진행 담당의 tpl-v1 클로징 도입("네, 지금까지 {주제 한 줄 요약}에 대해서 이야기 해봤는데요" 골격) → 해설 담당 정리 1턴으로 **끝나는가**. 그 뒤 추가 클로징 턴·고지·출처 나열이 있으면 위반. 골격 문구 변형도 위반. 인트로·마무리의 {주제 한 줄 요약} 불일치(수미상관 깨짐)는 의심 |
| C5 | 사건 종속 (v1.2) | 에피소드 전체가 하나의 사건의 전말 추적인가 — 축이 개념·원리·질문이고 사건은 사례로 쓰였는가. 마무리 요약이 "무슨 일이 있었나"로 끝나면 위반 신호 |

### D. 페르소나·규격

| # | 항목 | 무엇을 보나 |
|---|---|---|
| D1 | 페르소나 이탈 | 윤아(부드러움·과장 없는 리액션)/이음(간결·담백) 말투 이탈, 과장 리액션 |
| D2 | 역할 침범 | 사실 주장(수치·인용·고유명사·인과)이 진행 담당 턴에 등장 |
| D3 | 개인 경험 서사 | 가공의 사담·일화 (배경 색깔을 넘어선 경험담) |
| D4 | 시점 고정 표현 | "지금·요즘·최근·오늘" 등 (날짜는 절대 표기여야 함) |
| D5 | 낭독 규격 위반 | 표·URL·괄호 주석·마크다운 장식, 읽는 대로 표기 안 된 숫자, 음차 표기(가독 표기여야 함), 태그 화이트리스트 밖 사용 |

### F. 한국어 자연스러움 (v1.1 신설 — "소리 내 읽었을 때" 기준)

| # | 항목 | 무엇을 보나 |
|---|---|---|
| F1 | AI체·문어 은유 | 글에서만 쓰는 은유적 표현("~이 이야기의 입구예요" 류). 말로 뱉었을 때 어색한 문장 |
| F2 | 번역투 | 영어 직역 냄새("프로그래밍 언어 동네" 류), 한국어 화자가 안 쓰는 조합 |
| F3 | 기계적 표기 | 필요 이상 정밀한 날짜(년-월 원칙 위반)·수치 낭독, 목록 낭독처럼 들리는 문장 |
| F4 | 리액션 상식 부정합 | 청취자가 실제로는 느끼지 않을 감정의 연출 (일상적 사실에 과한 놀람·불안 등) |
| F5 | 비유 남용 | 자명한 내용에 붙은 비유, 이해를 더하지 않는 비유 |
| F6 | 어미 단조 | 해설 턴 어미가 한 계열('요'체만/'다'체만)로 고정 |

### E. 종합 (점수 5축 — 각 1~5점 + 한 줄 근거)

몰입(듣고 싶은가) · 자연스러움(대화 리듬) · 정보 밀도(15분의 가치) · 페르소나 일치 · 구성(전개의 설득력)
