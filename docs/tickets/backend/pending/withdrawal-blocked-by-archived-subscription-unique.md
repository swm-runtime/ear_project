## 문제

`archived_subscriptions`는 `original_transaction_id`에 **유니크**가 걸려 있다. 의도된 제약이다.

> `original_transaction_id` 유니크가 하나의 스토어 구독이 여러 계정에 연결되는 것을 계속 막는다. **탈퇴 후 재가입해도 마찬가지다.** (`domain.md` 11.5)

그런데 `domain.md` 12.3은 복원도 약속한다.

> 구독 권한은 복원된다 … `archived_subscriptions`만 있으면 새 계정에 티어를 붙일 수 있다.

**두 규칙이 부딪히는 지점이 있다.**

```
① 유료 사용자 탈퇴 → archived_subscriptions 에 행 생성 (transaction_id = T)
② 같은 사람이 재가입 → 복원으로 subscriptions 에 T 로 새 행
③ 다시 탈퇴 → archive() 가 T 를 또 insert → 23505
```

`archive()`는 충돌 처리 없이 삽입한다. 예외가 `dataSource.transaction` 안에서 터지므로 **탈퇴 전체가 롤백**되고, 사용자는 `INTERNAL_ERROR` 500을 받는다. 안내되는 복구 경로가 없다.

**결과: 그 사용자는 구조적으로 탈퇴할 수 없다.** 개인정보보호법 제21조 제1항의 파기 의무를 제품이 이행하지 못하는 상태다.

## 결정이 필요한 것

세 안이 **보존되는 기록의 범위를 다르게** 만든다. 법적 판단이 섞여 있어 코드로 정할 일이 아니다.

**안 A — 새 탈퇴가 기존 행을 덮어쓴다** (`ON CONFLICT … DO UPDATE`)
- 최신 상태가 남는다. 계정당 하나라는 성질도 유지된다.
- **대가**: 첫 계정의 거래 기록이 사라지고 `archived_at`이 갱신돼 **5년 시계가 다시 시작**한다.

**안 B — 기존 행을 그대로 두고 넘어간다** (`ON CONFLICT DO NOTHING`)
- 탈퇴는 성공한다. 구현이 가장 단순하다.
- **대가**: 두 번째 계정의 구독 이력이 **보존되지 않는다.** 그 계정에도 거래가 있었다면 시행령 제6조를 만족하지 못한다.

**안 C — 유니크를 `(user_hash, original_transaction_id)`로 바꾼다**
- 두 계정의 기록이 **모두 보존된다.** 법적으로 가장 안전하다.
- **대가**: "하나의 스토어 구독 = 하나의 계정" 보장이 이 테이블에서 사라진다. 그 보장이 필요하면 복원 경로에서 따로 확인해야 한다. `domain.md` 11.5 개정이 따라온다.

**안 C를 제안한다.** 보존 의무는 계정마다 성립하고, 중복 연결 차단은 아카이브 테이블이 아니라 **복원 시점 조회**로도 세울 수 있다. 다만 11.5가 이 유니크에 그 역할을 명시적으로 맡겨 뒀으므로, 문서 담당과 함께 정해야 한다.

## 함께 고칠 것

- **`archive()`가 유니크 위반을 흡수하지 않는다.** 어느 안을 택하든 이 경로가 raw `QueryFailedError`로 500이 되지 않게 한다(`architecture.md` 8.4).
- 탈퇴 실패 시 사용자에게 보일 안내가 없다. `auth.md` 4.3에 실패 경로가 정의돼 있지 않다.

## 참고 — 지금 도달 불가인 이유

`subscriptions`에 행을 쓰는 코드가 없다(영수증 검증 미구현). 그래서 오늘은 재현되지 않는다. **결제가 켜지면 첫 재가입 사용자에게서 바로 나타난다** — 그때는 이미 운영 중이라 고치기 더 어렵다.

2026-09-08 같은 트랜잭션에 사용자 행 잠금을 넣어, 판정 뒤 커밋된 구독이 아카이브 없이 파기되는 별개 문제는 해소했다. 이 건은 그와 다른 경로다.

## 완료 조건

- Given 유료 사용자가 탈퇴하고 재가입해 구독이 복원됐다 / When 다시 탈퇴한다 / Then 500이 아니라 정상 처리된다
- Given 같은 상황 / When `archived_subscriptions`를 본다 / Then 채택한 안이 정한 범위대로 기록이 남아 있다
- Given `domain.md` 11.5 / When 유니크의 역할을 읽는다 / Then 재가입 시의 동작이 적혀 있다
