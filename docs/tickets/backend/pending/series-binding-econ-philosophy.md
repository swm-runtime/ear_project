## 문제

- 팀원이 기획 시리즈 세 개를 만들어 운영에 **개별 콘텐츠로** 발행했다 — 키워드로 훑어보는 경제 상식(12편 중 11편, 10편은 재발행 예정) · 시대별로 보는 서양 철학(10편) · 시대별로 보는 동양 철학(8편). 운영에 시리즈 API 가 없던 때라 시리즈 칸 없이 올라갔다.
- 지금 시리즈로 묶으려면 회수 후 [시리즈 발행]으로 다시 올려야 하는데, 그러면 콘텐츠 ID 가 바뀌어 **담기·재생 기록이 끊긴다**. 업로드 뒤 시리즈 칸은 바꿀 수 없다(admin-api 4.10).
- CS 16편은 같은 문제를 일회성 마이그레이션(`1790700100000-SeedCsKeywordSeries`)으로 풀었다 — 같은 방식을 요청한다.

## 요청 내용

1. 시리즈 세 행을 만든다.

## 완료 조건

- Given 마이그레이션을 운영에 적용 / When `GET /admin/series` 를 본다 / Then 세 시리즈가 위 제목·편수로 있고, 경제 상식은 발행 11편·서양 10편·동양 8편이다
- Given 위 콘텐츠 / When 상세 응답을 본다 / Then `series` 객체가 실리고 `episode_no` 가 표와 같으며, content_id·content_version·담기·재생 위치가 그대로다
- Given 마이그레이션을 두 번 돌린다 / When 결과를 본다 / Then 첫 번째와 같다
- Given 마이그레이션 뒤 경제 상식 10화를 시리즈 칸과 함께 올린다 / When 업로드한다 / Then `episode_no` 10 이 받아들여지고 시리즈 발행 편이 12편이 된다
