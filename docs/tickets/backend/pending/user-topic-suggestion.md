**앱에서 사용자가 듣고 싶은 주제를 제안하면 서버가 받아 두고, 운영이 모아 볼 수 있게** 한다(10월 5주차 계획(2026-10-26 회의)).

- 받는 형식(자유 입력·선택지), 중복·악용 처리, 파이프라인 연결(소스 풀·백로그 게이트 1), 제안자에게 돌려줄 것은 **KAN-179 기획(기능 명세)이 정한다**
- 스키마는 `backend/domain.md`에 먼저 올리고, 계약은 `spec/api/`에 적는다

## 완료 조건

- Given 로그인한 사용자 / When 제안을 보낸다 / Then 저장되고, 기획이 정한 한도·중복 규칙을 넘으면 정해진 에러 코드로 거절된다
