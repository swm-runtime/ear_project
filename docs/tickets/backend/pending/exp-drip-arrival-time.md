> 단기 실험 8종(2026-10-29 확정) 중 하나다. A/B 그룹별 지표를 어드민 "실험 지표" 탭에서 보는 일은 실험 전체에 걸친 별도 정리 대상이다(아직 티켓 없음).

## 왜

도착 알림 시각에 따라 당일 재생이 달라지는지 본다. 편성 배치(현지 05:00)는 서비스 날짜 경계라 앞당길 수 없으므로 실험 대상은 도착 알림 시각(지금 현지 07:00)이다. 도착 알림은 정보성이라 야간 광고 제한 대상이 아니다.

## 무엇을 한다

- 공용 버킷 유틸을 만들고, 도착 알림 크론을 그룹 현지 07:30·08:00 두 번으로 바꿔 각 실행에서 해당 그룹만 보낸다.
- `notification_logs`에 사용자의 그룹이 남게 한다 — 어드민 "실험 지표" 탭에서 그룹별로 나눠 보기 위해(탭은 별도 정리).
- 전환 전 07:00 기준선 지표를 처리 기록에 남긴다.
- 지표: 도착 알림 → `push_open`, 당일 재생 여부. 변경 시각·그룹을 처리 기록에 남긴다.
- 문서 수정은 `changes/pending`에 기록.

## 결정 (2026-10-29)

- 사용자를 A/B로 나눈다: **A 그룹 07:30 · B 그룹 08:00**(그룹 현지). 같은 사용자는 늘 같은 그룹(사용자 id 해시 — 새 공용 버킷 유틸, 다른 실험에서 재사용).
- 바꾸기 전 **07:00 발송 기간의 지표를 처리 기록에 고정**한다(기간·발송 수·`push_open` 수와 비율·당일 재생 비율) — 두 그룹과 비교할 기준선.
- 아침 알림(KAN-288)은 드립이 없는 날만 전원 08:00 — 드립이 있는 날은 도착 알림만 간다(하루 한 건).

## 범위 밖

- 편성 배치 시각 변경.

## 완료 조건

- Given A 그룹 사용자 / When 그룹 현지 07:30 / Then 도착 알림이 나간다 · B 그룹은 08:00에 나간다(대상·문구는 종전과 같다)
- Given 같은 사용자 / Then 매일 같은 그룹이다
- Given 알림 기록 / Then 그룹이 함께 남는다
- Given 전환 전 / Then 07:00 기준선 지표가 처리 기록에 있다
- Given 드립이 없는 날 / Then 도착 알림은 없고 아침 알림(KAN-288)만 간다
