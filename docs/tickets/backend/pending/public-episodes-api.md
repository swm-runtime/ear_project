## 요청

랜딩(`landing-page/`)이 `next build` 때 한 번 불러 **공개 대상 편의 정적 페이지**를 굽는다. `GET /public/topics`(`public-api.md` 2.1)와 같은 성격 — 로그인 없음, 빌드 시점 fetch, 전역 IP 레이트 리밋만.

- **대상**: 앱 노출 판정과 같다(발행 상태 + 라이선스 유효) + **이어가 만든 편만**(파트너 편 제외 — 변경안 "공개 대상").
- **필드**(누구에게 보여도 되는 값만): 식별자(변경안 결정 1·2에 따라 id 또는 slug) · 제목 · 요약(발행 메타 설명 — 결정 3) · 챕터 제목 목록 · 주제 이름 · 길이(초) · 발행일 · 썸네일 URL · 출처 목록(`source_name` 등 앱 상세 "참고한 자료"와 같은 값) · 언어.
- **싣지 않는 것**: 오디오 URL(서명 URL을 id로 발급하지 않는다 — 2.2 원칙), 대본 전문, 원문 저장소 키, 운영 값(정렬·노출 여부·버전).
- 페이지네이션 또는 전체 목록 — 편수가 수천을 넘지 않는 동안 전체 한 번이 단순하다. 판단은 담당.
- `Cache-Control: public, max-age=300` (2.1과 같다).
- 랜딩은 **개발계 API를 본다**(`public-api.md` 1장) — 개발계 DB에 공개 대상이 있어야 페이지가 생긴다. 운영 데이터를 보게 할지는 이 티켓에서 함께 정한다(랜딩 env `LANDING_API_BASE_URL`).

## 완료 조건

- Given 발행·라이선스 유효한 이어 제작 편 / When `GET /public/episodes` / Then 위 필드로 목록에 나온다
- Given 파트너 편 · 회수 · 만료 편 / When 같은 요청 / Then 목록에 없다
- Given 응답 / When 키를 훑는다 / Then 오디오 URL · 대본 전문 · 저장소 키가 없다
- Given `public-api.md` / When 본다 / Then 2장 표와 새 절에 이 계약이 적혀 있다
