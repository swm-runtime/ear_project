## 배경 — 2026-10-14 조사

- **Apple**은 2025-07 연령 등급을 4+ · 9+ · 13+ · 16+ · 18+로 개편했고(12+·17+ 폐지), 개발자는 2026-01-31까지 새 설문을 다시 작성해야 했다. 설문 산출 등급은 수동으로 **올릴** 수 있다. 등급은 지역별로 다르게 표시될 수 있다.
- Apple **Declared Age Range API**는 앱이 OS에 사용자 연령 구간(생년월일 아님)을 물을 수 있는 API다. 미국 일부 주(텍사스 SB2420 — 시행·집행 상태 유동)·브라질·호주·싱가포르에서 18+ 앱의 성인 확인이 의무화되기 시작했다(2026-02-24 집행). 국가별 앱스토어 단위라 주 단위 차단은 불가.
- **Google Play**는 대상 연령·콘텐츠 선언(5세 이하 … 13–15 · 16–17 · 18+)으로 심사하고, 13세 미만을 포함하면 패밀리 정책(광고 SDK 자기인증 등)이 적용된다. IARC 설문이 등급을 산출한다. 선언이 부정확하면 삭제·정지 사유.
- 우리 앱의 리스팅은 하나다(KR·GLOBAL 같은 앱). 앱 내 연령은 GLOBAL 16 · KR 18이므로 스토어 등급 **16+**는 두 시장 규칙과 충돌하지 않는다(KR은 앱 안에서 18로 다시 거른다).

## 무엇을 한다

- **App Store Connect**: 새 체계로 연령 등급 설문 재작성(토크 팟캐스트 — 폭력·도박·성적 콘텐츠 없음, 사용자 생성 콘텐츠 없음, 무제한 웹 접근 없음). 산출 등급이 16+ 미만이면 **16+로 수동 상향**. 지역별 등급 표시 확인(한국·미국·EU 주요국).
- **Google Play Console**: 대상 연령을 **16–17 · 18세 이상**으로 선언(13세 미만·13–15 미포함 → 패밀리 정책 비적용 유지). IARC 설문 재작성, 광고 SDK·데이터 안전 섹션의 연령 관련 답변 일치 확인.
- **연령 확인 의무 조사**: 공개 후보 국가(영어권 우선 — 미국·영국·캐나다·호주·싱가포르, EU 보류)에서 16+ 앱에 OS 연령 신호 연동이 의무인지 확인. 의무라면 Declared Age Range API / Play Age Signals 연동을 **후속 FE 티켓**으로 발행(1단계는 자기 선언).
- 결과(설정값·스크린샷 아님, 날짜)를 처리 기록에 적고 KAN-198 제출 전 완료.
