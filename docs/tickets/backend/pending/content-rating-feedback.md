## 요청

**모든 편의 별점·의견을 받는 API와 참여 보상(Pro 7일) 지급**을 만든다(10월 5주차 계획(2026-10-26 회의)).

- 계약·보상 조건은 기획 티켓(KAN-278)이 정한다. 스키마는 `backend/domain.md`에 먼저 올린다
- 보상 지급 판정은 서버다(계정당 횟수 등) — 초대 코드 기간 지급(`features/subscription.md` 4.9) 재사용 여부를 검토한다. `users.tier` 직접 변경 금지
- 의견 원문은 운영 열람 범위를 지킨다(CLAUDE.md 개인정보 원칙)

## 완료 조건

- Given 보상 조건을 채운 계정 / When 별점·의견을 보낸다 / Then 저장되고 Pro 7일이 한 번 지급된다(응답·`plan`에 반영)
- Given 이미 보상을 받은 계정 / When 다시 참여한다 / Then 저장은 되고 보상은 다시 주지 않는다
