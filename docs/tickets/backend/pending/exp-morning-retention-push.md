> 단기 실험 8종(2026-10-29 확정) 중 하나다. A/B 그룹별 지표를 어드민 "실험 지표" 탭에서 보는 일은 실험 전체에 걸친 별도 정리 대상이다(아직 티켓 없음).

## 왜

드립 도착과 별개로 매일 아침 앱으로 불러오는 알림의 효과를 본다. 리텐션 알림 모듈(그룹 현지 18:00)을 그대로 쓰고 아침 슬롯을 더한다. 다시 오라는 내용은 광고성이라 마케팅 동의자에게만, 21~08시는 보내지 않는다 — 가장 이른 시각이 08:00이다.

## 무엇을 한다

- 아침 크론(그룹 현지 08:00)과 아침용 규칙·문구. type은 `retention.morning.<변형>`.
- 아침·저녁 일일 상한을 따로 둔다(지금 20시간 창과 충돌하지 않게). 주간 상한을 공유할지 정해 문서에 적는다.
- "(광고)"·수신거부 안내, 마케팅 동의자만(기존과 같음). 스위치는 기존 `RETENTION_PUSH_MODE`를 따르거나 아침 전용 키 — 구현 때 정한다.
- 앱은 이미 `retention.*`를 처리한다(탭 이동·포그라운드 숨김·`push_open`) — FE 변경 없음.
- 문서 수정은 `changes/pending`에 기록.

## 범위 밖

- 드립 도착 알림 시각 실험 — KAN-289.
- 새 탭 목적지(탐색 등) — 필요하면 FE 티켓.

## 완료 조건

- Given 스위치 on · 마케팅 동의 사용자 / When 그룹 현지 08:00 / Then 아침 알림이 하루 1건 이하로 간다
- Given 마케팅 미동의 사용자 / Then 아침 알림이 가지 않는다
- Given 같은 날 저녁 리텐션 대상 / Then 두 슬롯 상한이 서로를 막지 않는다(정한 규칙대로)
