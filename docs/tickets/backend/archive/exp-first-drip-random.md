## 왜

첫 드립이 인기 콘텐츠에 쏠려 다른 콘텐츠의 지표가 쌓이지 않는다. 지금은 인기순 300편 후보에 콜드스타트 점수(인기 0.5·신선도 0.3)와 다양성을 적용한다. 주제 안에서 무작위로 고르면 노출이 고르게 퍼진다.

## 무엇을 한다

- `selectContentIds`에 주제 안 무작위 선정을 새 env 스위치 뒤로 추가(시리즈는 1편만, 기존 제약 유지).
- 후보 풀(인기순 300 상한)이 무작위 범위를 좁히지 않게 확인.
- 배포 전 평가기는 첫 드립을 다루지 않는다 — 체크리스트에 수동 확인을 추가하고 `DRIP_ALGORITHM_VERSION`을 올릴지 판단.
- 문서 수정은 `changes/pending`에 기록.

## 범위 밖

- 정규 편성(2일차 이후) 변경.

## 완료 조건

- Given 스위치 on / When 같은 주제의 신규 가입자 여러 명 / Then 첫 드립 편이 사람마다 다르게 나온다(인기 상위만이 아니다)
- Given 스위치 off / Then 종전과 같다
- Given 시리즈 콘텐츠 / Then 1편만 첫 드립에 들어간다

## 처리 기록

- 2026-10-29 발행(마크다운 + Jira KAN-291).
- 2026-10-29 구현(스위치 기본 꺼짐) — 이 PR(`feat(be)/exp-first-drip-random`) · **반영 날짜 2026-10-29**.
  - **스위치** `FIRST_DRIP_RANDOM_ENABLED` — `true`를 명시했을 때만 켜진다(빈 값·`false`는 꺼짐, `env.validation.ts`는 `true`·`false`·빈 값만 받는다). 꺼져 있으면 `selectContentIds`는 종전 경로(콜드스타트 스코어링 + 다양성) 그대로다. `deploy/push.sh` 선택 키 목록에 넣어 Secrets에 없으면 빈 값 = 꺼짐.
  - **무작위 규칙**(`drip/first-drip-random.policy.ts`): 같은 필터(시장·주제·시리즈 1편만·본 것 제외·노출 기간)의 후보를 받는다 → 후보와 사용자 관심 주제 순서를 각각 Fisher–Yates로 섞는다 → 주제를 돌아가며 그 주제에 걸린 아직 안 뽑힌 후보 중 섞인 순서의 첫 편을 고른다(주제 안 균등 무작위, 주제가 여럿이면 한 주제에서 다 가져오지 않는다) → 순환으로 못 채우면 나머지를 섞인 순서대로. 그래도 모자라면 **인기 대체 편성은 종전 그대로**(인기순, 시리즈 1편만).
  - **후보 풀 상한**: 종전 풀은 인기순 300편 상한이라 카탈로그가 300을 넘으면 인기 하위 편이 후보에 못 든다. 켜졌을 때는 `findCandidates({ randomOrder: true })` — `ORDER BY RANDOM()`으로 자른다. 상한을 넘어도 무작위 범위가 인기 상위로 좁아지지 않는다.
  - **난수 주입**: `FirstDripService`가 `FIRST_DRIP_RANDOM_SOURCE` 토큰(선택)을 받는다 — 운영은 비워 `Math.random`, 테스트는 시드 난수(mulberry32)로 결과를 고정한다.
  - **`DRIP_ALGORITHM_VERSION`은 올리지 않았다**: 첫 드립 적립분은 `addItems`에 버전을 넘기지 않아 `algorithm_version = NULL`이다. 버전은 정규·탐험 편성분의 별점을 가르는 값이라, 올리면 바뀌지 않은 정규 편성의 별점만 두 버전으로 갈린다. 첫 드립 무작위 그룹의 지표를 따로 보려면 첫 드립 적립분 표시가 따로 필요하다 — 실험 지표 정리(아직 티켓 없음)에서 정한다.
  - **배포 전 평가기**는 첫 드립을 다루지 않는다 — 체크리스트 수동 확인 줄과 4.4 서술은 `changes/pending/exp-first-drip-random.md`에 기록(통합 때 반영).
  - **켜는 일은 운영 작업이다**(이 PR은 끈 채로 나간다): 개발계는 Secrets `ear/dev/api`에 `FIRST_DRIP_RANDOM_ENABLED=true`를 넣고 재배포 → 같은 주제로 신규 계정 여러 개를 가입시켜 첫 드립 편 비교. 운영은 실험 시작 결정 뒤 같은 방법으로 켠다.
