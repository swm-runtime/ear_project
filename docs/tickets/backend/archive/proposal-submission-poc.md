## 요청

제안서를 **제출**하고 **PoC 를 진행**한다(PM 2026-10-12).

## 착수 전에 PM 과 맞출 것

발행 시점에 아래가 적혀 있지 않다. 담당이 PM 에게 확인하고 처리 기록에 남긴다.

- PoC 의 범위(무엇을 보여 주면 성공인가)와 일정

## 완료 조건

- Given 위 두 가지를 PM 과 확인한 뒤, When 제출 기록을 보면, Then 제출처·제출 날짜·제출본 위치가 적혀 있다
- Given PoC, When 결과를 보면, Then 정한 성공 기준 대비 결과와 다음 단계가 적혀 있다
