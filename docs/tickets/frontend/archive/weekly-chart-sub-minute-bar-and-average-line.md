## 배경

KAN-113(주별 주제 분포) 개발계 확인 중 주간 카드에서 두 가지가 보였다. **서버 값은 정상이다** — `daily_listened_sec`는 초 단위 원값이고, 확인한 계정의 지난주 데이터는 `[121, 1275, 687, 1138, 128, 6, 0]`초다.

## 1. 1분 미만 청취가 "0분" 막대로 보인다 (결함)

- 앱은 `Math.floor(sec / 60)`으로 "N분"을 만든다. **1~59초는 0이 아니어서** 막대는 색이 있는 채로 최소 높이(`ZERO_BAR_HEIGHT` 3pt)로 서고, 탭하면 "0분"이 뜬다. 위 데이터의 토요일(6초)이 그 경우다 — "들은 게 없는데 막대가 있다"로 읽힌다.
- 회색 0막대 스타일은 `ratio === 0`일 때만 붙으므로 1초라도 있으면 색 막대다.
- **제안**: 1~59초는 말풍선·스크린리더 값을 **"1분 미만"** 으로 표기하고 막대는 그대로 둔다. 들은 사실은 맞고, 연속 청취 일수도 이 날을 "들은 날"로 센다(`profile.md` 4.5 — 최소 청취 시간 조건 없음). 축 최대값(`axisMax`)이 1분 미만이면 같은 표기. `profile-uiux.md` 4.6의 "60분 미만 N분(버림)"에 **1분 미만 예외**를 적는다(FE 소유 문서).

## 2. 하루만 지난 주는 평균선이 최대 막대 꼭대기에 겹친다 (설계대로 — 확인·결정)

- 이번 주 평균은 **오늘까지 지난 날 수**로 나눈다(`toDailyAverageSec` — 아직 오지 않은 요일을 분모에서 뺀 결정). 월요일에는 1로 나누므로 평균 = 그날 값이라 점선이 유일한 막대 꼭대기와 정확히 겹치고, 오른쪽 축의 최대값 라벨은 평균 라벨과 겹쳐 숨는다(`AXIS_LABEL_HEIGHT` 규칙). 2026-09-28(월) 확인 시 `[78, 0, …]`이 이 상태였다.
- 지난주는 7로 나누므로 정상. **가입 주**도 7로 나눠 실제보다 낮게 나온다(부수 — 가입일 이후 날 수로 나눌지 함께 정한다).
- **결정 필요**: (a) 지난 날이 1일이면 평균선·"평균" 라벨을 숨긴다 (b) 그대로 둔다(수학적으로는 맞다). 화면에서 다르게 보인 것이면 스크린샷을 이 티켓에 붙인다.

## 완료 조건

- Given 어느 요일 청취가 1~59초 / When 막대를 탭한다 / Then "1분 미만"이 뜬다(스크린리더도 같은 문구)
- Given 청취 0초 요일 / When 본다 / Then 종전처럼 회색 0막대이고 탭하면 "0분"이다
- Given 이번 주 월요일에 진입 / When 그래프를 본다 / Then 2번의 결정대로 그려진다
- Given `profile-uiux.md` 4.6 / When 읽는다 / Then 1분 미만 표기 규칙이 적혀 있다
