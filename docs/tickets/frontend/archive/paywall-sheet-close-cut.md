## 요지 (Jira 본문용)

- 요금제 비교가 얹힌 잠금 시트 · 한도 소진 페이월에서 [닫기]가 스크롤 경계(창 높이 72%)에 걸려 반쯤 잘린 채 보인다(iOS 개발계 실기기, KAN-304 확인 중 발견).
- 시트 안을 스크롤하면 나타나 기능은 정상이다. 스크롤 신호가 없어 깨진 화면처럼 보인다.
- [닫기]가 경계에서 잘려 보이지 않게 한다. 방법은 FE 판단 — 예: 스크롤 밖 시트 바닥에 고정.
- 결제 진행 중 닫기 차단(`paywall.md` 5장)은 그대로 둔다.
- Android도 같은 코드라 화면 길이에 따라 같을 수 있다(미확인).
- 상세 · 완료 조건은 원본 문서.

## 문제

iOS 개발계(TestFlight) 실기기에서 시리즈 잠긴 편을 탭하면 잠금 시트가 뜬다. 요금제 비교가 얹힌 시트 본문은 창 높이 72%(`PAYWALL_MAX_HEIGHT`)의 `ScrollView` 안에 있어 [닫기]가 스크롤 아래로 밀리고, 경계에서 버튼 가운데가 잘린 채 보인다.

- 시트 안을 스크롤하면 [닫기]가 나타난다 — 기능은 정상이다.
- 스크롤할 수 있다는 신호가 없어 버튼이 깨진 화면처럼 보인다.
- 한도 소진 페이월도 같은 시트 · 같은 구조다. Android도 같은 코드라 화면 길이에 따라 같을 수 있다(미확인).

재현: 무료 · 체험 종료 계정 → 시리즈 4편 이상(잠긴 편) 탭 → 잠금 시트.

## 요청

- [닫기]가 스크롤 경계에서 잘린 채 보이지 않게 한다. 방법은 FE 판단이다 — 예: [닫기]를 스크롤 영역 밖 시트 바닥에 고정하고 요금제 · 결제 버튼만 스크롤.
- 결제 진행 중 닫기 차단(`paywall.md` 5장)은 그대로 둔다.

## 완료 조건

- Given 무료 · 체험 종료 계정 / When iOS · Android에서 잠긴 편을 탭해 잠금 시트를 연다 / Then [닫기]가 스크롤 없이 온전히 보이거나, 스크롤 경계에 버튼이 잘린 채 걸리지 않는다
- Given 무료 한도를 다 쓴 계정 / When 한도 소진 페이월을 연다 / Then 위와 같다
- Given 결제 진행 중 / When [닫기]를 누른다 / Then 지금처럼 닫히지 않는다

## 처리 기록

- 2026-10-30 발행(마크다운). KAN-304 iOS 확인 3번(잠금 시트)은 기능 통과, 이 표시 문제만 따로 올린다.
- 2026-10-30 반영(효헌이 · 이주호 지시 "305티켓처리해줘"). `LimitNoticeSheet` — 요금제가 얹힌 시트(PW1·PW2)는 [닫기]를 `ScrollView` 밖 시트 바닥에 고정했다. 72% 상한은 스크롤 + 바닥 전체에 걸고 넘치면 스크롤만 줄어든다. 넘칠 때만 [닫기] 위에 구분선(`separator`)과 스크롤 막대를 보여 "더 있다"를 알린다. 결제 진행 중 닫기 차단(`isPurchasing` → 비활성 · `requestClose` 무시)은 그대로. 요금제가 없는 한도 안내·구독 UI 꺼진 빌드는 종전 그대로(스크롤 없음, [확인]이 본문 바로 아래). 문서: `spec/uiux/subscription-uiux.md` 4.6 · 4.6-1. 테스트: `LimitNoticeSheet.test.tsx` 4건 추가(잠금·한도 페이월의 바닥 고정, 넘칠 때만 구분선, 요금제 없는 안내는 종전). 실기기(iOS·Android 짧은 화면) 확인은 남음.
