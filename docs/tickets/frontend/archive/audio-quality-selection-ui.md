## 무엇을 한다

사용자가 재생 음질을 **압축 · AAC · WAV** 중에서 고른다. PM 결정(2026-10-06): Light·Daily 는 압축·AAC, Pro 는 WAV 까지.

1. **규칙 먼저** — 선택 위치(설정의 기본 음질 · 플레이어에서 바로 바꾸기 여부), 기본값, 셀룰러에서 WAV 처리를 `features/`에 적고 카피·상태를 `spec/uiux/`에 적는다
2. **허용 여부는 서버 값으로만** — 서버가 준 허용 음질 목록·현재 선택값을 그대로 그린다. **티어명 하드코딩·클라이언트 판정 금지**(CLAUDE.md). 허용 안 된 음질은 잠금 표시 + 탭하면 구독 업셀(`paywall.md`의 여는 지점 규칙)
3. **재생 연동** — 재생 URL 요청에 선택 음질을 보낸다. 서버가 대체해서 다른 음질을 주면 실제 재생 음질을 표시한다
4. **바꿀 때 재생 중 처리** — 다음 재생부터 적용 vs 즉시 교체. 즉시 교체는 지금 구조에서 끊김이 생기므로 KAN-124(음원 교체 제거)와 함께 정한다
5. **데이터 안내** — WAV 는 편당 약 100~200MB 라 셀룰러에서 처음 고를 때 한 번 안내한다
6. 접근성: 선택지는 라디오 그룹으로 읽히고, 잠긴 항목은 "Pro 구독 필요"를 함께 읽는다

> 2026-10-07 개정 — 10-06 확정(압축 = AAC 192k · 무손실 = FLAC, `aac`는 선택지에서 숨김)과 PM 범위 확정(10-07)에 맞춰 완료 조건을 고쳤다. 위 "무엇을 한다"의 AAC·WAV 표기는 발행 당시 기록이다.

## 완료 조건

- Given `features/settings.md` 4.6 · `settings-uiux.md` 4.1 "음질" / When 읽는다 / Then 선택 위치(설정 "음질" 섹션 하나)·잠금·업셀·다음 편부터 적용·셀룰러 안내(한 번) 규칙과 확정 카피가 적혀 있다
- Given 무손실이 허용되지 않은 계정 + 구독 UI 켜진 바이너리 / When 설정을 연다 / Then 압축에 체크, 무손실은 자물쇠로 보이고 누르면 요금제 관리 화면으로 가며 값은 바뀌지 않는다
- Given 구독 UI 꺼진 바이너리(운영) + 무손실 비허용 / When 설정을 연다 / Then 음질 섹션이 없다
- Given 무손실 허용 계정 / When 셀룰러에서 무손실을 처음 고른다 / Then 확인 팝업이 한 번 뜨고 [무손실로 바꾸기]면 저장, [취소]면 그대로다. 다시 고를 때는 뜨지 않는다
- Given 재생 중 음질을 바꿈 / When 4분 주기 갱신이 돈다 / Then 갱신 요청에 처음 받은 음질이 실려 같은 파일이 이어진다(다음 편부터 새 음질)
- Given 코드 / When 티어명을 grep 한다 / Then 음질 허용 판정에 티어명 분기가 없다
