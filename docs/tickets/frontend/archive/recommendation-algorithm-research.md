## 요청

추천(드립 편성·탐색 추천) 알고리즘 후보를 조사하고 몇 개를 테스트로 적용해 비교한다 — 현재 `features/drip-scheduling.md` 점수식(신호·메타·임베딩 축) 대비 대안(예: 콘텐츠 기반 유사도 가중 변경, 인기도 혼합, 탐험 비율) 2~3개를 정리하고, 개발계에서 적용해 추천 결과를 비교한다. 박준현의 "배포 전 사용자 추천 평가 체계" 티켓과 평가 기준을 맞춘다.

## 완료 조건

- Given 조사 기록, When 후보를 보면, Then 2개 이상 후보의 방식·장단점·적용 비용이 적혀 있다
- Given 개발계, When 테스트 적용 결과를 보면, Then 후보별 추천 결과 비교가 남아 있다
