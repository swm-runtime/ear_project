## 배경

PM(이주호) 요청: 콘텐츠를 분류한 주제와 별개로, SNS 해시태그처럼 **내용에 맞는 태그 2~4개**를 **탐색 카드와 상세 화면**에 띄운다(2026-10-08). 태그는 파이프라인이 대본을 보고 뽑고(KAN-139), 서버가 콘텐츠 응답에 `tags: string[]`으로 내려 준다(BE 티켓).

태그 값의 모양: 띄어쓰기 없는 2~10자, '#' 없이 온다(예: `뱅크런` `예금보험`). 화면이 '#'을 붙여 `#뱅크런`으로 보인다.

## 요청 내용

1. **탐색 카드**(피드·주제별·인기·검색 결과)에 태그를 표시한다.
2. **콘텐츠 상세 화면** 헤더에 태그를 표시한다 — 기존 "주제 태그"(`content_topics`, 드립 편성 근거)와 **구분되게**. 둘 다 태그 모양이라 섞이면 무엇이 분류이고 무엇이 내용인지 알 수 없다.
3. **탭 동작은 FE 가 정한다**(PM 2026-10-08) — 예: 표시만 / 그 말로 탐색 검색 실행. 정한 동작을 uiux 문서에 적는다.
4. 태그가 없는 콘텐츠(소급 전·파트너 콘텐츠)는 자리를 비우지 않고 줄 자체를 숨긴다.
5. 서버 응답이 오기 전에는 mock 으로 개발한다(`CLAUDE.local.md` mock 패턴).

## 완료 조건

- Given 태그 3개가 있는 콘텐츠 / When 탐색 피드·검색 결과 카드를 본다 / Then `#태그` 3개가 보인다
- Given 같은 콘텐츠 / When 상세 화면을 연다 / Then 헤더에 `#태그`가 주제 태그와 구분되어 보인다
- Given 태그가 없는 콘텐츠 / When 카드·상세를 본다 / Then 태그 자리가 비어 보이지 않는다(줄 숨김)
- Given 태그를 탭한다 / When 결과를 본다 / Then uiux 문서에 적은 동작대로 된다

## 처리 기록

- 2026-10-09 반영(PR `feat(fe)/content-hashtags`). 서버 계약(KAN-162 — `content.tags: string[]`, '#' 없이, 없으면 `[]`)을 탐색 DTO·상세 DTO 에 선택 필드로 받았다(옛 서버면 빈 배열).
  - 탐색 타일·인기 대표 카드: 하단 줄 `#태그 #태그 · N분`(최대 2, 한 줄). 태그 없으면 타일은 길이만, 대표 카드는 종전 주제 해시태그(소급 전 기간).
  - 상세 헤더: 주제 칩 밑 `#태그` 글자 한 줄(배경 없음 — 칩과 구분). 없으면 줄 없음.
  - **탭 동작: 표시만**(서버 API 문서와 같다). 검색 연결은 탐색 검색에 질의어를 넘기는 경로가 아직 없어 미루었다 — 필요하면 별도 티켓.
  - mock 에 태그(일부 빈 배열) 추가. `explore-uiux.md`·`content-detail-uiux.md` 갱신.
