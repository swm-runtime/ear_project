## 배경

추천 알고리즘을 실사용자 평가로 재기 위해, 서버는 버전별로 별점을 모으는 API를 이미 갖췄다(KAN-116). 어드민 "추천 검증"에서 버전별 평균 별점을 본다. 앱 팝업이 없어서 지금까지 별점이 한 건도 쌓이지 않았다.

2026-10-16 정책 결정(서버 반영 완료 — PR #1636):

- **가입 4일째부터, 한 사람에게 7일에 한 번** 묻는다. 무작위 표본은 없다.
- **가장 최근 편성분(보통 어제) 2편**을 묻는다. **듣지 않은 편도 묻는다.** 묻는 것은 콘텐츠 품질이 아니라 "이 추천이 마음에 드는가"다.
- 별 1~5와 "이번 주 그만 보기"는 그대로다. 닫은 뒤 따로 쉬는 기간은 없다(닫기도 별점과 같은 "물었다" 기록이다).

**판정은 전부 서버가 한다.** 앱은 `show`만 보고 띄운다. 편성 날짜·이번 주·가입 며칠째를 기기 시각으로 계산하지 않는다(CLAUDE.md 공통 원칙).

## 요청 내용

1. **진입 시 조회** — 라이브러리 첫 화면 진입 시 `GET /users/me/drip-feedback/prompt`를 부른다. `show=true`일 때만 팝업을 띄운다. 실패하면 조용히 넘어간다(팝업 없음, 에러 화면 없음).
2. **팝업 구성** — 팝업 안에 **지난 추천 콘텐츠 1~2편을 목록(나열) 형식으로** 보여준다. 각 행은 썸네일·제목과 별 1~5다. 이 목록은 `items[]` 순서 그대로 그린다.
   - 제목: **"최근 추천 어떠셨나요?" 하나로 둔다**(2026-10-16 결정). 묻는 편성분은 보통 어제지만 며칠 만에 들어오면 최대 6일 전 편성분일 수 있다. "어제/지난"을 나누려면 어제인지를 판정해야 하는데, 기기 날짜로 판정할 수 없고 7일에 한 번 묻는 팝업이라 나눠서 얻는 것이 적다. `features/drip-feedback.md` 5장의 "어제 추천…(아니면 '지난 추천')"은 문서 개정 대상이다(`changes/pending/drip-feedback-prompt-policy.md`).
   - 버튼: [보내기] · [이번 주 그만 보기] · 닫기(X 또는 바깥 탭).
3. **보내기** — 별점을 매긴 편만 `POST /users/me/drip-feedback`에 `{ ratings: [{ content_id, stars }] }`로 보낸다. 한 편만 매겨도 된다. 성공하면 닫고 토스트는 띄우지 않는다.
   - 실패 시 인라인 에러와 재시도를 보여준다.
   - 오프라인이면 큐에 넣어 재전송한다(서버 접수 기간 7일).
   - `DRIP_FEEDBACK_NOT_RATEABLE`(400)은 조용히 버린다. 접수 기간이 지난 것이다.
4. **닫기** — `POST /users/me/drip-feedback/dismiss`에 `{ placed_date }`(응답에 받은 값 그대로)를 보낸다. 앱을 그냥 종료하면 아무것도 보내지 않는다. 이 경우 다음 진입에 다시 뜬다(의도된 동작).
5. **이번 주 그만 보기** — `POST /users/me/drip-feedback/mute`를 보낸다. 즉시 닫고, 저장에 실패해도 이번 세션은 닫아 둔다.
6. **카피는 i18n 리소스로** — GLOBAL 사용자도 같은 팝업을 본다. 한국어·영어 카피를 리소스에 두고, `items[].language`(`ko`·`en`)는 표시용으로만 쓴다. 영어 카피 안: "How were your recent picks?" · "Send" · "Not this week".
7. **mock** — `show=true`(2편)·`show=false` 두 응답을 mock에 둔다.

## 범위 밖

- 서버 변경은 없다. 노출 규칙(누구에게·얼마나 자주)은 서버 몫이다.
- 별점은 다음 편성에 반영되지 않는다(PM 결정 2026-09-30). 앱에서 "반영된다"는 식의 문구를 쓰지 않는다.
- 확정 카피·화면 ID는 `spec/uiux`(라이브러리 또는 별도 문서) 개정 시 정한다. 이 티켓의 카피는 안이다.

## 완료 조건

- Given `show=true`, `items` 2편 / When 라이브러리에 진입한다 / Then 팝업 안에 두 편이 썸네일·제목·별 1~5 목록으로 나열된다
- Given 팝업 / When 한 편만 별 4를 매기고 [보내기] / Then 그 한 편만 전송되고 팝업이 닫히며, 같은 세션에서 다시 뜨지 않는다
- Given 팝업 / When 닫는다 / Then `dismiss`가 응답의 `placed_date`로 나가고, 재진입해도 뜨지 않는다(서버 `show=false`)
- Given 팝업 / When [이번 주 그만 보기] / Then `mute`가 나가고 즉시 닫힌다
- Given `show=false` 또는 조회 실패 / When 라이브러리에 진입한다 / Then 팝업이 뜨지 않고 다른 화면 동작에 영향이 없다
- Given 오프라인에서 [보내기] / When 온라인이 된다 / Then 큐에서 재전송된다. `DRIP_FEEDBACK_NOT_RATEABLE`이면 조용히 버린다
- Given GLOBAL(영어) 사용자 / When 팝업이 뜬다 / Then 카피가 영어다
- Given 개발계 / When 가입 4일 이상·최근 편성분이 있는 계정으로 진입 / Then 실제 팝업이 뜨고, 보낸 별점이 어드민 "추천 검증" 표의 평가 수에 반영된다
