## 무엇을 한다

법률 멘토를 만나 아래 쟁점을 점검받는다. 질문은 미리 정리해 가고, 답변은 **결정 사항**으로 남긴다.

### 질문 후보 (미팅 전 다듬는다)

1. **개인정보 처리방침 개정 적용 전 수집** — Android 광고 ID 수집이 처리방침 적용일(11/1)보다 먼저 운영에 나갔다(KAN-117). 되돌리기 전 수집분의 처리·고지 의무
2. **AI 생성 콘텐츠의 원문 활용 범위** — 기사·자료를 요약·재구성해 대화체로 만들 때 저작권·출처 표기 기준
3. **구독 결제·환불 고지** — 전자상거래법상 청약철회·자동갱신 고지, 가입 체험(7일 무제한) 종료 고지 방식
4. **탈퇴 후 보존 범위** — `archived_users` 이메일 5년 보존(전자상거래법 6조 2항)의 해석이 맞는지
5. **운영 DB 열람 기준** — 운영 목적의 사용자 데이터 열람 범위(CLAUDE.md 2026-10-04 규칙의 근거 확인)

## 완료 조건

- Given 미팅 전 / When 질문 목록을 본다 / Then 쟁점별로 현재 상태와 묻는 것이 한 문단으로 정리돼 있다
- Given 미팅 후 / When 처리 기록을 본다 / Then 질문별 답변과 그에 따른 결정(바꿀 문서·코드)이 적혀 있다
- Given 바꿀 것이 생긴 쟁점 / When 요청 문서를 본다 / Then 해당 파트의 `changes/`·`tickets/`에 요청이 발행돼 있다
