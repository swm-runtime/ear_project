## 요청

광고 영상 스토리보드를 만들어 외주에 맡기고, SW마에스트로(소마)에 비용 증빙 서류를 제출한다 — 스토리보드(컷·카피·길이) 확정 → 외주처 선정·계약 → 견적서·계약서·세금계산서 등 소마 증빙 규정에 맞는 서류 제출.

## 완료 조건

- Given 외주 계약, When 산출물을 보면, Then 스토리보드와 계약서가 있다
- Given 소마 제출 시스템, When 증빙을 보면, Then 필요 서류가 제출 완료 상태다
