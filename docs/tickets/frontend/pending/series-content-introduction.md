## 현재 상태

- PRD **FR-13**: "분할된 편은 시리즈로 묶어 순서를 유지한다" — 원칙은 있다
- 스키마: `contents.series_id`·`episode_no`·`total_episodes`가 있고 단일 콘텐츠는 셋 다 `null`(`domain.md` 5.1)
- 상세 화면: "N부작 중 M화" 표시 규칙이 있다(`content-detail.md` 4.3-1)
- **비어 있는 것**: 시리즈를 실제로 만드는 제작 절차, 드립 편성에서 다음 화 순서 보장, 라이브러리·탐색·플레이어에서의 묶음 표시·연속 재생, 탐색 "시리즈 여부" 필터

## 무엇을 한다

1. **범위 확정** — 첫 도입에 넣을 것/뺄 것
   - 제작: 파이프라인이 한 주제를 몇 편으로 나눠 만들지(분할 기준·편수 상한)
   - 편성: 드립이 시리즈 1화를 넣으면 다음 날 2화를 이어 넣는지, 건너뛴 화 처리
   - 표시: 라이브러리 묶음 표시, 플레이어 "다음 화" 연속 재생, 탐색 필터
2. **규칙 문서화** — `features/`에 시리즈 규칙(새 문서 또는 기존 문서 절)을 적는다
3. **티켓 분해** — AI(제작) · BE(편성·API) · FE(표시) 티켓을 발행하고 선행 관계를 링크로 건다

## 완료 조건

- Given 이 티켓 / When 처리 기록을 본다 / Then 첫 도입 범위(넣는 것·빼는 것)가 결정돼 있다
- Given `features/` / When 시리즈 규칙을 찾는다 / Then 제작·편성·표시 규칙이 적혀 있다
- Given Jira / When 이 티켓의 링크를 본다 / Then 파트별 티켓이 발행돼 선행 관계로 연결돼 있다
