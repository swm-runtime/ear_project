## 확인할 것

- 선결제 후 승인이 **가능한지**, 가능하다면 **조건**(금액 한도·사전 신청 필요 여부)
- 필요한 **증빙**(영수증·세금계산서·견적서·결과물)과 **제출 기한**
- 승인되지 않을 때 비용 처리(개인 부담 여부)

## 완료 조건

- Given 문의 후 / When 이 티켓을 본다 / Then 위 표의 문의처·대상 비용·답변이 채워져 있다
- Given 가능하다는 답변 / When 관련 결제 진행 티켓을 본다 / Then 조건·증빙·기한이 반영돼 있다
- Given 불가하다는 답변 / When 처리 기록을 본다 / Then 대안(사전 승인 절차 등)이 적혀 있다
