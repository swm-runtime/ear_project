## 배경

기획 시리즈(처음부터 N편으로 기획한 주제 묶음)를 들인다. 파이프라인이 시리즈를 만들고(AI KAN-136), 서버가 시리즈를 별도 대상으로 둔다(BE KAN-134, 2026-10-17 설계 확정). 첫 대상은 이미 발행된 "키워드로 빠르게 배우는 CS 지식" 16편이다 — 서버가 일회성으로 한 시리즈로 묶는다.

지금 앱은 시리즈를 모른다. 탐색에는 편마다 한 줄씩 나와 16편짜리 시리즈 하나가 목록을 덮고, 상세의 "N부작 중 M화"는 평평한 세 칸(`series_id`·`episode_no`·`total_episodes`)을 읽는다.

## 결정 사항 (BE KAN-134 · 2026-10-09·17 박수헌)

- **탐색에서 시리즈는 하나의 요소다.** 누르면 그 시리즈의 편 목록 화면으로 간다.
- **시리즈 표지는 1화 썸네일이다.** 따로 표지가 없다.
- **콘텐츠 제목은 그대로다** — "키워드로 빠르게 배우는 CS 지식 3 - 소프트웨어 설계"처럼 시리즈 이름이 들어 있다. 시리즈 이름을 따로 보여 줘도 제목을 줄이지 않는다.
- **"다음 화 듣기"는 보류한다.** 연속 재생·시리즈 구독도 두지 않는다.
- 일부 편만 발행된 시리즈도 탐색에 노출한다. 시리즈 카드의 순위는 서버가 정한다.

## 무엇을 한다

1. **탐색 시리즈 카드** — 피드·주제별·인기·검색 응답이 단일 콘텐츠와 시리즈 카드가 섞인 목록이 된다(항목 종류 `type: "content" | "series"` — 정확한 모양은 KAN-134 의 `explore-api.md` 개정을 따른다).
   - 카드: 시리즈 제목 · 표지(1화 썸네일) · 편수 · 주제. 지금 타일과 같은 크기·격자에 들어간다.
   - **카드 탭 = 시리즈 화면으로 이동.** `features/explore.md` 4.4 "행 탭 = 즉시 재생"의 예외다 — 단일 콘텐츠 행은 그대로 즉시 재생이다.
2. **시리즈 화면(신규)** — `GET /series/:id`로 그린다.
   - 머리: 시리즈 제목 · 소개 · 표지(1화 썸네일) · 편수.
   - 편 목록: `episode_no` 순. 편마다 제목 · 길이 · 내 상태(담음 · 완청 · 재생 위치)를 서버 값으로 보인다.
   - 편 행의 조작은 탐색 행과 같다 — 행 탭은 재생 확인 팝업 → 재생, [더보기]는 담기·상세 정보.
3. **`series` 객체로 시리즈 표시** — 카드·라이브러리 항목·플레이어 응답에 `series: { id, title, episode_no, total_episodes } | null`이 실린다(KAN-134 3번).
   - 상세의 시리즈 줄을 이 객체로 바꾼다: "{시리즈 제목} · N부작 중 M화". 단일 콘텐츠(`series = null`)는 지금처럼 시리즈 줄이 없다.
   - 평평한 세 칸을 계속 읽지 않는다. 객체가 없는 응답(구버전 서버)에도 깨지지 않게 선택 필드로 둔다.
4. **문서를 같은 PR에서 고친다** — `features/explore.md`(4.1 시리즈 카드 · 4.4 예외) · `features/content-detail.md` 4.3-1(시리즈 줄 문구·데이터 출처) · 시리즈 화면 규칙(새 절 또는 새 문서) · `spec/uiux`·`wireframe`(시리즈 카드·시리즈 화면).
5. **mock** — KAN-134 배포 전에는 mock 시나리오(시리즈 카드가 섞인 피드 · 시리즈 화면 · `series` 객체가 있는/없는 항목)로 만든다. 실서버 전환은 배포 뒤.

## 범위 밖

- "다음 화 듣기"·연속 재생·시리즈 구독(결정 사항 — 보류)
- 라이브러리의 "시리즈 묶음" 항목 종류 — 라이브러리는 편 단위 그대로다(`series` 객체로 시리즈 줄만 보인다)
- 시리즈 순위·노출 규칙(서버 몫)

## 확인할 것

- 시리즈 카드가 가로 캐러셀(섹션)과 두 칸 격자(필터·검색 결과) 양쪽에서 단일 타일과 구분되는지 — 편수 표시 위치는 화면 쪽 판단
- 시리즈 화면에서 아직 발행되지 않은 편(진행 중 시리즈)을 보일지 — 서버는 발행된 편만 준다(KAN-134). 총 편수와 발행 편수가 다를 때의 문구

## 완료 조건

- Given 시리즈 3편이 발행돼 있다 / When 탐색 피드·인기·검색을 본다 / Then 시리즈가 카드 하나로 나오고 편 3개가 따로 나오지 않는다
- Given 시리즈 카드 / When 탭한다 / Then 재생하지 않고 시리즈 화면으로 이동하며, 표지는 1화 썸네일이다
- Given 시리즈 화면 / When 편 목록을 본다 / Then 편이 번호순이고 편마다 담음·완청·재생 위치가 서버 값대로 보인다
- Given 시리즈 화면의 편 행 / When 탭한다 / Then 탐색 행과 같은 재생 확인 팝업 → 재생 흐름이다
- Given 단일 콘텐츠 행 / When 탭한다 / Then 지금처럼 즉시 재생 흐름이다
- Given `series`가 있는 콘텐츠의 상세 / When 본다 / Then "{시리즈 제목} · N부작 중 M화"가 보이고, 제목은 시리즈 이름을 포함한 원래 제목 그대로다
- Given `series = null`이거나 응답에 `series`가 없는 콘텐츠 / When 상세를 본다 / Then 오류 없이 시리즈 줄이 없다
- Given `features/explore.md`·`features/content-detail.md` / When 시리즈 규칙을 찾는다 / Then 시리즈 카드·카드 탭 예외·시리즈 화면·시리즈 줄 규칙이 적혀 있다
