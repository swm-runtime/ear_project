## 요지 (Jira 본문용)

- `spec/uiux`에 화면 ID · 확정 카피(한/영)를 먼저 — 후기 시트 · 먼저 묻는 시트 · 발급 안내 · S12 프로모션 · 사용 확인
- 더보기 시트 세 곳 [후기](상세 정보 아래) · 콘텐츠 상세 "내 후기". 플레이어 화면 · 완청 순간에는 띄우지 않는다
- 라이브러리 진입 시 먼저 묻는 시트 — 서버 `show`로만, 같은 세션에 추천 별점이 떴으면 띄우지 않는다
- 설정 [프로모션 코드 입력] → **[프로모션]**: 이용 중 · 사용 가능한 프로모션 · 진행 · 코드 입력, 쓰지 않은 프로모션 점 배지
- 쓸 수 있는지 · 사유 · 날짜 판정은 전부 서버 — 앱은 표시만. 백엔드 전에는 mock으로
- 상세 · 완료 조건은 원본 문서

## 요청

**모든 편에 후기를 남기는 화면과 후기 참여 프로모션 보관 · 사용 화면을 만든다**(10월 5주차 계획(2026-10-26 회의) · 기획 확정 2026-10-28).

1. **`spec/uiux` 먼저** — `content-review.md` 5장의 카피 초안을 확정(한/영)하고 화면 ID를 붙인다
   - 라이브러리 · 탐색 · 플레이어 · 콘텐츠 상세 uiux: 더보기 시트(L4 · E12 · PL7) [후기], 상세 "내 후기"
   - `library-uiux.md`: 먼저 묻는 시트(추천 별점 L16과의 순서)
   - `settings-uiux.md` 4.8: S12 개편(행 이름 · 화면 제목 · 구성 · 배지 · 사용 확인 · 사유)
2. **진입점** — 세 더보기 시트 [상세 정보] 아래 [후기], 상세 "내 후기"(내 별점 + [수정]). 서버가 후기 기능 꺼짐을 내려주면 그리지 않는다
3. **후기 시트** — 별 필수 · 글 n/500 · 보상 줄(서버가 진행 값을 줄 때만) · 이미 쓴 편은 채워진 채 [수정하기] · 안 들은 편은 안내 · 성공 토스트 · 실패는 `drip-feedback.md` 5장과 같다(망 단절 → 기기 보관 → 다음 진입 · 포그라운드 복귀에 재전송)
4. **먼저 묻는 시트** — 라이브러리 진입 시 앱 실행 × 계정 단위로 한 번만 조회(추천 별점과 같은 규칙). **같은 세션에 추천 별점 팝업이 떴으면 조회 · 표시하지 않는다.** 닫기 = `dismiss`, [이번 주 그만 보기] = `mute`
5. **발급 안내 시트** — 저장 응답에 프로모션이 있으면 [지금 쓰기](→ S12) / [나중에]
6. **S12 프로모션** — 행 이름 · 화면 제목 "프로모션" / "Promotions". 구성은 `content-review.md` 4.6
   - 사용 확인 팝업: 끝나는 날짜는 서버 값. 체험 중이면 한 줄 더
   - 쓸 수 없음: [사용하기] 흐림 + 사유 줄(`pro_subscribed` · `grant_active` 문구 매핑)
   - 성공: 기존 토스트 문자열(이름 "후기 참여") + 요약 재조회(결제와 같은 배선)
   - 쓰지 않은 프로모션이 있으면 설정 [프로모션] 행에 점 배지
   - 코드 입력은 지금 그대로(즉시 적용). **화면 문구에 "쿠폰"을 쓰지 않는다**
7. **mock** — 기존 onboarding · library 패턴으로 `api/content-review.mock.ts` + `IS_CONTENT_REVIEW_API_MOCKED`(`EXPO_PUBLIC_CONTENT_REVIEW_API=real`로 실서버) + `EXPO_PUBLIC_CONTENT_REVIEW_MOCK_SCENARIO`. 시나리오: 발급 직전(2/3) · 발급됨 · Pro 구독 중 · 다른 프로모션 이용 중 · 체험 중 · 스위치 꺼짐 · 안 들은 편
8. **문구 정리** — 지급 줄의 "이벤트 이용 중" 잔재: `spec/uiux/profile-uiux.md` 4장(390행 부근) · `plan-grant.ts` · `useSettingsScreen.ts` 주석 · `PlanSummaryCard.test.tsx`. 실제 화면은 이미 "프로모션 이용 중"이다
9. **하지 않는 것** — 플레이어 화면 · 완청 순간의 개입, 기기 시각으로 소멸 · 사용 가능 판정, 티어 비교, 평균 별점 표시

## 완료 조건

- Given 들어 본 편의 더보기 시트 / When [후기] → 별 4개 → [보내기] / Then 토스트 "후기 고마워요"가 뜨고, 다시 열면 내 후기가 채워진 채 [수정하기]다
- Given 들어 본 적 없는 편 / When [후기] / Then 시트 대신 안내가 뜬다
- Given 발급 직전(2/3) / When 3번째 후기를 보낸다 / Then 발급 안내 시트가 뜨고 [지금 쓰기]가 S12로 간다
- Given 무료 계정 S12 / When [사용하기] → 확인 / Then 성공 토스트가 뜨고 설정 · 프로필 · 요금제 관리에 "후기 참여 프로모션 이용 중 · Pro · N월 N일까지"가 보인다
- Given Pro 구독 중 / When S12 / Then [사용하기]가 흐리고 사유 줄이 보인다
- Given 쓰지 않은 프로모션이 있다 / When 설정 / Then [프로모션] 행에 점 배지가 있다
- Given 같은 세션에 추천 별점 팝업이 떴다 / When 라이브러리에 다시 들어온다 / Then 먼저 묻는 시트가 뜨지 않는다
- Given 서버가 후기 기능 꺼짐을 내려준다 / Then 더보기 시트에 [후기]가, 상세에 "내 후기"가 없다
- Given 망 단절 중 후기를 보냈다 / When 연결 뒤 포그라운드로 돌아온다 / Then 다시 보내진다
- Given 플레이어로 끝까지 들었다 / Then 플레이어 화면에 후기 요청이 뜨지 않는다
- Given GLOBAL 계정 / Then 같은 화면이 영어로 나온다
