## 요청

**모든 편에 별점·의견을 남기는 화면과 보상(Pro 7일) 안내**를 만든다(10월 5주차 계획(2026-10-26 회의)).

- 묻는 위치·카피·보상 안내는 기획 티켓을 따른다. 카피는 `spec/uiux/`에 먼저 올린다
- **보상 판정은 서버**, 앱은 응답을 표시만 한다
- 기존 추천 별점 팝업(KAN-116)과의 관계(합침·공존)는 기획 결정대로

## 완료 조건

- Given 기획이 정한 위치 / When 별점·의견을 보낸다 / Then 완료 안내가 뜨고, 서버가 보상을 줬으면 보상 안내가 뜬다
- Given 보상을 이미 받은 계정 / When 다시 보낸다 / Then 보상 안내 없이 완료만 뜬다
