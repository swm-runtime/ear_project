## 무엇을 한다

1. **조사** — 비슷한 형식(2인 대화체·10~15분·지식형)의 팟캐스트·오디오 콘텐츠 레퍼런스를 모아 구성 패턴을 정리한다(도입 훅, 전개 방식, 마무리·다음 편 예고, 화자 역할 분담).
2. **전문가 피드백** — 오디오/콘텐츠 전문가에게 현재 발행 에피소드 1~2편을 들려주고 구성·말투·길이 피드백을 받는다.
3. **정리** — 조사·피드백을 "지금 대본과 무엇이 다른가 / 무엇을 바꾸자"로 정리해 AI 파트(박수헌)에 대본 스킬·스펙 개선 요청(`docs/changes/pending/` 또는 AI 티켓)으로 넘긴다.

## 완료 조건

- Given 이 티켓 / When 처리 기록을 본다 / Then 조사한 레퍼런스 목록과 구성 패턴 요약이 있다
- Given 전문가 피드백 / When 처리 기록을 본다 / Then 누구에게(역할만) 무엇을 들려주고 어떤 피드백을 받았는지 적혀 있다
- Given 정리 결과 / When AI 파트 요청 문서를 본다 / Then 바꿀 항목이 대본 스킬·스펙 단위로 적혀 있다
