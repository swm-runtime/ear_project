## 문제

**카카오톡은 링크를 인앱 브라우저로 연다.** 인앱 브라우저는 유니버설 링크(iOS)·App Links(Android)를
타지 않으므로, **앱이 설치돼 있어도 앱으로 넘어가지 않는다.** 대신 랜딩의 미설치 안내 페이지가 뜬다.

메모·문자에서 탭하면 정상 동작한다(2026-09-08 실기기 확인) — **인프라·라우팅은 문제없다.**
문제는 링크가 도착하는 자리다.

> **이것이 왜 중요한가** — 우리 사용자가 링크를 주고받는 곳은 사실상 카톡이다. 지금 구조면
> 받는 사람 대부분이 안내 페이지에서 멈춘다. 앱을 이미 설치한 사람도 마찬가지다.

## 원인 두 겹

### ① 인앱 브라우저가 OS 링크 검증을 타지 않는다

우리가 고칠 수 없는 부분이다. **탈출 경로를 우리가 제공해야 한다.**

### ② 앱이 커스텀 스킴으로 열릴 수 없다 — 파서가 거절한다

`app.json`에 `scheme: "ear"`가 있어 `ear://...`로 앱을 띄울 수는 있는데, 게이트의 파서가
**https 만** 받는다.

```ts
// share.link.ts
const SHARE_LINK_PATTERN = /^https:\/\/earcast\.co\.kr\/contents\/([^/?#]+)/;
```

즉 `ear://contents/<id>`로 앱이 떠도 **목적지를 버리고 정상 진입 분기를 탄다.**
주석이 *"https 외 스킴·다른 host·다른 경로는 전부 null"* 이라고 의도를 밝히고 있으므로,
바꾼다면 **의도적인 확장**으로 다뤄야 한다.

## 요청 내용

1. **파서가 커스텀 스킴도 받게 한다** — `ear://contents/:id`. 다른 host·경로는 지금처럼 거절한다.
   보안 관점의 변화는 없다: 링크에 실리는 값은 `content_id` 하나이고, 조회 스코프는 언제나
   수신자 자신의 토큰이 정한다(`share.link.ts` 상단 주석).
2. **랜딩 안내 페이지에 [앱에서 열기]를 둔다** — `ear://contents/<id>`로 이동한다.
   인앱 브라우저에서도 커스텀 스킴은 대개 동작한다.
   - 지금 페이지는 **`content_id`를 읽지 않는다**(주석에 명시). 이 버튼을 두려면 읽어야 하므로
     그 결정을 함께 갱신한다 — 미리보기(제목·썸네일)를 그리자는 것이 **아니라** 링크 조립용이다.
3. **카톡 한정 탈출 경로를 검토한다** — `kakaotalk://web/openExternal?url=<encoded>`는 카톡
   인앱 브라우저에서 외부 브라우저를 여는 카카오 공식 스킴이다. 외부 브라우저로 나가면 유니버설
   링크가 정상 동작한다. **UA에 `KAKAOTALK`이 있을 때만** 노출한다.
   - Android는 `intent://…#Intent;scheme=https;package=com.android.chrome;end` 방식도 있다.
   - **둘 다 실기기 확인이 필요하다** — 카카오·구글 모두 동작이 바뀔 수 있는 영역이라 문서만 보고
     확정하지 않는다.
4. **버튼 문구와 배치는 `share-uiux.md`가 소유하지 않는다** — 랜딩은 앱 화면이 아니다.
   문구는 이 티켓에서 정하되 확정본을 여기 기록한다.

## 완료 조건

- Given 앱이 설치된 기기 / When **카톡에서** `https://earcast.co.kr/contents/<발행 id>`를 탭한다 / Then 앱이 열리거나, 안내 페이지의 **[앱에서 열기] 한 번으로** 앱이 열린다
- Given 그 경로로 앱이 열렸다 / When 관문을 통과한 사용자다 / Then **그 콘텐츠 상세에 도착한다**(목적지를 버리지 않는다)
- Given 앱이 설치되지 않은 기기 / When 같은 링크를 카톡에서 탭한다 / Then [앱에서 열기]를 눌러도 아무 일도 일어나지 않거나 스토어 안내로 이어진다(오류 화면이 뜨지 않는다)
- Given 메모·문자에서 탭한다 / When 앱이 설치돼 있다 / Then 지금처럼 곧바로 앱이 열린다(회귀 없음)
- Given `share.link.ts` / When 파서를 읽는다 / Then 허용 스킴이 문서화돼 있고, 다른 host·경로는 여전히 거절한다
