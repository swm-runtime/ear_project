## 요청

안드로이드 앱을 iOS 와 같은 수준으로 점검·수정한 뒤 배포한다 — JS 탭 바 갈래(CapsuleTabBar·떠 있는 머리 줄·JS 미니플레이어)의 화면 깨짐·동작 오류를 실기기에서 훑어 고치고, 개발계 aab(Play 내부 테스트)로 확인한 뒤 운영 트랙에 올린다.

## 완료 조건

- Given 안드로이드 실기기, When 라이브러리·탐색·플레이어·설정을 한 바퀴 돌면, Then 깨지거나 멈추는 화면이 없다
- Given Play 내부 테스트, When 최신 aab 를 받으면, Then 소셜 로그인·재생·푸시가 동작한다
