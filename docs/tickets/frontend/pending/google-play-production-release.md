## 요청

구글 플레이 스토어 운영(프로덕션) 트랙 출시를 끝까지 진행한다 — 운영 Android aab(최신 runtime) 빌드 → Play Console 업로드 → 스토어 등록정보·데이터 보안 양식(GA4·Sentry·Meta SDK 고지)·콘텐츠 등급 → 비공개/프로덕션 심사 제출 → 출시.

## 완료 조건

- Given Play Console, When 운영 트랙을 보면, Then 최신 버전이 심사 통과 후 출시 상태다
- Given 데이터 보안 양식, When 수집 항목을 보면, Then GA4·Sentry·Meta SDK 수집이 신고돼 있다
