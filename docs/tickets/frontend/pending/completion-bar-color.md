## 증상 (2026-10-23 박준현, Android dev 빌드)

라이브러리 카드에서 완청한 편과 듣는 중인 편이 구분되지 않는다 — "표시가 알아볼 수가 없다". 서버 상태·진행 값은 맞게 온다(개발계 `GET /users/me/library-items` 직접 확인 — `completed` 행은 바 100%로 그려질 값).

## 원인

완청 표시가 사진 아래 **높이 4pt 진행 바 하나**뿐이고(2026-09-22 PM — 좌상단 체크 스티커 제거), 채움 색 `palette.progress` 가 **회색 `#8E8E93`**, 트랙이 흰색 35%다. 완청은 같은 바를 100% 채울 뿐이라 듣는 중(예: 85%)과 색이 같고, 밝은 사진 위에서는 회색 바 자체가 묻힌다.

## 무엇을 한다

1. 바 채움 색을 상태별로 가른다 — **듣는 중**과 **완청**이 다른 색. 예: 듣는 중 = 흰색(사진 위 대비) · 완청 = 강조색(`chart` 계열 초록 `#4CBFA6` 같은 성공 색). 값은 PM 확인(`design.md` 애플 HIG — 시스템 초록 계열이면 "다 들음"으로 읽힌다).
2. 토큰을 나눈다 — `progress`(듣는 중) · `progressCompleted`(완청) 밝은·어두운 팔레트 둘 다. 코드에 색을 박지 않는다.
3. 밝은 사진 대비 — 바 아래 변 어둡힘(2026-09-22)이 두 색 모두에서 충분한지 실기기로 본다.
4. 낭독기 라벨은 그대로(`completedA11y` · `progressA11y`).

## 범위 밖

- 사진 위 체크 스티커 부활(2026-09-22 PM 결정 유지)
- 탐색 카드 완청 표시(지금은 낭독기 라벨만 — 필요하면 PM 이 따로 정한다)

## 완료 조건

- Given 라이브러리에 듣는 중(50%) 편과 완청 편이 나란히 있다 / When 카드를 본다 / Then 두 바의 색이 달라 한눈에 구분된다
- Given 밝은 사진의 완청 카드 / Then 완청 바가 보인다
- Given 어두운 모드 / Then 같은 구분이 유지된다
- Given 색 값 / Then `palette.ts` 토큰에서만 온다(밝은·어두운 둘 다)
