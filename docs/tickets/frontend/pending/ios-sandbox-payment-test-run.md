## 무엇을

개발계(preview) iOS 앱에서 **샌드박스 결제 시나리오를 처음부터 끝까지 혼자 돌리고, 각 단계의 앱 동작과 시각을 기록**한다. 서버 쪽 확인(로그·DB·티어)은 백엔드가 기록된 시각으로 대조하므로 **서버는 보지 않아도 된다.** 돈은 나가지 않는다(샌드박스).

## 시작 전 준비

1. **개발계 앱을 최신으로.** 결제 화면은 rt 32 preview 빌드(KAN-155)에만 있다. 그 빌드를 설치한 뒤 앱을 완전히 종료하고 다시 열어 OTA(preview 채널)까지 받은 상태에서 시작한다. **설정 화면 위쪽에 **"요금제 관리" 카드**가 보이면** 결제 모듈이 든 rt 32 빌드다 — 안 보이면 옛 빌드(rt 31)라 KAN-155 빌드를 기다린다. 2026-10-07 23:10 기준 개발계 iOS 1.2.0(44)가 dev 앱 TestFlight에 제출돼 있다 — TestFlight에서 설치한다.
2. **샌드박스 테스터 계정** — 박준현이 Slack에 남겨 둔 계정(이메일·암호). 기기에서 **설정 → App Store → 아래 "샌드박스 계정"** 에 로그인한다. 기기의 실제 Apple ID는 그대로 둔다(샌드박스 계정은 결제 시트에만 쓰인다). 항목이 안 보이면 앱에서 [구독하기]를 한 번 눌러 시트를 띄운 뒤 다시 확인.
3. **앱 계정** — 본인 소셜 계정으로 개발계 앱에 로그인하고 설정에서 **이메일 인증**까지 끝낸다(인증 없으면 결제 시트가 열리지 않는 것이 정상 — 그 안내가 뜨는지가 ①).
4. ⑥을 위해 **다른 소셜 계정 하나**를 준비한다(같은 사람의 다른 로그인이면 된다).

## 시나리오 — 순서대로. 단계마다 **시각(분 단위)과 앱에서 보인 것**을 적는다

| # | 하는 것 | 앱에서 기대하는 것 |
|---|---|---|
| ① | 이메일 미인증 상태로 페이월 → [구독하기] | 이메일 등록·인증 화면으로 안내(결제 시트 안 열림) |
| ② | 이메일 인증 뒤 페이월에서 **Pro [구독하기]** → 시트 승인(샌드박스 계정 암호) | 시트에 "환경: Sandbox"가 보이고, 승인 뒤 구독 중으로 바뀌며 막혔던 콘텐츠가 자동 재생된다 |
| ③ | 5분 기다린 뒤 설정 > 요금제 관리 | 갱신일이 5분씩 뒤로 간다(샌드박스 월간 = 5분 갱신, 12회 뒤 만료) |
| ④ | 기기 설정 → App Store → 샌드박스 계정 → **구독 관리 → 자동 갱신 끄기** → 앱 복귀 | 구독 화면이 "해지 예약"(만료일까지 유효)으로 바뀐다. 다시 켜면 "구독 중" |
| ⑤ | 앱 삭제 → 재설치 → 같은 계정 로그인 → 설정 > 요금제 관리 → **[구매 복원]** | "구독이 복원되었어요" + 구독 중 |
| ⑥ | **다른 소셜 계정**으로 로그인 → [구매 복원] | "이미 다른 계정에서 사용 중인 구독이에요"(409). 원래 계정으로 돌아오면 그대로 구독 중 |
| ⑦ | 원래 계정에서 Daily [변경] 시도 | 다운그레이드는 다음 갱신부터 — 구독 화면에 "N월 N일부터 Daily" 표시 |
| ⑧ | 구매 내역을 지운 뒤 새로 구매하되 **시트 승인 직후 앱을 강제 종료** → 다시 열기 | 자동으로 구독 중이 된다(미완료 거래 회복) |
| ⑨ | 12회 갱신 뒤(약 1시간) 또는 ④의 해지 예약 상태로 두고 만료 기다리기 | 무료로 돌아가고 페이월이 다시 뜬다 |
| ⑩ | (Pro 상태에서) 설정 > 음질 → **무손실** 선택 → FLAC이 있는 콘텐츠를 **LTE**에서 재생 | 다음 편부터 무손실. 재생 버튼 → 소리 시작까지 초를 3회 재서 적는다(KAN-141에 쓸 값) |

**처음부터 다시 하려면**: App Store Connect → 사용자 및 액세스 → 샌드박스 → 테스터 계정 → 그 계정의 **구매 내역 지우기**. 같은 곳의 "구독 갱신 속도"·"결제 중단 테스트"도 쓸 수 있다.
