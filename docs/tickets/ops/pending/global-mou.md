## 요청

### 후보 (2026-10-25 정리)

| 순위 | 기관 | 맞는 이유 |
|---|---|---|
| 1 | 해외문화홍보원(문체부) | 영어로 한국을 해외에 알리는 것이 본업 — Korea.net, 재외 한국문화원, 외국인 명예기자단 |
| 2 | 한국국제문화교류진흥원(KOFICE) | 해외 한류 실태조사 — 나라별로 먹히는 K콘텐츠 데이터(주제 선정 근거) |
| 3 | 한국콘텐츠진흥원(KOCCA) | K콘텐츠 해외 진출 지원사업·해외 비즈니스센터 |

| 참고 | 한국국제교류재단(KF) | 공공외교 — 학술·대학 쪽 비중이 크다 |

- **협약 목적을 먼저 정한다**: 청취자 통로 / 기관 홍보 콘텐츠 발주(매출) / 지원사업
- 기관 조직·담당 부서는 연락 전에 현재 기준으로 확인한다(개편 여부 미확인)
- 드라마·음악 클립·음원을 쓰려면 기획사·제작사와 **별도 권리 협약**이 필요하다 — 기관 MOU로 해결되지 않는다

## 완료 조건

- Given 착수 / When 이 문서를 본다 / Then 협약 목적과 접촉할 기관·담당 부서가 적혀 있다
- Given 첫 접촉 뒤 / When 처리 기록을 본다 / Then 기관별 접촉 날짜·응답·다음 단계가 적혀 있다
