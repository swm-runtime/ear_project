코드 없는 스토어 콘솔 설정이다. **공개 국가 선택은 지금 해도 되고, 영어 링크는 랜딩 영어 페이지가 운영에 배포된 뒤에** 넣는다 — 먼저 넣으면 심사관이 404를 본다.

## App Store Connect
1. 앱 정보 → 언어 추가에서 영어(English) 현지화를 연다.
2. 영어 현지화의 **개인정보 처리방침 URL**: `https://earcast.co.kr/en/privacy/`
3. 영어 현지화의 **설명** 끝에 두 줄(가이드라인 3.1.2 — 구독 앱 필수):
   - Terms of Use: https://earcast.co.kr/en/terms/
   - Privacy Policy: https://earcast.co.kr/en/privacy/
4. 한국어 현지화는 지금 링크(`/terms`, `/privacy`) 그대로.

## Google Play Console
1. 기본 스토어 등록정보에 영어(en-US) 번역을 추가하고 설명 끝에 위 두 줄을 넣는다.
2. **주의 — 앱 콘텐츠의 개인정보처리방침 URL은 언어별이 아니라 하나뿐이다.** 한국어 페이지(`/privacy`)를 그대로 두고, 그 페이지에서 영어판으로 가는 링크가 있어야 한다(한국어 처리방침 상단 "English" 링크 — 랜딩 브랜치에서 같이 넣는다).

## 공개 국가 — 6개국만 선택 (2026-10-15 결정)

**한국 · 싱가포르 · 말레이시아 · 필리핀 · 태국 · 인도네시아.** 그 밖은 전부 해제한다.

- 이유: 영어 처리방침이 이 5개 동남아 국가 기준으로 쓰였다. EU·영국(GDPR — 대리인·동의 팝업·국외 이전 계약), 미국 일부 주·호주(앱 연령 확인), 중국(별도 허가), 베트남(국외 이전 영향평가서 제출 — Decree 13)은 문서·동의가 준비되지 않았다.
- 나라 추가는 나중에 콘솔에서 언제든 할 수 있고 새 빌드가 필요 없다. 반대로 열었다가 닫으면 기존 설치자는 남고 신규만 막혀 정리가 지저분하니 좁게 시작한다.
- 국가 선택은 앱 단위다. 싱가포르에 사는 한국인도 같은 앱을 받고, 어떤 콘텐츠를 보는지는 가입 때 고른 언어가 정한다.
- **구독 상품(인앱 구매)의 판매 국가도 같은 6개국인지 확인한다.**

### App Store Connect
1. 앱 → **가격 및 사용 가능 여부**(Pricing and Availability)
2. **앱 사용 가능 여부**(App Availability) → **편집** → "모든 국가 또는 지역" 해제 → 6개국만 체크 → **저장**
3. 앱 → **구독**(Subscriptions) → 구독 그룹 → 각 상품 → **사용 가능 여부**(Availability)에서 같은 6개국인지 확인
4. 국가 선택은 심사 없이 바로 반영된다(최대 24시간)

### Google Play Console
1. 앱 → **테스트 및 출시** → **프로덕션** → **국가/지역** 탭
2. **국가/지역 수정**(또는 추가) → 6개국만 남기고 나머지 해제 → **저장**
3. **게시 개요**(Publishing overview)에서 변경 사항을 **검토를 위해 전송** — 관리형 게시를 쓰면 여기서 게시까지 눌러야 반영된다
4. 앱 → **수익 창출** → **제품** → **구독** → 각 상품의 기본 요금제 → 지역별 가격에서 6개국이 판매 중인지 확인

## 완료 조건
- Given App Store 영어 리스팅 / Then 설명에 영어 약관·처리방침 링크가 있고 개인정보 URL이 `/en/privacy/`이며 둘 다 200
- Given Play 영어 리스팅 / Then 설명에 두 링크가 있고, 개인정보 URL 페이지에서 영어판으로 갈 수 있다
- Given 두 스토어의 공개 국가 / Then 6개국만 선택돼 있고 구독 상품 판매 국가도 같다
