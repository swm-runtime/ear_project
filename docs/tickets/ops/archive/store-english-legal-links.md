## 1. 공개 국가 — 1차 7개국 (2026-10-15 결정)

**한국 · 싱가포르 · 말레이시아 · 필리핀 · 태국 · 인도네시아 · 홍콩.** 앱 공개 국가는 이 7곳만 남기고 전부 해제한다.

- 이유: 영어 처리방침이 동남아 5개국과 홍콩 기준으로 쓰였고, 서울 API·CloudFront 아시아 엣지(`PriceClass_200`)로 지연이 낮고, 민간 앱 데이터 현지화 의무가 없다. 홍콩은 영어가 공용어이고 K-컬처 소비가 많으며 추가 문서가 거의 필요 없어 1차에 넣었다. EU·영국(GDPR — 대리인·동의 팝업·국외 이전 계약), 미국(처리방침에 미국 내용 없음), 호주(앱 연령 확인), 중국(별도 허가), 베트남(국외 이전 영향평가서 제출 — Decree 13)은 문서·동의가 준비되지 않았다.
- **CloudFront는 별도 설정이 없다.** 7곳 모두 `PriceClass_200`의 아시아 엣지 범위 안이고, 접속 위치에 맞는 엣지는 CloudFront DNS가 자동으로 고른다. 가격 등급 변경은 호주·뉴질랜드 등 아시아 밖을 열 때만 검토한다.
- 나라 추가는 나중에 콘솔에서 언제든 할 수 있고 새 빌드가 필요 없다. 반대로 열었다가 닫으면 기존 설치자는 남고 신규만 막혀 정리가 지저분하니 좁게 시작한다.
- 국가 선택은 앱 단위다. 싱가포르에 사는 한국인도 같은 앱을 받고, 어떤 콘텐츠를 보는지는 가입 때 고른 언어가 정한다.
- **1.2.1을 먼저 열어도 안전하다.** main 브랜치 앱은 가입 때 언어 정보(`language_code`·`preferred_language`)를 보내지 않아 서버가 전원 KR 시장으로 판정한다. 7개국에서 1.2.1로 가입해도 숨겨진 GLOBAL 주제에 갇히지 않는다 — 동남아 거주 한국인이 한국어 앱을 쓰는 상태가 된다.
- 다음 단계 후보: 2차 브루나이·인도(인도는 해외 연령 18세 결정 뒤 — DPDP법 18세 미만 부모 동의), 3차 호주·뉴질랜드(CloudFront 가격 등급을 `All`로 올려야 현지 엣지 사용). 보류: 일본(일본어 콘텐츠 뒤)·베트남·EU·영국·중국.

### 구독 판매 국가 — 앱 공개 국가와 일부러 다르게 둔다

| 스토어 | 구독 판매 국가 | 이유 |
|---|---|---|
| App Store | 7개국 + **미국** (8곳) | 심사는 주로 미국 스토어 테스트 계정으로 진행된다. 미국에 상품이 없으면 심사 중 상품을 불러오지 못해 반려될 위험이 있어 넣어 둔다. 앱이 미국에 공개되지 않아 일반 미국 사용자는 결제할 수 없다 |
| Google Play | **모든 국가** (한국 가격 기준 자동 환산) | 앱 배포를 7개국으로 막았으니 실제 결제는 7개국에서만 일어난다 |

- App Store 가격(2026-10-15 설정): KRW ₩9,900 · MYR RM 29.90 · USD $5.99 · SGD $8.98 · IDR Rp 119,000 · THB ฿199 · PHP ₱399 · HKD $48. 대부분 미화 6~7달러 안팎이다.
- 자동 환산 가격은 환율 기준이라 현지 구매력이 반영되지 않는다(인도네시아·필리핀은 비싼 편). 반응을 본 뒤 그 나라만 따로 조정한다.
- **나라를 추가하면 그 나라 구독이 자동 환산 가격으로 바로 열린다.** 국가를 늘릴 때 그 나라 가격을 한 번 확인한다.
- 미국 멘토 사용: 앱이 미국에 공개되지 않으므로 **TestFlight 초대**(Android는 Play 내부 테스트 트랙)로 설치한다. 테스트 결제는 실제로 청구되지 않는다. TestFlight 빌드는 90일마다 만료된다.

### App Store Connect — 완료(2026-10-15)
1. 앱 → **가격 및 사용 가능 여부** → **앱 사용 가능 여부** → **편집** → 전체 해제 → 7개국만 체크 → **저장**
2. 앱 → **구독** → 구독 그룹 → 각 상품 → **사용 가능 여부**를 7개국 + 미국으로
3. 국가·구독 판매 국가 변경은 심사가 없다(최대 24시간 내 반영). 구독 상품은 이미 승인·판매 중이라 국가 추가로 재심사되지 않는다

### Google Play Console — 남음
1. 앱 → **테스트 및 출시** → **프로덕션** → **국가/지역** 탭 → **국가/지역 수정** → 7개국만 남기고 **저장**
2. **게시 개요**에서 변경 사항을 **검토를 위해 전송** — Play는 국가 변경도 검토를 거친다(보통 몇 시간~하루)
3. 관리형 게시가 켜져 있으면 승인 뒤 **게시**를 직접 눌러야 반영된다
4. 구독 기본 요금제 가격은 모든 국가 자동 환산으로 설정 완료(2026-10-15)

## 2. 영어 리스팅 — 글로벌 버전 심사 제출 때 (KAN-198과 함께)

**1.2.1에는 넣지 않는다.** 1.2.1은 이벤트 코드만 나가는 버전이고 영어 화면·영어 콘텐츠가 없다. 영어 리스팅이 앱에 없는 기능을 설명하면 Apple 가이드라인 2.3(정확한 메타데이터) 반려 위험이 있다. 스토어 현지화는 어느 버전에서든 추가할 수 있어 1.2.1에 넣어야 할 규칙도 없다. 그때까지 처리방침은 한국어 `/privacy/` 페이지의 영어판 링크로 충분하다.

### App Store Connect
1. 글로벌 버전 화면에서 영어(English) 현지화를 추가한다.
2. 영어 현지화의 **개인정보 처리방침 URL**: `https://earcast.co.kr/en/privacy/`
3. 영어 현지화의 **설명** 끝에 두 줄(가이드라인 3.1.2 — 구독 앱 필수):
   - Terms of Use: https://earcast.co.kr/en/terms/
   - Privacy Policy: https://earcast.co.kr/en/privacy/
4. 한국어 현지화는 지금 링크(`/terms`, `/privacy`) 그대로.

### Google Play Console
1. **스토어 등록정보** → 번역 관리 → English (United States) 추가 → 설명 끝에 위 두 줄.
2. **앱 콘텐츠의 개인정보처리방침 URL은 언어별이 아니라 하나뿐이다.** 한국어 `/privacy/`를 그대로 둔다 — 그 페이지 상단에서 영어판으로 갈 수 있다(운영 배포 확인 2026-10-15).

## 완료 조건

- Given 구독 판매 국가 / Then App Store는 7개국 + 미국, Play는 모든 국가이고 7개국 모두 가격이 잡혀 있다
- Given 글로벌 버전 App Store 영어 리스팅 / Then 설명에 영어 약관·처리방침 링크가 있고 개인정보 URL이 `/en/privacy/`이며 둘 다 200
- Given 글로벌 버전 Play 영어 리스팅 / Then 설명에 두 링크가 있고, 개인정보 URL 페이지에서 영어판으로 갈 수 있다
