## 왜

「키워드로 빠르게 배우는 CS 지식」 시리즈의 완청률이 좋다. IT 쪽 제작 비중을 올려 IT 사용자층을 노린다. 코드 변경 없이 운영 작업이 중심이다.

## 무엇을 한다

- 데이터·AI / IT·개발 하위 주제 스윕 빈도를 올린다(모드 A 수동 실행). IT 소스 풀 보강(도메인 티어 판단 — PIPELINE 미결 #2).
- IT 시리즈 기획: 콘솔 시리즈 → 게이트 S. CS 16편은 수동 제작 예외였으므로 자동 경로와의 형식 차이를 처리 기록에 남긴다.
- 병목은 게이트 2 검수 시간이다 — 주간 목표 편수를 정해 처리 기록에 남긴다.
- 유료 시리즈(KAN-290) 대비, 시리즈 기획 규칙에 "4편 이상, 1~3편이 훅"을 넣을지 판단(선택, 프롬프트 수정).
- IT 커뮤니티 홍보는 운영 — 커뮤니티별 초대 코드로 유입을 잰다(KAN-293).

## 범위 밖

- 자동 스윕 스케줄러·AI 시리즈 주제 제안(코드 작업 — 필요하면 별도 티켓).
