## 요청

잔여 예산 **3,150,000원**으로 만들 수 있는 콘텐츠 편수를 계산한다. 그 전제로 **1편을 만드는 데 드는 API 비용**을 단계별로 조사한다.

1. **OpenAI API 비용(1편당)** — 파이프라인에서 OpenAI 를 부르는 단계를 전부 모아 실제 사용량 기준으로 산정한다(`ai/PIPELINE.md` 단계 순서).
   - 단계별 모델명, 입력·출력 토큰(가능하면 최근 발행분 실측 — 워커 로그·OpenAI 사용량 대시보드), 단가(조사 시점 공식 가격표, 조사 날짜 명시)
   - 대상 예: 스윕·군집화·백로그, 대본 생성, QA·비평, 패키지(제목·요약), 추천 메타·임베딩(`ai/metadata-pipeline.md` — `text-embedding-3-small`), 썸네일 생성이 OpenAI 라면 포함
   - 재시도·재생성(QA 반려 후 재작성 등) 평균 횟수도 반영한다
2. **ElevenLabs API 비용(1편당)** — 다중화자 1콜(Text to Dialogue, `eleven_v3`, `ai/spec/06`) 기준.
   - 1편 평균 대본 글자 수(또는 오디오 길이) × 요금제의 글자·크레딧 단가. 현재 요금제·월 크레딧·초과 단가를 적는다
   - 재합성 비율 반영
3. **편수 산정** — `3,150,000원 ÷ (1편 OpenAI + ElevenLabs 비용)`. 환율(조사일 기준)과 요금제 월 고정비가 있으면 고정비를 먼저 빼고 계산한다. 낙관·보수 두 값을 낸다.
