## 무엇을 한다

1. 새 썸네일 스타일·규칙 확정 — 톤·구도·텍스트 유무·주제별 일관성
2. 파이프라인 썸네일 생성 프롬프트·후처리 갱신
3. 이미 발행된 콘텐츠 썸네일 일괄 교체 — **오디오를 건드리지 않는 경로**로(재발행으로 `contentVersion`이 바뀌면 사용자 재생 위치가 초기화된다 — `player-api.md` 4.3)

## 완료 조건

- Given 새 규칙 / When `docs/ai/`를 본다 / Then 썸네일 스타일·규칙이 적혀 있다
- Given 새로 발행한 콘텐츠 / When 썸네일을 본다 / Then 새 규칙대로 생성돼 있다
- Given 기발행 콘텐츠 / When 교체 후 앱에서 본다 / Then 썸네일만 바뀌고 사용자 재생 위치는 유지된다
