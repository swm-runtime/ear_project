## 배경

ElevenLabs **Pro 결제**로 TTS 원본을 무손실(PCM)로 받을 수 있다. PM 결정(2026-10-06): 사용자 음질을 **압축 · AAC · WAV** 3단계로 나누고 Light·Daily 는 압축·AAC, Pro 는 WAV 까지 고른다(KAN-141). 파이프라인은 무손실 마스터에서 3종을 만든다.

## 지금 막혀 있는 곳

- **원본이 PCM 으로 안 나온다.** 화자별 배속이 켜져 있으면 모든 요청이 `synthDialogueWithTimestamps`로 가고, 이 함수는 `FORMATS[Math.max(fmtIdx, 1)]`로 **mp3 를 강제**한다(`elevenlabs.ts` — "응답이 base64 JSON 이라 포맷은 mp3 계열만 쓴다"). 플랜을 올려도 이 경로에서는 PCM 을 요청하지 않는다
- **강등이 고정된다.** `fmtIdx`가 모듈 변수라 한 번 402/403 을 맞으면 워커 재시작 전까지 낮은 포맷으로 남는다
- **실행 기록이 실제 포맷을 안 보여준다.** 기록에는 배속 경로를 거친 세그먼트 포맷(`pcm_44100`)이 찍혀 원본 포맷(mp3 128k 등)이 가려진다

## 무엇을 한다

1. **원본 PCM** — Pro 에서 타임스탬프 엔드포인트가 `pcm_44100`(또는 상위 PCM)을 받는지 확인하고, 되면 원본을 PCM 으로 요청한다. 안 되면 대안(타임스탬프는 별도 강제 정렬 호출로 얻고 합성은 PCM 엔드포인트로 등)을 정한다
2. **강등 처리** — 요청 단위로 포맷을 고르고, 강등이 일어나면 실행 기록에 남긴다. 실행 기록에 **원본 포맷**을 정확히 적는다
3. **마스터 무손실** — 조립·정규화는 KAN-122 결론(스테레오 · 목소리만 정규화 · 2패스 `linear=true`)을 따르고 마스터 wav 를 무손실로 둔다
4. **3종 렌더** — 마스터에서 **한 번씩만** 인코딩: 압축(mp3) · AAC(m4a) · WAV. 비트레이트·채널은 KAN-141 과 확정한다
5. **패키지·발행** — 업로드 패키지(`upload-meta.json` 등)와 `/publish` 업로드에 3종을 싣는다. 서버 계약은 KAN-141(`admin-api.md`)
6. **기존 발행분** — 40편 재렌더 여부·순서를 정한다(크레딧 비용 · 재발행 시 사용자 재생 위치 초기화 — `player-api.md` 4.3)
7. `ai/spec/06-audio.md` 7장에 원본 포맷·3종 규격을 적는다

## 완료 조건

- Given 새로 렌더한 에피소드 / When 실행 기록을 본다 / Then 원본 포맷이 PCM 으로 적혀 있고 강등이 없었다(있었다면 그 사실이 적혀 있다)
- Given 같은 에피소드 / When 마스터와 원본 세그먼트를 비교한다 / Then 마스터는 무손실이고 16kHz 위 대역이 원본만큼 살아 있다(지금은 mp3 128k 원본이라 잘려 있다 — 2026-10-05 실측)
- Given 같은 에피소드 / When 패키지를 본다 / Then 압축·AAC·WAV 3종이 같은 길이로 들어 있다
- Given KAN-141 완료 / When `/publish`로 올린다 / Then 3종이 서버에 저장되고 음질별로 재생된다
- Given `ai/spec/06-audio.md` / When 7장을 읽는다 / Then 원본 포맷과 3종 규격이 적혀 있다
