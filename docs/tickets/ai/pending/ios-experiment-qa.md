## 왜

Android 개발계에서 박준현이 확인한 실험 화면을 iOS에서도 본다(2026-10-30). iOS는 자물쇠 아이콘(SF `lock.fill`) · 결제(StoreKit) · 알림 권한과 표시 방식이 Android와 달라 따로 확인해야 한다.

## 무엇을 한다

설정 › 버전에 "개발계"가 붙은 앱으로, 앱을 완전히 껐다 켠 뒤 시작한다.

**시리즈 잠금 (KAN-294)**
1. 무료 계정으로 시리즈 화면 → 4편부터 자물쇠, 1~3편 완청 표시
2. 1~3편 완청 상태에서 시리즈 머리 [재생]이 자물쇠
3. 잠긴 편 탭 → 소리 없이 잠금 시트(확인 팝업 · 플레이어 없음)
4. 잠금 시트에서 샌드박스 결제 → 그 편 자동 재생
5. 자동재생이 3편 뒤 4편으로 넘어가지 않음
6. 다크 모드 자물쇠 색 · 세로 정렬
7. 데일리 요금제면 4편 이후도 재생

**할인 배지 (KAN-299)**
8. 구독 화면: 정가 취소선 + "지금 할인 중" + 1,900 · 3,900원(App Store `dev.` 상품 대한민국 가격을 1,900원으로 내려 둠)
9. 결제 시트 금액 1,900 · 3,900원

**콘텐츠 후기·프로모션 (KAN-280)**
10. 더보기 › [후기] 시트 — 별점 · 글 입력 시 키보드가 입력칸을 가리지 않음
11. 라이브러리 진입 시 "다 들은 편, 어떠셨어요?" 시트(플레이어가 열려 있으면 안 뜸)
12. 끝까지 들은 편 3개에 후기(별점 + 글 10자 이상) → 발급 안내 시트 → [지금 쓰기] → 설정 › 프로모션 → [사용하기] → Pro 적용 · "후기 참여 프로모션 이용 중"

**푸시 (KAN-288 · 289)**
13. 아침 알림(앱을 내려 둔 상태) 수신 · 탭 시 라이브러리/그 콘텐츠로 열림 — 시험 대상 등록은 박준현에게 계정을 알려 주면 넣어 준다
14. 앱이 화면에 떠 있으면 아침 알림은 숨겨지고 드립 도착 알림은 배너로 뜸

**온보딩 (KAN-295)**
15. 온보딩 완료 → 가장 짧은 첫 편이 일시정지 상태 플레이어로 열림

**미니플레이어 (KAN-302 전 기록용)**
16. 잠긴 편이 미니플레이어에 남았을 때 Android와 같은 문제(평범한 ▶, 눌러도 재생 안 됨)가 있는지

테스트 계정 준비(무료 상태 · 시리즈 1~3편 완청 · 재생 횟수 등)가 필요하면 박준현에게 요청 — 개발계 DB로 맞춰 준다.
