## 요청

**사용자에게 주제 추천을 받는 기능을 기획**한다(PM 2026-10-12).

- 어디서 받는가(앱 화면 위치), 무엇을 받는가(자유 입력·선택지), 받은 주제가 파이프라인 어디로 들어가는가(소스 풀·백로그 게이트 1)
- 제안한 사용자에게 무엇을 돌려주는가(만들어지면 알림 등)와 악용·중복 처리

## 완료 조건

- Given 기능 명세 초안, When 8항목 템플릿과 대조하면, Then 빠진 항목이 없다
- Given 같은 초안, When 파이프라인 연결 절을 보면, Then 제안 주제가 들어가는 단계와 사람 검수 지점이 적혀 있고 PM 이 검토했다
