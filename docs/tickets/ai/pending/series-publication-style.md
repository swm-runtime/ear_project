## 배경

2026-10-22 PM 결정으로 앱 시리즈 화면 제목 바로 아래 줄(애플 뮤직 앨범의 아티스트 자리)에 **발행 이름**이 나간다. 예: "키워드로 훑어보는 경제 상식" → 제목 아래 "키워드", 그 아래 `경제 상식 · 12편 · 연재 중`.

- 서버에 칸을 새로 만들었다: `series.publisher_name varchar(50) NULL`(BE #1883, FE #1884). 관리자 `POST /admin/series`·`PATCH /admin/series/:id`가 `publisher_name`을 받고(앞뒤 공백 제거, 빈 문자열·null = 없음), `AdminSeriesItem.publisher_name`으로 돌려준다.
- 마이그레이션이 제목이 "키워드로"로 시작하는 시리즈(CS 지식·경제 상식)만 "키워드"로 채웠다. **철학 시리즈 두 개는 비어 있다** — 앱에선 제목 아래 줄 없이 나간다.
- **콘솔에는 입력 자리가 없다.** 지금 [시리즈 발행]으로 새 시리즈를 만들면 발행 이름이 빈 채로 나간다.

PM은 이 발행 이름을 **간행물**로 보고, 간행물마다 시리즈의 스타일이 정해지길 원한다(2026-10-22 "시리즈 발행(간행물) 스타일 지정"). 지금 파이프라인의 시리즈 디자인은 **키워드 시리즈 디자인** 하나뿐이고(`ai/spec/11-series.md` 7장 — 글자 칸 `series.thumb_*`를 채운 시리즈만 이 디자인), 이것이 사실상 "키워드" 간행물의 스타일이다.

## 무엇을 한다

1. **간행물 고르기** — 콘솔 시리즈 화면에서 시리즈의 간행물을 고른다(지금 목록: "키워드" 하나 + "없음"). 새 간행물을 더할 수 있게 둔다.
2. **발행 이름 보내기** — 고른 간행물 이름을 [시리즈 발행]의 `POST /admin/series`에 `publisher_name`으로 싣는다. 이미 발행된 시리즈는 간행물을 바꾸면 `PATCH /admin/series/:id`로 보낸다. "없음"이면 `null`.
3. **간행물 스타일 적용** — 간행물이 시리즈의 썸네일·표지 스타일을 정한다. "키워드"는 지금의 키워드 시리즈 디자인(라벨 "KEYWORD SERIES"·손글씨 큰 단어·밑줄·박스·편 번호/"전 N편")을 쓰고, "없음"은 일반 장면 썸네일이다. 지금 "글자 칸을 채웠나"로 갈리는 판정을 간행물 기준으로 옮긴다.
4. **기존 제품 시리즈** — 콘솔 "제품 시리즈" 목록에서 간행물(발행 이름)을 넣고 바꿀 수 있게 한다(철학 시리즈 두 개 포함).
5. `ai/spec/11-series.md`에 간행물 개념(이름 = 서버 `publisher_name`, 스타일 = 썸네일 디자인)을 적는다.

## 담당이 정할 것

- 간행물 목록을 어디에 둘지(코드 상수 / Supabase 표). 간행물마다 다를 스타일의 범위(썸네일만인지, 시리즈 제목 형식 "키워드로 …"·인트로 문구까지인지).
- 철학 시리즈 두 개의 간행물 이름(PM 확인).
- 간행물 이름 표기(한글 "키워드" — 앱에 그대로 나간다. 영어 시장 시리즈는 별도 이름).

## 완료 조건

- Given 콘솔 시리즈 화면 / When 간행물 "키워드"를 고르고 [시리즈 발행]을 누른다 / Then 서버 시리즈 행의 `publisher_name`이 "키워드"이고, 앱 시리즈 화면 제목 아래에 "키워드"가 나온다
- Given 간행물 "키워드"인 시리즈 / When 편 썸네일·표지를 만든다 / Then 키워드 시리즈 디자인으로 만들어진다
- Given 간행물 "없음"인 시리즈 / When 발행한다 / Then `publisher_name`은 null이고 편 썸네일은 일반 장면 썸네일이다
- Given 이미 발행된 제품 시리즈 / When 콘솔에서 간행물을 바꾼다 / Then `PATCH /admin/series/:id`로 `publisher_name`이 바뀌고 앱에 반영된다
- Given 운영 서버에 BE #1883이 아직 안 나갔다 / When 운영 콘솔로 시리즈를 만든다 / Then `publisher_name`을 보내지 않아 400이 나지 않는다(또는 릴리즈 뒤에 이 기능을 켠다)
- Given `docs/ai/spec/11-series.md` / When 간행물을 찾는다 / Then 이름·스타일 규칙이 적혀 있다
