## 요청

**추천으로 받은 편뿐 아니라 모든 편에 별점과 글 의견을 남기게 하고, 참여하면 Pro 일주일을 준다**(10월 5주차 계획(2026-10-26 회의)). 사용자 피드백을 직접 받는 통로다.

- 이미 있는 것: 추천 별점 팝업 "최근 추천 어땠나요?"(KAN-116 — `features/drip-feedback.md` · `spec/api/drip-feedback-api.md`, **드립 편성분만**)
- 정할 것
  1. 어디서 묻나(플레이어·완청 뒤·라이브러리 등)와 얼마나 자주
  2. 별점 대상(모든 편)·의견 길이·필수 여부
  3. **보상 조건** — 언제 몇 번 참여하면 주나, 계정당 몇 번인가(악용 방지)
  4. **보상 수단** — 후보: 초대 코드의 기간 지급(`features/subscription.md` 4.9 — 요금제 전체 권한, **계정당 지급은 동시에 하나**) · 가입 체험식(4.8 — 재생 한도만). `users.tier`를 직접 pro로 올리지 않는다(4.8 — 구독 동기화와 겹친다). 이미 구독 중이거나 다른 지급을 받는 중인 계정은 어떻게 하나
  5. 기존 추천 별점과 합칠지·따로 둘지
  6. 의견 원문을 누가 어디서 보나(운영 열람 범위)
