## 요청

콘텐츠 파이프라인을 처음부터 끝까지 **전수 점검**하고, 대본을 **구어체에 맞게 최적화**한다(PM 2026-10-12).

- 전수 점검 — 소스 풀 → 스윕 → 군집화·백로그 → 대본 → QA → 패키지·검수 → TTS → 발행 각 단계가 `PIPELINE.md`·`spec/` 규칙대로 도는지, 끊기거나 사람 손에 남은 곳이 어디인지 목록으로 남긴다
- 구어체 최적화 — 대본이 글말(문어체)로 읽히는 곳을 찾아 듣기 좋은 말투(윤아·이음 2인 대화체)로 다듬는다. 프롬프트(`skills/`)·QA 루브릭 어느 쪽을 고칠지는 점검 결과로 정한다

## 완료 조건

- Given 점검 기록, When 단계 목록을 보면, Then 단계마다 정상·문제·조치가 적혀 있다
- Given 구어체 개정 전후, When 같은 주제로 대본을 뽑아 비교하면, Then 개정 후 대본이 더 말하듯 읽히고 그 근거(바꾼 프롬프트·루브릭)가 CHANGELOG 에 적혀 있다
