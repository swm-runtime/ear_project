## 무엇을 한다

- **L0** (`PIPELINE_LOCALE=en`) — 한국어 전용 검사(어미·말끝·되물음 등)는 돌지 않는다. 형식 계약(구역 헤더·줄 문법·마지막 턴·템플릿 머리 문구)과 **단어 수 분량 하한**(잠정 13분 × 150 = 1,950단어)을 검사한다. 영어 문체 검사는 규칙 자산 v0와 함께 정의하고, 파일럿 판정으로 늘린다. L0 수정 한도 3회·비율 규칙 잔존 시 QA로 넘김은 승계.
- **TTS `normalize.ts`** — `en`은 영어 숫자·기호·약어 정규화. 한국판의 "잔존 영문 → 중단"은 `en`에서 돌지 않는다.
- **발음 사전** — "한국어 로마자 표기 → 영어 TTS가 맞게 읽는 철자" 치환(전역 사전 + 에피소드 맵, 전역 우선 — 구조 승계). **발음 누락 검사**: 설계 단계가 대본의 한국어 고유명사·단어를 `pronunciations.json`에 전부 등재하고, 등재 단어 중 발음 힌트가 없는 것이 있으면 합성을 중단한다(명세 6.7). 대본 전체에서 미등재 단어를 정규식으로 찾지 않는다.
- 영어 보이스 env 2개(값은 1번 결정 뒤). `package.ts` 분량 환산을 단어/분으로. 구간 요약 프롬프트 영어판.
- **첫 3편** 생성 → L0 → QA → TTS → 분량(분)·단어/분·단가 실측 → 1번 분량 잠정값 보정.

## 범위 밖

영어 L0 문체 규칙의 확장·골드·회귀 세트(파일럿 이후, 명세 7장)

## 완료 조건

- Given 영어 대본 1편 / When L0 → QA → TTS / Then 한국어 전용 검사에 걸리지 않고, 단어 수 하한으로 분량을 판정하며, 합성이 끝난다
- Given `pronunciations.json`에 발음 힌트 없는 등재 단어가 있다 / When TTS 입력을 만든다 / Then 합성이 중단되고 그 단어가 표시된다
- Given 한국어 대본(`PIPELINE_LOCALE` 미설정) / Then 종전 L0·TTS 결과와 같다(회귀)
- Given 첫 3편 / Then 분량(분)·단어/분·단가가 처리 기록에 있고 명세 6.4의 분량 값이 보정됐다
