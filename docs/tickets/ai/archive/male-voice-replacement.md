## 무엇을 한다

남자 화자 **이음**의 TTS 보이스를 지금의 **Yohan Koo**(`4JJwo477JUAx3HV0T7n7`, ko·male·professional)에서 다른 보이스로 바꾼다.

현재 값(`config.ts` 112~113행):

```ts
ttsVoiceYuna: process.env.TTS_VOICE_YUNA || "Lb7qkOn5hF8p7qfCDH8q",  // 윤아 = Annie
ttsVoiceEum:  process.env.TTS_VOICE_EUM  || "4JJwo477JUAx3HV0T7n7",  // 이음 = Yohan Koo
```

**여자 화자(윤아 = Annie)는 건드리지 않는다.**

## 먼저 읽을 것 — 이건 리브랜딩급 결정이다

`spec/06` 2장이 못박아 둔 내용이다. 에피소드마다 바뀌는 값이 아니고, 바꾸면 **이미 발행된 전 편과 새 편의 남자 목소리가 달라진다.** 결정 전에 아래를 정해야 한다.

### 1. 왜 바꾸는가 — 사유를 문서에 적는다

현행 보이스의 어떤 점이 문제인지(발음·톤·윤아와의 대비 부족·특정 단어 부자연 등)를 구체적으로 적는다. 사유가 없으면 다음에 또 같은 논의를 반복하고, 새 보이스도 같은 이유로 걸릴 수 있다.

### 2. 후보 선정 기준 (spec/06 2장 그대로 적용)

- **한국어 네이티브 보이스** — 외래어를 한국식 발음으로 읽는 것이 필수다
- **윤아(Annie)와의 톤 대비 확보** — 대화체라 두 목소리가 구분돼야 한다
- **전문 보이스 클론(PVC)은 회피** — v3 미최적화
- 발화 속도 설정값도 보이스와 함께 확정한다(아래 4항)

### 3. 기존 발행분을 어떻게 할 것인가

- **새 편부터만** — 목록에서 어느 시점부터 목소리가 바뀐다. 가장 싸다
- **전체 재합성** — 일관되지만 비용·시간이 크고, 콘텐츠 버전이 바뀌어 사용자의 **재생 위치·완청 기록**에 영향이 가는지 확인해야 한다. `script-segments.json`도 전부 다시 만들어야 한다

어느 쪽이든 **결정과 사유를 이 문서에 적는다.**

### 4. 배속 재조정이 따라온다

화자별 후처리 배속을 쓰고 있고(`TTS_SPEED_EUM` 기본 **1.0**, 참고로 `TTS_SPEED_YUNA`는 **1.2**), 이 값은 보이스의 원래 말 속도에 맞춰 잡은 것이다. **보이스가 바뀌면 1.0이 더 이상 맞지 않는다.** 새 보이스로 샘플을 뽑아 윤아와 나란히 듣고 값을 다시 정한다.

### 5. 발음 사전 재확인

전역 음차 사전(`skills/tts/pronunciation.json`)의 항목 중에는 **현행 보이스가 틀리게 읽어서 보정한 것**이 섞여 있다. 새 보이스에서는 그 보정이 오히려 어색해질 수 있다. 교체 후 샘플에서 사전 적용 구간을 훑는다.

## 작업 순서 (제안)

1. 후보 보이스 2~3개를 고른다(기준은 2항)
2. **같은 대본으로 샘플 합성** — 윤아와 함께 들어야 대비가 보인다. 외래어·고유명사가 섞인 구간을 반드시 포함
3. 배속값 후보를 함께 시험한다(4항)
4. PM 청취 확정
5. `config.ts` 기본값과 `spec/06` 2장의 보이스 표를 **같이** 고친다 — 문서와 코드가 어긋나면 다음 사람이 어느 쪽을 믿을지 모른다
6. 3항에서 정한 소급 범위대로 반영

**4번 전에는 운영 재합성을 돌리지 않는다.**

## 완료 조건

- Given 후보 보이스로 같은 대본을 합성했다 / When 윤아와 함께 듣는다 / Then 두 화자의 톤이 구분되고 외래어가 한국식 발음으로 나온다
- Given PM이 보이스를 확정했다 / When `config.ts`와 `spec/06` 2장을 연다 / Then 양쪽의 보이스 ID가 같다
- Given 새 보이스로 에피소드를 합성한다 / When 윤아 구간과 이음 구간의 말 속도를 비교한다 / Then 한쪽이 느리거나 빠르게 들리지 않는다(`TTS_SPEED_EUM` 재확정값 적용)
- Given 교체 사유와 소급 적용 범위를 묻는다 / When 이 문서를 연다 / Then 둘 다 사유와 함께 적혀 있다
- Given 소급 적용을 하기로 했다 / When 재합성 후 앱에서 해당 편을 연다 / Then 자막 시각이 맞고 재생 위치 정책이 문서대로 동작한다
