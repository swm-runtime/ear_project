콘텐츠 상세 — 표시 전용, 더보기 경유

세 화면(라이브러리·탐색·플레이어)의 더보기 시트 [상세 정보]로 진입하는 메타데이터 화면입니다(신설 2026-08-23, FR-40). 행 본문 탭 = 즉시 재생 원칙은 그대로이고 상세는 더보기 경유로만 열립니다. MVP는 표시 전용 — 재생·담기 액션이 없습니다. 조건부 항목(시리즈·원문)은 응답 값이 null이면 줄을 통째로 생략합니다.

이 시안의 용도. 범위 검증용입니다. 색·서체·간격은 제안이며 확정된 아이덴티티가 아닙니다. 각 요소의 번호는 명세 조항으로 연결됩니다. 주황 번호는 명세에 근거가 없거나 확정이 필요한 지점입니다. 화면 ID(CD 계열)는 uiux 명세 작성 시 확정하는 임시 표기입니다.

V1상세 화면 내 액션([재생]·[담기/제거]) 추가 여부 — 미결

MVP는 표시 전용으로 확정했다 — 같은 액션을 두 화면이 소유하면 재생 한도 판정·확인 팝업 규칙이 두 곳으로 복제된다(content-detail 4.4). 다만 상세까지 들어와 "듣고 싶다"가 된 사용자가 뒤로 나가 행을 다시 탭해야 하는 동선은 액션 추가의 근거가 될 수 있다. 추가한다면 판정·팝업을 동일하게 거친다. 사용 데이터를 본 뒤 판단한다.

V2화면 ID·타이틀 카피 — uiux 작성 시 확정

CD 계열 ID와 앱바 타이틀("상세 정보"는 시트 항목명을 그대로 쓴 임시값), 길이·발행일 표기 형식, 소개 접기/펼치기, 주제 태그 탭 동작 유무는 spec/uiux 작성 시 확정한다. 파일 크기·청취 상태는 두지 않는 것으로 확정(합의 2026-08-23)이라 검토 대상이 아니다.
