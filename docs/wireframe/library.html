V1하단 탭 구성이 미정

라이브러리·탐색·설정 3탭으로 그렸지만 어느 명세에도 탭 구성이 정의돼 있지 않습니다. settings.md는 "하단 탭 또는 라이브러리 상단의 설정 아이콘"이라며 두 경로를 다 열어둡니다. 시안에는 둘 다 그려져 있는데 중복입니다. 하나로 정해야 상단 우측 아이콘 자리가 확정됩니다.

library 2 / settings 2 / 화면 L1 · L4~L7

V2항목 하나짜리 더보기 메뉴

수동 완료 표시가 제거되고 공유·오프라인 저장이 P1로 빠지면서, 더보기 메뉴에 남은 항목은 삭제 하나입니다. 시트를 여는 비용이 항목 하나 값을 하는지 판단이 필요합니다 — 스와이프 삭제만 남기고 더보기를 없애는 선택지도 있습니다.

V3무료 잔여 재생 힌트가 없다

paywall.md 5장은 "라이브러리·탐색 카드에 오늘 재생 0/2 남음 힌트 표시"를 규정하는데 library.md에는 이 요소가 없어 시안에도 넣지 못했습니다. 카드마다 붙일지 상단에 한 번만 둘지 정하고, 정한 내용을 library.md 5장에 반영해야 합니다.

V4이어듣기 카드와 목록의 중복

이어듣기 카드의 콘텐츠가 아래 목록에도 그대로 나오는지 명세에 없습니다. 시안에서는 뺐습니다. 초기 콘텐츠 풀이 작아 목록이 3~5건일 때 중복이 특히 눈에 띄기 때문인데, 확정이 필요합니다.

library 4.1 / 화면 L1

V5주제 필터 칩의 출처

주제 필터가 사용자의 관심 주제 전체를 보여줄지, 라이브러리에 실제로 담긴 콘텐츠의 주제만 보여줄지 명세에 없습니다. 후자가 자연스럽지만(결과가 0인 칩을 고를 수 없으니) 명시가 필요합니다.

library 4.1 / 화면 L1 · L5

V6영구 제외를 알릴 것인가

삭제하면 그 콘텐츠는 드립에서 영구 제외됩니다(FR-16). 시안은 스낵바에 "삭제했어요"만 표시하고 이 사실을 알리지 않습니다. 사용자가 "정리하려고 지웠는데 다시 안 온다"고 느낄 수 있으므로 문구에 반영할지 결정이 필요합니다.
