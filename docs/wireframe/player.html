플레이어 — 화면을 보지 않아도 조작되는 재생

통근 맥락(눈·손 비가용)이 전제입니다. 탭 후 2초 내 재생 시작이 목표이고, 백그라운드·잠금화면 재생이 기본입니다. 재생 한도 판정과 확인 팝업은 재생을 시작시킨 화면(라이브러리·탐색)의 소유라 — 플레이어는 통과한 요청만 받습니다.

계정 온보딩 라이브러리 탐색 콘텐츠 상세 플레이어 프로필 설정 관심사 관리 커리어
이 시안의 용도. 범위 검증용입니다. 색·서체·간격은 제안이며 확정된 아이덴티티가 아닙니다. 각 요소의 번호는 명세 조항으로 연결됩니다. 주황 번호는 명세에 근거가 없거나 다른 문서와 어긋나는 지점입니다. 화면 ID는 PL 계열을 씁니다 — P는 프로필(P1–P10)이 선점했습니다.

PL1 – PL3

재생 화면

V3player.md 3장 조작 목록 — 공유 제거 · 스와이프 축소 추가 (반영 완료 2026-08-09)

3장 조작 목록의 개정 대상이 둘이다. ① 공유 제거 — 공유(FR-27)는 합의(2026-08-06)로 MVP 제외가 확정돼 라이브러리·탐색 더보기에 없다. 플레이어 더보기도 같은 기준으로 그리지 않는 것으로 결정했다(PL7). "더보기(공유·…)" 표기가 이 합의와 어긋난다. ② 아래로 스와이프 축소 추가 — 셰브론·뒤로가기와 같은 동작(재생 유지·미니플레이어로 접힘)으로 결정했으나(PL1 주석 1) 조작 목록에 없다. 개정 발행·반영 완료 — changes/archive/player-controls-share-and-swipe(fe).md(2026-08-09). P1 도입 시 형태는 탐색이 이미 정의해뒀다(explore.md 4.6 · explore-uiux 4.4 — OS 공유 시트, 텍스트 = 제목 + 저자·출처 + 스토어 링크. 딥링크가 아니다). 플레이어 공유도 같은 정의를 따르면 되므로 별도 정의 과제는 남지 않는다.
