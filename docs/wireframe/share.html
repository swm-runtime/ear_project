공유 — 전용 화면 없이, 진입점과 OS 시트로

콘텐츠를 OS 표준 공유 시트로 앱 밖에 전달합니다(FR-27, P1 — MVP 미노출, README 결정 42·48). 공유 전용 화면은 없습니다 — 이 기능의 전부는 진입점 네 곳(라이브러리·탐색·플레이어 더보기 시트 + 콘텐츠 상세 상단 바) + OS 공유 시트 + 수신자 링크 처리입니다. 공유 링크는 그 콘텐츠의 상세 화면으로 연결되고(개정 2026-08-25 — 종전 "스토어 링크" 폐기), 앱 미설치 수신자만 스토어로 폴백합니다. 서버 엔드포인트는 없고, 공유는 신호로 기록하지 않습니다.

계정 온보딩 라이브러리 탐색 콘텐츠 상세 플레이어 공유 프로필 설정 관심사 관리 커리어
이 시안의 용도. 범위 검증용입니다. 색·서체·간격은 제안이며 확정된 아이덴티티가 아닙니다. 각 요소의 번호는 명세 조항으로 연결됩니다. 주황 번호는 명세에 근거가 없거나 확정이 필요한 지점입니다. 화면 ID(SH1~SH3)는 제안이며 uiux 미채택 상태입니다(share.md 미결). SH3의 공유 시트는 OS 소유 UI의 모사입니다 — 앱이 이 시트를 그리지 않으며, 실제 모양·대상 목록은 플랫폼이 정합니다.

공유에서 나온 것

진입점 네 곳·OS 시트 위임·상세 연결 링크(스토어 폴백)·서버 무관여·신호 미기록은 share.md(작성 2026-08-25)로 확정했습니다. 남은 것은 V1(링크 기술 방식)이 가장 크고, 나머지는 P1 활성화 시점의 작업입니다. 백엔드 코드 변경은 없습니다 — 공유 조립은 클라이언트, 수신자 진입은 기존 단건 상세 조회 재사용입니다.

V1공유 링크의 기술 방식 — 미결

유니버설 링크/App Links는 https 도메인 확보가 전제다(미설치 수신자가 같은 링크로 스토어·웹에 떨어질 수 있어 폴백이 링크 하나로 성립). 커스텀 스킴(ear://contents/:id)은 도메인이 필요 없지만 미설치 수신자에게 죽은 링크라 스토어 링크를 텍스트에 병기해야 한다. share.md가 확정한 것은 목적지(상세)와 폴백(스토어)이며, 방식은 P1 활성화 결정 시점에 도메인 확보 여부로 정한다.
