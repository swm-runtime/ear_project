진입점은 프로필 우상단 아이콘 하나입니다(하단 탭이 아닙니다). 이 화면이 직접 소유하는 조작은 토글과 배속 시트뿐이고 — 낙관적으로 즉시 반영하고 실패하면 원복합니다 — 나머지는 전부 소유 화면으로 보냅니다.

이 시안의 용도. 범위 검증용입니다. 색·서체·간격은 제안이며 확정된 아이덴티티가 아닙니다. 각 요소의 번호는 명세 조항으로 연결됩니다. 주황 번호는 명세에 근거가 없거나 다른 문서와 어긋나는 지점입니다. 설정은 프로필 스택 위의 push 화면이라 하단 탭바를 그리지 않았습니다.
