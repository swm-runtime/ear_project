# 콘텐츠 상세 UI/UX 명세서

> 기준 문서: [`docs/features/content-detail.md`](../../features/content-detail.md) · 재생 판정·확인 팝업·페이월은 [`docs/features/paywall.md`](../../features/paywall.md), 담기·삭제 규칙은 [`docs/features/explore.md`](../../features/explore.md) 4.3 · [`docs/features/library.md`](../../features/library.md) 4.5, 로딩·오류 표현은 [`docs/features/common-error-handling.md`](../../features/common-error-handling.md)
> 와이어프레임: [`docs/wireframe/content-detail.html`](../../wireframe/content-detail.html) (화면 ID CD1–CD4 — 시안의 임시 ID를 정식 채택)
> API: 단건 상세 조회 — `content-detail-api.md` 작성 시 이 문서의 표시 항목·담김 여부·소스 목록 형태와 대조한다. `ai_generated` 소스 목록은 계약 확정 전이며 FE는 `[{title, author|null, url|null}]` 가정 mock으로 선행한다(`tickets/backend/pending/content-sources-structured-list.md`)

## 1. 범위

세 화면(라이브러리·탐색·플레이어)의 더보기 시트 [상세 정보]로 진입하는 콘텐츠 상세 화면(FR-40, 합의 2026-08-23) — 헤더(썸네일·제목·주제 태그·[재생]·[담기]/[삭제]) / 소개 / 메타(길이·발행일·시리즈) / 출처의 구성, origin 두 갈래의 출처 표시, 조건부 생략, 액션 상태와 로딩·조회 실패·회수까지 `content-detail.md` 5장 화면 상태 표를 화면 단위로 풀어낸 문서다.

**이 문서는 동작 규칙을 새로 정하지 않는다.** 진입·조회·표시 항목·액션 규칙은 `content-detail.md`가, **재생 한도 판정·확인 팝업·페이월은 `paywall.md`가**, 담기는 `explore.md` 4.3이, 삭제는 `library.md` 4.5가 소유한다. 여기서 정하는 것은 **무엇을 어떤 상태로 보여주고, 조작에 어떻게 반응하는가**다.

- **진입은 더보기 시트 경유뿐이다.** 행·카드 본문 탭 = 즉시 재생 원칙(PRD 5.2·5.3)은 그대로이며, 이 화면이 그 사이에 끼어들지 않는다. *(P1 — FR-27 활성화 시 **공유 링크 수신** 진입이 추가된다. 규칙은 `share.md` 4.3 — 회수·만료 시 복귀할 원 화면이 없으므로 라이브러리로 이동한다.)*
- *(P1 — FR-27 활성화 시)* **상단 바 우측에 [공유] 아이콘이 추가된다**(신설 2026-08-25 — MVP 미노출). 동작·전달 내용은 `share.md`가, 화면 표현은 `share-uiux.md`(SH2·SH3 — 정식 채택 2026-08-25)가 소유한다.
- **표시 전용 화면이 아니다**(확정 2026-08-23). 헤더의 [재생]·[담기]/[삭제]로 바로 행동한다 — 규칙은 전부 소유 문서의 것을 재사용하고, 이 화면은 진입점 하나가 늘어난 것뿐이다.
- **조건부 항목은 응답 값의 null 여부 하나로 판정한다**(`content-detail.md` 4.3-1). 클라이언트가 별도 조건을 계산하지 않고, null이면 줄(블록)을 통째로 생략한다 — 자리를 비워두거나 "없음"으로 채우지 않는다.
- 확인 팝업·페이월·한도 안내의 구성·문구는 다루지 않는다. 이 화면은 **그것을 여는 지점**만 소유한다.

## 3. 화면 흐름

```
라이브러리(L4) · 탐색(E12) · 플레이어(PL7) 더보기 시트 ─[상세 정보]─> 시트 닫힘 + 상세 진입
   └─> 단건 상세 조회 (목록 응답 재사용 금지 — 최신 status·담김 여부)
         ├─ 로딩 ──────────────────> CD3 스켈레톤 (0.3초 미만 미표시)
         ├─ 성공 · published ──────> CD1 / CD2 (origin·시리즈·담김 여부로 변형)
         ├─ 성공 · status ≠ published ─> CD4 — 상세를 그리지 않고 토스트 + 원 화면 복귀
         └─ 실패 ──────────────────> CD3 전면 에러 + [다시 시도]

CD1 / CD2
   ─[재생]─> 재생 한도 판정 (paywall.md 4.1 — 서버가 판정, 행 탭과 같은 경로)
   │    ├─ 차감 있음 · 억제 안 됨 ─> 확인 팝업 (L3과 동일) ─┬─[재생하기]─> 플레이어 (+ 미담김이면 자동 적립)
   │    │                                                     └─[취소]────> 상세 유지 (적립·차감 없음)
   │    ├─ 차감 있음 · 오늘 억제됨 ─> 플레이어 (팝업 없음 · 차감은 그대로)
   │    ├─ 차감 없음 ─────────────> 플레이어 (+ 미담김이면 자동 적립)
   │    ├─ 소진(BLOCKED) ─────────> 페이월 바텀시트 (적립 없음)
   │    ├─ 소진 · 최상위 티어 ────> 한도 안내 (페이월 없음)
   │    └─ 현재 재생 중인 콘텐츠 ─> 새 재생 없이 플레이어로 복귀
   ─[담기] (미담김)─> 처리 중(버튼 로딩) ─┬─ 성공 ─> 토스트 + 버튼 [삭제]로 전환
   │                                       └─ 실패 ─> 원상 유지 + 토스트
   ─[삭제] (담김)──> 처리 중(버튼 로딩) ─┬─ 성공 ─> 버튼 [담기]로 전환 (고지 없음 · 재생 중이어도 재생 유지)
   │                                       └─ 실패 ─> 원상 유지 + 토스트
   ─[원문 보기 / 링크 있는 소스 항목]─> 인앱 브라우저 (+ 클릭 기록)
   ─[뒤로가기]─> 원 화면 복귀 — 목록 스크롤 위치 유지, 플레이어 진입이었으면 재생 유지된 채 플레이어로
```

**진입 경로가 셋이어도 화면은 하나다.** 어느 시트에서 들어왔든 같은 구성·같은 규칙이고, 뒤로가기는 **들어온 곳으로** 복귀한다. 플레이어에서 진입한 경우 상세가 떠 있는 동안에도 재생은 계속된다(`content-detail.md` 2장).

## 4. 화면별 명세

### 4.1 CD1 정상 — 화면 골격 (파트너 · 시리즈 · 미담김)

**구성** — 앱바(뒤로가기 · 타이틀 "상세 정보" — 카피 미확정, 6장) / **헤더**(썸네일 · 제목 · 주제 태그 칩 · 액션 버튼 줄 [재생]·[담기]) / **소개**(`description`) / ― 구분선 ― / **메타**(길이 · 발행일 · 시리즈) / ― 구분선 ― / **출처**(4.5). 세로 스크롤 화면이다.

- **구분선은 두 개다** — 헤더+소개 / 메타 / 출처의 세 영역을 가른다(`content-detail.md` 4.2). 소개가 메타보다 먼저 온다.
- **항상 표시** — 제목·주제 태그·소개·길이·발행일. **조건부** — 시리즈 줄(4.4), 소스의 저자·링크(4.6).
- **길이는 초 단위까지 표기한다** — "14분 21초"(확정 2026-08-23). 목록 행의 분 단위 표기와 달리 상세는 정확한 값을 보여주는 자리다. 값은 `duration_sec` 하나에서 변환해 그린다.
- **주제 태그는 서버가 내려준 `content_topics`를 그대로 그린다.** MVP에서 태그는 **탭 대상이 아니다**(탐색 필터 이동 등의 동작 없음 — 9장 미결). 탭 가능해 보이는 시각 처리를 하지 않는다.
- **소개는 전문을 표시한다.** 접기/펼치기는 두지 않는다(제안 — 9장 미결). 재생 전에 내용을 가늠할 유일한 수단인 화면에서 소개를 다시 접으면 화면의 존재 이유가 줄어든다.
- **하단 탭바를 두지 않는다.** 세 화면 어디서든 위에 쌓이는 푸시 화면이고, 복귀는 앱바·시스템 뒤로가기다.

**헤더 액션 버튼 줄** — [재생]이 주 액션(primary), [담기]/[삭제]가 보조 액션(outline) 자리다.

| 버튼 | 스타일 | 분기 |
|---|---|---|
| [재생] | **primary** — 항상 이 자리 | 없음(항상 표시) |
| [담기] | outline — 중립색 | 상세 응답의 담김 여부 = 미담김 |
| [삭제] | outline — **위험색** | 상세 응답의 담김 여부 = 담김 (CD2) |

- **버튼 상태는 상세 응답의 담김 여부로 그린다**(`content-detail.md` 4.4). 클라이언트가 진입 경로("라이브러리에서 왔으니 담김")로 추정하지 않는다 — 탐색·플레이어 진입에서도 담긴 콘텐츠일 수 있다.
- **[삭제]의 위험색은 더보기 시트의 제거·삭제 항목과 같은 규칙이다**(`library-uiux.md` 4.7 — 세 화면 공통). 파괴적 조작이 중립 버튼으로 보이면 안 된다.

### 4.2 [재생] — 판정을 여는 지점

**행 탭과 동일한 재생 판정 경로를 거친다**(`paywall.md` 4.1~4.2). 진입점이 다르다고 조건·문구·판정이 달라지지 않는다.

- 탭 → 서버 판정 → 확인 팝업 / 페이월 / 한도 안내 / 즉시 재생. **확인 팝업의 구성·문구·[오늘은 그만 보기]는 `library-uiux.md` 4.6(L3)과 완전히 동일하고, 억제 상태도 같은 로컬 키를 공유한다.** 이 문서는 다시 정의하지 않는다.
- **화면에 보이는 상태를 근거로 재생을 통과시키지 않는다**(`paywall.md` 4.1). 상세를 띄워 둔 사이 한도가 소진됐으면 탭 시점 판정이 페이월을 띄운다.
- **재생이 실제로 시작되면 미담김 콘텐츠는 라이브러리에 자동 적립된다**(`explore.md` 4.4와 동일 — `source = save`). 팝업 [취소]·페이월 차단 시 적립 없음. 적립되면 **[담기] 버튼도 [삭제]로 전환된다** — 담김 여부가 실제로 바뀌었기 때문이다.
- **현재 재생 중인 콘텐츠**(플레이어에서 진입)면 새 재생을 시작하지 않고 **플레이어로 복귀한다.** 판정·차감이 다시 일어나지 않는다. 이때도 버튼 라벨은 "재생" 그대로다(라벨 분기를 두지 않는다 — 제안, 최종 확인 9장).
- 판정 요청 인플라이트 중 [재생] 연타는 무시한다(`common-error-handling.md` 7장).

### 4.3 [담기] / [삭제] — 처리 중·성공·실패

**[담기]** (미담김 → 탭)

- `explore.md` 4.3과 동일 — `LibraryItem(source = save)` 생성, 신호 적재는 서버 몫이라 화면에 나타나지 않는다.
- 성공: **토스트 "라이브러리에 담았어요" + [보러가기](라이브러리 탭 이동, 3초)** + 버튼이 **[삭제]로 전환**된다(확정 2026-08-23 — `explore-uiux.md` 4.4의 담기 토스트와 동일 구성. 담기 피드백이 화면마다 다르지 않게 한다). [보러가기]를 탭하면 상세를 떠나 라이브러리 탭으로 이동한다.
- **담기에는 어떤 티어에서도 페이월이 뜨지 않는다**(PRD 5.4). 한도 소진 상태에서도 담기는 정상 동작한다.

**[삭제]** (담김 → 탭)

- `library.md` 4.5와 **동일한 결과** — 소프트 삭제 + 드립 영구 제외. **영구 제외를 고지하지 않는다.**
- 성공: **버튼이 [담기]로 전환되는 것이 피드백의 전부다**(확정 2026-08-23 — 토스트·스낵바 없음). 라이브러리 목록의 스와이프 삭제(L5)와 달리 [실행 취소] 스낵바를 두지 않는다 — 이 화면에는 버튼 [담기]가 그대로 남아 있어 재담기 경로가 화면에 이미 보인다. 단, 재담기는 실행 취소가 아니라 **신규 담기**다(`added_at` 새로 적재, 드립 영구 제외는 유지 — `library-uiux.md` 4.7의 복구와 다르다).
- **재생 중인 콘텐츠를 삭제해도 재생은 유지된다**(`player.md` 7과 동일). 미니플레이어·재생을 끊지 않는다.
- 삭제 후 뒤로가기: 라이브러리에서 진입했다면 목록에서 해당 아이템이 사라져 있다(스크롤 위치는 유지). 탐색에서 진입했다면 행은 그대로다 — 탐색은 담김 여부로 목록을 거르지 않는다(`content-detail.md` 7장).

**처리 중(변형 — 담기·삭제 공통)**

- 탭한 버튼을 **버튼 로딩 상태**로 바꾸고 **중복 탭을 차단한다.** [재생]과 뒤로가기는 막지 않는다 — 단일 값 조작이라 이탈해도 결과가 서버에 남고, 연타는 서버 유니크 제약이 멱등 처리한다(`explore.md` 7).
- 실패: 버튼을 원래 상태로 되돌리고 토스트로 알린다(`common-error-handling.md` 4.4 — 낙관적 반영 원상 복구와 같은 규칙). 문구는 공통 규약을 따른다.
- 처리 도중 응답이 엇갈리면 마지막 조작이 최종 상태다 — 오래된 응답을 화면에 덮어쓰지 않는다(`explore-api.md` 4.3의 `client_seq` 규칙과 같은 취지).

### 4.4 메타 영역 — 조건부 생략

**구성** — 라벨·값의 행 목록: **길이** "14분 21초" / **발행일** "2026년 8월 12일"(형식 제안 — 6장) / **시리즈** "3부작 중 1화"(조건부).

| 항목 | 판정 | 표시 |
|---|---|---|
| 길이 | 항상 | "N분 N초" — `duration_sec`에서 변환. 초 단위까지(확정 2026-08-23) |
| 발행일 | 항상 | `published_at` — "YYYY년 M월 D일" 형식 제안(카피 미확정, 6장) |
| 시리즈 | `series_id != null` | **"N부작 중 M화"**(`total_episodes` · `episode_no`). null이면 **줄을 통째로 생략**한다(CD2) |

- **단일 콘텐츠는 시리즈 관련 셋 다 null이다**(`domain.md` 5.1). 자리를 비워두지도, "시리즈: 없음"으로 채우지도 않는다 — 두 줄 화면과 세 줄 화면이 있는 것이 정상이다.
- **파일 크기·나의 청취 상태(진행률·완청)를 이 영역에 추가하지 않는다**(확정 2026-08-23 — `content-detail.md` 4.2).

### 4.5 출처 — partner(원문) 구성 (CD1)

**구성** — 영역 라벨 "출처"(카피 미확정, 6장) / **저자**(`author_name`) / **제공**(`source_name` — 파트너명) / **[원문 보기]**.

- **셋 다 필수 값이라 항상 표시된다**(`domain.md` 5.1 체크 제약이 이중 방어). partner에는 조건부 생략이 없다.
- **[원문 보기]는 더보기 시트의 [원문 보기]와 같은 동작이다** — 인앱 브라우저로 `source_url`을 열고 원문 유입 클릭(`source_link_clicks`)을 기록한다(`explore.md` 4.3 · `player.md` 4.5와 같은 규칙). 링크 항목임이 드러나는 형태(외부 링크 아이콘 + 강조색)로 그린다.
- 재생 멘트(시작·종료 고지) 밖에서 출처를 확인할 수 있는 노출면이다(FR-12). 고지 문구를 이 화면에서 변형·요약하지 않는다.

### 4.6 출처 — ai_generated(소스) 구성 (CD2)

**구성** — 영역 라벨 "참고한 소스"(카피 미확정, 6장) / 소스 항목의 세로 목록 — 항목마다 **제목**(강조) + **저자**(보조 톤, 조건부).

- **전부 나열한다.** "외 N건" 생략 표기를 쓰지 않는다(확정 2026-08-23). 목록 길이 제한·더보기 접기를 두지 않는다.
- **URL 문자열을 화면에 노출하지 않는다.** 링크가 있는 소스는 **항목 자체가 탭 대상**이다 — 탭하면 인앱 브라우저로 그 소스의 링크를 연다. 탭 가능함은 항목 우측의 외부 링크 아이콘으로 드러낸다.
- **링크 없는 소스는 탭 대상이 아니다.** 아이콘 없이 정적 텍스트로만 표시하고, 탭해도 아무 일도 일어나지 않는다. **목록에서 빼지 않는다** — 나열은 전수다. 비활성(disabled) 스타일을 입히지 않는다 — 고장이 아니라 원래 링크가 없는 항목이다.
- **저자 없는 소스는 제목 한 줄만 표시한다.** "저자 없음"·"미상"으로 채우지 않는다(조건부 생략 — `content-detail.md` 4.3-1).
- 소스 데이터는 백엔드 계약 확정 전이다(`tickets/backend/pending/content-sources-structured-list.md`). FE는 `[{title, author|null, url|null}]` 가정 mock으로 그리고, 계약 확정 시 필드를 맞춘다 — **화면 구성은 계약과 무관하게 이 절이 기준이다.**

### 4.7 CD3 로딩 · 조회 실패

**로딩** — 헤더(썸네일·제목 2줄)·메타 자리의 스켈레톤. 앱바는 먼저 그린다.

- **0.3초 미만이면 표시하지 않는다**(`common-error-handling.md` 5장).
- 로딩 중에는 액션 버튼을 그리지 않는다 — 담김 여부를 모르는 상태에서 [담기]/[삭제] 어느 쪽도 그릴 수 없고, [재생]만 먼저 활성화하면 반쪽 화면이 된다.
- **시트에서 이미 본 제목이 있어도 부분 데이터로 반쪽 화면을 그리지 않는다.** 단건 재조회(최신 status·담김 여부)가 이 화면의 존재 이유다(`content-detail.md` 4.1).

**조회 실패** — **공통 전면 에러 + [다시 시도]**(`common-error-handling.md` 4.3 — 화면 진입 조회는 차단형). 공통 컴포넌트를 그대로 쓴다. 오프라인 진입도 같은 화면이며 문구는 공통 규약("인터넷 연결을 확인해주세요")을 따른다. [다시 시도] 연타는 인플라이트 중 무시한다.

### 4.8 CD4 회수 · 만료 — 상세를 그리지 않는다

조회 결과 `status ≠ published`(회수·만료)면 **상세 화면을 그리지 않고 원 화면으로 복귀하며 토스트 "제공이 종료된 콘텐츠예요"를 띄운다**(기존 회수 안내와 같은 문자열 — `library-uiux.md` · `explore-uiux.md`와 공유).

- 상세도 노출면이므로 회수 즉시 반영(FR-32)의 예외가 아니다. 더보기 시트를 연 시점과 조회 시점 사이에 회수될 수 있다.
- **라이브러리에서 진입했다면 복귀한 목록도 갱신되어 해당 아이템이 사라져 있다**(`library.md` 회수 동기화 규칙).
- 반쯤 그린 상세 위에 토스트를 얹지 않는다 — 화면 전환 자체가 일어나지 않거나, 로딩 중이었다면 로딩째로 복귀한다.

## 5. 공통 컴포넌트 규칙

| 컴포넌트 | 용도 | 규칙 |
|---|---|---|
| **스켈레톤** | 진입 조회 | 헤더·메타 자리. 0.3초 미만 미표시. 액션 버튼은 그리지 않음 |
| **전면 에러** | 조회 실패·오프라인 | [다시 시도]만. 공통 컴포넌트 그대로 |
| **버튼 로딩** | 담기·삭제 처리 중 | 탭한 버튼만 로딩 + 중복 탭 차단. [재생]·뒤로가기는 막지 않음 |
| **토스트** | 담기 완료 · 회수 안내 · 담기/삭제 실패 | 3초. 삭제 성공은 무음(버튼 전환이 피드백) |
| **다이얼로그** | 재생 확인 팝업 | `library-uiux.md` 4.6(L3)과 동일 — 이 문서는 여는 지점만 소유 |
| **인앱 브라우저** | [원문 보기] · 링크 있는 소스 항목 | 더보기 시트의 [원문 보기]와 같은 동작. 닫으면 상세로 복귀 |

- **사용자가 시작한 액션의 결과는 조용히 처리하지 않는다** — 담기 성공은 토스트, 실패는 원상 복구 + 토스트. 삭제 성공만 버튼 전환이 그 역할을 한다(4.3).
- **자동 적립(재생 개시 후 save)의 실패는 알리지 않는다** — 사용자가 시작하지 않은 통신이다(`common-error-handling.md`).

## 7. 접근성

- **터치 타깃 최소 44×44pt** — 앱바 뒤로가기, [재생]·[담기]/[삭제], [원문 보기], 링크 있는 소스 항목(행 전체가 히트 영역).
- **낭독 순서는 시각 순서를 따른다** — 제목 → 주제 태그 → [재생] → [담기]/[삭제] → 소개 → 메타 → 출처. 썸네일은 장식 이미지로 처리해 낭독에서 제외한다(제목이 곧 그 내용이다).
- **길이는 표기 그대로 낭독된다** — "14분 21초". "861초"·"14:21" 같은 다른 형태로 읽히지 않게 표시 문자열을 그대로 라벨로 쓴다.
- **조건부 생략은 낭독에서도 생략이다** — 시리즈 줄이 없는 화면에서 "시리즈, 없음"을 읽어주지 않는다. 그리지 않은 것은 존재하지 않는 것이다.
- **소스 항목의 탭 가능/불가를 역할로 가른다** — 링크 있는 항목은 button/link 역할 + **외부 링크로 열림을 낭독한다**("딥 워크, 칼 뉴포트" → "몰입을 부르는 환경 설계, 링크, 브라우저로 열기"처럼 동작이 드러나게). 링크 없는 항목은 **정적 텍스트**로 두고 어떤 역할·힌트도 붙이지 않는다 — 탭 무반응이 오류로 읽히면 안 된다. [원문 보기]도 같은 규칙(외부 링크 낭독)이다.
- **[담기]↔[삭제] 전환을 낭독한다** — 버튼 라벨 변경만으로는 스크린리더에 아무 일도 일어나지 않은 것과 같다. 담기 성공은 토스트(`aria-live="polite"` 상당)가 알리고, 삭제 성공은 무음이므로 **"라이브러리에서 삭제했어요" 상당의 상태 변화를 polite로 한 번 알린다**(시각 피드백이 버튼 전환뿐인 것과 균형을 맞춘다).
- 처리 중 버튼은 로딩(busy) 상태가 함께 읽히게 한다. 회수 안내 토스트는 조작의 직접 결과이므로 `assertive`.
- **[삭제]의 위험색은 색만으로 구분하지 않는다** — 라벨 "삭제" 자체가 파괴적 동작을 말하므로 추가 형태 단서는 요구하지 않지만, 낭독 라벨을 "삭제"보다 구체적으로("라이브러리에서 삭제") 붙여 무엇에서 삭제되는지 드러낸다. [담기]도 "라이브러리에 담기"로 낭독한다.
- 확인 팝업·페이월의 포커스 규칙은 `library-uiux.md` 7장을 그대로 따른다.
- **동적 텍스트 200%에서 잘리지 않아야 한다** — 위험한 곳은 헤더 액션 버튼 줄(두 버튼이 폭을 다툰다 — 넘치면 세로 쌓기 허용), 메타의 라벨·값 행(줄바꿈 허용, 폰트 축소 금지), 소스 항목 제목(여러 줄 허용).

## 8. 금지 사항

`content-detail.md`와 소유 문서의 규칙이 명시적으로 금지했거나 곧장 따라 나오는 것들이다. **UI 구현 시 되살아나기 쉬우므로 여기 모아 둔다.**

**진입·조회**

- **행·카드 본문 탭에 이 화면을 끼워 넣는 것** — 본문 탭 = 즉시 재생 판정이다. 진입은 더보기 시트 [상세 정보] 하나다
- **목록 응답을 재사용해 상세를 그리는 것** — 진입 시 단건 재조회가 규칙이다(최신 status·담김 여부)
- 회수·만료 콘텐츠의 **상세를 그리는 것** — 안내 후 원 화면 복귀다
- 시트에서 본 제목·썸네일로 **부분 화면을 먼저 그리는 것** — 스켈레톤 아니면 완전한 화면이다

**표시**

- **URL 문자열을 화면에 노출하는 것** — 링크는 항목 탭·[원문 보기]로만
- 소스 목록에 **"외 N건" 생략 표기**를 쓰거나 접기·길이 제한을 두는 것 — 나열은 전수다
- **링크 없는 소스를 목록에서 빼는 것** / 반대로 탭 가능해 보이게 그리는 것
- 빈 조건부 항목을 **"없음"·"미상"으로 채우거나 자리를 비워두는 것** — 줄을 통째로 생략한다
- **나의 청취 상태(진행률·완청)·파일 크기를 표시하는 것** — 제외 확정(2026-08-23)
- 조건부 판정을 **클라이언트가 계산하는 것** — 응답 값의 null 여부 하나로 판정한다
- origin 분류명("AI 생성"·"파트너")을 **라벨로 노출하는 것**

**액션**

- **표시된 화면 상태를 근거로 재생을 통과시키는 것** — 판정은 탭 시점의 서버 몫이다
- 담기·삭제에 **페이월·확인 팝업·영구 제외 고지**를 붙이는 것
- 처리 중 **중복 탭을 허용하는 것** — 버튼 로딩 + 차단이다
- 팝업 [취소]·페이월 차단에 **자동 적립을 붙이는 것** — 적립은 재생이 실제 시작된 뒤다
- 현재 재생 중인 콘텐츠의 [재생]에서 **새 재생을 시작하는 것** — 플레이어 복귀다
- 삭제 시 **재생을 중단하는 것** — 재생 중 콘텐츠를 삭제해도 재생은 유지된다
