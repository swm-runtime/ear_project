## 1. 범위

**이 문서는 동작 규칙을 새로 정하지 않는다.** 판정(티어·만료·버튼 종류)은 서버가 하고(`subscription-api.md` 4.1 `action` · 4.2 `plan.status`), 동작 규칙은 `subscription.md` · `paywall.md` 가 소유한다. 여기서 정하는 것은 **화면 ID·상태·확정 카피·접근성**이다.

**노출 조건 — 세 겹이 전부 열려야 그린다**(`frontend/src/shared/lib/feature-flags.ts`):

| 겹 | 값 | 꺼져 있으면 |
|---|---|---|
| 빌드 플래그 | `EXPO_PUBLIC_SUBSCRIPTION_UI=on` | 구독을 한 글자도 언급하지 않는다(App Store 2.1(b) — KAN-66) |
| 결제 네이티브 모듈 | 바이너리에 `ExpoIap` 가 있다(런타임 검사) | 같다 — 플래그가 켜진 번들이 OTA 로 옛 바이너리(runtime 31 이하)에 닿아도 결제 버튼만 보이는 상태가 되지 않는다 |
| 플랫폼 | iOS, 또는 Android + `EXPO_PUBLIC_SUBSCRIPTION_ANDROID=on` | Android 는 Play 상품 등록(KAN-130) 전까지 꺼 둔다 |

꺼진 바이너리에서 이 문서의 화면은 하나도 그려지지 않는다 — 설정 구독 섹션·프로필 [구독 알아보기]·페이월 요금제 비교가 모두 빠지고, 한도 소진은 **한도 안내 시트**(`paywall.md` 5장) 그대로다.

## 3. 화면 흐름

```
[구독하기]·[업그레이드]·[변경] 탭
   ├─ is_email_verified == false ──> 토스트 "구독하려면 이메일 인증이 필요해요"
   │                                 → 이메일 등록·인증(A 계열). 페이월이면 시트를 내려 둔다
   │                                 → 인증 성공 → (페이월은 시트를 다시 연다) → 같은 요금제로 결제 시트
   ↓ 결제 의도 → 스토어 결제 시트(StoreKit 2)
   ├─ 닫음(취소) ─────────────────> 원래 화면. 문구 없음
   ├─ 승인 대기(Ask to Buy) ──────> 안내 "결제 승인을 기다리고 있어요…"
   ↓ 결제 완료 → "구독을 확인하고 있어요"
   ├─ 서버 200 ────────────────────> 토스트(4.3) → 화면 갱신. 페이월이면 시트 닫힘 → 막혔던 콘텐츠 자동 재생
   ├─ 503 · 네트워크 ──────────────> "구독을 확인하고 있어요… 잠시 후 자동으로 반영됩니다"(뒤에서 재시도)
   │                                 페이월이면 같은 문구 토스트 후 시트 닫힘
   └─ 400 · 409 ───────────────────> 인라인 오류(4.4). 시트·화면 유지
```

## 4. 화면별 명세

### 4.1 SB1 구독 관리 — 골격

앱바: 뒤로(유리 원 셰브론) + **"구독 관리"**. 본문 순서: 섹션 제목 **"현재 구독"** → 현재 구독 카드 → 섹션 제목 **"요금제"** → SB2 → 결과 안내(SB3) → **[구매 복원]** → 필수 표기(4.5).

| 상태(서버 `plan.status`) | 카드 |
|---|---|
| 로딩 | 카드 자리 스켈레톤(0.3초 미만은 그리지 않는다) |
| 조회 실패 | **"구독 정보를 불러올 수 없어요"** + [다시 시도] |
| `free` | **"무료 이용 중"** / "하루 N편까지 들을 수 있어요"(N = 서버 `daily_play_limit`, `null` 이면 "제한 없이 들을 수 있어요") |
| `subscribed` | 플랜명 / **"다음 결제일 N월 N일"** / (다운그레이드 예약 시) **"N월 N일부터 {플랜명} 요금제가 적용돼요"**(`pending_plan.effective_at`) / **[구독 해지]** |
| `cancel_scheduled` | 플랜명 / **"N월 N일까지 이용 가능해요"** — 중립 톤 / **[구독 다시 시작]** |
| `grace` | 플랜명 / 경고 면 **"결제에 문제가 있어요"** + "결제 수단을 확인하지 않으면 구독이 종료될 수 있어요" / **[결제 수단 확인]** |
| 다른 스토어 구독(`store` ≠ 이 기기의 스토어) | 위 상태 문구 + **"Google Play에서 구독 중이에요. 구독한 기기에서 변경해주세요"**(iOS 에서 본 Play 구독. 반대는 "App Store에서…") — 스토어 이동 버튼 없음 |

- [구독 해지]·[구독 다시 시작]·[결제 수단 확인]은 **스토어 구독 관리 화면으로 보낸다**(해지 API 없음 — `subscription.md` 4.5). 어느 스토어인지는 서버 `store` 가 정한다.
- 날짜는 서버 값(ISO)을 기기 로캘의 월·일로 표기만 한다. 만료·해지 판정을 하지 않는다.
- 결제·복원 진행 중에는 **전체 로딩 + 뒤로가기·스와이프 차단**.

### 4.2 SB2 요금제 카드

서버 `plans[]` 순서(낮은 티어 → 높은 티어) 그대로. 무료 요금제도 비교를 위해 그린다.

| 요소 | 내용 |
|---|---|
| 이름 · 가격 | 서버 `name` / 유료: **스토어가 준 현지 가격 + "/월"**(예: `₩3,900/월`) · 무료: **"무료"** |
| 설명 | 서버 `description` |
| 기능 줄 | **"하루 N편 듣기"**(`null` → "무제한 듣기") · **"이어 PICK 하루 N편"** · **"광고 없음"/"광고 포함"** — 전부 `entitlements` 값 |
| 버튼(서버 `action`) | `purchase` **[구독하기]** · `upgrade` **[업그레이드]** · `downgrade` **[변경]**(보조 버튼) + "다음 결제일부터 적용돼요" · `current` **"이용 중"** 배지(버튼 아님, 카드 테두리) · `none` 버튼 없음 |

- **가격은 스토어 현지 가격만 그린다.** 스토어 조회가 실패하거나 상품 하나라도 빠지면 카드 대신 **"요금제를 불러올 수 없어요"** + [다시 시도] — `price_krw` 로 메우지 않는다(`subscription-api.md` 4.1).
- 버튼 종류를 클라이언트가 고르지 않는다(티어 순서 비교 금지).
- 결제·복원 진행 중에는 모든 버튼 비활성, 누른 카드의 버튼에만 스피너.

### 4.3 SB3 결제 결과 — 확정 카피

| 결과 | 표현 | 문구 |
|---|---|---|
| 구독 성공 | 토스트 | **"구독이 시작되었어요"** |
| 업그레이드 성공 | 토스트 | **"요금제가 변경되었어요"** |
| 다운그레이드 예약 | 토스트 | **"N월 N일부터 {플랜명} 요금제가 적용돼요"** |
| 결제 취소 | — | 없음 |
| 검증 중 | 인라인 | **"구독을 확인하고 있어요"** |
| 반영 지연(503·네트워크) | 인라인(페이월은 토스트 후 닫힘) | **"구독을 확인하고 있어요… 잠시 후 자동으로 반영됩니다"** |
| 화면 밖 회복(재시도·다음 실행) | 토스트 | **"구독이 반영되었어요"** |
| 승인 대기 | 인라인 | **"결제 승인을 기다리고 있어요. 승인되면 자동으로 반영돼요"** |
| 이미 구독 중(스토어) | 인라인 | **"이미 구독 중이에요. [구매 복원]을 눌러 이 계정에 연결해주세요"** |
| 이메일 인증 필요 | 토스트 → 인증 화면 | **"구독하려면 이메일 인증이 필요해요"** |
| 복원 성공 / 없음 | 토스트 | **"구독이 복원되었어요"** / **"복원할 구독이 없어요"** |

### 4.5 스토어 정책상 필수 표기

카드 목록 아래 작은 보조 글씨 + 링크 두 개. **완곡하게 바꾸지 않는다.**

- iOS
  - "구독은 1개월 단위이며, 결제는 구매 확인 시 Apple 계정으로 청구돼요."
  - "현재 기간이 끝나기 최소 24시간 전에 해지하지 않으면 같은 가격·기간으로 자동 갱신되고, 갱신 요금은 기간 종료 전 24시간 이내에 청구돼요."
  - "해지는 [구독 해지] 또는 기기의 설정 > Apple 계정 > 구독에서 할 수 있어요. 해지해도 남은 기간이 끝날 때까지 이용할 수 있어요."
- Android(2단계)
  - "구독은 1개월 단위이며, 결제는 구매 확인 시 Google Play 계정으로 청구돼요."
  - "해지하지 않으면 같은 가격·기간으로 매달 자동 갱신돼요."
  - "해지는 [구독 해지] 또는 Google Play 스토어 > 결제 및 정기 결제에서 할 수 있어요. 해지해도 남은 기간이 끝날 때까지 이용할 수 있어요."
- 링크: **[이용약관]** · **[개인정보처리방침]**(설정의 같은 목적지)

### 4.6 PW1 페이월 시트

`paywall.md` 5장 "바텀시트 구성" 그대로 — **한도 안내 시트 위에 얹는다.**

순서: 주의색 빈 링 `0` → 제목(**"오늘 청취 한도를 모두 사용했어요"** 또는 서버 문구) → "매일 새벽 4시에 다시 채워져요" → **SB2** → SB3 안내 → **[구매 복원]**(밑줄 링크) → 필수 표기(4.5) → **[닫기]**(보조 면 — 결제 버튼이 주 동작).

- 무료 한도 소진(`PLAY_LIMIT_EXCEEDED` · 소진 잔여 표시 탭)으로 열렸을 때만 요금제를 얹는다. **유료 한도 안내(`PLAY_LIMIT_REACHED`)는 한도 안내 그대로**다.
- 시트가 화면 높이의 약 72% 를 넘으면 시트 안에서 스크롤한다.
- 결제·복원 진행 중에는 **[닫기]·딤 탭·뒤로가기·끌어 내리기로 닫히지 않는다.**
- 결제 성공 → 시트 닫힘 → 토스트 → **막혔던 콘텐츠 자동 재생**(재생 게이트가 다시 요청 — 서버가 다시 판정한다). [닫기] → 원래 화면, 재생 없음.
- 검증이 30초를 넘기면 반영 지연과 같이 토스트 후 시트를 닫는다(재시도는 뒤에서 계속).

## 5. 접근성

- 요금제 카드: 버튼 라벨은 "{플랜명} {버튼}"(예: "프로 구독하기"). 버튼이 없는 카드(무료·이용 중)는 카드 전체를 "{플랜명}, {가격}, {기능 줄}" 하나로 읽는다.
- "이용 중"·결제 문제는 **색만으로 구분하지 않는다** — 배지 글자·경고 제목을 함께 둔다.
- 결과 안내(SB3)는 바뀔 때 읽히도록 라이브 영역으로 둔다. 결제 문제 배너는 `alert`.
- 터치 타깃 44pt 이상(복원·약관 링크 포함).

## 6. 금지 사항

- 플래그·결제 모듈·플랫폼 중 하나라도 꺼진 바이너리에서 구독·요금제·가격을 언급하는 것. "웹에서 구독하세요" 류 외부 결제 안내(3.1.1)
- `price_krw` 를 화면 가격으로 쓰는 것(폴백 포함)
- 티어명·티어 순서로 버튼·기능을 분기하는 것 — `action` · `entitlements` 만 본다
- 결제 취소에 문구를 띄우는 것
- 기기 시각으로 만료·해지를 판정하는 것

## 7. 미결 사항

- **"구독이 종료되었어요"(만료됨) 안내** — `subscription.md` 5장의 상태지만 `GET /users/me/subscription` 의 `status` 는 4분기(`free` 포함)라 만료와 미구독이 구분되지 않는다. 지금은 미구독과 같게 그린다(`changes/pending/subscription-purchase-screen-kan120(fe).md` B).
- Android(2단계) — Play 상품 ID 확정(KAN-130) 후 오퍼 토큰·업/다운그레이드 교체 모드를 실기기로 확인하고 `EXPO_PUBLIC_SUBSCRIPTION_ANDROID=on`.
