# 플레이어 UI/UX 명세서

> 기준 문서: [`docs/features/player.md`](../../features/player.md) · 재생 한도 판정·재청취 창은 [`docs/features/paywall.md`](../../features/paywall.md) 4.1~4.3-1, 삭제·미니플레이어 노출 판정은 [`docs/features/library.md`](../../features/library.md) 4.2·4.4·4.5, 로딩·오류 표현은 [`docs/features/common-error-handling.md`](../../features/common-error-handling.md)
> 와이어프레임: [`docs/wireframe/player.html`](../../wireframe/player.html) (화면 ID PL1–PL11)
> API: `player-api.md`는 아직 없다. 통신 계약은 `player.md` 6장 + `backend/domain.md`로 추정하되 **확정 계약으로 취급하지 않는다**

## 1. 범위

콘텐츠를 실제로 듣는 화면 — 재생 화면 3상태(재생 중·버퍼링·완료), 시트 4종(배속·수면 타이머·스크립트·더보기), 오류 3종(로드 실패·회수·네트워크 끊김), 그리고 미니플레이어까지 `player.md` 5장 화면 상태 표를 화면 단위로 풀어낸 문서다.

**이 문서는 동작 규칙을 새로 정하지 않는다.** 재생 시작·위치 저장·완청 판정·신호 기록은 `player.md`가, **재생 한도 판정·재생 확인 팝업·재청취 창은 `paywall.md`가**, 삭제와 미니플레이어의 노출·대상 판정은 `library.md`가 소유한다. 여기서 정하는 것은 **무엇을 어떤 상태로 보여주고, 사용자 조작에 어떻게 반응하는가**다.

- **플레이어는 통과한 요청만 받는다.** 한도 판정과 재생 확인 팝업은 **재생을 시작시킨 화면**(라이브러리·탐색·딥링크 처리)이 소유한다(`paywall.md` 4.2). 플레이어 화면에 페이월·확인 팝업의 정의를 두지 않는다. **예외는 완료 화면(PL3)의 ▶ 재청취 하나** — 재청취 창 밖이면 플레이어가 직접 확인 팝업·페이월을 띄운다(확정 2026-08-10 — `paywall.md` 4.2 예외. 팝업·시트의 정의는 여전히 paywall 소유이고, 이 화면은 호스트만 맡는다).
- **판정과 표시를 섞지 않는다.** 완청(90%)·재청취 창(15일)·회수(403) 판정은 서버 소유다. 클라이언트가 기기 시각이나 로컬 계산으로 게이트를 흉내 내지 않는다.
- 통근 맥락(눈·손 비가용 — PRD 3.1)이 전제다. **화면을 보지 않아도 조작 가능해야 하며**, 백그라운드·잠금화면 재생이 기본이다. 접근성(7장)이 부가 사항이 아니라 이 화면의 핵심 요건이다.

- 재생 확인 팝업·페이월 바텀시트는 `paywall.md`가 소유하고 여는 쪽 화면(L3 등)이 그리므로 **PL 번호를 부여하지 않는다.** 여기 ID를 붙이면 두 문서가 같은 팝업을 각자 정의하게 된다.
- 수면 타이머(PL5)·스크립트(PL6)는 **FR-25 P1**이었으나 2026-09-17(스크립트)·2026-09-19(타이머)에 활성화됐다. 진입은 앱바의 달 아이콘·컨트롤 줄의 스크립트 토글이다(4.1). 스크립트 데이터가 없으면 토글을 그리지 않는다.
- **전체 플레이어는 앱에서 유일하게 어두운 팔레트**다(개정 2026-09-18 — `changes/archive/player-dark-theme.md`, `frontend/architecture.md` 4.3 예외). 바탕 `#17171A` 위에 아트워크를 화면 가득 강하게 흐린(`blurRadius` 60, 1.25배) 뒤 바탕색 72% 막을 얹어 곡의 색이 배게 한다(썸네일이 없으면 단색). 글자·포인트 `#FFFFFF`, 면 `#26262B`, 보조 글자 `#A0A0A8`, 트랙·비활성 `#45454C`. 재생 확인 팝업·미니플레이어·탭 화면은 밝은 테마 그대로다. 기기 다크 모드 설정과 무관하게 항상 어둡다.

## 3. 화면 흐름

```
목록 탭 · 미니플레이어 ▶ · 푸시 ──> 한도 판정·확인 팝업 (여는 화면 소유 — paywall.md 4.1·4.2)
                                        └─ 통과 ──> 플레이어 진입
플레이어 진입 ──> PL2 (메타 즉시 + 서명 URL 요청)
   ├─ 오디오 준비 완료 ──> PL1 재생 중 (목표: 탭 후 2초 내)
   │     └─ 버퍼링 2초 초과 ──> PL2 버퍼링 (재생 버튼 자리 인디케이터)
   ├─ 메타·URL·오디오 실패 ──> PL8 로드 실패 ─[다시 시도]─> PL2
   └─ 403 회수 ──> PL9 ─[닫기]─> 원래 화면 (목록 제거는 라이브러리 소유)

PL1 ─[±10초 · 시크 · 배속(PL4) · 타이머(PL5) · 스크립트 토글(PL6) · 재생 목록 핸들(PL12) · 더보기(PL7)]─> PL1
   ─[max_reached 90% 도달]─> 완청 기록 (서버 판정 — 화면 변화 없음, 재생은 계속)
   ─[재생 끝 도달]─> PL3 완료 (자동 이탈 없음)
   ─[셰브론 · 뒤로가기 · 아래로 스와이프]─> 축소 — 재생 유지 + PL11 미니플레이어
   ─[재생 중 네트워크 끊김]─> 버퍼 소진까지 재생 유지 ──> PL10 일시정지 + 배너

PL3 ─[▶]─> 재청취 (판정은 서버 — paywall.md 4.3-1)
   ├─ 재청취 창(15일) 내 ──> 게이트·팝업 없이 위치 0부터 재생 + replay 신호
   └─ 창 밖 ──> 새 차감 — 그 시점의 한도 판정을 다시 거친다 (확인 팝업·페이월)

PL11 ─[본문 탭 · 위로 끌어올리기]─> 전체 플레이어로 확대 (재생 상태 그대로 · autoplay 아님)
    ─[▶]─> 재생 시작 — 카드 탭과 같은 판정·팝업 경로 (library.md 4.2)
    (닫기 조작 없음 — 2026-09-25. 종료 수단은 완청·다른 콘텐츠 재생뿐, 4.8)
```

**축소와 정지는 다른 조작이다.** 플레이어를 접는 조작(셰브론·뒤로가기·아래로 스와이프)은 셋 다 같은 동작 — 재생 유지 + 미니플레이어 전환 — 이고, 재생을 멈추는 조작은 일시정지뿐이다.

- 접는 조작이 재생을 멈추면 "화면을 치웠더니 소리도 꺼졌다"가 된다. 통근 맥락에서 화면은 주머니에 넣는 것이지 끄는 것이 아니다.

## 4. 화면별 명세

### 4.1 PL1 재생 중 — 화면 골격

> **개정 2026-09-17 — 컨트롤·패널 재설계**(`changes/archive/player-controls-redesign.md`). 보조 줄·[원문 보기] 칩을 없애고 컨트롤을 한 줄에 모았다. 어두운 팔레트는 2026-09-18(2장).

```
앱바        좌: 셰브론(축소) / 우: 수면 타이머 달 아이콘(4.6) · 더보기 ⋯
히어로      아트워크(정사각) / 제목(한 줄, 넘치면 가로 스크롤) / 카테고리(주제명 최대 2개 "·" 연결)
시크바      + 시간 라벨(현재·전체)
컨트롤 줄   배속(텍스트 "1.0×") · [10초 뒤로] · 재생/일시정지 · [10초 앞으로] · 스크립트 토글
하단 핸들   "재생 목록" — 위로 끌면 재생 목록 시트(PL12)가 올라온다(4.6-1)
```

- **보조 줄이 없다.** 배속은 컨트롤 줄 왼쪽 끝에 **배경 없는 텍스트**로, 타이머는 앱바로 올렸다(재생 조작이 아니라 세션 설정이다). 컨트롤이 한 줄에 모여 손끝 위치가 하나로 고정된다.
- **[원문 보기] 칩이 없다.** 원문은 더보기 시트(4.7)의 [원문 보기]만 남긴다 — 플레이어 본문에 같은 진입점이 둘 있을 이유가 없다. `source_link_clicks`(`player.md` 4.5) 계약은 더보기 경로가 그대로 쓴다.
- **제목이 넘치면 가로 스크롤(marquee)한다.** 두 줄로 접지 않는다 — 히어로 높이가 제목 길이에 따라 흔들리면 컨트롤 위치가 움직인다. 36dp/s, 1.8초 정지 후 순환, 모션 축소 설정에서는 말줄임으로 대체.
- **제목 아래 카테고리 줄** — 콘텐츠의 주제(`content.topics`, `player-api.md` 4.1) 이름을 최대 2개 "·"로 잇는다. 주제가 없으면 줄 자체를 그리지 않는다.
- ±10초 아이콘은 **원형 화살표 안에 숫자 10**(4.2). 선 굵기 1.8. 재생 버튼은 흰 원 + 검정 아이콘(primary/onPrimary 반전). 시크바 채움·썸은 흰색, 트랙은 회색.
- 상태바는 플레이어가 떠 있는 동안 밝은 글자(`style="light"`), 걷히면 앱 기본.

- **일시정지는 별도 화면이 아니다.** 같은 레이아웃에서 중앙 버튼만 ⏸ ↔ ▶ 로 전환된다(`player.md` 5장). 상태마다 레이아웃이 바뀌면 화면을 보지 않는 사용자가 손끝 위치로 조작할 수 없다.
- **저자·출처는 플레이어에 싣지 않는다**(개정 2026-09-15 — 출처·저자는 콘텐츠 상세에서만 보인다. 종전 "상시 노출" 규칙 폐기). FR-12 고지는 **오디오 멘트**(`content-pipeline.md` 4.3)와 **콘텐츠 상세**(`content-detail.md` 4.3) 두 곳이 맡는다 — FR-12는 표시 위치를 특정하지 않는다("적합한 형태로"). 파트너 계약에 "모든 노출면 표기" 조항이 있으면 되돌린다 — 근거·검토 메모는 `changes/archive/source-shown-only-on-detail.md`.
- **앱바에 제목을 두지 않는다.** 제목은 본문에 크게 한 번만 있다. 두 곳에 있으면 동적 텍스트 200%에서 앱바가 먼저 넘친다.
- **뒤로가기(하드웨어 버튼·제스처)는 축소다. 종료가 아니다**(4.8). 재생은 유지되고 미니플레이어로 접힌다.
- **스크립트 데이터가 없으면(생성 실패 포함, `has_script: false`) 스크립트 토글 자체를 그리지 않는다**(`player.md` 4.6·7장). 눌러도 빈 패널이 열리는 버튼을 두지 않는다.
- 배속 텍스트에는 현재 배속을 상시 표시한다("1.2×"). 타이머가 설정되면 앱바 달 아이콘을 채우고 왼쪽에 남은 시간을 표시한다(4.6).
- 백그라운드·잠금화면: 앱을 내려도 재생이 유지되고, 잠금화면·알림 센터에 재생/일시정지·±10초 컨트롤을 제공한다(`player.md` 4.2). **잠금화면의 구간 이동 값도 화면과 같은 ±10초다** — 두 곳의 값이 다르면 사용자가 어느 쪽이 얼마를 건너뛰는지 외워야 한다.

### 4.2 재생 컨트롤 — ±10초 · 시크바

| 컨트롤 | 표시·반응 |
|---|---|
| 재생/일시정지 | 토글. 중앙 최대 크기 버튼. 완료 상태의 ▶는 4.4 |
| [10초 뒤로] | `max(0, position - 10)`. 아이콘 안에 숫자 **10** 병기 |
| [10초 앞으로] | `min(duration, position + 10)`. 끝 도달 시 완료 처리(PL3) |
| 시크바 | **드래그 중에는 위치 라벨만 갱신**하고, 손을 뗀 시점에 seek |
| 배속 | 컨트롤 줄 왼쪽 끝. 텍스트만("1.0×", 배경 없음). 탭 → PL4 시트 |
| 스크립트 토글 | 컨트롤 줄 오른쪽 끝, 말풍선 두 개 아이콘(2인 대화체). 탭 → 스크립트 패널(4.6) 열림/닫힘. 열려 있으면 primary 색 |
| 재생 목록 핸들 | 화면 하단 고정 "재생 목록". 위로 끌면 재생 목록 시트(4.6-1) 열림, 아래로 끌면 닫힘, 탭은 토글 |

- **앞뒤 모두 ±10초로 동일하다**(확정 2026-08-10). 아이콘에 숫자를 병기하는 이유 — 좌우 화살표 모양만으로는 값이 같은지 알 수 없고, 잠금화면 OS 컨트롤과 값이 일치함을 화면에서도 확인할 수 있어야 한다.
- **드래그 중 실시간 seek를 하지 않는다.** 드래그마다 오디오를 끊으면 위치를 고르는 동안 소리가 튄다. 시크로 건너뛴 구간이 완청 계산(`max_reached_sec`)에 들어가지 않는 것은 서버 판정이며, 화면은 이를 표시·안내하지 않는다 — "여기까지 들어야 완청" 류의 진행 표식을 시크바에 그리지 않는다.
- **오디오 포커스 상실(전화·타 앱)·블루투스 이어폰 해제는 일시정지 상태로 수렴한다.** 자동 재개하지 않으며, 화면·잠금화면 모두 ▶(재생) 상태로 표시된다(`player.md` 4.2·7장). 일시정지 아이콘이 남아 있으면 소리가 나는 중으로 읽힌다.
- 재생 위치 저장(5초 주기·일시정지·이탈·백그라운드)은 **백그라운드 동기화**다. 실패해도 사용자에게 알리지 않는다(`common-error-handling.md` 4.3).

### 4.3 PL2 진입 직후 · 버퍼링

- **메타(아트워크·제목)는 진입과 동시에 즉시 그린다.** 진입 시 전체 화면 로딩·스켈레톤을 두지 않는다 — 메타는 목록에서 이미 갖고 온 데이터다.
- **로딩 표시는 재생 버튼 자리에만, 버퍼링이 2초를 넘을 때만 노출한다**(`player.md` 4.1). 그 전에는 아무것도 띄우지 않는다.
  - 목표가 "탭 후 2초 내 재생"이므로, 정상 경로에서는 로딩을 한 번도 보지 않아야 한다. 공통 0.3초 규칙(`common-error-handling.md` 5장)보다 이 화면 전용 2초 규칙이 우선한다 — 미디어 버퍼링은 조회 로딩과 다른 성격이다.
- **오디오 준비 전에는 ±10초·시크바·보조 칩을 비활성으로 그리고 조작을 받지 않는다.** 아직 재생기가 없는데 조작을 받으면 준비 완료 시점에 몰아서 반영되거나 버려진다 — 어느 쪽도 사용자가 예측할 수 없다.
- 서명 URL·원본 경로는 화면·로그 어디에도 노출하지 않는다(FR-33 — `player.md` 4.8).

### 4.4 PL3 재생 완료 — ▶ = 처음부터 + replay

- **완료돼도 화면을 자동으로 닫지 않고, 레이아웃도 바꾸지 않는다**(`player.md` 5장). 시크바 100% · 시간 라벨 양쪽 모두 전체 길이 · 중앙 버튼 ▶. 완청 표식은 따로 얹지 않는다(개정 2026-09-22 — 라이브러리의 체크 마킹 폐기와 같이 뺐다).
  - 완료 전용 화면(다음 콘텐츠 카드·큰 [다시 듣기] 버튼)으로 갈아끼우면 손끝으로 외운 컨트롤 위치가 무효가 된다. 연속 재생은 비범위다 — 다음 콘텐츠 유도를 넣지 않는다. **재생 목록 패널(4.6-1, 열람·선택)은 별개다** — 자동 다음 재생이 아니다.
- **▶ 탭 = 위치 0부터 재생 + `replay` 신호 기록**(개정 2026-08-09). [10초 뒤로]로 끝부분만 되짚는 것도 그대로 동작한다.
- **재청취 창(차감일로부터 15일) 안에서는 이 ▶가 게이트·팝업 없이 바로 재생된다**(`paywall.md` 4.3-1). 차감이 없으므로 확인 팝업도 없다 — "차감되지 않는데 차감된다고 알리지 않는다".
  - **판정은 서버 소유다.** 클라이언트가 15일을 계산해 게이트를 흉내 내지 않는다. 창 안인지 밖인지는 재생 요청의 서버 응답이 정한다.
- **창이 지난 재청취는 새 차감이다.** 그 시점의 한도 판정을 다시 거치며, 판정 결과에 따라 재생 확인 팝업 또는 페이월이 뜬다. 이때 재생을 다시 시작시킨 화면은 플레이어이므로 **팝업·페이월은 플레이어 위에 띄운다**(`paywall.md` 4.2 "여는 쪽 소유" 원칙의 적용 — 9장 미결에서 확정 여부 확인).
- 완청 판정(90% 도달 순간)은 재생 종료를 기다리지 않고 이미 일어났다(`player.md` 4.4). **90% 도달 시점에 화면은 아무것도 하지 않는다** — 축하 토스트·배지 애니메이션을 띄우지 않는다. 재생 중인 사용자를 방해할 이유가 없다.

### 4.5 PL4 배속 선택 시트

**구성** — 핸들 / 제목 **"재생 속도"** / 행 5개: **0.8× · 1.0× · 1.2× · 1.5× · 2.0×** (현재값에 체크 표시)

- **탭 즉시 세 가지가 한 번에 일어난다: 현재 재생에 적용 + 전역 저장 + 시트 닫힘.** [확인]·[적용] 버튼을 두지 않는다.
  - 배속은 듣던 채로 고르는 조작이다. 적용 버튼을 거치게 하면 귀로 확인하며 고르는 흐름이 끊긴다.
- **선택값은 전역 설정(`user_settings.default_playback_rate`)으로 저장되어 다음 콘텐츠에도 적용된다.** 설정 > 기본 배속과 같은 저장소다 — 어느 쪽에서 바꿔도 함께 바뀐다.
- **저장 실패 시 재생 배속을 원복하지 않는다.** 재생기에는 이미 적용됐고 다음 저장이 덮어쓴다. 에러 UI도 띄우지 않는다 — 백그라운드 동기화 실패는 알리지 않는다(`common-error-handling.md` 4.3).
- 허용값은 5개뿐이다. 슬라이더·커스텀 입력을 두지 않는다 — 서버도 같은 값만 검증한다.
- 딤 영역 탭·뒤로가기로 닫으면 아무것도 바뀌지 않는다(선택 자체가 일어나지 않았다).

### 4.6 PL5 수면 타이머 · PL6 스크립트 패널

**두 화면 모두 FR-25(P1)였으나 활성화됐다** — 스크립트 2026-09-17(`changes/archive/player-controls-redesign.md`), 타이머 2026-09-19(`changes/archive/sleep-timer-p1.md`).

**PL5 수면 타이머 시트**

- **진입은 앱바의 달 아이콘**(더보기 왼쪽)이다 — 재생 조작이 아니라 세션 설정이라 컨트롤 줄에 두지 않는다.
- **구성** — 핸들 / 제목 **"수면 타이머"** / 행 6개: **5분 · 10분 · 15분 · 30분 · 이 에피소드 종료 시 · 해제**. 현재 선택은 굵기 + ✓.
- 배속 시트와 같은 문법 — **탭 즉시 적용 + 닫힘.** 시트 문법이 화면마다 다르면 같은 조작을 매번 새로 배워야 한다.
- 설정되면 **달을 채워 그리고**(선으로만 그린 달은 켜졌는지 아이콘만으로 알 수 없었다 — 색이 아니라 형태로 구분) 아이콘 왼쪽에 **남은 시간 `"MM:SS"`**만 표시한다(달 아이콘이 "타이머"를 말하므로 글자 "타이머"는 없다 — 앱바 폭). "이 에피소드 종료 시"는 `"종료 시"`. 1초마다 갱신한다.
- 만료 시 **4초 페이드아웃 후 일시정지**하며 앱을 종료하지 않는다. 시간은 벽시계 기준이고 화면을 접어도(미니플레이어) 계속 간다. 만료와 완청 시점이 겹치면 완청 처리가 우선하며, 세션이 끝나면 타이머를 먼저 걷는다(`player.md` 4.7·7장).
- 마지막 선택 저장(`user_settings.sleep_timer_last_choice`)은 아직 없다 — 시트는 매번 "꺼짐"에서 시작한다(`player.md` 4.7 제안 값 집합, BE Lowest).

**PL6 스크립트 — 시트가 아니라 인라인 패널이다**

- 스크립트를 열면 별도 시트가 덮는 게 아니라 **히어로가 압축된다**: 아트워크 56dp 썸네일 + 제목(lg)이 한 줄로 붙고, 그 아래 공간을 스크립트가 채운다. 시크바·컨트롤은 **위치 그대로**다 — 압축 전환 중에도 컨트롤이 움직이지 않는다(320ms, ease-out).
- 진입은 컨트롤 줄 오른쪽 끝의 **스크립트 토글**(4.2). 히어로에서 **왼쪽 스와이프 → 열림, 오른쪽 스와이프 → 닫힘.** 패널 안 오른쪽 스와이프도 닫힘이다.
- 현재 재생 구간을 하이라이트하고 자동 스크롤한다. **현재 문단은 상자로 감싸지 않는다**(애플 뮤직·팟캐스트 가사 방식 — 불투명 카드가 흐린 바탕 위에서 덩어리져 보였다). 현재 문단은 흰색 + 굵게, 나머지는 보조 글자색에 불투명도 0.7 — **밝기 + 굵기**로 구분하며 색만으로 구분하지 않는다(7장). 패널의 위·아래 경계는 문단 자체의 불투명도로 처리한다(배경색 띠는 바탕이 그림이라 막대처럼 보였다).
- 세그먼트는 턴 단위이고 `speaker`(윤아·이음)를 문단 머리에 그린다(`player.md` 4.6). **문단 탭 → 해당 위치로 seek.**
- **텍스트 선택·복사를 차단한다**(FR-33 재배포 방지 — `player.md` 4.6).
- 데이터는 발급 응답의 `has_script`가 `true`일 때 패널을 처음 열 때 조회한다(`player-api.md` 4.7). 없으면 토글 자체가 없다(4.1).
- 재생 목록 패널(4.6-1)과 **동시에 열리지 않는다** — 하나를 열면 다른 하나가 닫힌다.

### 4.6-1 PL12 재생 목록 패널 (신설 2026-09-17 — `changes/archive/player-queue-panel.md`)

목록의 정체·게이트·자동 재생 금지는 `player.md` 4.2-1이 소유한다. 이 절은 자리·전환·줄의 생김새·카피만 정한다.

**자리·전환 — 유튜브 뮤직 방식**(PM 확정 2026-09-17). 스크립트와 **다른 전환**이다.

- **아래에서 올라오는 시트**다. 닫힘엔 화면 바닥에 손잡이("재생 목록")만 보인다.
- 손잡이를 끌어올리면 **손가락이 곧 진행값**이다 — 시트가 올라온 만큼 위의 플레이어가 **세로 구조(아트워크 → 제목·카테고리 → 시크바 → 컨트롤) 그대로** 공백을 접으며 압축된다. 앨범 사진이 **화면 가로를 꽉 채우는 배경**(앱바 위부터 시크바 시간 라벨까지, 어두운 오버레이 0.45)이 되고 앱바 아이콘·제목·카테고리·시크바는 그 위에 흰색으로 얹힌다. 제목은 사진 아래쪽 가장자리, 시크바는 사진의 맨 아래 띠 — 이때 시크바 트랙만 흰 35%다(사진과 검정 바탕 모두에서 "어두운 위의 옅은 선"). 컨트롤 줄은 사진 밖에 그대로 남는다.
- 목록은 **컨트롤 아래**, 손잡이 밑에 선다. 시트 배경을 칠하지 않는다 — 흐린 바탕이 목록 뒤까지 이어진다.
- 놓으면 이동 비율 35% 또는 속도 0.5dp/ms로 열림/닫힘 확정(제안값, 9장). 탭은 토글. 목록 위 오른쪽 스와이프는 닫힘.

**줄**

- 줄 탭 = 재생(단일 게이트 — `player.md` 4.2-1). 지금 재생 중인 줄은 **제목 굵기 + 낭독 꼬리표 "재생 중"** — 색만으로 구분하지 않는다. 완청한 줄은 낭독에 "완청함". 줄에 카드 배경은 없다.
- **순서 변경**(추가 2026-09-18, 서버 저장 2026-09-19 KAN-70·74): 줄 오른쪽 손잡이(가로줄 두 개, 히트 44pt)를 잡고 끌어 순서를 바꾼다. 끄는 줄은 손가락을 따라가고 지나친 줄은 한 칸씩 비켜 준다. 끄는 동안 목록 스크롤·플레이어 끌어내리기·시트 끌기는 반응하지 않는다. 누르는 동안만 줄 전체가 옅은 흰색(8%)으로 밝아지고, 끄는 줄은 살짝 커져(1.03) 그림자와 불투명 면으로 떠 보인다(애플 뮤직 재생 대기 목록). 뷰포트 위·아래 끝 56px 안에 들어오면 목록이 그쪽으로 자동 스크롤된다. 순서는 `sort=queue` 조회 / `PUT /users/me/library-items/queue-order` 저장(`library-api.md` 4.1·4.8)이며 클라이언트는 응답 순서를 그대로 그린다. 새로 담긴 항목은 맨 위.
- 낭독기: 손잡이는 adjustable, 라벨 `"<제목> 순서 변경, N개 중 M번째"`, 액션 "위로 이동"·"아래로 이동"이 끌기의 대체 수단이다.
- 상태: 로딩(인디케이터) / 빈 목록 / 조회 실패(+[다시 시도]) 세 가지를 **패널 안에서** 그린다. 전면 오류로 바꾸지 않는다 — 플레이어는 계속 동작한다.

### 4.7 PL7 더보기 시트

**구성** — 대상 요약(**썸네일 · 제목 · 길이**, 출처·저자 제외 — 개정 2026-09-15) / 구분선 / **[상세 정보]**(추가 2026-08-23) / **[원문 보기]** / **[라이브러리에서 삭제]**(위험색) / [닫기]

- **라이브러리 L4·탐색 E12와 같은 시트 문법이다** — 대상 요약 상단 + 좌측 정렬 액션 행 + [닫기]. 같은 "더보기" 조작인데 화면마다 시트가 다르면 같은 문법이 깨진다. **라이브러리에서 빼는 조작은 세 화면 모두 위험색이다.**
- **대상 요약을 생략하지 않는다.** 시트가 올라오면 뒤 화면이 딤 처리된다 — 삭제 대상을 눈으로 확인하지 못한 채 파괴적 액션을 누르게 하지 않는다.
- **[상세 정보]가 추가됐다**(합의 2026-08-23 — 상세 화면 도입 FR-40, 세 화면 더보기 통일). 탭하면 시트가 닫히고 콘텐츠 상세 화면(CD 계열)으로 이동한다 — **재생은 유지**되고 뒤로가기로 플레이어에 복귀한다. 규칙·화면은 `content-detail.md`·`content-detail-uiux.md`가 소유한다.
- **[원문 보기]는 `source_url`이 있을 때만 노출한다**(확정 2026-08-10 — 세 화면 더보기 통일). 화면 상시 노출(4.1)과의 중복은 파트너 유입 접점 확대로 감수한다. 동작은 4.1과 동일 — 인앱 브라우저 + 클릭 기록.
- **[라이브러리에서 삭제] 후 플레이어 화면과 재생을 모두 유지한다**(확정 2026-08-10). 삭제는 `library_items`만 소프트 삭제하고 재생 이력은 남으므로 재생과 충돌하지 않는다(`library.md` 4.5).
  - 삭제 결과는 스낵바 **"삭제했어요" + [실행 취소]** 5초로만 알린다 — 플레이어 화면 위에 띄운다. 스낵바 규칙(교체·타이머 초기화·낙관 반영 후 지연 전송)은 라이브러리 소유 규칙을 그대로 따른다.
  - 삭제했다고 플레이어를 닫거나 재생을 멈추면 목록 정리가 재생 취소로 읽힌다.
- **공유는 P1 미노출이다**(FR-27 MVP 제외 — 합의 2026-08-06). P1 활성화 시 형태는 `share.md` 정의(소유 이전 2026-08-25 — OS 공유 시트, 텍스트 = 제목 + 저자·출처, 링크 = 콘텐츠 상세 연결)를 따르고, 공유해도 **재생은 유지**된다. 별도 정의 과제가 없다.
- 시트는 딤 영역 탭·뒤로가기로 닫힌다. 액션 행 탭 외에는 아무것도 바뀌지 않는다.

### 4.8 플레이어 축소 · PL11 미니플레이어

> **개정 2026-09-17·18·23** — 축소·확대를 미니플레이어와 **이어지는 모션**으로(`changes/archive/player-controls-redesign.md`), 미니플레이어를 캡슐 탭 바 독으로 옮기고 종료를 **아래로 끌기**로(`changes/archive/mini-player-drop-dismiss.md`). **2026-09-25 — 닫기 자체를 없앴다**(`changes/archive/mini-player-not-dismissable.md`, 아래 PL11).

**축소 — 3가지 조작, 1가지 동작**

셰브론 탭 · 뒤로가기 · **화면을 아래로 스와이프** — 셋 다 같은 동작이다: **재생 유지 + 미니플레이어로 전환.** 재생을 멈추는 조작은 일시정지뿐이다(3장).

- **축소와 확대는 같은 경로의 역재생이다.** 시트가 미니플레이어 카드 사각형 ↔ 전체 화면으로 늘고 줄며, 아트워크는 미니플레이어 썸네일(44dp) ↔ 히어로 아트워크로 크기·위치가 함께 움직인다. 열림 420ms, 닫힘 340ms. 시트 색은 밝은 미니플레이어 색에서 출발해 진행도 12%까지 유지 → 40%에서 검정에 닿는다(끝까지 고르게 섞으면 중간이 탁한 회색 판으로 보였다). 흐린 커버 배경도 같은 구간(12~40%)에 나타난다.
- **아래 스와이프는 화면을 밀어 내리는 것이 아니라 이 모션의 진행값을 손가락이 잡는 것이다.** 끌어내린 만큼 아트워크가 줄고 시트가 오므라든다. 놓을 때 임계(화면 높이 20% 또는 500dp/s — 제안값, 9장)를 넘으면 그 자리에서 이어서 내려앉고, 미달이면 스프링으로 되돌아온다(1을 넘지 않음). 종전 "화면이 손가락을 따라 내려온다" 방식은 놓는 순간 원위치에서 축소가 다시 시작돼 위로 튀었다.
- **전환 중 제목 글자는 제자리 페이드다**(2026-09-18). 이동·크기 변화를 하지 않는다 — 미니 제목은 미니플레이어 실측 자리에 고정된 채 진행도 0~12%에서 사라지고, 풀 화면 제목은 최종 자리에 고정된 채 컨트롤·시크바와 같은 구간(45~80%)에 들어온다. 움직이는 것은 아트워크와 시트뿐이다. 글자가 커지는 아트워크와 경로가 겹치고 손으로 끌 때 따로 놀았다.
- **교차 페이드를 쓰지 않는다**("애플처럼"). 모션 레이어는 착지까지 불투명하고, 착지 좌표는 미니플레이어 썸네일의 **실측값**(measureInWindow)이다. 컨트롤·시크바·앱바는 시트와 함께 내려가며 중간(45~80%)에 사라진다 — 카드가 통째로 접히는 느낌. 미니플레이어 ▶는 시트가 자라는 첫 12%에서 사라지고 닫힐 때 같은 구간에서 나타난다. 모션 레이어의 미니 제목·▶는 밝은 테마 색 그대로.
- 패널(스크립트·재생 목록)이 열린 채 축소하면 압축된 히어로 좌표에서 모션이 출발한다.
- 구현 메모(기록만): 플레이어 라우트는 투명 모달(`transparentModal`)이고 미니플레이어가 자기 화면 좌표를 스토어에 올려 도착·출발 지점으로 쓴다.

**PL11 미니플레이어**

**구성** — 썸네일 · 제목 · 진행 바 · 재생/일시정지 버튼. **캡슐 탭 바(`CapsuleTabBar`)의 독 안**에 하나만 둔다(2026-09-23 — iOS 26 유리는 같은 `GlassContainer` 안에 있어야 가까워질 때 모핑 병합된다). 그래서 **라이브러리·탐색·프로필 세 탭 모두에서 보인다.** 탭 밖 화면(탐색 검색)은 화면 안 절대 배치(병합 없음). 밝은 테마 그대로다(2장).

- **노출·대상 판정 규칙(비완청 중 `last_played_at` 최신 1건 · 위치 0이면 미노출 · 대상 없으면 미노출)은 라이브러리 소유다**(`library.md` 4.2 · `library-uiux.md` 4.4). 이 문서는 컴포넌트의 상태와 조작만 정한다.
- **앱 재실행 복원은 일시정지 상태로만 뜬다.** 소리는 나지 않고(FR-24 자동 재생 금지), 버튼 아이콘은 **▶(재생)** 이다 — 일시정지 아이콘을 그려두면 지금 소리가 나는 중으로 읽힌다.
- **본문 탭 = 전체 플레이어로 확대.** 재생 상태는 그대로다(일시정지였으면 일시정지인 채 열림 — 확대가 재생을 시작시키지 않는다).
- **위로 끌어올리기 = 확대**(2026-09-18). 잡고 위로 끌면 전체 플레이어가 손가락을 따라 펼쳐진다 — 끌어내려 축소하는 것의 반대 방향, 같은 "드래그 = 진행값" 규칙. 시작: 위로 10dp 이상 + 수직 이동이 수평의 1.5배 이상. 시작하는 순간 탭과 같은 경로로 플레이어를 띄우되 **재생을 시작시키지 않는다**(복원 스냅샷 상태에서도). 진행도 = 끌어올린 거리 ÷ (화면 높이 × 0.7). 놓을 때 진행도 25% 초과 또는 위로 0.5dp/ms 이상 튕김 → 끝까지 연다, 아니면 되감고 화면을 걷는다. 멈췄다 놓으면 튕김으로 치지 않는다. 터치를 빼앗기면(시스템 제스처) 끝까지 연다.
- **▶ 탭 = 재생 시작.** 카드 탭과 완전히 같은 판정·팝업 경로를 거친다(`library.md` 4.2). 미니플레이어가 한도를 우회하는 뒷문이 되지 않는다.
- **닫을 수 없다**(개정 2026-09-25 — `changes/archive/mini-player-not-dismissable.md`). 종전 **아래로 끌기 = 종료**(2026-09-23)와 그 임계·흡수 모션 규칙은 폐기했다 — iOS 26 시스템 탭 바의 액세서리(미니플레이어 자리)는 닫힐 때 유리 껍데기가 탭 바로 합쳐지는 모션을 시스템이 제공하지 않아 내용만 사라지거나 껍데기가 남아 어색했다(#723·#724·#725 시도). 애플 뮤직도 미니플레이어를 치울 수 없다 — 재생을 끝내거나 다른 곡으로 바꿀 뿐이다.
  - **종료 수단 = 재생 종료(완청)·다른 콘텐츠 재생.** 복원 스냅샷(일시정지 ▶)도 치울 수 없다 — 재생하거나 두면 된다.
  - 위로 끌어 열기는 그대로다. 낭독기의 '재생 종료' 커스텀 액션도 제거했다(7장).
  - 구현 메모: `MINI_PLAYER_DISMISSABLE = false` 한 상수로 묶었다. 캡슐 독(iOS 26 미만·Android)의 흡수 모션 코드는 남아 있으나 꺼져 있다.
- **가로 스와이프에는 아무 기능이 없다.** 곡 넘기기 등을 할당하지 않는다 — 연속 재생이 비범위다.

### 4.9 PL8 로드 실패 · PL10 네트워크 끊김

**PL8 — 로드 실패** (메타·서명 URL 요청 실패 또는 오디오 준비 실패)

- 화면을 유지한 채 인라인으로 **"재생할 수 없어요"** / 보조 **"잠시 후 다시 시도해주세요"** + [다시 시도].
- **이 시점에는 재생이 시작되지 않았으므로 카운트도 차감되지 않았다**(`paywall.md` 4.3). 잔여 표시를 줄이는 등 차감된 것처럼 그리지 않는다.
- [다시 시도] 연타는 인플라이트 요청이 있으면 무시한다(`common-error-handling.md` 7장).

**PL10 — 재생 중 네트워크 끊김**

- **끊김을 감지해도 버퍼가 소진될 때까지 재생을 유지한다.** 소진 시점에 일시정지 + 하단 배너 **"네트워크를 확인해주세요"**.
  - 감지 즉시 멈추면 버퍼에 남은 몇십 초를 버리는 셈이다. 지하철 통근 맥락에서 짧은 끊김은 정상 상황이다.
- **온라인 복귀 시 배너는 자동으로 사라지지만 재생은 자동 재개하지 않는다.** 사용자가 ▶를 눌러야 이어서 재생된다 — 오디오 포커스 상실과 같은 수렴 규칙이다(4.2).
- 위치 저장 미전송분은 큐에 적재돼 복귀 시 동기화된다(최대 5초 손실 허용). **사용자에게 알리지 않는다.**
- **재생 중 서명 URL 만료**: 끊기기 전에 백그라운드에서 갱신한다 — 성공하면 화면 변화가 없다. 갱신 실패 시 일시정지 + PL10과 같은 배너 자리에 **"재생할 수 없어요"** + [다시 시도]를 띄운다(문구 재사용 제안 — 9장 미결).

### 4.10 PL9 회수된 콘텐츠

파트너가 회수한 콘텐츠(FR-32)는 재생 URL 요청이 403(`CONTENT_WITHDRAWN`)으로 거부된다.

- 안내는 **"제공이 종료된 콘텐츠예요"** + [닫기]. [닫기]로 원래 화면에 복귀한다.
- **오류 톤으로 쓰지 않는다.** 실패 문구·[다시 시도]를 붙이지 않는다 — 재시도로 해결되는 상태가 아니고, 사용자가 잘못한 것도 아니다.
- **카운트는 차감되지 않는다.** 재생이 시작되지 않았기 때문이다.
- 라이브러리 목록에서의 제거·미니플레이어 내림은 라이브러리 소유 규칙(L13)이 처리한다. 플레이어는 안내와 복귀만 담당한다.

## 5. 공통 컴포넌트 규칙

| 컴포넌트 | 용도 | 규칙 |
|---|---|---|
| **바텀시트** | 배속(PL4) · 타이머(PL5) · 더보기(PL7) | 딤 탭·뒤로가기로 닫힘. 배속·타이머는 **탭 즉시 적용 + 닫힘**(적용 버튼 없음). 어두운 불투명 면(2장) |
| **인라인 패널** | 스크립트(PL6) | 히어로 압축, 컨트롤 위치 유지. 좌우 스와이프로 열고 닫는다(4.6) |
| **끌어올리는 시트** | 재생 목록(PL12) | 손가락 = 진행값. 위의 플레이어가 세로 구조 그대로 압축(4.6-1). 스크립트와 동시에 열리지 않는다 |
| **스낵바** | 더보기 삭제(PL7) | "삭제했어요" + [실행 취소] 5초. 규칙은 라이브러리 소유 |

| **미니플레이어** | 축소·복원(PL11) | 캡슐 탭 바 독 안의 요소(모든 탭). 노출 판정은 라이브러리 소유. 밝은 테마 |

- **로딩·에러가 컨트롤 레이아웃을 밀지 않는다.** 인디케이터는 재생 버튼 자리를, 배너는 컨트롤 줄 아래 자리를 쓴다 — 화면을 보지 않고 조작하는 사용자의 손끝 지도를 지킨다.
- **사용자가 시작하지 않은 실패는 알리지 않는다**(`common-error-handling.md` 4.3). 위치 저장·신호 전송·배속 저장 실패가 해당한다.

## 6. 카피 원칙

- **해요체**로 통일한다. 내부 용어("서명 URL", "버퍼", "신호", "차감", "재청취 창")를 화면에 노출하지 않는다.
- **사용자 노출 문자열 전수** — features와 1:1 대조용.

| 화면 | 문자열 | 근거 |

## 7. 접근성

통근 맥락(눈·손 비가용)이 전제이므로 **이 장은 부가 요건이 아니라 화면의 핵심 요건이다.**

**화면을 보지 않는 조작**

- **컨트롤 위치는 모든 상태(PL1·PL2·PL3·PL10)에서 동일하다.** 재생 버튼은 중앙 최대 크기(시안 64pt), ±10초는 그 좌우 고정. 손끝 위치 기억만으로 조작할 수 있어야 한다.
- **잠금화면·알림 센터 컨트롤**(재생/일시정지·±10초)을 항상 제공한다. 백그라운드 재생이 기본이다.
- 이어폰 조작은 재생/정지만 지원한다(더블탭 다음 트랙 없음 — 연속 재생이 비범위다. 재생 목록 패널은 열람·선택 전용).

**터치 타깃·스크린리더**

- **터치 타깃 최소 44×44pt** — ±10초 버튼, 배속 텍스트, 스크립트 토글, 재생 목록 핸들·줄 손잡이, 앱바 달 아이콘, 셰브론, 더보기, 미니플레이어의 재생 버튼(시각 30pt → 히트 44pt)과 본문 탭 영역.
- 재생 버튼 라벨은 상태별로: **"재생" / "일시정지" / (완료 상태) "처음부터 다시 재생"**. 완료의 ▶가 "재생"으로만 읽히면 이어듣기로 오해된다.
- ±10초 버튼은 **"10초 뒤로" / "10초 앞으로"**.
- **시크바는 slider 역할** + `aria-valuetext` **"24분 30초 중 9분 12초"**. `09:12`가 "영 구 콜론 일 이"로 읽히면 안 된다. 스크린리더의 증감 조작(위/아래 스와이프)은 ±10초 단위로 동작시킨다 — 화면 버튼과 같은 값이다.
- 배속 텍스트는 **"재생 속도, 1.2배"** 로 읽힌다. "×" 기호를 그대로 읽히게 두지 않는다. PL4 행도 "1.2배, 선택됨" 형태다.
- 앱바 달 버튼은 **"수면 타이머, 9분 41초 남음"**, 종료 시는 **"수면 타이머, 이 에피소드 종료 시"**. 시각 문자열("09:41")을 그대로 읽히지 않는다.
- 스크립트 토글은 "스크립트" + 열림/닫힘 상태. 재생 목록 줄은 `{제목}, {N}분(, 재생 중)(, 완청함)`, 손잡이는 adjustable **"<제목> 순서 변경, N개 중 M번째"** + 액션 "위로 이동"·"아래로 이동"(4.6-1).
- 버퍼링 인디케이터는 **"재생 준비 중"** 으로 알린다(2초를 넘겨 나타난 시점에 한 번).
- PL10 배너는 `aria-live="polite"` — 재생이 멈춘 사실은 소리의 부재로 이미 전달됐다. PL9 회수 안내는 사용자 조작의 직접 결과이므로 `assertive`.

**제스처 대체 수단**

- **미니플레이어는 닫을 수 없으므로(4.8, 2026-09-25) 낭독기 '재생 종료' 커스텀 액션도 없다.** 종전(2026-09-23)에는 아래로 끌기 종료의 대체로 이 액션을 제공했다. 확대는 본문 탭이 대체한다.
- 아래로 스와이프 축소의 대체 수단은 셰브론과 뒤로가기가, 끌어올려 열기의 대체 수단은 본문 탭이 이미 맡는다 — 별도 액션이 필요 없다. 스크립트 패널 좌우 스와이프의 대체 수단은 토글 버튼, 재생 목록 시트 끌기의 대체 수단은 핸들 탭이다.
- 스크립트 문단은 각각 포커스 가능하며 탭(더블탭)으로 seek된다. 자동 스크롤은 스크린리더 포커스를 빼앗지 않는다.

**동적 텍스트·색**

- **동적 텍스트 최대 200%에서 잘리지 않아야 한다.** 제목은 한 줄 가로 스크롤(모션 축소 시 말줄임), 시간 라벨은 고정폭 숫자 유지 — 컨트롤 줄(배속·±10·재생·토글)은 크기를 줄이지 않는다.
- **색만으로 상태를 구분하지 않는다.** 스크립트 현재 문단은 밝기 + 굵기, 재생 목록의 재생 중 줄은 굵기 + 낭독 꼬리표, 타이머 켜짐은 달의 채움(형태), [라이브러리에서 삭제]의 위험색은 텍스트 라벨을 동반한다.
- **대비 기준은 흰 글자/어두운 바탕이다**(2026-09-18 — 어두운 팔레트). 본문 `#FFFFFF`·보조 `#A0A0A8`는 `#17171A` 위에서 4.5:1 이상. 흐린 커버 배경 위에서도 바탕색 72% 막이 같은 대비를 보장한다. 위험색·강조색은 어두운 바탕 대비 4.5:1 이상.
- 시트·전체 안내는 포커스를 가두고, 닫으면 열기 전 요소로 포커스를 되돌린다.

## 8. 금지 사항

`player.md`·`paywall.md`·`library.md`가 명시적으로 금지했거나 확정 결정에 반하는 것들이다. **UI 구현 시 되살아나기 쉬우므로 여기 모아 둔다.**

**재생·완료**

- 진입 시 **전체 화면 로딩·"생성 중" 상태** — 메타는 즉시, 로딩은 재생 버튼 자리에 2초 초과 시만
- 버퍼링 2초 이내에 인디케이터를 띄우는 것
- 완료 시 **화면 자동 이탈·자동 다음 콘텐츠 재생**(연속 재생은 비범위)
- 완료 화면의 **레이아웃 교체**(완료 전용 카드·버튼 세트) — 시크바 100% + ▶ 유지
- 90% 완청 시점의 **축하 토스트·애니메이션**
- **클라이언트가 재청취 창(15일)·완청(90%)·한도를 로컬 계산해 게이트**하는 것 — 판정은 서버다
- 시크바 **드래그 중 실시간 seek**
- 시크바에 "완청 기준선(90%)" 등 **판정 지점 표식**을 그리는 것
- 오디오 포커스 상실·네트워크 복귀 후 **자동 재개**
- **기기 시각을 판정·표시 근거로** 쓰는 것

**컨트롤·시트**

- 앞뒤 구간 이동 값을 **다르게** 두거나 잠금화면과 화면의 값을 **다르게** 두는 것 (±10초 통일)
- 배속 시트에 **[확인]·[적용] 버튼** — 탭 즉시 적용 + 닫힘
- 배속 **슬라이더·커스텀 값 입력** — 허용값 5개뿐
- 배속 저장 실패 시 **재생 배속 원복·에러 UI**
- 스크립트 데이터가 없는데 **스크립트 토글을 비활성으로 노출**하는 것 — 아예 그리지 않는다
- `source_url`이 없는데 더보기 시트에 **[원문 보기]를 비활성으로 노출**하는 것 — 아예 그리지 않는다
- 플레이어 본문에 **[원문 보기]를 다시 두는 것** — 더보기 시트 하나뿐이다(개정 2026-09-17, FR-12 고지는 오디오 멘트·콘텐츠 상세가 맡는다)
- 재생 목록 패널에 **검색·필터·페이지네이션**을 붙이거나, 완청 후 **다음 줄을 자동 재생**하는 것
- 스크립트의 **텍스트 선택·복사 허용**(FR-33)
- 더보기 시트에 **공유**를 노출하는 것(P1 활성화 전)
- 수동 완료 표시 액션을 더보기에 추가하는 것

**축소·미니플레이어·삭제**

- 플레이어를 접는 조작(셰브론·뒤로가기·스와이프)이 **재생을 정지**시키는 것
- [라이브러리에서 삭제] 후 **플레이어를 닫거나 재생을 중단**하는 것 (확정 2026-08-10 — 화면·재생 유지)
- 미니플레이어 확대(본문 탭)가 **재생을 시작**시키는 것
- 미니플레이어 ▶가 **판정·팝업을 건너뛰는 것** — 카드 탭과 같은 경로다
- 미니플레이어 **가로 스와이프·아래로 끌기에 종료나 다른 기능**을 할당하는 것 — 미니플레이어는 닫을 수 없다(2026-09-25, 4.8)
- 끌어 종료에 **확인 팝업·실행 취소 스낵바**를 붙이는 것
- 미니 ↔ 전체 전환에 **교차 페이드**를 쓰거나 제목 글자를 **이동·확대**시키는 것(4.8)
- 복원 미니플레이어에 **일시정지 아이콘**을 그리는 것 — ▶여야 한다

**오류**

- 회수 안내(PL9)에 **[다시 시도]·오류 톤**
- 로드 실패·회수 시점에 **차감된 것처럼 표시**하는 것 — 재생이 시작되지 않았다
- 위치 저장·신호 전송 실패를 **사용자에게 알리는 것**
- 네트워크 끊김 감지 **즉시 재생을 멈추는 것** — 버퍼 소진까지 유지
